# apps/runtime-cell/cmd/kody-exec

The command runner that runs inside a machine: one JSON request on stdin (`command`, `cwd`, `timeoutMs`, unknown fields refused, 64 KiB at most), one JSON result on stdout (`exitCode`, `stdout`, `stderr`, `truncated`, `durationMs`). A thin `main` over `internal/kodyexec`.

## Rules and limits
- On Linux it becomes a subreaper first (`kodyexec.BecomeSubreaper`), so the timeout also kills daemons the command forked.
- A request it cannot run exits 2; the command's own outcome (exit 124 on timeout, capped output) is in the result. Its `main` calls `os.Exit` directly, not `lifecycle.ExitCode`.
- It runs inside the machine: it imports nothing of the control side ([`apps/runtime-cell/AGENTS.md`](../../AGENTS.md)).

## Tests
- None here; `go test ./internal/kodyexec`.
