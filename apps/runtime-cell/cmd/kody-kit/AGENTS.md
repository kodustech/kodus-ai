# apps/runtime-cell/cmd/kody-kit

Build tooling for the microVM kit (`apps/runtime-cell/microvm-kit`), run on a build host, never by the cell: `rootfs` turns an OCI layout or a tar into an ext4 root with `kody-guest` as init, `manifest` writes the kit's manifest and prints the digest the cell pins (`-firecracker-kit-digest`), `verify` checks a kit against a digest.

## Owns
- The subcommands and their flags: `main.go` `buildRootfs`, `manifest`, `verify`. Free space defaults to 64 MB for a sandbox profile and 1024 MB for an environment; `SOURCE_DATE_EPOCH` fixes file times.

## Does not own
- The ext4 build: `internal/rootfs`. The profiles: `internal/guestinit` (`ProfileByName`). The manifest and its verification: `internal/kit` (`Make`, `Load`).

## Rules and limits
- `rootfs` needs `mkfs.ext4` from e2fsprogs 1.47.1 or later and libarchive.
- The cell verifies the kit with `kit.Load` too; this command adds no rule of its own.

## Tests
- None here; `go test ./internal/kit ./internal/rootfs`.
