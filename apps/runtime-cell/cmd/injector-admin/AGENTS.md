# apps/runtime-cell/cmd/injector-admin

The owner's command line for the running injector's vault: it reads one request on stdin and talks to the injector's owner-local Unix socket (`-vault-admin-socket`). A thin `main` over `internal/injector/admincli.Run` with `internal/injector/management.Call`; it runs on the cell host, as the owner, never in a machine.

## Rules and limits
- No secret is a flag or printed: values arrive on stdin. The commands, their input and their output are `internal/injector/admincli`; the socket protocol is `internal/injector/management`.
- `main` exits with `admincli.Run`'s code; nothing else here.

## Tests
- None here; `go test ./internal/injector/admincli ./internal/injector/management`.
