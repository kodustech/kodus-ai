# apps/runtime-cell/cmd/injector

The injector binary: the composition root of the cell's credential injector ([architecture.md](../../../../docs/runtime/architecture.md), "Egress, injector"). Only the egress proxy reaches it; it ends a machine's TLS with a leaf of the cell CA, adds the credential and goes on to the address the proxy validated. Its control port takes signed policies and serves `GET /v1/alerts`.

## Owns
- Wiring the injector: `main.go` `run` (cell CA key pair, `policy.Store`, the alert log, the vault, the org secret store, `injector.Injector`, the sweep, the control mux, `/metrics`).
- The vault flags: `vault.go` `vaultOptions` (`-vault-dir`, `-vault-key-file`, `-vault-cell-id`, `-vault-admin-socket`), opened through `injector.OpenConfiguredVault`; the owner socket serves `injector/management`.
- The org secret store flags: `secrets.go` `secretStoreOptions` (OpenBao over AppRole): all empty means no store, partly set refuses to start (`injector.ErrVaultConfig`).
- `-trusted-proxies`: `proxies.go` `trustedProxies` (IPv4 only; a name stops startup, since addresses are compared as text).

## Does not own
- Injection, masking, alerts and the vault itself: `internal/injector`. The owner-local socket protocol: `internal/injector/management`, its CLI `cmd/injector-admin`.
- Which hosts are credentialed: the agent's signed policy (`internal/policy`).

## Rules and limits
- The data plane never imports the control side ([`apps/runtime-cell/AGENTS.md`](../../AGENTS.md) "Package boundaries").
- No `-trusted-proxies`: every connection is refused (`injector.proxies.unconfigured` alarm). No vault: credentials refused. No secret store: placeholder hosts refused.
- The admin socket needs the full vault configuration; flags never authorize a claim, only the verified policy store does (`injector.PolicyClaimAuthorizer`).
- A configured vault makes a policy delete revoke the claim's durable grants (`control.Server.DurableDelete`).

## Tests
- `go test ./cmd/injector`: `-trusted-proxies` parsing, vault flag combinations (`TestInjectorVaultFlagsRefuseDefaultAndPartialConfiguration`), owner management requiring a vault.
