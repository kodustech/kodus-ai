# apps/runtime-cell/internal/metrics

The counters and gauges of the cell's processes, served in the Prometheus text format (0.0.4) on a local listener. A leaf package with no dependency: the cell (`cmd/cell/serve.go`, `GET /metrics`), the injector and the egress process's mirror each build one `Registry` and hand it to the parts that record.

## Owns
- `metrics.go` `Registry`: `Counter`, `Gauge`, `GaugeFunc` register a family (a second registration of a name returns the first); `WriteText` and `Handler` expose them.
- `metrics.go` `Vec`: `Inc`, `Add`, `Set`, `Value` by label values.

## Does not own
- Logs and traces: `internal/telemetry`.
- What each component counts: the component registers its own families (`agent`, `hubclient`, `reaper`, `injector`, `mirror`, `preview`…).

## Rules and limits
- Every method is safe on a nil `*Vec`: a part built without a registry records nothing.
- Names and labels follow [`../../AGENTS.md`](../../AGENTS.md) "Names, errors, logs" (`cell_<subject>_<unit>`, `_total`, label values from a fixed set, never a host or an id).
- Counters, gauges and gauge funcs only: no histograms.

## Where new code goes
- A new metric: registered by the component that records it, not here, and listed in `libs/runtime/telemetry/taxonomy.json` (copied to `internal/telemetry`; `telemetry` `TestEveryCellMetricIsInTheTaxonomy` fails otherwise). A new kind of family (a histogram) is the only reason to change this package.

## Tests
- `go test ./internal/metrics` (pure).
