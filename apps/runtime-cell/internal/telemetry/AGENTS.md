# apps/runtime-cell/internal/telemetry

The cell's side of the Runtime telemetry taxonomy ([`docs/runtime/observability.md`](../../../../docs/runtime/observability.md)): OpenTelemetry traces exported like the TS processes, the W3C trace context a hub frame carries, and the `slog` handler every cell process logs through. A leaf used by every `cmd/*` (`NewHandler`, `Setup`), the agent (spans per frame and claim) and the guest.

## Owns
- Traces: `telemetry.go` `Setup` (W3C propagator; OTLP over HTTP only when `OTEL_EXPORTER_OTLP_ENDPOINT` or `OTEL_EXPORTER_OTLP_TRACES_ENDPOINT` is set, nothing leaves the host otherwise), `Tracer`, `Remote` (a frame's `traceparent` as the parent), `Traceparent`, `LogIDs`, `ID`.
- The taxonomy: the embedded `taxonomy.json`, its attribute keys (`ClaimID`, `RunID`, `CellID`…), `CanonicalKey` (an older field name such as `claim` to its key), `TaxonomyJSON`.
- Redaction of telemetry: `redaction.go` `Handler` and `NewHandler` (taxonomy names, active `traceId` and `spanId`, every string scrubbed, sensitive keys dropped), `Scrub` (secret shapes from `protocol.TelemetrySecretShapes`, then `redact.Patterns`, 2 KiB), `RedactingExporter` (only taxonomy attributes, no status message).

## Does not own
- Metrics: `internal/metrics`. The log event names and when to log: each component, by [`../../AGENTS.md`](../../AGENTS.md) "Names, errors, logs".
- The token-pattern rules: `internal/redact`.

## Rules and limits
- No secret value, placeholder, canary or token reaches a log line or a span; this is the Go half of `libs/runtime/telemetry/telemetry-guard.ts`.
- `taxonomy.json` is a byte copy of `libs/runtime/telemetry/taxonomy.json` (`TestTaxonomyFileMatchesTS`). Every `cell_*` metric registered under `internal/` or `cmd/` must be listed in it (`TestEveryCellMetricIsInTheTaxonomy`).
- `traceparentShape` in `telemetry.go` compiles the generated `protocol.TraceparentShapePattern`.

## Where new code goes
- A new span attribute or log field with a fixed name: `libs/runtime/telemetry/taxonomy.json` first, copied here, then its constant in `telemetry.go`.
- A new secret shape: the TS guard (it generates `protocol.TelemetrySecretShapes`), never a regexp here.

## Tests
- `go test ./internal/telemetry` (in-memory exporter and handler; reads the libs taxonomy from the repository).
