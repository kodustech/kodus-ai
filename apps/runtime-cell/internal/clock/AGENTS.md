# apps/runtime-cell/internal/clock

The time source of the cell's control side, so retries, backoffs and expiries run in tests without sleeping. A leaf ([package rules](../../AGENTS.md), "Package boundaries"); the agent and its parts (`evidence`, `outbox`, `pool`), the drivers (`awsec2`, `dockergvisor` and its `buildcache`, `buildstate`), `injector`, `mirror` and `preview` take a `Clock`.

## Owns
- `clock.go` `Clock` (`Now`, `After`), `Real` (the wall clock), `Or` (the wall clock when nil).
- `Fake`: a manual clock. `After` never blocks: it advances by `d` and fires at once, so a backoff loop runs instantly and the time it waited shows in `Now`. `Set` and `Advance` move it.

## Rules and limits
- The rule that time-based logic takes a `clock.Clock` or a `now` func, and tests use `clock.Fake`: [package rules](../../AGENTS.md), "Tests". `lease` and `enrollment` take a `now func() time.Time` instead.
- `Fake.After` fires immediately; a test that needs a timer to stay pending cannot use it.

## Tests
- No tests of its own; it is exercised by every package that uses `Fake`.
