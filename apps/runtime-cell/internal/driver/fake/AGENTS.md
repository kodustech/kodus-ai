# apps/runtime-cell/internal/driver/fake

Test and dev code: an in-memory `MachineDriver` that isolates nothing (isolation `none`). Unit tests of the agent, the lease manager and the reaper use it, as do `test/conformance` and `test/integration`; `cmd/cell` wires it (`wire.go` `wireFake`) only behind `gateFake`, which refuses it without `-dev`.

## Owns
- `fake.go` `Driver` (`New`, `NewForCell`): the real drivers' invariants in memory (validated specs, an immutable `kodus:hard-expires`, per-claim groups, `driver.ErrNotOwned` for another cell when `CellID` is set), a pool (`PoolCreate`, `Adopt`), `Bake`, `Reset`, `Diagnose`, and test hooks (`Plant`, `PlantTags`, `SetFailCreate`, `SetTag`, `Machines`).
- `sandbox.go` `Sandboxes`: code sandboxes as host directories served by the real guest agent in process, over a pipe.

## Rules and limits
- Never selectable outside `-dev` ([`apps/runtime-cell/AGENTS.md`](../../../AGENTS.md) "Package boundaries"); `internal/archrules` keeps an isolation backend or a placement from importing it.

## Tests
- `go test ./internal/driver/fake`: it passes `drivertest.Run` and `drivertest.RunRequests` (`conformance_test.go`).
