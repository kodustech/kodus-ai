# apps/runtime-cell/internal/driver

The `MachineDriver` port: everything a cell knows about the cloud, cluster or host it runs machines on. The agent, the lease manager, the pool and the reaper call it; each package under `internal/drivers/*` implements it. It runs in the cell process and holds no state of its own beyond the metrics wrapper.

## Owns
- The core contract: `driver.go` `MachineDriver`, split into `Describer`, `ClaimNetworker`, `MachineCreator`, `MachineKeeper`; what a machine is (`MachineSpec`, `MachineRef`, `Role`) and what a driver states about itself (`Capabilities`, `Isolation`, `ProductionIsolation`).
- Every optional capability, in one struct: `parts.go` `Parts` (`Baker`, `Resetter`, `Composer`, `Recipes`, `Pooler`, `Sandboxes`, `Snapshots`, `Memory`, `Diagnoser`, `SQLObservers`, `Sweeper` and the rest) and what derives from it (`Bakes`, `SnapshotsMemory`, `SandboxMemoryMB`).
- What a boot must honor: `request.go` `UpRequest`, `SandboxRequest`; the sandbox capability `sandbox.go` `Sandboxer`; compose and recipe boots `ownership.go` `ComposeBooter`, `RecipeRunner`, `RecipeStepError`.
- The ceiling and lease tags: `driver.go` `MachineSpec.AllTags`, `Ceiling`, `Expired`, `ClampToCeiling`, `LeaseEnd`, `LeaseLapsed`, `Matches`; the claim id rule `ownership.go` `ValidateClaimID`.
- The errors every driver returns and the agent reads: `ErrNotOwned`, `ErrUnsupported`, `ErrWorkloadBoot` (`WorkloadBootFailed`), `ErrWorkloadRecipe`, `ErrOutOfMemory`, `ErrImageTooLarge`, `ErrSizeUnavailable`, `ErrDiskCapacity` in `driver.go`; `resource_errors.go` `ErrResourceEnforcement`, `ErrResourceCleanupPending`; `observer_sql.go` `ObserverSQLError`.
- Sizes and per-sandbox rates: `driver.go` `ClaimSize.Within`; `iolimits.go` `IOLimits.For` (per vCPU, with defaults and ceilings).
- A Run's decoys as a driver plants them: `canary.go` `Canary`, `CanaryEnvOf`, `CanaryFileOf`.
- Measuring every driver the same way: `observed.go` `Observed` (calls, time, `cell_driver_not_owned_total`) and `Outcome`.

## Does not own
- Any backend: `internal/drivers/*`. Which driver a cell runs and its flags: `cmd/cell/drivers.go`.
- What the agent does with a capability, and the order of a claim's stages: `internal/agent`.
- Lease renewal and the reaper's pass: `internal/lease`, `internal/reaper`.

## Rules and limits
- The package rules on parts, ceilings, ownership and requests are in [`apps/runtime-cell/AGENTS.md`](../../AGENTS.md) "Package boundaries" and "Untrusted input"; this package is where they are typed.
- `Observed` hands back every part it was given: a wrapper never hides a capability (`TestObservedHandsBackEveryPart`).
- A claim id is at most 48 letters, digits and `-`, so every backend can use it as a name.

## Where new code goes
- A new optional capability: a field of `Parts` with its interface here, its wrapping in `Observed` when it should be measured, and the drivers that offer it returning it from their `Parts()`.
- A new thing `Up` or `CreateSandbox` must honor: a field of `UpRequest` or `SandboxRequest`, and a check in `drivertest.RunRequests`.
- A new rule every driver keeps: the conformance suite in `driver/drivertest`, not here.

## Tests
- `go test ./internal/driver` (pure): the ceiling rule, sizes, `Observed`.
- Every driver's behavior against the contract: `internal/driver/drivertest`.
