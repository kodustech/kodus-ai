# apps/runtime-cell/internal/isolation/firecracker

The microVM backend of `internal/isolation`: one Firecracker microVM per machine, started by the jailer as a user of its own, chrooted, in its own PID namespace and cgroup, with the verified kit's kernel and root (`internal/kit`), the root a reflink clone of the kit's base, a tap on the claim's bridge (`placement/hostnet`) and the guest agent as the VM's init over vsock. Only `drivers/microvm` holds it, in the cell process and in the out-of-process reaper (`ForReaper`).

## Owns
- Opening the backend: `firecracker.go` `New` (host checks, the kit's bases on a clone-capable state directory, the VMMs' cgroup), `Missing`, `Unavailable`; `host.go` `ProbeHost` with the shared/dedicated host policy (`internal/hostcheck`).
- A machine's life: `firecracker.go` `Create`, `Start`, `Pause`, `Destroy`, `Discard`, `DialGuest`, `DialVsock`; one `Record` per machine in the state directory, `Machines`, `Inventory`.
- The jail and the VM's configuration: `jailer.go` `Jail.Args`, `VM.Config`, `VM.BootArgs`, `MemoryMaxMB`, `ResidentMB` (the VMM's overhead and cache room on top of the guest).
- Disk room: `room.go` `ErrNoDiskRoom` (a machine is admitted only if every machine could write its disks full), data disk sizing; `disk_linux.go` reflink with no fallback to a copy.
- Per-machine rates: `limits.go` (Firecracker's token buckets on each drive and the NIC, `io.max` on the VMM's cgroup) from `driver.IOLimits`.
- Snapshots: `snapshot.go` `Taint`, `Snapshot`, `Restore`, `SnapshotRound`, `RestoreInPlace`, `LatestTemplate`, `ForgetSession`, `ForgetClaim`, `SweepSnapshots`, kept in `isolation/vmsnap`.
- What outlives a machine: `vmlog.go` `MachineLogs` (states and the log tail past the jail, bounded in count and age); `orphans.go` `ReapOrphans` (ends the VMM processes, cgroups, jails, states files, taps and network namespaces no record names; a record is written before any of them exists).

## Does not own
- Bridges, taps and nftables: `internal/placement/hostnet`. The snapshot store's files and manifests: `internal/isolation/vmsnap`.
- What runs in the VM: `internal/guest`, `internal/guestinit`. The driver's rules (claims, taints before compose, data disks from a setup's peak): `internal/drivers/microvm`.

## Rules and limits
- A state directory that cannot reflink, or sits on a buffered loop device, is refused at start; the root is never copied in full.
- No two live machines share a VMM user, a jail or an address; a machine that cannot start leaves nothing.
- A machine tainted with secrets, credentials or canaries never becomes a snapshot; a snapshot never crosses orgs, a session restores once, a template restores only on its kit and host, a round only into its claim's own machine.
- A shared cell (`HostShared`) refuses a host whose SMT, KSM, swap or CPU mitigations are not those of a multi-tenant host; a dedicated one reports them.
- The package rules on backends: [`apps/runtime-cell/AGENTS.md`](../../../AGENTS.md) "Package boundaries".

## Where new code goes
- A new VMM call: `api.go` and the method that needs it; a new jailer or VM setting: `jailer.go`, with its case in `firecracker_test.go`.
- A host check: `internal/hostcheck` when another backend could share it, else `Checks` here.

## Tests
- `go test ./internal/isolation/firecracker` runs anywhere: a fake launcher, fake host checks and a temporary state directory.
- `disk_linux_test.go` needs `KODY_E2E_REFLINK_DIR` (XFS or btrfs) and `KODY_E2E_NOREFLINK_DIR`. Real VMs, on a KVM host as root: `test/fcregress`.
