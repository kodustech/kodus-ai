# apps/runtime-cell/internal/isolation/gvisor

The gVisor backend of `internal/isolation` on the docker placement: every machine is a container under runsc in the host's Docker, joined to its claim's network, and the cell reaches a sandbox's guest agent over a `docker exec -i` stream. Only `drivers/dockergvisor` holds it, in the cell process and in the reaper.

## Owns
- `gvisor.go` `Backend` (`New` refuses a Docker without the runtime, `ErrNoRuntime`): `Create` runs a holder (`dockercli.HolderSpec`) or, for a sandbox, a sandbox container running `GuestCommand` as `GuestUser` rooted at `/workspace`; `Pause`/`Start` stop and start the machine's compose project; `Destroy` takes the project down with its volumes unless a bake keeps them (`DestroyOptions.KeepData`).
- The shared I/O policy on its machines: `BoundIOOn`, Docker blkio and the host veth's rate (`dockercli.IOBound`, `driver.IOLimits`).
- The reaper's view: `Ender`, `NewEnder` end a machine without asking Docker for runsc, so a machine past its ceiling goes whatever runtimes the host lists now (`drivers/dockergvisor/reap.go`).

## Does not own
- Booting the compose project inside an environment machine: `drivers/dockergvisor/up.go`. The compose allowlist: `internal/compose/sandbox`.
- The docker binary: `internal/dockercli`. The claim network: `internal/placement/docker`.

## Rules and limits
- No memory snapshots: `Snapshot` and `Restore` fail with `driver.ErrUnsupported`, and `Taint` keeps nothing (`TestGVisorKeepsNoMemorySnapshotUntilP3`). A gVisor snapshot must record taints before it exists.
- An engine that cannot stream runs no sandboxes (`ErrNoSandboxes`, `Backend.Sandboxes`).
- The package rules on backends: [`apps/runtime-cell/AGENTS.md`](../../../AGENTS.md) "Package boundaries".

## Where new code goes
- A Docker call this backend needs: a method on its `Engine` (or `SandboxEngine`, `EndingEngine`) interface, implemented by `dockercli.CLI`.

## Tests
- `go test ./internal/isolation/gvisor` (a recording engine, no Docker). Real runsc: `test/gvisoregress`.
