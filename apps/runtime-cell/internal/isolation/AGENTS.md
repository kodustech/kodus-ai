# apps/runtime-cell/internal/isolation

The `IsolationBackend` port (`docs/runtime/isolation-architecture.md` C3): what makes one machine and keeps it apart from the host, under a placement (`internal/placement`) that says where machines live and how their network attaches. Two backends implement it, `isolation/gvisor` and `isolation/firecracker`; `drivers/dockergvisor` and `drivers/microvm` compose a backend with a placement. It also says what the host offers and which backend a cell runs. It runs in the cell process.

## Owns
- The port: `isolation.go` `Backend` (`Create`, `Discard`, `Start`, `Pause`, `Snapshot`, `Restore`, `Taint`, `Destroy`, `DialGuest`), `Capabilities`, `Spec`, `Machine`, `Shape`.
- What a snapshot is for and why a machine may never become one: `Purpose` (`template`, `session`, `round`), `Taint` (`secrets`, `credentials`, `canaries`, `pr_code`), `SnapshotRequest`, `SnapshotRef`.
- The host probe: `host.go` `ProbeHost` (`/dev/kvm` a character device the cell can open, the arch in the protocol's words, `ArchOf`).
- The backend choice: `choose.go` `Choose` resolves `-isolation-backend` (`auto` takes firecracker only with a usable KVM, a kit and a microVM driver that runs environments; gVisor otherwise). `cmd/cell/drivers.go` calls it.
- A backend's record of its machines past their end: `machinelog.go` `MachineLog`, `Transition`, `MachineLogReader`.
- `ErrUnavailable`, `UnavailableError`: a backend this host cannot run; the cell refuses to start rather than run claims under another isolation.

## Does not own
- Claims, leases, the reaper, egress, the build path, the registry, the sandbox pool: the drivers and the packages above them.
- A claim's network: `internal/placement`.

## Rules and limits
- A backend never imports the agent, the hub client, the lease or a driver ([`apps/runtime-cell/AGENTS.md`](../../AGENTS.md) "Package boundaries", enforced in `internal/archrules`).
- A snapshot ends its source machine, whatever its purpose. `Taint` is called before the thing it names is handed over; a backend that cannot record it fails, and the caller does not hand it over.
- Every method acts only on a machine the driver checked is this cell's.

## Where new code goes
- A new backend: a package under `isolation/`, never a branch inside a driver; its name in `Choose` when `auto` may pick it.
- A new fact a backend states: a field of `Capabilities`, set by each backend.

## Tests
- `go test ./internal/isolation` (pure): the choice, the host probe, the errors.
