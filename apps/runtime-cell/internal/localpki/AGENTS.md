# apps/runtime-cell/internal/localpki

A cell host's local PKI (`cell local-pki`), for a cell whose image has no shell: the same files the installer's host script writes with openssl. It runs once in the cell binary before the cell serves (`cmd/cell/localpki.go`), never in a serving cell.

## Owns
- `localpki.go` `Write`: makes what is missing under `Options.Dir` from the identity `cell register` wrote (`IdentityDir`): the cell-local CA and the egress, injector and observer leaves, the injector's own CA, and the ed25519 policy key. `Options.Rotate` re-issues the leaves; `Options.Copies` copies mounted files as 0600, owned by this process.
- `IssueLeaf` (`cell issue-cert`): a P-256 leaf with a subject Helm cannot write, such as the runtime-worker's `OU=worker`.

## Does not own
- The cell's identity and the hub's CA: `internal/enrollment`.
- Loading keys and pinning peers at run time: `internal/tlsutil`.

## Rules and limits
- Three roots, each for one thing ([self-hosted.md](../../../../docs/runtime/self-hosted.md)): the hub's CA pins the hub and signed the cell's identity; the cell-local CA signs the egress, injector and observer certificates and never a cell identity; the injector's CA signs only the leaves machines see for a secret's host.
- Files that exist are kept, so a restarted pod keeps the keys its enforcers already trust.
- The installer's script and this package write the same layout; a change to one is a change to both.

## Tests
- `go test ./internal/localpki` (temporary directories, `testpki`).
