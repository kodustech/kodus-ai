# apps/runtime-cell/internal/injector/management

Write-only vault administration for the injector's local OS owner, over a Unix socket the running injector serves: put or register a secret version, bind it to a claim, list metadata, revoke. Not a product RBAC API and not a claim-control transport. The server runs in the injector process (`cmd/injector`); the client in `cmd/injector-admin`. The operations, their JSON and what they do not do are in [README.md](README.md).

## Owns
- The server: `server.go` `Serve` (the six operations, strict bounded JSON with exact fields, at most `MaxBodyBytes` in and `MaxResponseBytes` out, a concurrency bound, audit of operation, outcome and duration only).
- The socket: `socket.go` (a 0700 parent, a 0600 socket, never over an existing one; cleanup keeps a replacement), `peer_linux.go` and `peer_darwin.go` (the kernel's peer uid must be the process's, both ways; `peer_unsupported.go` refuses).
- The client: `client.go` `Call` (checks ownership and socket identity before sending, sanitizes metadata it reads back).
- `port.go` `VaultAdmin`: what the server needs of the vault; `wire.go` the request and answer types and `Error` (a fixed code).

## Does not own
- The vault, its encryption and its revocations: `internal/injector` (`EncryptedVault`).
- Who may read a credential: the signed live policy (`internal/injector` `PolicyClaimAuthorizer`).
- Parsing the command line: `internal/injector/admincli`.

## Rules and limits
- No TCP listener, no secret-read endpoint, no value in any answer; errors are fixed codes without request input or backend details.
- Cancellation reaches the vault operation; a durable revocation stays authoritative.
- A grant made here is still refused until a signed live policy authorizes the claim (`TestOwnerProvisioningSignedPolicyInjectionAndRevocation`).

## Where new code goes
- A new operation: `VaultAdmin`, `server.go`, `wire.go`, the CLI's list in `admincli`, and the README.

## Tests
- `go test ./internal/injector/management` (real Unix sockets in temporary directories, `testpki` for the signed-policy test).
