# apps/runtime-cell/internal/injector/admincli

The owner's command line for the injector's vault (`cmd/injector-admin`): one JSON request read from stdin, sent over the owner-local management socket. It runs on the cell host, by the injector's OS owner, never inside the cell agent or a machine.

## Owns
- `cli.go` `Run`: the flags (`-socket`, `-operation` once each), the operations (`put`, `register-external`, `list`, `bind`, `revoke-version`, `revoke-claim`), a bounded read of stdin, and the output: canonical metadata for `list`, nothing for the others.
- `Call`: the transport it is given; `cmd/injector-admin` passes `internal/injector/management` `Call`.

## Does not own
- The socket, its peer checks and the request format: `internal/injector/management` ([README](../management/README.md)).
- The vault: `internal/injector`.

## Rules and limits
- No value is accepted in a flag, returned in an error or written to the output; a transport error or a response body is never printed.
- An empty or oversized request, a cancelled context, or a missing transport is refused before the vault is called; a stalled stdin is interrupted on cancellation.

## Tests
- `go test ./internal/injector/admincli` (a fake `Call`).
