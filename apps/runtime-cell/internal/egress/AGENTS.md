# apps/runtime-cell/internal/egress

The egress proxy: a claim's machines' only way out (ADR-040, ADR-056, [egress-allowlist.md](../../../../docs/runtime/egress-allowlist.md)). It never opens TLS: it reads the ClientHello's SNI or the plain HTTP Host, checks it against the claim's signed policy and the Kodus deny list, checks the destination against what the resolver handed the claim, and splices or hands the connection to the injector. Data plane: it runs in the egress process (`cmd/egress`), never in the cell agent.

## Owns
- A connection's decision: `proxy.go` `Proxy.Serve`, `serveConn`, `checkName` (allowlist, deny list, ECH), `chooseTarget` (the address the resolver handed the claim, or the proxy's own lookup; private addresses only inside `InternalCIDRs`, link-local never).
- Routing to the injector for credentialed hosts and for inspected hosts from a machine that trusts the cell CA (`InjectorAddr`, a PROXY v1 line and the replayed ClientHello); `Enforceable` refuses a policy that needs an injector the proxy does not have (`ErrNoInjector`).
- Live connections: `conns.go` (idle timeout, `MaxConnLifetime`, `MaxConnsPerSource`), cut by `Revalidate` when a new policy no longer allows them and by `CloseClaim`.
- Plain HTTP: one checked request per connection (`forwardOneRequest`); the inspected-tier rule checked here; a request carrying a secret placeholder refused (`placeholders.go`, `ReasonPlaceholderLeak`, `Alerts.PlaceholderLeak`).
- The upload budget, observe only (D8): `upload_budget.go`, logged once per claim as `egress.upload_budget.exceeded`, never cut.
- The control port: `control.go` `Control.Handler` (the signed policy protocol, `GET /v1/events`, `/v1/connections`, `/v1/alerts`, `/metrics`); `events.go`, `alerts.go`, `metrics.go`.
- `origdst_linux.go` `OriginalDst` (`SO_ORIGINAL_DST`); other platforms return an error.

## Does not own
- The policy's format and signature: `internal/policy`, `internal/policy/control`.
- The deny list, the allowed addresses and the resolver's answers: `internal/netguard`.
- Ending TLS, credentials and response masking: `internal/injector`.
- DNS: `internal/resolver`. The mirror: `internal/mirror`. Wiring the process: `cmd/egress`.

## Rules and limits
- The data plane never imports the control side ([package rules](../../AGENTS.md), "Package boundaries"); the agent reaches this only through the mTLS control port.
- Inside TLS a client may send another Host or coalesce HTTP/2 to another name the certificate covers; an allowlist entry on a shared CDN carries that risk. The injector checks Host for the hosts it receives.
- A ClientHello with ECH is refused unless it goes to the injector.
- An inspected host reached from a source that does not trust the cell CA stays SNI passthrough and is counted (`kodus_egress_inspect_bypassed_total`); the trust rules are in the [package rules](../../AGENTS.md), "Untrusted input".
- Every refusal is an `egress.blocked` event; every connection let through is logged on close (`egress.allowed`, bytes, duration).

## Where new code goes
- A new reason to refuse a connection: `checkName` or `chooseTarget`, a reason counted by `Metrics`, and a case in `proxy_test.go`.
- A new route on the control port: `control.go`, behind its mTLS and signature check.

## Tests
- `go test ./internal/egress` (in-process listeners, `testpki`); `test/conformance` drives the proxy and the injector together.
