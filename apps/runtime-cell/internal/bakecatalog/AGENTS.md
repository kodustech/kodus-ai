# apps/runtime-cell/internal/bakecatalog

The durable record of an environment's baked generations: which exist, which one each environment boots from, and which are retired and waiting for their artifacts to go. A pure package with its own lock, run in the cell process and held by `internal/drivers/dockergvisor`, the only driver that uses it today.

## Owns
- A generation's life: `catalog.go` `Catalog.Stage` (recorded, retired and held, before any artifact exists), `Publish` (eligible and current), `Acknowledge` (the driver installed its latest pointer), `Prune` (retire what nothing holds, then remove artifacts through the driver's func).
- Holds that keep a generation from being dropped while a copy, a tag or a live machine uses it: `Catalog.Hold`. Holds live in memory only.
- The file itself: `Open` takes an exclusive lock in `Config.Dir`, reads one JSON file. One written by another cell or driver, with loose permissions, past `maxBytes` or not canonical is never fatal: `Open` renames it `catalog.json.foreign-<unix>` (one kept), calls `Config.Quarantined` and starts empty. `Config.Adopt` (a fleet host told its org, [host-providers.md §8.2.1](../../../../docs/runtime/host-providers.md)) instead keeps another cell's catalog, retires the generations of every other org and leaves `Owner()` as the cell that made them. Writes go by rename and a directory sync.
- A generation's bake key: `Generation.Key` (`RefsDigest` for several repositories, `SHA` for one), `IsRefsDigest`.

## Does not own
- What a generation's artifacts are and how they are made or removed: the driver (`drivers/dockergvisor/bake.go` `newGeneration`, its `Config.Valid` and `Prune` funcs).
- Which claim output may be baked: the agent's pin before it acks `image.bake` ([package rules](../../AGENTS.md), "Untrusted input").

## Rules and limits
- A crash at any point leaves cleanup work, never an eligible partial generation: a generation is eligible only after `Publish`, which the caller calls once every artifact exists.
- Until `Acknowledge`, both the new generation and the one it replaced stay eligible, including after `ErrCommitUncertain` (the rename may not be durable; the change is kept in memory).
- At most `MaxGenerations` (1024) eligible plus retired generations; past it `Stage` returns `ErrLimit`.
- `Config.Valid` is checked on read and on write: a generation whose id or artifact names this driver would not make is refused.
- `Catalog.Each` runs under the catalog's lock: its callback must not call the catalog.

## Where new code goes
- A new field of a generation: `Generation`, with `omitempty` when old files must read unchanged, and a case in `catalog_test.go` that reads a file written without it.

## Tests
- `go test ./internal/bakecatalog` (temporary directories, no services): a generation's life from stage to prune, a failed removal, a second controller, an uncertain commit.
