# apps/runtime-cell/internal/observerclient

The cell's side of binding an observer to one claim: it sends the private configuration (targets, generation, SQL credentials) to the observer's `PUT /v1/config` and accepts the answer only when the observer echoes the configuration's fingerprint and generation. It runs in the cell process; `cmd/cell` calls it for the container observer and the microVM observer.

## Owns
- `configure.go` `Configure`: endpoint checks, the request, the verification of `observer.ConfigFingerprintHeader` and `ConfigGenerationHeader`, retries every 2 s for up to 3 minutes; it returns an `observer.HTTPClient`.

## Does not own
- The configuration's shape and fingerprint: `internal/observer` (`ClaimConfig`, `ConfigFingerprint`).
- The mTLS client it is given: `cmd/cell`.

## Rules and limits
- The endpoint must be `https` on an IP literal, with no user, query or fragment.
- A redirect is refused: private SQL credentials never go to another origin. Credentials never appear in an error.
- A 409 is accepted only with the matching fingerprint and generation, never as proof the observer is the claim's.
- The retry deadline reads `time.Now`, not a `clock.Clock` ([`../../AGENTS.md`](../../AGENTS.md) "Tests").

## Tests
- `go test ./internal/observerclient` (httptest observer).
