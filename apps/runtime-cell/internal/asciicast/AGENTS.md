# apps/runtime-cell/internal/asciicast

A bounded terminal recording in the asciicast v2 layout, with no library: one JSON header line, then one `[seconds, code, data]` array per event. It runs in the cell process; `internal/agent/evidence` uses it to record a step's exec output as the step's cast.

## Owns
- `asciicast.go` `New` (the header: size, start time, `TERM`), `Cast.Add` (one event at an offset since the start), `Bytes`, `Truncated`, `Events`.
- The event codes `Output`, `Input` and `Marker`.

## Does not own
- Redacting the text it records and choosing its bound and size: `internal/agent/evidence` (`evidenceCastBytes`, `castWidth`, `castHeight`).
- Uploading the cast: `internal/agent/evidence`.

## Rules and limits
- Past `Cast.Max` bytes an event is cut on a rune boundary to what fits, the cast is marked truncated, and every later event is dropped.
- It writes what it is given. A caller that records anything unredacted leaks it.

## Tests
- `go test ./internal/asciicast` (pure).
