# apps/runtime-cell/internal/machinetrust

What a claim's machines trust when they must accept the cell CA: a bundle of the public roots plus the cell CA, the cell CA alone, where both are mounted inside a machine and the variables that point tools at them. A pure rule package in the cell process, called by `cmd/cell` (which writes the files once at start), the drivers (which mount them), `compose/sandbox` and `guest`.

## Owns
- The paths inside a machine: `machinetrust.go` `Dir` (`/etc/kodus`), `BundleTarget`, `CellCATarget`, and `SystemStoreTarget` (a code sandbox's tool image only).
- The variables and their values: `EnvNames`, `Env`, `IsEnvName`.
- Building the files: `Build` (the bundle and the CA alone, both re-encoded from parsed certificates), `ReadRoots` over `SystemRootFiles`, `Write` (rename into place, 0644).
- A code sandbox's binds: `Files.SandboxMounts`.

## Does not own
- Which claims get the trust files: `internal/agent/org_secrets.go` `needsCellTrust` and `cellTrustFor` (org secrets, or a cell with `-egress-inspect`).
- The flags `-cell-ca-cert` and `-machine-roots`: `cmd/cell/trust.go`.
- The CA's key and the TLS it terminates: `internal/injector`.

## Rules and limits
- Certificates only: a cell CA file with any other PEM block (a key) is refused, so the injector's key never reaches a machine; it must hold exactly one CA certificate.
- Public roots come from the cell's own trust store or the operator's file, read once at start, never from the network.
- A compose file may not mount under `Dir`; in a compose service the cell's `EnvNames` values replace the file's and the recipe's. The rule is linked in [`../../AGENTS.md`](../../AGENTS.md) "Untrusted input".
- A secret may not be named after one of `EnvNames` (`agent.secretNameRefused`).

## Where new code goes
- A tool that reads another variable: a name in `EnvNames` and its value in `Env`, with a case in `TestEnvPointsEveryVariableAtTheMountedFiles`; the product's list in `libs/runtime/api/domain/secrets.ts` follows.

## Tests
- `go test ./internal/machinetrust` (temporary directories, `testpki` CAs).
