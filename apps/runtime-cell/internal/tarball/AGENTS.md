# apps/runtime-cell/internal/tarball

How a repository reaches the cell without git (S-05): the commit's tarball is downloaded through the Git API with the claim's download token, extracted by a child process with no network that refuses links and paths outside the root, and the token is revoked right after, whatever happened. It runs in the cell process; the agent calls it for each repository of a claim, and `cmd/cell extract` is the child.

## Owns
- `fetch.go` `FetchExtractRevoke` and `FetchOptions` (download capped at `MaxBytes`, 2 GiB by default), `Revoke` (three tries with backoff, each up to 10 s past the caller's ctx), the `Revoker` and `Extractor` ports.
- Extractors: `NetNSExtractor` (a new network and user namespace on Linux, `isolate_linux.go`; refused elsewhere unless `AllowWithoutNetNS`, `isolate_other.go`), `RunExtractChild` (the child's side), `InProcessExtractor` (tests and the fake cell only).
- The extraction rules: `extract.go` `Extract`, `Limits` (`DefaultLimits`: 200 000 files, 4 GiB total, 1 GiB a file, directories counted), `RefusedError`, `Stats`.

## Does not own
- The tarball URL and the revocation call on the Git API: `internal/gitsource`.
- Where the checkout goes and what the cell writes into it later: `internal/agent` (`claims.WorkDir`), `internal/checkoutfs`.

## Rules and limits
- The token is revoked on every path, a refused archive and a failed download included; a revocation that never works fails the fetch, so a valid token is never let go silently ([`../../AGENTS.md`](../../AGENTS.md) "Untrusted input": every download token of a claim is revoked).
- A symlink is kept only when it resolves inside the destination; any other symlink, a hard link, a device, a `..` or absolute path, or a `.git` entry refuses the whole archive and leaves the destination empty.
- The child runs with `PATH=/usr/bin:/bin` only and dies with its parent (`Pdeathsig`).
- `Revoke` sleeps with `time.Sleep` between tries rather than a `clock.Clock`; tests shorten `revokeBackoff`.

## Tests
- `go test ./internal/tarball`. `TestMain` (`extract_test.go`) re-executes the test binary as the isolated child; the network checks run on Linux with user namespaces and skip elsewhere.
