# apps/runtime-cell/internal/hostcheck

Reads what makes a host fit to run many orgs' sandboxes side by side (SMT, KSM, swap, CPU mitigations, microcode), the same for every driver ([isolation-architecture.md](../../../../docs/runtime/isolation-architecture.md), "Host checks"). A pure package run in the cell process at start.

## Owns
- `hostcheck.go` `Probe`: reads sysfs and procfs under a root through a read func and returns a `State`.
- `State.Unsafe`: the findings a shared cell refuses, in words.
- The policies `Shared` (refuses SMT, KSM or swap on, an unmitigated CPU vulnerability, or what it cannot read) and `Dedicated` (starts and reports the same findings).

## Does not own
- Resolving `-host-policy`, refusing or warning, and the heartbeat report: `cmd/cell` (`wire.go` `checkSharedHost`, `microvm.go` `hostReport`).
- The microVM cell's refusal, with its other prerequisites: `internal/isolation/firecracker` (`host.go`).

## Tests
- `go test ./internal/hostcheck` (a fake root).
