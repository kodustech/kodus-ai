# apps/runtime-cell/internal/compose

Reads a checkout's docker compose project and adapts it to run on a cell, as data: a YAML tree in, a YAML tree out, no docker binary. A pure package of the cell process; the agent (`internal/agent`) and the dev-only `drivers/localdocker` call it. Each adaptation is one method named for what it does, so a caller composes the ones it needs.

## Owns
- Loading: `project.go` `Load` (a recipe's files laid over each other in order, or the first of `DefaultFiles`; `ErrNoComposeFile`), `FromYAML`, `SingleService`; `overlay.go` the compose merge rules with `!reset` and `!override`; `NamedVolumes`, `ServiceNames`.
- Profiles: `profiles.go` `ActivateProfiles` keeps what compose would start and refuses a dependency left behind.
- Side-by-side adaptations: `adapt.go` `PublishOnLoopback`, `DropContainerNames`, `AddLabels` (refuses the reserved prefix), `AddEnvironment` (the recipe's value wins, `$` escaped), `NameBuiltImagesAfterProject`, `MakeExternalVolumesPrivate`, `MakeExternalNetworksPrivate`.
- A recipe's fake services: `fakes.go` `AddRecipeFakes` (validated whole before it applies, `FakeComposeError`).

## Does not own
- The security allowlist and the forced limits of a gVisor cell: `internal/compose/sandbox`. These adaptations are not a security boundary.
- The recipe's format and its rules: `internal/recipe`. The compose command lines: `internal/composecmd`.

## Rules and limits
- Every path resolves inside the checkout through `os.Root`: a compose file the PR links out of it is refused, never read.
- The PR's file is read bounded and refused past the node bound before it is decoded (`internal/yamlbound`): the cell parses it in its own process, outside any claim's cgroup.
- Keys the cell does not touch survive untouched (`Project` is a plain YAML tree).

## Where new code goes
- A new adaptation: one method on `Project` in `adapt.go`, with its own test; the caller (agent or driver) decides when to apply it.
- A rule that is a security boundary goes in `compose/sandbox`, not here.

## Tests
- `go test ./internal/compose` (pure, temporary directories).
