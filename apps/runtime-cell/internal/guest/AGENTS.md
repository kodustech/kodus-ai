# apps/runtime-cell/internal/guest

The guest agent: the one process inside a sandbox machine that runs its commands and touches its files on the cell's behalf, and the cell's client for it. It runs inside the machine (`cmd/kody-guest`, under gVisor through docker exec's stdio, or in a Firecracker microVM over vsock through `internal/guestinit`); the client side (`Client`) runs in the cell. Both speak the cell protocol's own frames (`sandbox.op` in, `guest.result` out).

## Owns
- Files below the root: `fs.go` `OpenRoot`, `FS.Read` (bounded chunks), `Write`, `Stat`, `Remove`, `List` (stops at `maxEntries` and says so).
- Commands: `exec.go` `FS.Exec` (`/bin/sh` in a cwd below the root, `BaseEnv` plus the request's env, the whole process group killed at the deadline, output capped and with env values masked).
- The server: `server.go` `Serve`, `Run` (at most `MaxConcurrent` ops per stream; one more is answered busy).
- The stream: `stream.go` `WriteFrame`, `ReadFrame` (4-byte length, at most `protocol.MaxFrameBytes`; a longer one ends the stream), `Client.Do` (requests matched to answers, safe for concurrent use; `ErrClosed` when the stream ends).
- `trust.go` `MountedTrustEnv`: the trust variables of a sandbox the cell mounted its CA into, nil otherwise.

## Does not own
- Booting a microVM and starting this server as its user: `internal/guestinit`. The vsock handshake: `internal/vsock`.
- Which machine a step runs on and dialing it: `internal/agent` (`sandbox.go` `dialGuest`), the drivers.
- The trust files and their targets: `internal/machinetrust`.

## Rules and limits
- Every bound and no-follow rule lives here, inside the machine: a path is opened one segment at a time relative to the directory before it with `O_NOFOLLOW`, so no symlink, committed or made a moment ago, takes an op outside the root. `O_NOFOLLOW` is not trusted alone (runsc follows a directory link despite it): every directory and every file opened is checked against its entry, same device and inode. A FIFO is neither read nor waited on.
- Anything on the stream that is not a `sandbox.op` ends it: only the cell talks here.
- An env value of `maskMin` bytes or more never comes back in a result's output.
- It imports nothing of the control side ([package rules](../../AGENTS.md), "Package boundaries").

## Where new code goes
- A new sandbox op: its body in `libs/runtime/protocol` first, then `Run` and an `FS` method, with a test in `guest_test.go` that tries it through a planted symlink.

## Tests
- `go test ./internal/guest` (temporary directories, pipes). `test/conformance` and `test/fcregress` (KVM, root) run it in real machines.
