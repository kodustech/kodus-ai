# apps/runtime-cell/internal/placement/hostnet

The host-network Placement for microVMs: a claim's network is a Linux bridge on the host in a /24 of the cell's pool, each machine joins it through a tap of its own in its own network namespace, and one nftables ruleset leaves the cell's egress address as the only thing a machine reaches. The microvm driver holds it; the Firecracker backend asks it for taps; the reaper removes leftover taps by name.

## Owns
- `hostnet.go` `Placement` (`New`, the `placement.Placement` methods, `AttachTap`, `AttachTapAt`, `DetachTap`, `Taps`, `Egress`, `Ruleset`), `Config`, `Prerequisites` (the host tools it needs).
- The ruleset: `rules.go` `Rules.Ruleset` (an `inet` table for what a machine reaches, a `bridge` table that pins each tap to its own MAC and address), replaced whole with `nft -f` on every change.
- State that the kernel cannot label: one JSON file per network under `Config.StateDir`, read back by `New`.
- Leftovers: `orphans.go` `TapName`, `NetnsName`, `HostTaps`, `HostNetns`, `PruneNetworks`, and `TapRemover` for the out-of-process reaper.

## Does not own
- The VMM and its jailer, which open the tap: `internal/isolation/firecracker`.
- When a claim's network is made or released: `internal/drivers/microvm`.
- The egress itself (proxy and resolver on the egress address): `cmd/egress`, `cmd/resolver`.

## Rules and limits
- No route out and no NAT: machines reach the egress (resolver 53, proxy 80 and 443 by default) through their bridge's gateway, and other machines of their own claim, nothing else of the host.
- A tap may send only from its own MAC and address (IPv4 and ARP): the egress allowlist is per source address. A tap is not made when it cannot be fenced.
- The egress address must be outside the pool. Bridges are `kfb*`, taps `kft*`, namespaces `kfn*`, so wildcard rules cover this placement's interfaces only.
- Only the cell's placement writes the nft table; the reaper removes taps by name and never rewrites it. The cell prunes networks no machine holds at start, before it serves.
- Claim bridges are let through Docker's forward drop policy once (`ensureDockerForward`).
- `DefaultPool` repeats `netguard.DefaultClaimSubnets` and `placement/docker.DefaultPool`: change all three together.

## Tests
- `go test ./internal/placement/hostnet` with a recording `Runner` (anywhere).
- `kernel_linux_test.go` on a real kernel: `KODY_E2E_HOSTNET=1`, as root in a throwaway privileged container (it changes the host's network).
