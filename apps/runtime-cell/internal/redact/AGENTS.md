# apps/runtime-cell/internal/redact

The cell's last pass over everything that leaves it (S-51): exact values the cell knows, in every spelling, then a token-pattern net for the values it never knew. The replacement is one way, `[redacted:<rule>]`. A leaf package used by the agent (frames through `redactOutbound`), evidence, the hub client, the observer, the injector, the browser runner, logs (`internal/telemetry`) and the drivers' output paths.

## Owns
- `redact.go` `Redactor` (`New` with `Known` values, `String`), `Patterns` (the rule net alone), `Rule`, `LoadRules`, `DefaultRules`, `Marker`, `MinKnownLen`.
- Spellings of a known value: `variants.go` `Variants` (base64 and base64url with their embedded cores, percent encoding, hex, JSON escapes; a port of the TS `secretVariants`), `EncodeURIComponent`.
- Masking streams: `mask.go` `Mask`, `Contains`, `MaskingWriter` (across chunk boundaries).
- Frames: `protocol.go` `Redactor.StepResult` and `StepStream` (every text field, kept under the protocol's caps), `Clip`, `ClipMiddle`.
- The rule data: `rules/gitleaks-rules.json` (a curated subset of gitleaks' default rules, MIT).

## Does not own
- Which values a claim's redactor knows (tokens, secrets, keys): the agent and `agent/claims`.
- Where frames are redacted: `agent.deliver` and `agent.deliverOnce` only ([`../../AGENTS.md`](../../AGENTS.md) "Untrusted input").
- Run canaries: the cell does not redact them; the worker checks for them.

## Rules and limits
- `rules/gitleaks-rules.json` is a byte copy of `libs/runtime/redaction/gitleaks-rules.json` (`TestRulesFileMatchesTS`); `Variants` matches the TS original on `testdata/ts-variants.json`.
- A known value shorter than `MinKnownLen` (4) is not matched exactly, so it cannot break earlier markers.
- Nothing downstream needs a redacted value: credentials reach the app through the injector, never through output.
- The protocol caps in `protocol.go` (`MaxExecStream`, `MaxReason`…) come from `protocol/constants_gen.go`; a new cap is a named export in `libs/runtime/protocol` first.

## Where new code goes
- A new token pattern: `libs/runtime/redaction/gitleaks-rules.json`, copied here, with examples the rule must redact (`TestEveryRuleRedactsItsExamples`).
- A new text field in a frame: its line in `StepResult` or `StepStream`, with a case in `TestS51StepResultCarriesNoSecret`.

## Tests
- `go test ./internal/redact` (pure; reads the libs rules from the repository).
