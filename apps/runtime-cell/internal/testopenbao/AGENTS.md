# apps/runtime-cell/internal/testopenbao

Test code: OpenBao as Kodus ships it (the repository's `docker/openbao` config and policies, Postgres storage, static auto-unseal, the self-initialized AppRoles) in throwaway containers, for the `dockersmoke` tests of the injector (`internal/injector/openbao_container_smoke_test.go`) and of the agent's org secrets (`internal/agent/org_secrets_smoke_test.go`). Nothing here is production code.

## Owns
- `openbao.go` `Start` (containers removed when the test ends; skips without docker), `Env` (an OpenBao started elsewhere: `KGR_OPENBAO_ADDR`, `KGR_OPENBAO_CA_FILE`, `KGR_OPENBAO_DIR`), `Bao` (`Login`, `Call`, `WriteSecret`, `RoleFiles`, `Restart`, `WaitReady`), `Image` (pinned by digest), `Mount`.

## Rules and limits
- It lives outside `internal/testing/`, unlike the package rule for fakes ([`../../AGENTS.md`](../../AGENTS.md) "Package boundaries"); it takes `testing.TB`, so only tests can call it.

## Tests
- No tests of its own; run its callers with `go test -tags dockersmoke`.
