# apps/runtime-cell/internal/policy/control

The policy control protocol between the cell agent and the data-plane components that enforce a claim's policy (egress proxy, resolver, injector). Each component serves it on its control port behind mTLS: signed policies come in with `PUT /v1/policy`, signed removals drop them with `DELETE /v1/policy/{claim}`. The agent's side is `Pusher`, a port of the agent; `cmd/cell` wires it.

## Owns
- The server side: `control.go` `Server` (`Register`, `Handler`; hooks `Enforceable`, `OnPolicy`, `OnDelete`, `DurableDelete`), `SignRemoval`, the headers (`SignatureHeader`, `SignedAtHeader`, `DenyFingerprintHeader`), `MaxRemovalSkew`.
- The agent's side: `Pusher` (`Push`, `Remove`) over named endpoints (`ParseEndpoints`, `URL`, `RequiredEndpoints`), `ErrDenyListsDiffer`.
- Reading back what the egress did for a claim: `denied.go` `DeniedReader` (the proxy's `GET /v1/events` and the resolver's `GET /v1/queries`, one entry per host for the failure bundle), `outbound.go` `OutboundReader` (`GET /v1/connections` and refusals in a window, for a probe round's evidence).

## Does not own
- The policy, its signature and the store: `internal/policy`.
- The mTLS and the pin to the agent's certificate: `internal/tlsutil`.
- The fingerprint itself: `netguard.DenyList.Fingerprint`.

## Rules and limits
- A push fails when the components report different operator deny-list fingerprints, so no claim runs on a policy enforced two ways; a component that reports none is not compared.
- A component that cannot enforce a verified policy as signed refuses it with 422 and keeps what it had (`Enforceable`).
- A removal is signed and its time must be within `MaxRemovalSkew`. An invalid removal never reaches `DurableDelete`; when durable revocation fails, the policy is still dropped from memory and the answer is 503, never an acknowledgement.
- A policy body is at most 2 MiB (a large `go.sum`'s pins). `Push` names the endpoint that failed.

## Where new code goes
- A new route of a component's control port that the agent calls: a reader here next to `DeniedReader`, never an HTTP call built in `agent`.

## Tests
- `go test ./internal/policy/control` (httptest components).
