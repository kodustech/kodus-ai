# apps/runtime-cell/internal/policy

The per-claim egress policy: the cell agent builds and signs it (ed25519), and the egress proxy, the resolver and the injector verify it and decide every connection by it. The proxy and the resolver hold only the agent's public key, no credential. It is the shared vocabulary of the control side and the data plane; `policy/control` carries it between them.

## Owns
- The policy and how it is made: `policy.go` `ClaimPolicy`, `Spec`, `Build` (least privilege: a host the deny list refuses never reaches the signed allowlist, it is returned for the caller to report), `MergeAllow`, `NormalizeHost`.
- Signing: `Sign`, `Verify` (the exact bytes, unknown fields refused, expiry), `Signed`, `ErrBadSignature`.
- What the components keep: `Store` (`Put`, `Delete` with a tombstone, `Sweep`, `ForSource`, `ForClaim`, `Claims`), `ErrStale`.
- Per-host questions: `Allows`, `Injects`, `PinsGo`, `PinsImage`; the inspected tier `inspect.go` `InspectRule.Permits`, `Inspects`, `InspectsFrom`; the image builder `build.go` `FromBuild`, `BuildRefuses`.
- Org secrets as placeholders: `secrets.go` `Secret`, `NewPlaceholder`, `ValidPlaceholder`, `SecretsFor`, `Placeholders`.
- The cell's own names: `AppHost`, `MirrorHost`.

## Does not own
- The Kodus deny list and the recommended inspect rules: `internal/netguard`.
- Pushing and removing policies, and reading denials back: `internal/policy/control`.
- Enforcing it on the wire: `internal/egress`, `internal/resolver`, `internal/injector`. When the agent builds it: `internal/agent` (`egress_sync.go`).

## Rules and limits
- Allow holds exact hosts, no wildcards; a secret with a wildcard host is refused. A secret's hosts become reachable only through the injector (`CredentialHosts`), and a denied host never carries a secret.
- An inspected host lets out only GET and HEAD with no body, under its paths and none of its except paths, with a bounded URI; an opaque URL or empty path is refused, never defaulted. A git push is refused everywhere (S-56, S-57).
- Only sources whose machines trust the cell CA are inspect sources; from any other, TLS to an inspected host stays SNI passthrough. The image builder reaches only its passthrough hosts unless it trusts the cell CA ([`../../AGENTS.md`](../../AGENTS.md) "Untrusted input").
- A source belongs to one claim. A re-push replaces a policy only when it is not older; a deleted claim's tombstone keeps a replayed policy out until it would have expired.
- `Verify` refuses unknown fields: a new field is `omitempty`, and the components that verify it ship before the agent that signs it.

## Where new code goes
- A new kind of decision per host or source: a method on `ClaimPolicy` here, used by every component that enforces it, with its case in `policy_test.go`.
- A new field: `ClaimPolicy` and `Spec`, its check in `validate`, and its `Build` step.

## Tests
- `go test ./internal/policy` (pure).
