# apps/runtime-cell/internal/protocol

The Go side of the cell protocol (`libs/runtime/protocol`): the envelope and every message body, a strict decoder that refuses what the TS decoder refuses with the same error codes, and the zod refinements a JSON Schema cannot carry. A leaf package used by the agent, the hub client, the observer, the guest and most of the cell.

The types and constants are generated from `libs/runtime/protocol` (zod) and never edited by hand: `types_gen.go` (by `internal/protocol/gen` from `schema/protocol.schema.json`), `constants_gen.go` and `schema/protocol.schema.json` (by `libs/runtime/protocol/scripts/dump-json-schema.ts`). The procedure is [`../../AGENTS.md`](../../AGENTS.md) "Protocol".

## Owns
- Decoding and encoding: `codec.go` `Decode`, `Encode`, `Header`, `Message`, `DecodeError` and its codes, `ClaimScopedTypes`, `ReplyTypes`, `SupportedVersions`, `ValidTraceparent`.
- The strict parse before any schema: `strictjson.go` `parseStrict` (duplicate keys, depth, trailing data, reserved keys such as `__proto__`), mirroring `libs/runtime/protocol/strict-json.ts`; `jsonschema.go`, a validator of exactly the keywords the TS side emits.
- Refinements mirrored from zod: `CheckReadOnlySQL`, `CheckBrowserExploreRequest`, `CheckBrowserExploreResult`, `BrowserSelectorProblem` (`codec.go`); `sandbox.go` `CheckSandboxOp`, `CheckCallerEnv`, `SandboxExecMaxEnvWire`; `authored_files.go` `CheckAuthoredFiles`.
- Hello features: `features.go` `Features`, `Accepted` (a field of `HubAcceptedFeatures` is sent only when the hub's ack names it), `MaxClaimSize`.
- Times: `timestamp.go` `ParseTime`, `FormatTime`.

## Does not own
- The protocol's definition: `libs/runtime/protocol` (zod). The shared fixtures: `libs/runtime/protocol/fixtures`.
- Sending and acking frames: `internal/hubclient`; redacting them: `internal/agent` (`redactOutbound`) and `internal/redact`.

## Rules and limits
- Every rule in [`../../AGENTS.md`](../../AGENTS.md) "Protocol" applies: changes start in zod, constants come from `constants_gen.go`, date-time fields go through `ParseTime` and `FormatTime`.
- A frame two parsers could read differently is refused before any schema runs (ADR-051, S-30). Object keys compare byte for byte.
- A refinement mirrored here keeps the TS error code.

## Where new code goes
- A new message or field: the zod schema, then dump and `go generate ./internal/protocol`, then a fixture.
- A new zod refinement: its Go mirror in `codec.go`, `strictjson.go` or the file of its message family (`sandbox.go`, `authored_files.go`).

## Tests
- `go test ./internal/protocol` (includes `TestGeneratedTypesAreCurrent` and `TestSharedFixtures` over `libs/runtime/protocol/fixtures`).
- The TS side: `API_NODE_ENV=test npx jest libs/runtime/protocol`.
