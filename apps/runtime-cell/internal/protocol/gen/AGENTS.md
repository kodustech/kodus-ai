# apps/runtime-cell/internal/protocol/gen

The generator of `internal/protocol/types_gen.go`: a `go run` command that reads the JSON Schema `libs/runtime/protocol` exports (`schema/protocol.schema.json`) and writes the Go types. Build tooling only, never in a shipped binary; `go generate ./internal/protocol` runs it (`codec.go`'s `//go:generate`).

## Owns
- `main.go`: schema to Go types (`gen.goType`, `object`, `enum`, `union`), names from schema paths (`gen.name`), gofmt'd output.

## Does not own
- The schema and `constants_gen.go`: `libs/runtime/protocol/scripts/dump-json-schema.ts`. The protocol itself: `libs/runtime/protocol` (zod).

## Rules and limits
- The TS side is the source of truth. The output is never edited by hand; a type the generator gets wrong is fixed here and regenerated ([`../../../AGENTS.md`](../../../AGENTS.md) "Protocol").

## Tests
- `internal/protocol` `TestGeneratedTypesAreCurrent` runs this generator and fails when `types_gen.go` differs.
