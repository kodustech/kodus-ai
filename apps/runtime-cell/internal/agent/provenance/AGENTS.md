# apps/runtime-cell/internal/agent/provenance

What the cell remembers about where its machines and images came from (S-52): which machines ran PR code, which images this cell baked from a default-branch commit, each environment's last bake, and which environments have a bake in progress. A part of the agent with its own lock, in the cell process. It holds ids only and decides nothing: the agent asks it before a machine becomes an image or a pool machine, and before a claim boots from a bake.

## Owns
- `provenance.go` `Record`: `Taint`, `Untaint`, `Tainted` (machines); `Add`, `Baked`, `Latest`, `Images` (images); `Resolve` (reads `LatestImage` as the environment's last bake in one read); `Reserve` (one bake in progress per environment, `finish` gives it back once); `Counts`.

## Does not own
- The decisions that read it (taint before compose, refuse a tainted bake, pool admission): `internal/agent` `image_policy.go`, `pool_claims.go`.
- The durable record of baked generations across restarts: `internal/bakecatalog`.

## Rules and limits
- In memory only: at start the agent restores which images it baked from the driver's bake catalog (`agent.go` `recoverBakes`, `Parts.BakeCatalog`); taints and bakes in progress do not come back.
- The bake rule it serves is in [`apps/runtime-cell/AGENTS.md`](../../../AGENTS.md) "Untrusted input" (nothing from a PR claim becomes a bake or a pool machine).

## Tests
- `go test ./internal/agent/provenance` (pure).
