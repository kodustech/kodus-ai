# apps/runtime-cell/internal/agent/claims

The cell's record of the claims it holds: each claim's state machine, its machines, its running steps and its egress policy, behind the claim's own lock; and the registry that bounds how many a cell holds. A part of the agent, in the cell process; every agent file that touches a claim goes through it.

## Owns
- States: `claim.go` `State` (`Acquiring`, `Ready`, `Failed`, `Held`, `Released`) and the transitions `MarkReady`, `MarkFailed` (or `Held` until a hold time, for a failed setup claim), `Release`, `BeginCleanup` (true once), `Halt`, `Compromise`.
- What a claim carries after acquire: machines (`SetNetwork`, `SetWorkload`, `SetObserver`, `Machines`), the redactor, the start kind (cold, pool, bake), cell trust (`MarkCellTrusted`), pins for the mirror (`SetGoPins`, `SetImagePins`), preparation phases, the compose project, the round snapshot, the observer generation.
- Steps: `AddStep`, `TryAddStep` (bounded by a limit), `CompleteStep`, `RemoveStep`, `CancelStep`.
- The egress allowlist by generation: `SetAllow` (an older policy is stale), `PendingAllow`, `MarkAllowApplied`, `EgressLock`, `PendingInspect`.
- `registry.go` `Registry` (at most `Max` claims; `Remove` drops only that claim, not a new one with the same id). `id.go` `ValidID`, `WorkDir`.

## Does not own
- What triggers a transition (acquire, prepare, settle, release): `internal/agent`. The claim's state on the hub: `apps/runtime/src/hub` (`transitionClaim`).

## Rules and limits
- A claim id is a plain path segment (`ValidID`); a claim's directory is built only with `WorkDir` ([`apps/runtime-cell/AGENTS.md`](../../../AGENTS.md) "Untrusted input").
- What `claim.acquire` said is fixed at creation; everything else changes under the claim's lock and is read through its methods, never by copying fields across goroutines.
- `Settled` closes once the claim leaves `Acquiring`; `Prepared` once the preparation returned and everything it made is in the lease.

## Where new code goes
- New per-claim state: a field behind the lock with a setter and a getter here, not a field on `Agent`.

## Tests
- `go test ./internal/agent/claims` (pure).
