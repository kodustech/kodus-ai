# apps/runtime-cell/internal/browser

Browser probes (ADR-071) in the cell's browser runner: a Kodus image, pinned by digest, that a driver starts per probe round on the claim network. This package checks the probe's closed step list, hands the runner its job, reads back one tar stream within fixed bounds, redacts the text artifacts with the claim's redactor, and diffs each screenshot against the baseline round's. It runs in the cell process, called by `internal/agent`; the runner itself is `browser-runner/` (Playwright).

## Owns
- `browser.go` `Check`: the closed list (S-31) before any container starts: one kind per step, paths on the app, no internal selector engine, a plain key name, no role. `Job`, `Session` (bounded by `MaxSession`, so the video is too), `AppHost`.
- `capture.go` `Capture.Run`: one round: the runner, the tar stream held to the design's bounds, the HAR and trace scanned and refused or trimmed when they carry a credential, the console and network clipped to fit a `step.result` frame, the baseline screenshots read by signed GET without redirects.
- `explore.go` `Explorer.Run`, `CheckExploreRequest`: the same isolated runner for exploration; it returns no probe result, coverage or artifacts, and its observations never enter the replay gate.
- `pixeldiff.go` `Diff`, `PixelDiff.Ratio`, `EncodePNG`, `DefaultTolerance`.
- The ports it is given: `Runner` (`ErrJobRefused` is the runner's exit 2) and `Redactor`.

## Does not own
- Starting the runner container: the driver (`internal/drivers/dockergvisor/browser.go` `BrowserRunner`).
- Uploading artifacts with their grant and the claim's evidence: `internal/agent`, `internal/agent/evidence`.
- What a pixel difference means for the verdict: `libs/runtime/gate` (pixel-only differences never fail a check).

## Rules and limits
- Images and video cannot be redacted: the runner only ever sees the environment's seed data.
- Nothing here takes page script from the probe: the steps are checked against the closed list here and again in the runner (`browser-runner/steps.mjs`). A change to the list is a change to both.
- Every artifact has a bound: screenshot dimensions and decode memory before a diff, a trace's uncompressed size (a zip bomb stops there), the result within one frame.

## Where new code goes
- A new step kind: `libs/runtime/protocol` first, then `Check`, then `browser-runner/steps.mjs`, with a refusal case in `capture_test.go`.

## Tests
- `go test ./internal/browser` (a fake `Runner` and tar streams). `smoke_test.go` and `modes_smoke_test.go` run the real runner image behind the `dockersmoke` tag.
