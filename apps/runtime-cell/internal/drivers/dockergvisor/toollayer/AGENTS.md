# apps/runtime-cell/internal/drivers/dockergvisor/toollayer

The cell's store of tool layers ([`docs/runtime/persistent-state.md`](../../../../../../docs/runtime/persistent-state.md) section 4): the tree a CLI install leaves, built once per `(org, key)` in a clean builder, copied out through this package's own extractor, and mounted read-only into reviews of that org. A subpackage the driver will hold as a field; it holds directories and a clock and knows no Docker. It runs in the cell process.

## Owns
- `key.go` `ComputeKey`: sha256 of the canonical record; refuses without an image digest (U6).
- `install.go` `CheckInstall`: the Go twin of `checkCliInstallCommand` for npm and pnpm, held to the same answers by `cli-install-commands.json`.
- `extract.go`, `entry.go`: the only door into the store (tar to blobs, every refusal of section 4.3, the entry script and its shebang).
- `store.go` `Store`: `Ingest`, `Lookup` (returns a held, verified `Hit`), `Hold`, `PurgeOrg`, limits and LRU eviction. `verify.go`: stat fingerprint per mount, full sha256 at the first mount after a start, every 24 h and on a fingerprint difference (U8). `miss.go`: build on the second miss within 7 days (U9). `builds.go` `Builds`: the admission of builds, one per key at a time, one per cell and two per org, no retry for 10 minutes after a failure. `gc.go`: `GC`.

## Does not own
- Running the builder (the agent's `layer_build.go`), the tar stream's transport, the mounts, the label, the flags: the driver (`../toollayers.go`) and `cmd/cell`.
- Whether a layer is wanted at all: the provider's key plan in `libs/sandbox`.

## Rules and limits
- Paths come from the org id (hashed) and from hex digests this package computed or validated; a caller never supplies one. Every directory on the way to a tree is an `Lstat`-checked real directory.
- Nothing is written through a path the archive chose: file content goes to `blobs/<sha256>`, the tree is built later from validated segments. Never shell out to `tar`.
- A mismatch evicts the layer and answers `ErrMiss`; the caller installs as today. A layer is never partly kept.
- `cli-install-commands.json` is byte-identical to `libs/runtime/protocol/cli-install-commands.json`; change both in one PR, and the API's validator with them.
- Linking a file into another layer changes its ctime, so a fingerprint difference only triggers the rehash; the rehash decides and refreshes.

## Tests
- `go test -race ./internal/drivers/dockergvisor/toollayer` (temporary directories, no Docker). Adversarial archives are built in the tests.
