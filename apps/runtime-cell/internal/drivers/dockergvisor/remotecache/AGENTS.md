# apps/runtime-cell/internal/drivers/dockergvisor/remotecache

docker-gvisor's exported BuildKit cache kept off the cell, in an OCI distribution registry, so it outlives the cell's disk floor: the default branch's setup pushes the cache its build exported, and a build that finds the environment's state and exported cache gone pulls it back ([`docs/runtime/build-cache.md`](../../../../../../docs/runtime/build-cache.md)). A subpackage the driver holds (`driver.go`, wired in `cache_remote.go`, from `-gvisor-build-cache-remote` and its auth file); it knows no Docker and no BuildKit. It runs in the cell process.

## Owns
- `remotecache.go` `New`: the store's location checked (`http(s)://host/prefix`, plain HTTP only to loopback, no credentials in the URL); a redirect to another host loses the `Authorization` header.
- `Key.Repository`: one repository per org, environment and service, named from hashes that start with the org's, so no two orgs share one and a credential can be scoped to an org's prefix.
- `Registry.Push`: a BuildKit local cache (an OCI layout) uploaded by the cell; a cache with holes, a symlinked `blobs` or blob, or a blob that does not match its name is refused.
- `Registry.Pull`: every blob checked against its digest and size as it streams, before the cache reaches a build; a manifest that is not a cache is refused; `ErrNotFound` when there is none.

## Does not own
- Who may push: the driver pushes only a seeding setup's cache, never a pull request's (`cache_remote.go`; the rule is in [`../../../../AGENTS.md`](../../../../AGENTS.md) "Untrusted input").
- The cache on the cell's disk: `../buildcache`.

## Rules and limits
- The builder never holds the store's credential or a route to it; only the cell moves the files.
- The credential (`Config.Auth`) stays in this package: never in a URL, an error or a log (`TestTheCredentialStaysWithTheRegistry`).
- Pulls are bounded by `Config.MaxBytes` (`DefaultMaxBytes` when zero); a pull on a build's path is bounded by `DefaultPullTimeout`, past which the build runs cold.

## Tests
- `go test ./internal/drivers/dockergvisor/remotecache`: an in-process registry over `httptest`. The driver's use of it: `cache_remote_test.go` in the parent package.
