# apps/runtime-cell/internal/observer/observersrv

The observer machine's server as both its programs run it: `cmd/observer` on TCP in its container, and the guest agent's observer mode (`cmd/kody-guest`) on vsock in an observer microVM. It wraps `observer.Server` in an HTTP server with mTLS that accepts only the cell agent's client CA.

## Owns
- `observersrv.go` `Run` and `Options`: TLS from `tlsutil.Server`, shutdown when ctx ends (10 s grace), the server closed on return.
- `legacySQLClient`: the static DSN template (`{address}`) older cells still pass; Postgres only.

## Does not own
- Probes, configuration binding and preview proxying: `internal/observer`.
- The listener: the caller hands it a TCP or vsock listener.

## Rules and limits
- `Insecure` serves plain HTTP for local development only; the caller decides when it is allowed.
- An empty legacy DSN opens nothing: the process's own `PG*` environment never fills it in.

## Tests
- `go test ./internal/observer/observersrv`.
