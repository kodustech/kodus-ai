# apps/runtime-cell/internal/observer

The probe runner that decides a verdict, outside the claim's app (ADR-053): typed HTTP requests and read-only SQL against the claim's exposed ports, a log of every request by method and route, and the database effects of a round. It runs in the observer machine (`cmd/observer` in a container, or the guest agent's observer mode in an observer microVM, both through `observersrv`); `InProcess` runs it inside the agent for the fake cell only. The agent reaches it only through `Client`; the gate compares its results in the runtime-worker.

## Owns
- One claim's probes: `observer.go` `Prober` (`New`, `RunStep`, `Run`, `Log`, `Close`), `Target`, `Config`, `TargetsOnlyTransport`, `Route`.
- Refusals: `ProbeRefusedError` (the step is inconclusive, never a finding, S-31), `IsSideDetectingPath`, `UnreachableError`.
- The frame round trip: `server.go` `Handler` (`POST /v1/run` takes a `probe.run` frame, answers a `step.result`; `GET /v1/requests`), `StepResult`, `Client` with `InProcess` and `HTTPClient`.
- Binding an observer to one claim: `config_server.go` `Server` (`PUT /v1/config`, generations, `ConfigFingerprint`, `ClaimConfig`).
- SQL with the claim-local account: `managed_postgres.go` `ManagedPostgresConfig`, `OpenManagedPostgres`; the closed query subset `managed_sql.go` `ManagedSQLQuery`.
- Database effects of an HTTP probe: `dbeffects.go` (Postgres row and counter deltas since a mark, MySQL counts), secret-looking columns replaced by `RedactedValue`.
- Preview traffic to the claim's app: `preview.go` `PreviewHandler`, `PreviewRefuse`, `PreviewPath`.

## Does not own
- Serving it with TLS on TCP or vsock: `internal/observer/observersrv`. Configuring it from the cell: `internal/observerclient`.
- The claim-local SQL account and its provisioning script: `internal/observerauth`; who creates it: `internal/drivers/dockergvisor/observer_sql.go`.
- Browser probes: the agent's browser runner (`internal/browser`); shell steps run in the VM.
- The preview tunnel and its routes: `internal/preview`.
- The verdict: `libs/runtime/gate`.

## Rules and limits
- It never sees code, `.git` or processes. Paths that read the code instead of its behavior (`.git`, `.env*`, `.kodus`, `/proc`, `/sys`…) are refused.
- HTTP dials only the targets' addresses, takes no proxy from the environment and follows no redirect. A body over `MaxBody` is cut with its length and hash headers; a result over `MaxRows` is refused, never cut. Timeouts are bounded (`MinProbeTimeout`, `MaxProbeTimeout`).
- SQL is read-only (`protocol.CheckReadOnlySQL`, READ ONLY transactions); managed SQL errors never return the server's text, and an inherited `PG*` environment is refused.
- One claim per observer: a frame for another claim is a 409. A new generation waits for active probes, then closes the old pools.
- A refusal's reason may quote the app's database: it is redacted and clipped (`redact.Patterns`, `redact.Clip`).
- A preview request reaches only an http target of the configuration and is never logged as a probe's request.
- This package is on the data plane: it never imports the control side ([`../../AGENTS.md`](../../AGENTS.md) "Package boundaries").

## Where new code goes
- A new probe kind: a case in `Prober.Run` after the protocol change in `libs/runtime/protocol`, refusing what it cannot run.
- A new SQL dialect for the managed account: `managed_*.go`, with the same pinning and error rules.

## Tests
- `go test ./internal/observer` (httptest apps, an in-memory SQL driver in `fakesql_test.go`).
