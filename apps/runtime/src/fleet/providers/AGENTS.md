# apps/runtime/src/fleet/providers

The host provider adapters runtime-fleet holds (docs/runtime/host-providers.md §9), and the registry that maps a pool's provider kind to one.

## Owns
- `registry.ts` `ProviderRegistry`.
- One folder per adapter (`boat/`), implementing `HostProvider` from `libs/runtime/fleet/host-provider.ts`.

## Does not own
- The port, the errors and the conformance suite: `libs/runtime/fleet`.
- When a host is made or destroyed: `../reconcile.ts` and `../per-run-host.ts`.

## Rules and limits
- An adapter maps every failure to `ProviderError` and never puts a provider message or body in it.
- An adapter passes `describeHostProviderConformance` on recorded responses, and has a live test only behind an opt-in variable.
- No SDK: plain `fetch`, so no dependency is added for a provider.

## Where new code goes
- A new provider: `providers/<kind>/`, its class schema in `libs/runtime/fleet/pool.ts`, its registration in `../runtime-fleet.module.ts`.

## Tests
- Each adapter's spec next to it.
