# apps/runtime/src/worker/canary

The runtime-worker's side of canaries (ADR-043): per-Run decoy credentials planted in the machines, which nothing legitimate ever reads back. This module finds and redacts them in what crosses the control plane's boundaries and turns a hit into a typed error the Run treats as a security halt. It runs in the runtime-worker, inside Run steps; the canary values themselves come from `libs/runtime/canary`.

## Owns
- `canary.ts` `CanaryGuardedLlmGateway`: refuses to send a prompt that carries one of the Run's canaries (`CanaryLeakError('llm_prompt')`). `RunDependenciesFactory` (`worker/dbos/run-deps.factory.ts`) wraps every LLM gateway with it.
- `CanaryLeakError` and `canaryLeakSite` / `isCanaryLeak`: the leak site (`llm_prompt`, `probe_output`, `exec_output`, `egress`, `publish`), recognized by name and message so it still matches after DBOS serialized a recorded step's error.
- `redactCanaries`, `redactDeep`: every form of a canary (verbatim, base64, base64url, its random core in any case) replaced by `[redacted]`.
- Re-exports `HmacCanaryVault` and `containsCanary` so worker code imports canaries from one place.

## Does not own
- Deriving the canaries and the vault: `libs/runtime/canary` (`HmacCanaryVault`, keyed by `canaryKeyFrom` from the seal key).
- Planting them: `worker/run/run-orchestrator.ts` `acquireRequest` puts them in the acquire, derived again on every replay, and the cell writes them into the machine.
- Deciding what a leak does to the Run: `worker/run/run-orchestrator.ts`; checking evidence uploads: `worker/run/run-evidence.ts` and `shared/evidence`.

## Rules and limits
- A canary's value is never logged, checkpointed, projected or published. `CanaryLeakError` names the site, never the value.
- The guard checks every message of a prompt before the inner gateway is called; a hit sends nothing.
- `canaryLeakSite` reads `llm_prompt` when it recognizes a leak but cannot parse the site.

## Where new code goes
- A new boundary to check: a `LeakSite` in `libs/runtime/canary` and in `SITES` here, then the check at the boundary, with a case in `canary.spec.ts`.

## Tests
- `API_NODE_ENV=test npx jest apps/runtime/src/worker/canary` (no services).
