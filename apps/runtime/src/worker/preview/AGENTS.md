# apps/runtime/src/worker/preview

The worker side of preview URLs ([preview-urls.md](../../../../../docs/runtime/preview-urls.md)): one claim of consumer `preview` per start of a preview, booted from the environment's recorded setup at the Run's commit for one side, never the Run's own machines. It runs in the runtime-worker: the API opens, reads and stops previews through the signed env-session listener (`worker/env-session`), and every replica's tick wakes, sleeps, renews and heals them; the preview edge (`apps/runtime/src/edge`) serves the browser and writes only activity and wake requests.

## Owns
- Opening and stopping: `preview.service.ts` `PreviewService.open`, `status`, `stop` (one preview per Run side; a second open answers the same preview), and `expirePullRequest` (a newer Run or a closed PR ends the older previews, called from `worker/commands/run-requested.handler.ts`).
- The tick: `PreviewService.tick` (every 10 s from `EnvSessionListener`): a security event on a live preview claim stops it first; then wake on a viewer's request, sleep after the idle window or at the ceiling, renew a used lease (`RENEW_BEFORE_MS`), re-route a cell with no tunnel (`TUNNEL_STALE_MS`), expire records after `PREVIEW_RECORD_DAYS`.
- The boot: the setup's recipe, expose and Kody's build files; the side's egress policy; canaries per start (`deps.canaries`); the route of the first http expose entry.
- Policy per open: `policyColumns` (idle and ceiling minutes, the monthly machine-minute cap `capReached`, a fork's PR side never with the environment's hosts or the org's secrets).
- The hub routes: `hub-preview-routes.ts` `HubPreviewRoutes` (`/internal/claims/:id/preview-route`, `preview-unroute`, on the replica that holds the claim).

## Does not own
- Preview rows and tunnel records: `shared/persistence/preview-store.ts`. Shapes, states, defaults and reasons: `libs/runtime/contracts/preview.ts`.
- The browser-facing edge, grants and sessions: `apps/runtime/src/edge`. The tunnel and route on the hub and cell: `hub/claims`, `apps/runtime-cell`.
- The acquire itself: `worker/env` (`HubEnvironmentClient`).

## Rules and limits
- Off without `RUNTIME_PREVIEW_DOMAIN` (`PreviewError` 409 `PREVIEW_OFF_CODE`, saying what to set); refused while the Runtime is stopped for the org or past the month's cap.
- Every state change is a conditional update in the store, so two replicas never both start or stop one preview.
- A wake opens the repo token the API sealed at the last open only within `PREVIEW_TOKEN_WAKE_MS` (50 min); after that the viewer opens it again from Kodus. A start not settled after 45 min is blocked.
- A security event leaves the machines as evidence: the preview stops and its sessions end, the claim is not released.
- A failed security read stops nothing that tick, but is logged as an error, never taken as "no violation".
- Every hub call carries the claim's `organizationId` ([apps/runtime/AGENTS.md](../../../AGENTS.md) "Tenant scope").

## Where new code goes
- A new preview action from the product: a route in `PREVIEW_ROUTES` (`libs/runtime/contracts/preview.ts`), the map in `env-session-server.ts`, a method here.
- Something the tick does per preview: `tick`, bounded by `TICK_BATCH`, with its count in the tick's result.

## Tests
- `API_NODE_ENV=test npx jest apps/runtime/src/worker/preview` (in-memory preview store, fake hub and environment).
- The Pg store: `shared/persistence/pg-preview-store.integration.spec.ts` (`RUNTIME_IT_DATABASE_URL`).
