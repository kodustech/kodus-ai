## Cómo funciona Together AI

Together AI sirve modelos de código abierto, como DeepSeek, Kimi, GLM y gpt-oss, a través de una API **compatible con OpenAI**. Kodus se comunica con ella mediante el proveedor compatible con OpenAI, por lo que no hay cambios de código, solo credenciales BYOK.

## Modelos recomendados

<Info>
  El catálogo serverless de Together cambia con frecuencia. Consulta la [lista de modelos serverless](https://docs.together.ai/docs/serverless-models) para ver los IDs de modelo, longitudes de contexto y precios actuales. Usa la cadena exacta del modelo en la API.
</Info>

Together lista estos modelos de chat serverless con function calling y salidas estructuradas:

| ID del modelo | Ventana de contexto |
| ------------- | ------------------- |
| `moonshotai/Kimi-K3` | ~1M tokens |
| `deepseek-ai/DeepSeek-V4-Pro-0813` | ~1M tokens |
| `zai-org/GLM-5.3` | ~1M tokens |
| `openai/gpt-oss-120b` | ~131k tokens |

## Crear clave de API

<Warning>Se requiere una cuenta de Together AI para crear una clave de API. Together es prepago: debes comprar créditos antes de poder crear claves, y el acceso a la API se suspende cuando el saldo llega a cero. Consulta la [documentación de facturación de Together](https://docs.together.ai/docs/billing).</Warning>

Ve directamente a la [página de claves de API de Together](https://api.together.ai/settings/projects/~current/api-keys) para crear una nueva clave de API.

O sigue estos pasos:

1. Crea una cuenta en [api.together.ai](https://api.together.ai) o inicia sesión si ya tienes una
2. Abre la [página de claves de API](https://api.together.ai/settings/projects/~current/api-keys)
3. Haz clic en **Create key**
4. Dale un nombre como 'Kodus' o cualquier nombre descriptivo
5. Copia tu clave de API. Together muestra una clave nueva una sola vez

## Configurar Together AI en Kodus

### Opción 1 — Página AI providers (recomendado)

Sigue [Conectar un proveedor](/es/how_to_use/byok#conectar-un-proveedor) y elige **Custom → OpenAI-compatible**. Usa estos valores en el formulario.

| Campo | Valor |
| --- | --- |
| **Key** (en la tarjeta **API key**) | tu clave de API de Together |
| **Base URL** | `https://api.together.ai/v1` |
| **Model** | p. ej., `zai-org/GLM-5.3` |
| **Max concurrent requests** | opcional; en **Advanced (optional)**, expande **Advanced settings**; redúcelo si ves errores de límite de velocidad |

Together publica la URL base en su [guía de compatibilidad con OpenAI](https://docs.together.ai/docs/inference/openai-compatibility).

Haz clic en **Test & save** y elige el modelo predeterminado y de respaldo en [Routing](/es/how_to_use/code_review/configs/routing).

<Note>
  Usa la URL base sin `/chat/completions`. Define un modelo de otro proveedor como **Fallback model** para que las revisiones sigan funcionando si Together te aplica un límite de velocidad.
</Note>

### Opción 2 — Alojamiento autónomo (variables de entorno)

Para darle un modelo a una instancia con alojamiento autónomo mediante `.env`:

```env
API_LLM_PROVIDER=openai_compatible
API_LLM_PROVIDER_MODEL="zai-org/GLM-5.3"
API_LLM_BASE_URL="https://api.together.ai/v1"
API_LLM_API_KEY="your-together-api-key"
```

Sigue la guía de instalación para [aplicar el cambio de modelo](/es/how_to_deploy/deploy_kodus/generic_vm#aplicar-cambios-en-el-modelo).

## Solución de problemas

<AccordionGroup>
  <Accordion title="Problemas con la clave de API">
    - Verifica que tu clave de API sea correcta y esté activa en la [página de claves de API](https://api.together.ai/settings/projects/~current/api-keys)
    - Comprueba que tu cuenta de Together AI tenga saldo de créditos; el acceso a la API se suspende en cero
    - Asegúrate de que no haya espacios al final ni comillas en el valor del `.env`
  </Accordion>

  <Accordion title="Modelo no encontrado">
    - Usa la cadena exacta del modelo en la API de la [lista de modelos serverless](https://docs.together.ai/docs/serverless-models), respetando mayúsculas y minúsculas
    - Los endpoints serverless y los dedicados admiten modelos distintos; un modelo que no está en la lista serverless necesita un endpoint dedicado
  </Accordion>

  <Accordion title="Errores de conexión">
    - Verifica que tu servidor tenga acceso a internet para alcanzar `api.together.ai`
    - Comprueba si hay restricciones de firewall
    - Revisa los registros de la API y del worker para ver el error upstream exacto
  </Accordion>

  <Accordion title="Límite de velocidad">
    - Together devuelve HTTP 429 cuando se excede un límite. Consulta la [documentación de límites de velocidad](https://docs.together.ai/docs/rate-limits) de Together
    - Reduce **Max concurrent requests** en el modelo, o contacta a Together para pedir límites más altos
  </Accordion>
</AccordionGroup>
