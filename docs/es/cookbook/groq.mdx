## Cómo funciona Groq

Groq Cloud sirve modelos abiertos a través de una API **compatible con OpenAI**. Kodus se comunica con ella mediante el proveedor compatible con OpenAI, por lo que no hay cambios de código, solo credenciales BYOK.

## Modelos recomendados

<Info>
  El catálogo de Groq cambia con frecuencia. Consulta la [página de modelos de Groq](https://console.groq.com/docs/models) para ver los modelos de producción actuales, ventanas de contexto, precios y límites.
</Info>

| ID del modelo | Ventana de contexto |
| ------------- | ------------------- |
| `openai/gpt-oss-120b` | 131,072 tokens |

Los agentes de revisión de Kodus llaman a herramientas y esperan salida estructurada. La página de Groq para este modelo indica uso de herramientas y modo JSON Schema. Verifica ambos en cualquier otro modelo antes de cambiar.

## Crear clave de API

<Warning>Se requiere una cuenta de Groq Cloud para crear una clave de API.</Warning>

Ve directamente a la [página de claves de API de Groq](https://console.groq.com/keys) para crear una nueva clave de API.

O sigue estos pasos:

1. Ve a la [consola de Groq](https://console.groq.com)
2. Inicia sesión o crea tu cuenta
3. Abre **API Keys**
4. Haz clic en **Create API Key**
5. Dale un nombre como 'Kodus' o cualquier nombre descriptivo
6. Copia la clave de API y guárdala en un lugar seguro

<Info>
  Solo los propietarios del equipo o los usuarios con el rol de desarrollador pueden crear o administrar claves de API en Groq.
</Info>

## Configurar Groq en Kodus

### Opción 1 — Página AI providers (recomendado)

Sigue [Conectar un proveedor](/es/how_to_use/byok#conectar-un-proveedor) y elige **Custom → OpenAI-compatible**. Usa estos valores en el formulario.

| Campo | Valor |
| --- | --- |
| **Key** (en la tarjeta **API key**) | tu clave de API de Groq |
| **Base URL** | `https://api.groq.com/openai/v1` |
| **Model** | `openai/gpt-oss-120b` |
| **Max concurrent requests** | opcional; en **Advanced (optional)**, expande **Advanced settings**; redúcelo si ves errores de límite de velocidad |

Haz clic en **Test & save** y elige el modelo predeterminado y de respaldo en [Routing](/es/how_to_use/code_review/configs/routing).

<Note>
  Usa la URL base sin `/chat/completions`. Define un modelo de otro proveedor como **Fallback model** para que las revisiones sigan funcionando si Groq te aplica un límite de velocidad.
</Note>

### Opción 2 — Alojamiento autónomo (variables de entorno)

Para darle un modelo a una instancia con alojamiento autónomo mediante `.env`:

```env
API_LLM_PROVIDER=openai_compatible
API_LLM_PROVIDER_MODEL="openai/gpt-oss-120b"
API_LLM_BASE_URL="https://api.groq.com/openai/v1"
API_LLM_API_KEY="your-groq-api-key"
```

Sigue la guía de instalación para [aplicar el cambio de modelo](/es/how_to_deploy/deploy_kodus/generic_vm#aplicar-cambios-en-el-modelo).

## Solución de problemas

<AccordionGroup>
  <Accordion title="Problemas con la clave de API">
    - Verifica que tu clave de API sea correcta y esté activa en la [consola de Groq](https://console.groq.com/keys)
    - Comprueba que tu plan de Groq pueda usar el modelo que elegiste
    - Asegúrate de que no haya espacios al final ni comillas en el valor del `.env`
  </Accordion>

  <Accordion title="Modelo no encontrado">
    - Comprueba que el ID del modelo esté escrito exactamente como en la página de modelos de Groq
    - Verifica que el modelo esté en la lista actual de modelos de Groq; los modelos se retiran con el tiempo
    - Groq retiró `llama-3.3-70b-versatile` y `llama-3.1-8b-instant` para los planes Free y Developer el 16 de agosto de 2026. Los contratos Enterprise no se ven afectados. Consulta las [deprecaciones](https://console.groq.com/docs/deprecations) de Groq
  </Accordion>

  <Accordion title="Errores de conexión">
    - Verifica que tu servidor tenga acceso a internet para alcanzar `api.groq.com`
    - Comprueba si hay restricciones de firewall
    - Revisa los registros de la API y del worker para ver el error upstream exacto
  </Accordion>

  <Accordion title="Límite de velocidad">
    - Groq devuelve HTTP 429 cuando se excede un límite, y los límites dependen de tu plan
    - Consulta los límites exactos de tu organización en la página Limits de tu cuenta de Groq ([console.groq.com/settings/limits](https://console.groq.com/settings/limits)) y en la [documentación de límites de velocidad de Groq](https://console.groq.com/docs/rate-limits)
    - Reduce **Max concurrent requests** en el modelo, o mejora tu plan
  </Accordion>
</AccordionGroup>
