## Cómo funciona Fireworks AI

Fireworks AI es una plataforma de inferencia que sirve modelos populares de código abierto, como DeepSeek, Kimi, GLM y Qwen, a través de una API **compatible con OpenAI**. Kodus se comunica con ella mediante el proveedor compatible con OpenAI, por lo que no hay cambios de código, solo credenciales BYOK.

## Modelos recomendados

<Info>
  El catálogo de Fireworks cambia con frecuencia. Consulta la [biblioteca de modelos de Fireworks](https://fireworks.ai/models) para ver los modelos, ventanas de contexto y precios actuales.
</Info>

Los IDs de modelo de Fireworks tienen la forma `accounts/fireworks/models/<model>` y escriben una versión con una `p`: GLM 5.3 es `glm-5p3`. Copia el ID desde la página del modelo en la biblioteca.

| ID del modelo | Ventana de contexto |
| ------------- | ------------------- |
| `accounts/fireworks/models/glm-5p3` | 1,048,576 tokens |

Los agentes de revisión de Kodus llaman a herramientas y esperan salida estructurada. Elige un modelo que admita function calling, algo que indica la página del modelo.

## Crear clave de API

<Warning>Se requiere una cuenta de Fireworks AI para crear una clave de API.</Warning>

1. Inicia sesión en [app.fireworks.ai](https://app.fireworks.ai), o crea una cuenta.
2. Abre la página de claves de API: [app.fireworks.ai/settings/users/api-keys](https://app.fireworks.ai/settings/users/api-keys).
3. Haz clic en **Create API key**.
4. Copia la clave y guárdala en un lugar seguro. Fireworks no vuelve a mostrarla.

## Configurar Fireworks AI en Kodus

### Opción 1 — Página AI providers (recomendado)

Sigue [Conectar un proveedor](/es/how_to_use/byok#conectar-un-proveedor) y elige **Custom → OpenAI-compatible**. Usa estos valores en el formulario.

| Campo | Valor |
| --- | --- |
| **Base URL** | `https://api.fireworks.ai/inference/v1` |
| **Model** | p. ej., `accounts/fireworks/models/glm-5p3` |
| **API key** | tu clave de API de Fireworks |
| **Max concurrent requests** | opcional; redúcelo si ves errores de límite de velocidad (en **Advanced (optional)**) |

Haz clic en **Test & save** y elige el modelo predeterminado y de respaldo en [Routing](/es/how_to_use/code_review/configs/routing).

<Note>
  Usa la URL base sin `/chat/completions`. En **Code review → Routing**, define un modelo de otro proveedor como **Fallback model** para que las revisiones sigan funcionando si Fireworks falla.
</Note>

### Opción 2 — Alojamiento autónomo (variables de entorno)

Para darle un modelo a una instancia con alojamiento autónomo mediante `.env`:

```env
API_LLM_PROVIDER=openai_compatible
API_LLM_PROVIDER_MODEL="accounts/fireworks/models/glm-5p3"
API_LLM_BASE_URL="https://api.fireworks.ai/inference/v1"
API_LLM_API_KEY="your-fireworks-api-key"
```

Sigue la guía de instalación para [aplicar el cambio de modelo](/es/how_to_deploy/deploy_kodus/generic_vm#aplicar-cambios-en-el-modelo).

## Solución de problemas

<AccordionGroup>
  <Accordion title="Problemas con la clave de API">
    - Verifica que tu clave de API sea correcta y esté activa en la [consola de Fireworks AI](https://app.fireworks.ai)
    - Comprueba si tienes créditos suficientes en tu cuenta de Fireworks AI
    - Asegúrate de que no haya espacios al final ni comillas en el valor del `.env`
  </Accordion>

  <Accordion title="Modelo no encontrado">
    - Usa el ID completo `accounts/fireworks/models/<model>`, escrito como aparece en la biblioteca de modelos
    - Verifica que el modelo esté disponible para inferencia serverless; algunos modelos necesitan un despliegue dedicado
  </Accordion>

  <Accordion title="Errores de conexión">
    - Verifica que tu servidor tenga acceso a internet para alcanzar `api.fireworks.ai`
    - Comprueba si hay restricciones de firewall
    - Revisa los registros de la API y del worker para ver el error upstream exacto
  </Accordion>

  <Accordion title="Límite de velocidad">
    - Comprueba tu uso actual en el panel de Fireworks AI
    - Una cuenta sin método de pago ni créditos tiene un límite de solicitudes mucho menor. Consulta los [límites de velocidad](https://docs.fireworks.ai/guides/quotas_usage/rate-limits) de Fireworks
    - Reduce **Max concurrent requests** en el modelo, o considera un despliegue dedicado para mayor rendimiento
  </Accordion>
</AccordionGroup>
