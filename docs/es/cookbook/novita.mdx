## Cómo funciona Novita

Novita es una plataforma de inferencia sin servidor que aloja modelos de código abierto, como DeepSeek, Kimi, GLM, MiniMax y Qwen, detrás de una API **compatible con OpenAI**. Kodus tiene un proveedor dedicado **Novita**, así que solo necesitas una clave de API.

## Modelos recomendados

<Info>
  Consulta la [lista de modelos de Novita](https://novita.ai/models/llm) para ver los modelos y precios actuales. La lista en `https://api.novita.ai/openai/v1/models` es pública y muestra el tamaño de contexto y las funciones de cada modelo.
</Info>

Los IDs de modelo de Novita son cadenas `org/model`, en su mayoría en minúsculas. Estos modelos figuran en el catálogo de Novita con function calling y salidas estructuradas:

| ID del modelo | Ventana de contexto |
| ------------- | ------------------- |
| `deepseek/deepseek-v4-pro` | ~1M tokens |
| `moonshotai/kimi-k3` | ~1M tokens |
| `zai-org/glm-5.3` | ~1M tokens |
| `minimax/minimax-m3` | ~1M tokens |
| `qwen/qwen3.8-27b` | ~1M tokens |

## Crear clave de API

<Warning>Se requiere una cuenta de Novita para crear una clave de API.</Warning>

1. Abre [**Key Management**](https://novita.ai/settings/key-management) en la consola de Novita.
2. Selecciona **Create API Key** y ponle un nombre, por ejemplo `kodus`.
3. Elige una caducidad: **Permanent**, 90 días, 30 días o 24 horas. No puedes cambiarla después, y Novita rechaza una clave caducada.
4. Copia la clave. Novita la muestra completa una sola vez.

## Configurar Novita en Kodus

### Opción 1 — Página AI providers (recomendado)

Este flujo es el mismo en Kodus Cloud y en una instancia con alojamiento autónomo.

<Steps>
  <Step title="Abrir AI providers y elegir Novita">
    En la barra lateral, abre **AI providers** ([app.kodus.io/byok](https://app.kodus.io/byok) en Cloud, `/byok` en tu propia instancia). En la pestaña **Providers**, haz clic en el mosaico **Novita**. Está en **Connect your first provider**, o después de **Add another provider** si ya conectaste uno.
  </Step>

  <Step title="Pegar tu clave de API y elegir el modelo">
    Pega tu clave de Novita en el campo **Key** de la tarjeta **API key**. Deja **Base URL (optional)** vacío: Kodus llama entonces a `https://api.novita.ai/v3/openai`. En la tarjeta **Model**, elige un modelo de la lista, o elige **Type model manually**.
  </Step>

  <Step title="Test & save">
    Haz clic en **Test & save**. Kodus envía una solicitud de un token al modelo y guarda la configuración si tiene éxito.
  </Step>
</Steps>

Luego abre **Code review → Routing** (el botón **Configure routing** de la página **AI providers** lo abre). En la tarjeta **Models**, define el modelo de Novita como **Default model** y un modelo de otro proveedor conectado, como OpenAI o Anthropic, como **Fallback model**, para que las revisiones sigan funcionando si Novita no está disponible. Haz clic en **Save settings**.

### Opción 2 — Alojamiento autónomo (variables de entorno)

En una instancia autohospedada, selecciona el proveedor compatible con OpenAI en `.env` y usa la misma URL base que el proveedor Novita integrado.

```env
API_LLM_PROVIDER=openai_compatible
API_LLM_PROVIDER_MODEL="deepseek/deepseek-v4-pro"
API_LLM_BASE_URL="https://api.novita.ai/v3/openai"
API_LLM_API_KEY="your-novita-api-key"
```

Sigue la guía de instalación para [aplicar el cambio de modelo](/es/how_to_deploy/deploy_kodus/generic_vm#aplicar-cambios-en-el-modelo).

## Solución de problemas

<AccordionGroup>
  <Accordion title="Problemas con la clave de API">
    - Verifica que tu clave de API sea correcta y esté activa en la [consola de Novita](https://novita.ai/settings/key-management)
    - Comprueba si tienes créditos suficientes en tu cuenta de Novita
    - Asegúrate de que no haya espacios al final ni comillas en el valor del `.env`
  </Accordion>

  <Accordion title="Modelo no encontrado">
    - Los IDs de modelo son cadenas `org/model`, y unos pocos contienen mayúsculas. Copia el ID exacto de la lista de modelos de Novita
    - Comprueba que el modelo siga en la lista de `https://api.novita.ai/openai/v1/models`
  </Accordion>

  <Accordion title="Errores de conexión">
    - Verifica que tu servidor tenga acceso a internet para alcanzar `api.novita.ai`
    - Comprueba si hay restricciones de firewall
    - Revisa los registros de la API y del worker para ver el error upstream exacto
  </Accordion>
</AccordionGroup>
