## Cómo funciona Chutes

Chutes AI es una plataforma de cómputo sin servidor descentralizada para modelos de código abierto. Expone un endpoint de inferencia **compatible con OpenAI** en `https://llm.chutes.ai/v1`. El uso se factura por token contra el saldo de tu cuenta.

Kodus se comunica con Chutes a través del mismo adaptador compatible con OpenAI que usa para todo lo demás, por lo que no hay cambios de código, solo credenciales BYOK.

<Info>
  Los precios y las condiciones de facturación cambian. Confirma siempre en [chutes.ai/pricing](https://chutes.ai/pricing) antes de cargar saldo en una cuenta.
</Info>

### Modelos recomendados

Chutes usa identificadores estilo HuggingFace `org/model`. Muchos terminan en `-TEE`, pero lo que indica si un modelo se ejecuta en un entorno de ejecución confiable (TEE) es el indicador `confidential_compute` del catálogo, no el nombre. Estos modelos figuran en el catálogo con llamadas a herramientas y salidas estructuradas:

| ID del modelo | Ventana de contexto |
| ------------- | ------------------- |
| `moonshotai/Kimi-K2.7-Code` | ~262k tokens |
| `deepseek-ai/DeepSeek-V4-Pro-0813` | ~1M tokens |
| `zai-org/GLM-5.3` | ~1M tokens |
| `Qwen/Qwen3.5-397B-A17B-TEE` | ~262k tokens |

El catálogo cambia con frecuencia. Consulta la lista en vivo en [llm.chutes.ai/v1/models](https://llm.chutes.ai/v1/models), que es pública y muestra el precio, la longitud de contexto y las funciones compatibles de cada modelo.

## Crear una clave de API

<Warning>Se requiere una cuenta de Chutes con saldo cargado.</Warning>

1. Crea una cuenta en [chutes.ai/auth/signup](https://chutes.ai/auth/signup). Puedes registrarte con Google, GitHub o un nombre de usuario.
2. Carga saldo en la app de Chutes. La facturación es de pago por uso, sin compromiso mínimo, y las opciones de pago están en [chutes.ai/pricing](https://chutes.ai/pricing).
3. En la app de Chutes, crea una clave de API. Las claves empiezan con `cpk_`. Guárdala como una contraseña.

## Configurar Chutes en Kodus

### Opción 1 — Página AI providers (recomendado)

Sigue [Conectar un proveedor](/es/how_to_use/byok#conectar-un-proveedor) y elige **Custom → OpenAI-compatible**. Usa estos valores en el formulario.

| Campo | Valor |
| --- | --- |
| **Key** (en la tarjeta **API key**) | tu clave de API de Chutes |
| **Base URL** | `https://llm.chutes.ai/v1` |
| **Model** | elige de la lista, o escribe un ID como `zai-org/GLM-5.3` |
| **Max concurrent requests** | opcional; en **Advanced (optional)** → **Advanced settings**. Déjalo vacío, o define un tope si Chutes devuelve errores de límite de velocidad |

Haz clic en **Test & save** y elige el modelo predeterminado y de respaldo en [Routing](/es/how_to_use/code_review/configs/routing).

<Note>
  Define un modelo de otro proveedor como **Fallback model**, para que las revisiones sigan funcionando si Chutes devuelve errores o tu saldo se agota.
</Note>

### Opción 2 — Alojamiento autónomo (variables de entorno)

Para darle un modelo a una instancia con alojamiento autónomo mediante `.env`:

```env
API_LLM_PROVIDER=openai_compatible
API_LLM_PROVIDER_MODEL="zai-org/GLM-5.3"
API_LLM_BASE_URL="https://llm.chutes.ai/v1"
API_LLM_API_KEY="your-chutes-api-key"
```

Sigue la guía de instalación para [aplicar el cambio de modelo](/es/how_to_deploy/deploy_kodus/generic_vm#aplicar-cambios-en-el-modelo).

## Cuándo elegir Chutes

- **Quieres modelos de código abierto detrás de un solo endpoint**, incluidos DeepSeek, Kimi, GLM y Qwen.
- **Te importa el cómputo confidencial.** Los modelos marcados con `confidential_compute: true` en el catálogo se ejecutan dentro de entornos de ejecución confiables, útil si tu postura de cumplimiento lo requiere.

Elige Synthetic si prefieres una suscripción plana, o Z.AI si tu modelo preferido es específicamente la familia GLM.

## Solución de problemas

<AccordionGroup>
  <Accordion title="Errores 401 / de autenticación">
    - Confirma que la clave esté activa en el panel de Chutes y que la cuenta tenga saldo.
    - Asegúrate de que no haya espacios al final ni comillas en el valor del `.env`.
  </Accordion>

  <Accordion title="Modelo no encontrado">
    - Chutes usa el formato `org/model`, y algunas variantes terminan en `-TEE`. Copia el ID exacto, con sus mayúsculas y minúsculas, de [llm.chutes.ai/v1/models](https://llm.chutes.ai/v1/models).
    - Los modelos se agregan y se retiran con el tiempo. Un ID de modelo que funcionaba antes puede desaparecer de la lista.
  </Accordion>

  <Accordion title="Respuestas lentas o errores de límite de velocidad">
    - Define un modelo de otro proveedor como **Fallback model** en **Code review → Routing**.
    - Reduce **Max concurrent requests** en **Advanced (optional)** → **Advanced settings**.
  </Accordion>

  <Accordion title="Errores de conexión">
    - Confirma que tu servidor pueda alcanzar `llm.chutes.ai`.
    - Revisa los registros de la API y del worker para ver el error upstream exacto.
  </Accordion>
</AccordionGroup>
