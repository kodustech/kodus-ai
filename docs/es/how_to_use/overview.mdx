## Qué es Kodus

**Kody** revisa pull requests en GitHub, GitLab, Bitbucket, Azure Repos y Forgejo. Comprueba los cambios con las reglas de tu equipo. Kodus es de código abierto y puede ejecutarse en tu propia infraestructura.

## Qué hace Kodus

- [Entiende el resultado de una revisión](/es/how_to_use/code_review/flow#qué-recibes). Descubre qué publica Kody en el PR y cómo solicitar otra revisión.
- [Ajusta lo que comprueba Kody](/es/how_to_use/code_review/configs/what_to_review). Elige las categorías, la gravedad mínima y qué debe comprobar Kody.
- [Enseña a Kody las reglas de tu equipo](/es/how_to_use/code_review/configs/kody_rules). Usa reglas y memorias para aplicar las convenciones del equipo en las revisiones.
- [Comprueba el PR frente a su tarea](/es/how_to_use/code_review/business_logic_validation). Compara la implementación con los requisitos de tu gestor de tareas.

## Lenguajes Compatibles

Kody funciona con cualquier lenguaje de programación o tipo de archivo de forma inmediata usando análisis semántico (LLM), respaldado por búsqueda de código (estilo grep) para un contexto preciso a nivel de repositorio.
