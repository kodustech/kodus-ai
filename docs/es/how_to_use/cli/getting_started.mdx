Esta guía te lleva de cero a un diff revisado en menos de cinco minutos.

<Steps>
  <Step title="Instalar">
    <Tabs>
      <Tab title="Instalador de Skills (Recomendado)">
        Instala o actualiza el CLI y luego instala los skills de Kodus en los agentes de IA que encuentre en tu máquina (Claude Code, Cursor, Codex y otros — consulta [Agentes de IA](/es/how_to_use/cli/ai_agents)).

        macOS y Linux:

        ```bash
        curl -fsSL https://review-skill.com/install | bash
        ```

        Windows PowerShell:

        ```powershell
        powershell -NoProfile -ExecutionPolicy Bypass -Command "$tmp = Join-Path $env:TEMP 'kodus-install.ps1'; Invoke-WebRequest https://review-skill.com/install.ps1 -OutFile $tmp; & $tmp"
        ```
      </Tab>
      <Tab title="npm">
        ```bash
        npm install -g @kodus/cli
        ```

        `pnpm add -g @kodus/cli`, `yarn global add @kodus/cli` y `bun add -g @kodus/cli` funcionan igual.
      </Tab>
      <Tab title="npx (Sin Instalación)">
        ```bash
        npx @kodus/cli review
        ```
      </Tab>
    </Tabs>

    <Note>Requiere Node.js 22.19.0 o posterior.</Note>

    Verifica la instalación:

    ```bash
    kodus --version
    kodus status
    ```
  </Step>

  <Step title="Autenticarse">
    Elige la opción que se adapte a tu situación. También puedes omitir la autenticación y ejecutar `kodus review` directamente: funciona en modo de prueba con límites por hora.

    <Tabs>
      <Tab title="Desarrollador individual">
        Inicia sesión con una cuenta personal:

        ```bash
        kodus auth login
        ```

        El CLI abre la página **Authorize Kodus CLI** en tu navegador e imprime su URL por si el navegador no se abre. Verifica los detalles de **Device**, **Mode** y **Expires**, haz clic en **Authorize CLI** y luego vuelve a la terminal.

        Si no has iniciado sesión en Kodus en ese navegador, primero llegas a la página de inicio de sesión y, tras iniciar sesión, al dashboard. Abre de nuevo la URL de la terminal para llegar a **Authorize CLI**. El CLI espera hasta 10 minutos.

        En una máquina sin navegador, ejecuta `kodus auth login --device-code` en una terminal privada. El CLI muestra la página de autorización (`https://app.kodus.io/cli/authorize` en Kodus Cloud) y un código de un solo uso. En la barra de direcciones del navegador, añade el código a la URL como parámetro `code` y haz clic en **Authorize CLI**. El código caduca a los 10 minutos. Mantén el código y el enlace completo fuera de los registros y los mensajes compartidos. Para CI, guarda una clave de equipo como secreto `KODUS_TEAM_KEY`.

        Tu inicio de sesión se almacena en `~/.kodus/credentials.json` y se actualiza automáticamente.
      </Tab>
      <Tab title="Equipo (clave compartida)">
        Un owner de la organización genera una clave de equipo en la barra lateral, en **Organization → CLI keys** (<a href="https://app.kodus.io/organization/cli-keys" target="_blank">app.kodus.io/organization/cli-keys</a>).

        Define la clave como variable de entorno `KODUS_TEAM_KEY` en la terminal donde ejecutas el CLI. Ejecuta `kodus status` para confirmar que el CLI detecta la clave.

        <Warning>Guarda la clave cuando se muestre — no se volverá a mostrar.</Warning>
      </Tab>
      <Tab title="Agente de IA">
        Para agentes de programación de IA (Claude Code, Cursor, Codex), las claves de equipo son la opción recomendada: sin inicio de sesión individual, sin indicaciones interactivas. Establece la clave una sola vez:

        ```bash
        export KODUS_TEAM_KEY=kodus_xxxxx
        ```

        Agrégala a tu perfil de shell para que el agente la recoja en cada ejecución.
      </Tab>
      <Tab title="CI/CD">
        Usa una clave de equipo. Guárdala como secreto y exponla al job como `KODUS_TEAM_KEY`:

        ```bash
        export KODUS_TEAM_KEY=kodus_xxxxx
        ```

        Consulta [Configuración Self-Hosted](/es/how_to_use/cli/self_hosted#integración-con-ci/cd) para ver ejemplos de GitHub Actions, GitLab CI y pipelines genéricos.
      </Tab>
    </Tabs>

    <Info>
      **¿Usas Kodus auto-alojado?** Apunta el CLI a tu API antes de autenticarte:

      ```bash
      export KODUS_API_URL=https://kodus-api.yourcompany.com
      ```

      Se requiere HTTPS excepto para `localhost`.
    </Info>

    Confirma el estado de autenticación:

    ```bash
    kodus auth status
    ```
  </Step>

  <Step title="Ejecutar tu primera revisión">
    Dentro de cualquier repositorio git con cambios no confirmados:

    ```bash
    kodus review
    ```

    El CLI analiza el diff de tu árbol de trabajo e imprime un resumen. En una terminal interactiva de macOS y Linux, los hallazgos se abren en el visor de diff Hunk, junto al código. En Windows, o con `--no-hunk`, navegas una lista archivo por archivo, previsualizas las correcciones sugeridas y las aplicas.

    Variaciones comunes:

    ```bash
    kodus review --staged             # Only staged files
    kodus review --branch main        # Compare current branch against main
    kodus review --commit abc123      # Analyze a single commit
    kodus review --fix                # Apply every fixable issue (asks to confirm)
    kodus review --prompt-only        # Compact output for AI agents
    kodus review --fail-on error      # Exit 1 on error-or-worse issues (CI-friendly)
    ```

    <Tip>
      Con un inicio de sesión o una clave de equipo, las revisiones del árbol de trabajo (predeterminado) y `--staged` envían el contenido de los archivos modificados junto con el diff. `--branch`, `--commit` y `--fast` envían solo el diff, ya que el backend puede leer esos commits por sí mismo. Por eso funcionan bien en ramas enormes. Las revisiones de prueba siempre envían solo el diff.
    </Tip>

    <Note>
      Solo se revisan los cambios rastreados. Ejecuta `git add` en un archivo nuevo para incluirlo.
    </Note>
  </Step>

  <Step title="Elegir los siguientes pasos">
    Según tu objetivo:

    <CardGroup cols={2}>
      <Card title="Automatizar en cada envío" icon="shield-check" href="/es/how_to_use/cli/commands#kodus-hook">
        Instala el hook pre-push con `kodus hook install`. Revisa la rama que envías y bloquea el envío si hay hallazgos críticos.
      </Card>
      <Card title="Ejecutar revisiones en CI" icon="infinity" href="/es/how_to_use/cli/self_hosted#integración-con-ci/cd">
        Ejemplos de GitHub Actions, GitLab CI y pipelines genéricos.
      </Card>
      <Card title="Conectar con un agente de IA" icon="robot" href="/es/how_to_use/cli/ai_agents">
        Alimenta `--prompt-only` en Claude Code, Cursor o Codex para bucles de corrección autónomos.
      </Card>
      <Card title="Configurar el repositorio" icon="sliders" href="/es/how_to_use/cli/commands#kodus-config-remote">
        Lee y cambia la configuración de revisión desde el CLI.
      </Card>
    </CardGroup>
  </Step>
</Steps>

## Variables de Entorno

Estas variables de entorno configuran el CLI en todos los comandos.

| Variable                     | Descripción                                                                        |
| ---------------------------- | ---------------------------------------------------------------------------------- |
| `KODUS_API_URL`              | Endpoint de la API (predeterminado: `https://api.kodus.io`)                        |
| `KODUS_APP_URL`              | URL de la aplicación web a la que apunta `kodus config remote open` (predeterminado: `https://app.kodus.io`) |
| `KODUS_TEAM_KEY`             | Clave de equipo para acceso compartido y agentes de IA                             |
| `KODUS_TOKEN`                | Un token de acceso de inicio de sesión, usado tal cual y sin actualizarse. Tiene prioridad sobre cualquier otra credencial. Para CI, usa una clave de equipo |
| `KODUS_GITHUB_PAT`           | Token de GitHub para revisiones de prueba de repositorios privados. También se leen `GITHUB_TOKEN` y `GH_TOKEN` |
| `KODUS_SKIP_HOOK`            | Establécelo en cualquier valor para omitir el hook pre-push en un solo `git push`  |
| `KODUS_REQUEST_TIMEOUT_MIN`  | Tiempo de espera de cada solicitud a la API en minutos (predeterminado: `60`)      |
| `KODUS_DISABLE_UPDATE_CHECK` | Establécelo en `1` para desactivar el aviso de actualización                       |
| `CF_ACCESS_CLIENT_ID`        | ID de cliente de Cloudflare Access (APIs detrás de Zero Trust)                     |
| `CF_ACCESS_CLIENT_SECRET`    | Secreto de cliente de Cloudflare Access                                            |

Para configuraciones auto-alojadas y Cloudflare Access, consulta [Configuración Self-Hosted](/es/how_to_use/cli/self_hosted).
