Las Fuentes Globales de Reglas te permiten apuntar Kodus a uno o más repositorios conectados e importar sus archivos de reglas como Kody Rules **globales**. A diferencia de las [Reglas de Repositorio](/es/how_to_use/code_review/configs/repository_rules), que solo se aplican al repositorio donde viven, las reglas importadas desde una fuente global se aplican a **todos** los repositorios durante la revisión de código.

Úsalo cuando un equipo mantiene sus estándares de arquitectura y código en un repositorio dedicado de "standards" y quiere que se apliquen en todas partes, sin copiar archivos de reglas a cada proyecto.

## Cómo funciona

- Seleccionas repositorios conectados para que actúen como **fuentes**.
- Kodus escanea la rama predeterminada de cada repositorio fuente en busca de archivos de reglas, en las mismas ubicaciones y con la misma plantilla que las [Reglas de Repositorio](/es/how_to_use/code_review/configs/repository_rules) (`.kody/rules/`, `rules/**/*.md`, etc.).
- Cada archivo de reglas se convierte en una regla global, que se muestra en la página global **Kody Rules** con el archivo del que proviene.
- Durante la revisión de código de cualquier repositorio, estas reglas globales se aplican junto con las reglas propias de ese repositorio, sujetas a la [herencia](/es/how_to_use/code_review/configs/rules_inheritance).
- Las instrucciones escritas para agentes de programación (`CLAUDE.md`, `AGENTS.md`, `.cursor/rules/**`) no se importan. Las reglas globales importadas desde ellas en el pasado se conservan pero quedan congeladas; consulta [Instrucciones para Agentes de Código](/es/how_to_use/code_review/configs/rules_file_detection).

<Info>
Solo los repositorios ya conectados en la página **Repositories** pueden ser fuentes, de modo que las reglas importadas se mantengan al día mediante el disparador de pull request descrito abajo.
</Info>

## Configuración

1. En la barra lateral, elige **Global** en el selector de alcance en la parte superior del grupo **Code review** y luego abre **Kody Rules**.
2. Haz clic en **Configuration** para abrir el panel lateral y busca **Global rule sources**.
3. Haz clic en el selector de repositorios y elige uno o más repositorios conectados.
4. Haz clic en **Import selected**.

La importación se ejecuta en segundo plano. Al terminar, las reglas importadas aparecen en tu lista de Kody Rules globales. Un repositorio que elegiste pero aún no importaste muestra **Not imported yet**.

## Mantener las reglas al día

- **Al hacer merge:** cuando se fusiona un pull request en un repositorio fuente, sus archivos de reglas se vuelven a escanear y las reglas globales se actualizan. Los archivos sin cambios se omiten.
- **Resync now:** vuelve a escanear todas las fuentes bajo demanda. Úsalo tras un push directo a la rama predeterminada de un repositorio fuente, que no se detecta automáticamente.

## Eliminar una fuente

Eliminar un repositorio de la lista **borra las reglas globales importadas desde él**, así que dejan de aplicarse durante la revisión de código. Se te pide confirmación antes. Las reglas de tus otras fuentes, y las reglas que escribiste a mano, no se ven afectadas.

## Los repositorios fuente no se revisan

Un repositorio usado como fuente de reglas globales se trata como repositorio de configuración, no como base de código. Kodus **omite la revisión de código** en los pull requests abiertos en él, igual que hace con un repositorio de [configuración centralizada](/es/how_to_use/code_review/configs/centralized_config).

## Disponibilidad por plan

| Plan | Acceso |
|------|--------|
| **Free**, self-hosted sin una clave de licencia válida, o un plan cancelado o vencido | No disponible. |
| **Trial** | Hasta **5 reglas globales en total**, sumando todos los repositorios fuente. Solo se importan las 5 primeras reglas encontradas; alcanzado el límite, no se importa nada más hasta que elimines algunas o hagas upgrade. |
| **De pago** (cloud) y **self-hosted con licencia** | Ilimitado. |

En el plan Trial, un contador muestra cuántas de las 5 reglas están usadas, y un diálogo de confirmación indica cuántas más se añadirán antes de importar.

## Relacionados

- [Reglas de Repositorio](/es/how_to_use/code_review/configs/repository_rules): las ubicaciones y la plantilla de los archivos de reglas que Kodus importa.
- [Herencia de Reglas](/es/how_to_use/code_review/configs/rules_inheritance): cómo se combinan las reglas globales, de repositorio y de directorio durante la revisión.
