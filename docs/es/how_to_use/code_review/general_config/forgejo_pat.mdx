## Introducción

Para habilitar a Kody a realizar revisiones de código automáticas en Forgejo, necesitas generar un **Access Token**. Este token permite que Kody acceda a tus repositorios, pull requests, webhooks, issues, etc., con los permisos específicos listados a continuación.

---

## Generar el Access Token en Forgejo

1. Accede a tu instancia de Forgejo y haz clic en el ícono de avatar en la esquina superior derecha
2. Selecciona **Settings**
3. Navega a **Applications**
4. En **Generate New Token**, asígnale un nombre (por ejemplo `kodus_code_review`)
5. Selecciona los permisos requeridos (ver abajo)
6. Haz clic en **Generate Token**
7. **Copia** el token inmediatamente y guárdalo de forma segura — no podrás verlo nuevamente después de cerrar la página

---

## Permisos Requeridos para Kody

El token debe incluir **todos** los siguientes permisos para funcionar correctamente con Kody:

| Categoría | Nivel | Propósito |
|----------|-------|---------|
| `repository` | **Read & Write** | Acceder al código, ramas y archivos, crear comentarios en PRs y gestionar webhooks |
| `issue` | **Read & Write** | Leer y publicar comentarios y reacciones en los pull requests |
| `organization` | **Read** | Listar las organizaciones a las que pertenece el usuario del token y sus repositorios |
| `user` | **Read** | Leer información básica del usuario, necesaria para la autenticación |

El usuario del token también debe ser **admin de cada repositorio** que Kody revisa. Forgejo solo permite que un admin del repositorio cree webhooks y descarte revisiones; sin eso, Kody no puede registrar el webhook automáticamente ni retirar su aprobación cuando una revisión posterior la retiene.

---

## Agregar el Token a Kody

Pega el token generado en Kodus: durante el onboarding (**Connect your Git tool** → pestaña **Forgejo** → **Connect via token**), o más tarde en la barra lateral en **Repositories** → **Connect a provider** → **Forgejo**. Completa **Forgejo Instance URL** y **Personal Access Token**, y luego haz clic en **Validate and save**.

Para reemplazar un token más adelante, haz clic en **Update token** en la tarjeta de **Forgejo** en **Repositories**, pega el nuevo token y haz clic en **Update token**.

---

## Notas Importantes

- El token se **muestra solo una vez** después de la creación. Guárdalo de forma segura.
- Si el token se ve comprometido, revócalo inmediatamente y crea uno nuevo.
- Audita periódicamente los tokens y sus permisos para confirmar que aún son necesarios.
