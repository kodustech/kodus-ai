Si ya tienes reglas definidas en Cursor, GitHub Copilot, Claude u otras herramientas de codificación con IA, puedes importarlas a Kodus para que las mismas convenciones se apliquen durante la revisión de código.

## Cómo funciona

Kodus detecta archivos de reglas en tu repositorio y los sincroniza como Kody Rules. Los formatos de archivo compatibles incluyen:

- `.cursorrules` (Cursor)
- `.github/copilot-instructions.md` (GitHub Copilot)
- `CLAUDE.md` (Claude)
- Otros archivos de configuración de herramientas de IA

## Configuración

1. Selecciona el repositorio en el selector de alcance en la parte superior del grupo **Code review** de la barra lateral, abre **Kody Rules** y haz clic en **Configuration**
2. Activa **Auto-sync rules from repo**. La primera vez, Kodus pregunta si quieres escanear el repositorio de inmediato (**Sync now**) o usar **Skip initial scan**
3. Kodus importa los archivos de reglas que encuentra como Kody Rules (origen **Auto-sync**) y los mantiene sincronizados a partir de entonces
4. Las reglas importadas se aplican de inmediato durante la revisión de código. Para revisarlas primero, activa **Kody knowledge approval** en la misma hoja de **Configuration**: las reglas importadas esperarán entonces en la sección **Pending review** hasta que las apruebes (**Approve**) o descartes (**Discard**)

## Por qué esto importa

Sin la sincronización, tu IDE y las herramientas de revisión de código aplican estándares diferentes. Un desarrollador que sigue las reglas de Cursor puede que igual reciba una marca durante la revisión por algo que su IDE no detectó — o viceversa.

La importación garantiza **una única fuente de verdad** para los estándares de codificación en todo tu flujo de trabajo.

Para más detalles, consulta [Sincronizar Reglas del IDE](/es/how_to_use/code_review/configs/rules_file_detection).
