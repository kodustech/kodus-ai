Kodus es de código abierto y puede alojarse de forma autónoma en tu propia infraestructura. Esto te da control sobre dónde viven tus datos de revisión, qué proveedor de LLM usan las revisiones y cómo tu proveedor de Git llega a Kodus.

## Opciones de despliegue

### Docker (recomendado)

Despliega Kodus usando Docker Compose en cualquier VM:

1. Clona el repositorio `kodus-installer`
2. Copia `.env.example` a `.env`, genera las claves y completa tus valores
3. Ejecuta `./scripts/install.sh`
4. Ejecuta `./scripts/doctor.sh` para verificar el stack
5. Abre la interfaz web, crea tu cuenta de administrador, conecta un proveedor de LLM (no se ejecuta ninguna revisión sin un modelo) y conecta tu proveedor de Git

El instalador inicia la app web, la API, el servicio de webhooks, el worker, PostgreSQL, MongoDB y RabbitMQ. Las instrucciones paso a paso están en [Desplegar con Docker](/es/how_to_deploy/deploy_kodus/generic_vm).

### Desarrollo local

Para pruebas o contribuciones, usa el [inicio rápido local](/es/how_to_deploy/local_quickstart/orchestrator). Ejecuta todo el stack en tu máquina.

## Conectar tu proveedor de Git

| Proveedor | Conexión |
| --- | --- |
| GitHub | GitHub App que creas tú, o un token. [GitHub App](/es/how_to_deploy/platforms/github/github_app) |
| GitLab | App de OAuth que creas tú, o un token. [GitLab OAuth](/es/how_to_deploy/platforms/gitlab/gitlab_oauth) |
| Bitbucket | API token en Cloud; usuario y contraseña en Data Center (alpha). [Webhooks de Bitbucket](/es/how_to_deploy/platforms/bitbucket/bitbucket_webhook) |
| Azure Repos | Token. [Webhooks de Azure DevOps](/es/how_to_deploy/platforms/azure_devops/azdevops_webhook) |
| Forgejo | Token. El soporte es mantenido por la comunidad. [Webhooks de Forgejo](/es/how_to_deploy/platforms/forgejo/forgejo_webhook) |

## Qué controlas

- **Datos** — los datos de pull requests, sugerencias y ajustes se guardan en tu propio PostgreSQL y MongoDB
- **Proveedor de LLM** — usa cualquier proveedor, o un modelo autoalojado mediante un endpoint compatible con OpenAI
- **Red** — tu proveedor de Git debe llegar al servicio de webhooks (puerto 3332), y Kodus debe llegar a tu proveedor de Git y a tu proveedor de LLM
- **Configuración** — los ajustes viven en tu `.env` y en la app web

Cada instancia envía un heartbeat anónimo por día; consulta [Telemetría Anónima](/es/how_to_deploy/deploy_kodus/telemetry) para inspeccionarlo o desactivarlo.

## Requisitos

- Docker y Docker Compose
- Recursos de cómputo suficientes para los servicios de API y worker
- Un dominio o IP fija a la que pueda llegar tu proveedor de Git, si es un proveedor en la nube como GitHub.com o GitLab.com
- Acceso de red a tu proveedor de Git (GitHub, GitLab, Bitbucket, Azure Repos o Forgejo)

Para la guía de despliegue completa, consulta [Desplegar con Docker](/es/how_to_deploy/deploy_kodus/generic_vm).
