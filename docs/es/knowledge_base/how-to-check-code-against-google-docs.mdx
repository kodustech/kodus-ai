---
title: "Cómo verificar el código contra especificaciones de Google Docs"
description: "Valida la implementación de tu pull request contra especificaciones escritas en Google Docs."
---

Las especificaciones y requisitos de producto a menudo viven en Google Docs. Google Docs no es una fuente de tareas integrada para la Validación de Lógica de Negocio, que lee tareas de Linear, Jira, Notion, Git Issues o un plugin personalizado. Un enlace de Google Docs en el comando no se lee.

Dos formas de verificar un PR contra una especificación de un Google Doc:

## Pega los requisitos en el comando

Copia los requisitos del documento y comenta en tu PR:

```
@kody -v business-logic
## Requirements
1. Users with role "admin" can delete any comment
2. Users can only edit their own comments within 24 hours
3. Deleted comments show "[removed]" placeholder
```

Kody verifica el PR contra el texto que escribiste. No se necesita un tracker, pero el texto debe tener al menos 40 caracteres. El resultado es un comentario en el PR, **Kody · Business Logic**, con cada requisito marcado como **MET**, **PARTIAL**, **MISSING**, **CHECK MANUALLY** o **NOT IN TASK**.

## Mantén los requisitos en una tarea

Copia los requisitos en la descripción de una tarea de tu tracker, bajo un encabezado como `Acceptance criteria`, y nombra la tarea en el título del PR, en la rama o en la descripción. Kody entonces verifica cada PR que referencia la tarea, sin necesidad de un comando. Si los criterios están bajo un encabezado o en un campo personalizado, define **Requirements → Where acceptance criteria live** en los ajustes de Business Logic. Una página de Notion funciona como tarea: pon su URL en el PR.

## Consejos

- Mantén las especificaciones estructuradas, con secciones claras y requisitos numerados.
- Divide los documentos grandes en secciones y verifícalas una a la vez para obtener feedback más enfocado.
- Después de corregir una brecha, comenta `@kody -v business-logic` de nuevo. Se actualiza el mismo comentario.

Para más detalles, consulta [Validación de Lógica de Negocio](/es/how_to_use/code_review/business_logic_validation).
