description: "Configura Linear en Kodus y comprueba un PR contra su issue."

## Cómo conectar

1. En la barra lateral, abre **Plugins** (instalar un plugin requiere el rol Owner)
2. Haz clic en el mosaico de **Linear**
3. Haz clic en **Authenticate with** el plugin y autoriza el acceso a tu espacio de trabajo de Linear (OAuth), o ingresa una clave de API de Linear y haz clic en **Connect**
4. El plugin se instala en cuanto se conecta, con sus herramientas de solo lectura seleccionadas. Para cambiarlas más tarde, ábrelo, edita **Selected tools** y haz clic en **Update Tools**

Mantén seleccionadas estas herramientas, porque Kody lee los issues con ellas: `get_issue`, `get_team`, `list_teams`, `list_issues` y `get_document`. Una herramienta que desactives no se puede usar.

## Qué habilita

### Validación automática de lógica de negocio

Menciona el issue de Linear en el título, la rama o la descripción del PR. Con **Business Logic** activado en **Code review → What to review** (el valor predeterminado), Kody comprueba el PR en la primera revisión. Kody lee el issue, su issue principal, sus sub-issues y los documentos adjuntos.

### Validación bajo demanda

Pega cualquier URL de Linear, o una clave de issue, en un comentario de PR:

```
@kody -v business-logic https://linear.app/your-team/issue/TEAM-123
```

## Qué obtienes

Kody publica un comentario **Kody · Business Logic** con los requisitos comprobados y el código en el que se basa cada resultado. Una nueva comprobación actualiza ese comentario. Consulta la [Validación de lógica de negocio](/es/how_to_use/code_review/business_logic_validation) para ver los estados y las opciones de comprobación.

## Consejos

- Escribe criterios de aceptación claros en tus issues de Linear para la validación más exhaustiva.
- Un requisito entregado por un sub-issue aparece como **CHECK MANUALLY**, nunca como faltante.

## Herramientas del plugin en conversaciones

Kody puede usar el plugin cuando lo mencionas en un comentario de PR. También se puede activar para un [agente personalizado](/es/how_to_use/code_review/custom_agents_knowledge_and_tools#plugins-mcp).
