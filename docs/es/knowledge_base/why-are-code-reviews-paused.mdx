---
title: "Por qué están pausadas mis revisiones de código"
description: "Comprende el comportamiento de pausa automática de Kodus y cómo reanudar las revisiones de código automatizadas."
---

Si Kodus dejó de revisar tus PRs después de funcionar bien antes, probablemente se deba a la característica de **pausa automática**.

## Qué es la pausa automática

La pausa automática previene el spam de revisiones durante el desarrollo activo. Cuando Kodus detecta pushes consecutivos rápidos (por defecto: 3 pushes en 15 minutos), pausa las revisiones en ese PR y publica un comentario "Auto-paused – comment @kody start-review when you're ready.". Los pushes posteriores se omiten hasta que reanudes.

Esto es una característica, no un error — evita inundar los PRs con múltiples revisiones mientras todavía estás haciendo cambios activamente.

## Cómo reanudar

- **Comenta** `@kody start-review` en el PR para reanudar y activar una revisión de inmediato
- **Cambia la cadencia** a "Automático" si siempre quieres revisiones en cada push

## Cambiar el comportamiento

Ve a **Code review → General** → **Enable Automated Code Review** → **Review Cadence**:

| Modo | Comportamiento |
|------|----------------|
| **Automatic** | Revisa cada push — sin pausa (por defecto) |
| **Auto-pause** | Se pausa tras una ráfaga de pushes; ajústalo con **Pushes to trigger pause** y **Time window (minutes)** |
| **Manual** | Solo revisa cuando comentas `@kody start-review` |

Para más detalles, consulta [Configuración General](/es/how_to_use/code_review/configs/general).
