## Pasos

1. **Crea una cuenta** en [kodus.io](https://kodus.io) o [aloja Kodus tú mismo](/es/how_to_deploy/deploy_kodus/generic_vm)
2. **Conecta GitHub** — en el paso **Connect your Git tool** del onboarding, haz clic en **Install Github app** (también puedes conectarlo más tarde desde **Repositories** en la barra lateral: haz clic en **Github** en **Connect a provider** y luego en **Go to OAuth** en la pestaña **OAuth**)
3. **Selecciona repositorios** — elige qué repositorios debe revisar Kodus, o activa [Revisar todos los repositorios](/es/how_to_use/code_review/configs/review_all_repositories) en **Repositories**
4. Abre un pull request en un repositorio seleccionado. Consulta [qué publica Kody y cómo comprobar el estado](/es/how_to_use/code_review/flow).

## Configuración personalizada

Usa [kodus-config.yml](/es/how_to_use/code_review/configs/general#kodus-config-yml) para personalizar la configuración de revisión por repositorio.

## Usar un Personal Access Token

Si no puedes instalar la GitHub App, conéctate en su lugar con un Personal Access Token (PAT) de GitHub. Elige **Connect via token** en el onboarding (o la pestaña **Token** al conectar GitHub en **Repositories**). Las revisiones se publican entonces desde la cuenta del propietario del token, y GitHub Checks/el estado del PR no están disponibles. Kodus crea un webhook en cada repositorio seleccionado; consulta [Crear un Webhook](/es/how_to_deploy/platforms/github/github_webhook) si eso falla.

## Autoalojado

Una instancia autoalojada de Kodus se conecta con una GitHub App que creas tú mismo, o con un token. **Install Github app** necesita las credenciales de la App en tu `.env`: consulta [Configuración de la GitHub App](/es/how_to_deploy/platforms/github/github_app). Para permitir que los usuarios también inicien sesión con GitHub, consulta [GitHub OAuth App](/es/how_to_deploy/platforms/github/github_oauth).

Para la guía de configuración completa, consulta [Inicio Rápido](/es/how_to_use/quickstart).
