### Run the Installation Script

<Tip>
  Looking for more control? Check out our [docker-compose
  file](https://github.com/kodustech/kodus-installer/blob/main/docker-compose.yml)
  for manual deployment options.
</Tip>

Run the script:

```bash
./scripts/install.sh
```

### What the Installer Does

Our installer automates several important steps:

- Checks that Docker and Docker Compose are installed
- Validates the required variables in `.env`
- Creates the Docker networks Kodus uses
- Starts the services with Docker Compose and waits for RabbitMQ and PostgreSQL to be healthy

The `api` container runs the database migrations and seeds when it starts.

When it finishes, the Kodus Web App and the backend services (API, worker, webhooks, and the MCP manager if enabled) are running on your machine.

You can verify your installation by visiting `http://localhost:3000` - you should see the Kodus Web Application interface.

<Warning>
  Code Review features will not work yet unless you complete the reverse proxy
  setup. Without this configuration, external Git providers cannot send webhooks
  to your instance.
</Warning>
