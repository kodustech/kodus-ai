## What is Kodus

**Kody** reviews pull requests on GitHub, GitLab, Bitbucket, Azure Repos and Forgejo. It checks the changes against your team’s rules. Kodus is open source and can run on your own infrastructure.

## What Kodus does

- [Read a review](/en/how_to_use/code_review/flow#what-you-get). Learn what Kody posts to a PR and how to request another review.
- [Tune what Kody checks](/en/how_to_use/code_review/configs/what_to_review). Choose review categories, the minimum severity and where Kody should look.
- [Teach Kody your standards](/en/how_to_use/code_review/configs/kody_rules). Use Kody Rules and memories to apply your team’s conventions across reviews.

## Supported Languages

Kody works with any programming language or file type out of the box using semantic (LLM) analysis, backed by code search (grep-style) for precise, repository-wide context.
