## What is Developer Activity

Developer Activity shows the pull requests each developer opens over time, so you can see workload and activity patterns across the team.

In the Cockpit, it's the **Team Activity** chart on the **Productivity** tab: a table with one row per developer and one column per week (Sunday to Saturday), newest first. Each row shows the developer's total PRs for the range, and each week shows one bar per PR opened.

## How We Calculate It

```
Activity = COUNT(PRs opened) per developer per week
```

- A PR counts on the date it was **opened**, whatever its status today (open, merged or closed). For a PR opened before its repository was connected, and not among the PRs imported at connection, that is the date Kodus first recorded it.
- The developer is the PR author's username on your Git provider. PRs without an author are left out.
- It covers the date range selected at the top of the Cockpit.

Compare it with [PRs by Developer](/en/how_to_use/cockpit/metrics/prs_by_developer), which counts PRs by the date they **closed**.

## Why It Matters

- **Balance workload**: see whether work is spread evenly across the team
- **Track trends**: see how activity changes over time
- **Spot bottlenecks**: find where work piles up on a few people

PR counts say nothing about PR size or difficulty, so read them next to [PR Size](/en/how_to_use/cockpit/metrics/pr_size).
