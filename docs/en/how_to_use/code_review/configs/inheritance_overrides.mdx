## Overview

Kodus configurations work across three levels: **Global**, **Repository**, and **Directory**.

<Note>
The most specific level wins: Directory > Repository > Global
</Note>

```
Global
 ├─ Repository A
 │   ├─ Directory A1
 │   └─ Directory A2
 └─ Repository B
```

## How It Works

Fields inherit from the parent level by default. When you change a field at Global, all repositories and directories without an override update automatically.

<Info>
Overrides are per field. You can override one field and inherit everything else.
</Info>

Once overridden, a field stops following the parent and uses its local value instead.

## In the app

- **Switching levels:** the scope picker at the top of the sidebar's **Code review** group lists **Global** ("applies to every repository"), then every repository Kody reviews, with its directory scopes indented beneath. A repository with no settings of its own is marked **Inherits Global**. Switching scope keeps you on the same page where that page exists at the new scope.
- **Adding a level:** a repository gets its own settings the first time you save a change at its scope. To add a directory scope, pick the repository and choose **Add directory scope** at the bottom of the picker. See [Directory-Level Settings](/en/how_to_use/code_review/configs/directory_level).
- **Seeing overrides:** a numeric pill next to a scope or page in the sidebar counts the settings overridden at that level ("N settings overridden at this level"). On the page, each overridden field shows an **Overridden** badge; its undo button returns the field to inheritance.
- **Removing a level:** the **⋯** menu next to the scope picker has **Delete configuration**, and **Edit directories** for a directory scope. After deleting, a repository uses the Global configuration and a directory's folders use their repository's. A repository's configuration can be deleted only after its directory scopes are removed.

## kodus-config.yml

When **Prefer kodus-config.yml settings** is on for a repository, Kody reads `kodus-config.yml` from the root of the repository's default branch. It applies on top of Global and the repository's own settings, and below any setting a directory scope overrides. See [General](/en/how_to_use/code_review/configs/general#config-priority).

```
Global
 └─ Repository
     └─ kodus-config.yml at the repository root (optional)
         └─ Directory
```

- The root file is the only file Kody reads. It does not read a `kodus-config.yml` inside a folder.
- The root file is read only when the switch is on at the **repository** scope. The switch also appears at directory scope, but it does not change a review.
- Directory scopes take their settings from the app or from a [centralized config](/en/how_to_use/code_review/configs/centralized_config) repository, which writes into the same Global, repository and directory settings.
- The directory level applies only when the pull request touches exactly one directory scope. See [Directory-Level Settings](/en/how_to_use/code_review/configs/directory_level#selection-rules).

## Examples

<Tabs>
  <Tab title="Global change propagates">
    You change **Minimum severity to post** (on **What to review**) at Global.
    
    All repositories and directories without an override update automatically. Overridden ones stay unchanged.
  </Tab>

  <Tab title="Repository override">
    In Repository X, you override the **Review starts** message (on **What Kody writes → Comments during the review**).
    
    Directories within Repository X now inherit from Repository X (unless they have their own override).
  </Tab>

  <Tab title="Return to inheritance">
    In Repository Y, you remove the override for the category switches on **What to review**.
    
    The field follows Global again and receives future Global changes.
  </Tab>
</Tabs>

## Best Practices

- Start at Global with strong defaults
- Only override when you have a specific need for that repo/directory

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="If I change something at Global, will it break my local adjustments?">
    No. Local overrides stay unchanged.
  </Accordion>

  <Accordion title="Can I override just one field and inherit the rest?">
    Yes. Overrides are per field.
  </Accordion>

  <Accordion title="Does a Directory inherit from Repository or Global?">
    From Repository first, including the repository's `kodus-config.yml` when it is preferred. If Repository has no override for that field, it inherits from Global.
  </Accordion>
</AccordionGroup>
