## How Fireworks AI works

Fireworks AI is an inference platform that serves popular open-source models, such as DeepSeek, Kimi, GLM and Qwen, through an **OpenAI-compatible** API. Kodus talks to it through the OpenAI-compatible provider, so there are no code changes, only BYOK credentials.

## Recommended Models

<Info>
  Fireworks' catalog changes often. See the [Fireworks model library](https://fireworks.ai/models) for current models, context windows and pricing.
</Info>

Fireworks model IDs have the form `accounts/fireworks/models/<model>`, and spell a version with a `p`: GLM 5.3 is `glm-5p3`. Copy the ID from the model's page in the library.

| Model ID | Context Window |
| -------- | -------------- |
| `accounts/fireworks/models/glm-5p3` | 1,048,576 tokens |

Kodus review agents call tools and expect structured output. Pick a model that supports function calling, which the model page states.

## Creating API Key

<Warning>Fireworks AI Account is required to create API Key.</Warning>

1. Sign in at [app.fireworks.ai](https://app.fireworks.ai), or create an account.
2. Open the API keys page: [app.fireworks.ai/settings/users/api-keys](https://app.fireworks.ai/settings/users/api-keys).
3. Click **Create API key**.
4. Copy the key and store it somewhere safe. Fireworks does not show it again.

## Configure Fireworks AI in Kodus

### Option 1 — AI providers page (recommended)

Follow [Connect a provider](/en/how_to_use/byok#connect-a-provider) and choose **Custom → OpenAI-compatible**. Use these values in the form.

| Field | Value |
| --- | --- |
| **Base URL** | `https://api.fireworks.ai/inference/v1` |
| **Model** | e.g. `accounts/fireworks/models/glm-5p3` |
| **API key** | your Fireworks API key |
| **Max concurrent requests** | optional; lower it if you see rate-limit errors (under **Advanced (optional)**) |

Click **Test & save**, then choose the default and fallback under [Routing](/en/how_to_use/code_review/configs/routing).

<Note>
  Use the base URL without `/chat/completions`. On **Code review → Routing**, set a model from another provider as **Fallback model** so reviews keep running if Fireworks fails.
</Note>

### Option 2 — Self-hosted (environment variables)

To give a self-hosted instance one model through `.env`:

```env
API_LLM_PROVIDER=openai_compatible
API_LLM_PROVIDER_MODEL="accounts/fireworks/models/glm-5p3"
API_LLM_BASE_URL="https://api.fireworks.ai/inference/v1"
API_LLM_API_KEY="your-fireworks-api-key"
```

Follow the installation guide to [apply the model change](/en/how_to_deploy/deploy_kodus/generic_vm#apply-a-model-change).

## Troubleshooting

<AccordionGroup>
  <Accordion title="API Key Issues">
    - Verify your API key is correct and active in [Fireworks AI Console](https://app.fireworks.ai)
    - Check if you have sufficient credits in your Fireworks AI account
    - Make sure there are no trailing spaces or quotes in the `.env` value
  </Accordion>

  <Accordion title="Model Not Found">
    - Use the full `accounts/fireworks/models/<model>` ID, spelled as in the model library
    - Verify the model is available to serverless inference; some models need a dedicated deployment
  </Accordion>

  <Accordion title="Connection Errors">
    - Verify your server has internet access to reach `api.fireworks.ai`
    - Check if there are any firewall restrictions
    - Review the API and worker logs for the exact upstream error
  </Accordion>

  <Accordion title="Rate Limiting">
    - Check your current usage in the Fireworks AI dashboard
    - An account without a payment method or credits has a much lower request limit. See Fireworks' [rate limits](https://docs.fireworks.ai/guides/quotas_usage/rate-limits)
    - Lower **Max concurrent requests** on the model, or consider a dedicated deployment for higher throughput
  </Accordion>
</AccordionGroup>
