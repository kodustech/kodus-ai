## How Groq works

Groq Cloud serves open models through an **OpenAI-compatible** API. Kodus talks to it through the OpenAI-compatible provider, so there are no code changes, only BYOK credentials.

## Recommended Models

<Info>
  Groq's catalog changes often. See [Groq's models page](https://console.groq.com/docs/models) for the current production models, context windows, prices and limits.
</Info>

| Model ID | Context Window |
| -------- | -------------- |
| `openai/gpt-oss-120b` | 131,072 tokens |

Kodus review agents call tools and expect structured output. Groq's page for this model lists tool use and JSON Schema mode. Check both on any other model before you switch.

## Creating API Key

<Warning>Groq Cloud Account is required to create API Key.</Warning>

Go directly to [Groq's API Keys page](https://console.groq.com/keys) to create a new API Key.

Or, follow these steps:

1. Go to [Groq Console](https://console.groq.com)
2. Sign in or create your account
3. Open **API Keys**
4. Click **Create API Key**
5. Give it a name like 'Kodus' or any descriptive name
6. Copy the API Key and save it somewhere safe

<Info>
  Only team owners or users with the developer role may create or manage API keys in Groq.
</Info>

## Configure Groq in Kodus

### Option 1 — AI providers page (recommended)

Follow [Connect a provider](/en/how_to_use/byok#connect-a-provider) and choose **Custom → OpenAI-compatible**. Use these values in the form.

| Field | Value |
| --- | --- |
| **Key** (in the **API key** card) | your Groq API key |
| **Base URL** | `https://api.groq.com/openai/v1` |
| **Model** | `openai/gpt-oss-120b` |
| **Max concurrent requests** | optional; under **Advanced (optional)**, expand **Advanced settings**; lower it if you see rate-limit errors |

Click **Test & save**, then choose the default and fallback under [Routing](/en/how_to_use/code_review/configs/routing).

<Note>
  Use the base URL without `/chat/completions`. Set a model from another provider as the **Fallback model** so reviews keep running if Groq rate-limits you.
</Note>

### Option 2 — Self-hosted (environment variables)

To give a self-hosted instance one model through `.env`:

```env
API_LLM_PROVIDER=openai_compatible
API_LLM_PROVIDER_MODEL="openai/gpt-oss-120b"
API_LLM_BASE_URL="https://api.groq.com/openai/v1"
API_LLM_API_KEY="your-groq-api-key"
```

Follow the installation guide to [apply the model change](/en/how_to_deploy/deploy_kodus/generic_vm#apply-a-model-change).

## Troubleshooting

<AccordionGroup>
  <Accordion title="API Key Issues">
    - Verify your API key is correct and active in [Groq Console](https://console.groq.com/keys)
    - Check that your Groq plan can use the model you chose
    - Make sure there are no trailing spaces or quotes in the `.env` value
  </Accordion>

  <Accordion title="Model Not Found">
    - Check that the model ID is spelled exactly as on Groq's models page
    - Verify the model is in Groq's current model list; models are retired over time
    - Groq retired `llama-3.3-70b-versatile` and `llama-3.1-8b-instant` for Free and Developer plans on August 16, 2026. Enterprise contracts are unaffected. See Groq's [deprecations](https://console.groq.com/docs/deprecations)
  </Accordion>

  <Accordion title="Connection Errors">
    - Verify your server has internet access to reach `api.groq.com`
    - Check if there are any firewall restrictions
    - Review the API and worker logs for the exact upstream error
  </Accordion>

  <Accordion title="Rate Limiting">
    - Groq returns HTTP 429 when a limit is exceeded, and limits depend on your plan
    - See your organization's exact limits on the Limits page of your Groq account ([console.groq.com/settings/limits](https://console.groq.com/settings/limits)), and in the [Groq rate limits documentation](https://console.groq.com/docs/rate-limits)
    - Lower **Max concurrent requests** on the model, or upgrade your plan
  </Accordion>
</AccordionGroup>
