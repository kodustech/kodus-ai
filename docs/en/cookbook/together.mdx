## How Together AI works

Together AI serves open-source models, such as DeepSeek, Kimi, GLM and gpt-oss, through an **OpenAI-compatible** API. Kodus talks to it through the OpenAI-compatible provider, so there are no code changes, only BYOK credentials.

## Recommended Models

<Info>
  Together's serverless catalog changes often. See the [serverless models list](https://docs.together.ai/docs/serverless-models) for current model IDs, context lengths and pricing. Use the exact API model string.
</Info>

Together lists these serverless chat models with function calling and structured outputs:

| Model ID | Context Window |
| -------- | -------------- |
| `moonshotai/Kimi-K3` | ~1M tokens |

## Creating API Key

<Warning>A Together AI account is required to create an API key. Together is prepaid: you must buy credits before you can create keys, and API access is suspended when the balance reaches zero. See [Together's billing docs](https://docs.together.ai/docs/billing).</Warning>

Go directly to [Together's API keys page](https://api.together.ai/settings/projects/~current/api-keys) to create a new API Key.

Or, follow these steps:

1. Create an account at [api.together.ai](https://api.together.ai) or log in if you have one already
2. Open the [API keys page](https://api.together.ai/settings/projects/~current/api-keys)
3. Click **Create key**
4. Give it a name like 'Kodus' or any descriptive name
5. Copy your API key. Together shows a new key only once

## Configure Together AI in Kodus

### Option 1 — AI providers page (recommended)

Follow [Connect a provider](/en/how_to_use/byok#connect-a-provider) and choose **Custom → OpenAI-compatible**. Use these values in the form.

| Field | Value |
| --- | --- |
| **Key** (in the **API key** card) | your Together API key |
| **Base URL** | `https://api.together.ai/v1` |
| **Model** | e.g. `zai-org/GLM-5.3` |
| **Max concurrent requests** | optional; under **Advanced (optional)**, expand **Advanced settings**; lower it if you see rate-limit errors |

Click **Test & save**, then choose the default and fallback under [Routing](/en/how_to_use/code_review/configs/routing).

<Note>
  Use the base URL without `/chat/completions`. Set a model from another provider as the **Fallback model** so reviews keep running if Together rate-limits you.
</Note>

### Option 2 — Self-hosted (environment variables)

To give a self-hosted instance one model through `.env`:

```env
API_LLM_PROVIDER=openai_compatible
API_LLM_PROVIDER_MODEL="zai-org/GLM-5.3"
API_LLM_BASE_URL="https://api.together.ai/v1"
API_LLM_API_KEY="your-together-api-key"
```

Follow the installation guide to [apply the model change](/en/how_to_deploy/deploy_kodus/generic_vm#apply-a-model-change).

## Troubleshooting

<AccordionGroup>
  <Accordion title="API Key Issues">
    - Verify your API key is correct and active on the [API keys page](https://api.together.ai/settings/projects/~current/api-keys)
    - Check that your Together AI account has a credit balance; API access is suspended at zero
    - Make sure there are no trailing spaces or quotes in the `.env` value
  </Accordion>

  <Accordion title="Model Not Found">
    - Use the exact API model string from the [serverless models list](https://docs.together.ai/docs/serverless-models), including capitalization
    - Serverless and dedicated endpoints support different models; a model that is not in the serverless list needs a dedicated endpoint
  </Accordion>

  <Accordion title="Connection Errors">
    - Verify your server has internet access to reach `api.together.ai`
    - Check if there are any firewall restrictions
    - Review the API and worker logs for the exact upstream error
  </Accordion>

  <Accordion title="Rate Limiting">
    - Together returns HTTP 429 when a limit is exceeded. See Together's [rate limits documentation](https://docs.together.ai/docs/rate-limits)
    - Lower **Max concurrent requests** on the model, or contact Together about higher limits
  </Accordion>
</AccordionGroup>
