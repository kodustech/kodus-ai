## How Moonshot works

Moonshot AI publishes the **Kimi** models (K3.1 Pro, K3 and the earlier K2 series). Its API is both OpenAI-compatible and Anthropic-compatible. Kodus has a dedicated **Moonshot** provider, which connects over the Anthropic-compatible endpoint (`https://api.moonshot.ai/anthropic`). You can also reach Kimi through the **OpenAI-compatible** provider.

Moonshot offers **two paths** to the Kimi models, each with its own endpoint and keys:

- **Developer API** (`platform.kimi.ai`): pay per token. Rate limits depend on your cumulative recharge.
- **Kimi Code Plan** (`kimi.com/code`): a Kimi membership with a **dedicated coding endpoint**. Usage is limited by a rolling 5-hour rate window and a monthly quota.

<Note>
  Kimi Code comes with a Kimi membership: Plus and above on the current plans, Andante and above on the legacy plans. Its keys are separate from Developer API keys.
</Note>

Moonshot also runs a China platform at `platform.kimi.com` (`platform.moonshot.cn` redirects there), with base URL `https://api.moonshot.cn/v1`. Keys from `platform.kimi.ai` are independent from keys from the China platform.

### Developer API (pay-per-token)

<Info>

| Model | Context Window | Notes |
| ----- | -------------- | ----- |
| **Kimi K3.1 Pro** (`kimi-k3.1-pro`) | 1,048,576 tokens | Latest flagship. |

Developer API endpoints: `https://api.moonshot.ai/v1` (OpenAI-compatible) and `https://api.moonshot.ai/anthropic` (Anthropic-compatible). Concurrency, requests per minute and tokens per minute depend on your cumulative recharge.

## Creating an API Key

<Warning>A Moonshot account is required to create an API key.</Warning>

<Tabs>
  <Tab title="Kimi Code Plan subscriber">
    1. Go to [kimi.com/code](https://www.kimi.com/code) and subscribe to a membership that includes Kimi Code.
    2. Open the [Kimi Code Console](https://www.kimi.com/code/console).
    3. Click **Create API Key**, enter a name and confirm. Copy the key: the console does not show it again.

    <Note>
      Kimi Code keys are for the Kimi Code endpoints. Using a Developer API key or base URL with Kimi Code returns 401.
    </Note>
  </Tab>

  <Tab title="Developer API (pay-per-token)">
    1. Sign in at [platform.kimi.ai](https://platform.kimi.ai), or at [platform.kimi.com](https://platform.kimi.com) for the China platform.
    2. Recharge your account. On `platform.kimi.ai`, the minimum recharge to start using the API is $1.
    3. Open [platform.kimi.ai/console/api-keys](https://platform.kimi.ai/console/api-keys) and create a key. Give it a descriptive name (for example `kodus-prod`) and copy it.

    <Note>
      Keys from `platform.kimi.ai` are for `api.moonshot.ai`. They are independent from keys from the China platform, which are for `api.moonshot.cn`.
    </Note>
  </Tab>
</Tabs>

## Configure Moonshot in Kodus

The primary flow is the **AI providers** page, which is the same on Kodus Cloud and on a self-hosted instance. Self-hosted users who prefer fixing the provider at the process level can use environment variables instead.

### Option 1 — Moonshot provider (recommended for the Developer API)

<Steps>
  <Step title="Open AI providers and pick Moonshot">
    In the sidebar, open **AI providers** ([app.kodus.io/byok](https://app.kodus.io/byok) on Cloud, `/byok` on your own instance). On the **Providers** tab, click the **Moonshot** tile (under **Connect your first provider**, or **Add another provider** if you already connected one).
  </Step>

  <Step title="Paste your API key and pick the model">
    Paste your Developer API key from [platform.kimi.ai](https://platform.kimi.ai/console/api-keys) in the **API key** card. The **Model** picker then loads Moonshot's models. Pick one (for example `kimi-k3.1-pro`) or choose **Type model manually**. Kodus fills in the `https://api.moonshot.ai/anthropic` endpoint for you. This tile has no plan selector and no base URL field, so for a Kimi Code Plan key or the China platform use Option 2 below.
  </Step>

  <Step title="Test & save">
    Click **Test & save**. Kodus tests the connection and saves the config on success. A 401 means the key is wrong or belongs to a different platform.
  </Step>
</Steps>

### Reasoning

Kimi K3.1 Pro and K3 always reason. Moonshot's API has no setting to turn it off and says not to send a `thinking` parameter for them. Leave **Thinking / Reasoning** under **Advanced (optional)** at its default, and do not add a `thinking` block with **Custom**. **Test & save** rejects **Off** for these models. See [Thinking models](https://platform.kimi.ai/docs/guide/use-thinking-models).

### Tuning concurrency

- **Kimi Code Plan**: Moonshot does not publish a concurrency number for the plan. Set **Max concurrent requests** (under **Advanced (optional)**) to a low value and raise it while reviews run without 429 errors.
- **Developer API**: leave it empty (no cap). Your limit depends on your cumulative recharge. Set it if you see 429 errors during reviews.

<Note>
  Under **Code review → Routing**, set **Default model** to Kimi and pick a model from another provider as **Fallback model**. Kodus re-runs a failed call on the fallback once. See [Routing](/en/how_to_use/byok#routing:-which-model-runs-each-task).
</Note>

### Option 2 — OpenAI-compatible endpoint

For the Kimi Code Plan, the China platform, or Moonshot's OpenAI-compatible endpoint, open **AI providers**, pick **OpenAI-compatible** under **Custom** on the **Providers** tab, and fill:

| Field | Value |
| --- | --- |
| **Base URL** | `https://api.moonshot.ai/v1` (Developer API)<br />`https://api.kimi.ai/coding/v1` (Kimi Code Plan, overseas)<br />`https://api.kimi.com/coding/v1` (Kimi Code Plan, China)<br />`https://api.moonshot.cn/v1` (China platform) |
| **Model** | `kimi-k3.1-pro` or `kimi-k3` on the Developer API and the China platform<br />`k3.1-pro` or `k3` on Kimi Code |
| **API key** | your Moonshot or Kimi Code key (matching the base URL above) |
| **Max concurrent requests** (under **Advanced (optional)**) | low on Kimi Code Plan, raised while reviews run without 429 errors; empty on the Developer API |

### Option 3 — Self-hosted (environment variables)

To give a self-hosted instance one model through `.env`:

```env
API_LLM_PROVIDER=openai_compatible
API_LLM_PROVIDER_MODEL="kimi-k3.1-pro"
API_LLM_BASE_URL="https://api.moonshot.ai/v1"    # or https://api.kimi.ai/coding/v1 for Kimi Code Plan (model k3.1-pro)
API_LLM_API_KEY="your-moonshot-or-kimi-code-api-key"
```

To use the Anthropic-compatible endpoint instead, set `API_LLM_PROVIDER=anthropic_compatible` and `API_LLM_BASE_URL="https://api.moonshot.ai/anthropic"`.

Follow the installation guide to [apply the model change](/en/how_to_deploy/deploy_kodus/generic_vm#apply-a-model-change).

## Choosing between Kimi Code Plan, Developer API, and aggregators

- **Kimi Code Plan**: flat-rate membership on its own coding endpoint, with a rolling 5-hour rate window and a monthly quota. Best for steady PR volume. Check Moonshot's terms for using a Kimi Code key from third-party tools, and see [Subscriptions and coding plans](/en/how_to_use/byok#subscriptions-and-coding-plans).
- **Moonshot Developer API**: pay per token, with rate limits that depend on your cumulative recharge. Best for bursty workloads.
- **OpenRouter**: one billing relationship across many providers. OpenRouter does not mark up inference prices but charges a fee when you buy credits; see its [FAQ](https://openrouter.ai/docs/faq). Pick it when Kimi is one model in a mixed-provider setup.

## Troubleshooting

<AccordionGroup>
  <Accordion title="401 after Test — key doesn't match endpoint">
    - Kimi Code keys are for the Kimi Code endpoints. Using a Developer API key or base URL with Kimi Code returns 401.
    - Keys from `platform.kimi.ai` are for `api.moonshot.ai` (`/v1` and `/anthropic`).
    - Keys from `platform.kimi.com` are for `api.moonshot.cn/v1`.
    - The **Moonshot** tile always uses `https://api.moonshot.ai/anthropic`, so it needs a `platform.kimi.ai` key. Connect Kimi Code or China platform keys through **OpenAI-compatible** with the matching **Base URL**.
  </Accordion>

  <Accordion title="429 errors and insufficient balance">
    - On the Developer API, a depleted balance returns 429 with `exceeded_current_quota_error`. Recharge your account in the console.
    - A 429 can also be a rate limit (concurrency, requests per minute or tokens per minute) or an overloaded engine. Lower **Max concurrent requests** for rate limits; recharging does not fix an overloaded engine.
    - Kimi Code returns 429 when you reach the 5-hour window, the monthly quota or a concurrency limit. See Moonshot's [Kimi Code error reference](https://www.kimi.com/code/docs/en/kimi-code/error-reference) and [Developer API error codes](https://platform.kimi.ai/docs/api/errors).
  </Accordion>

  <Accordion title="Model not found">
    - Developer API ids are `kimi-k3.1-pro` and `kimi-k3`. Kimi Code ids are `k3.1-pro`, `k3` and `k3-256k`.
    - Check [platform.kimi.ai/docs/models](https://platform.kimi.ai/docs/models) for the current Developer API list. Older models are retired.
  </Accordion>

  <Accordion title="Slow responses">
    - Kimi K3.1 Pro and K3 always reason, and reasoning cannot be turned off, so a response can take a while.
    - On the Developer API, Moonshot lists `kimi-k3.1-pro-highspeed` as a faster variant of K3.1 Pro.
  </Accordion>

  <Accordion title="Region / connectivity">
    - Developer API keys are tied to their platform: `platform.kimi.ai` for `api.moonshot.ai`, `platform.kimi.com` for `api.moonshot.cn`.
    - Kimi Code has separate endpoints: `api.kimi.ai/coding/v1` (overseas) and `api.kimi.com/coding/v1` (China).
    - Confirm outbound HTTPS to the chosen endpoint is allowed from your Kodus deployment.
  </Accordion>
</AccordionGroup>
