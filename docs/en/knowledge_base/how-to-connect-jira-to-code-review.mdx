title: "How to connect Jira to your code review tool"
description: "Link Jira to Kodus so your AI code reviews automatically validate PRs against task requirements and acceptance criteria."
---

Connecting Jira to Kodus enables two powerful features: automatic **business logic validation** against Jira tickets, and richer context for code review suggestions.

## How to connect

1. In the sidebar, open **Plugins**
2. Click the **Jira** tile
3. Authenticate (OAuth or API token) and authorize access to your Jira workspace
4. Choose the tools Kody can use, then click **Install plugin**

## What it enables

### Automatic business logic validation

When a PR is linked to a Jira ticket and the **Business Logic** category is on in **Code review → What to review**, Kodus automatically:
- Fetches the ticket title, description, and acceptance criteria
- Compares the PR diff against the requirements
- Reports missing implementations, scope mismatches, and gaps

### On-demand validation

Paste any Jira URL in a PR comment:

```
@kody -v business-logic https://your-org.atlassian.net/browse/PROJ-123
```

### Richer code review context

With Jira connected, Kody can use MCP functions in your rules to fetch task context, check issue status, and cross-reference requirements.

## Requirements

- Jira Cloud or Jira Data Center
- OAuth or API token access
- Permissions to read the relevant projects

For details on business logic validation, see [Business Logic Validation](/en/how_to_use/code_review/business_logic_validation). For plugin setup, see [Plugins](/en/how_to_use/code_review/plugins).
