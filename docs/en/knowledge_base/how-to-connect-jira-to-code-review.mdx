---
title: "Connect Jira and validate pull requests"
description: "Set up Atlassian Rovo in Kodus and check a PR against its Jira ticket."
---

You need permission to read the Jira projects referenced by your pull requests.

## How to connect

1. In the sidebar, open **Plugins** (installing a plugin needs the Owner role)
2. Click the **Atlassian Rovo** tile (Jira)
3. Click **Authenticate with** the plugin and authorize access to your Jira workspace (OAuth), or enter your Atlassian email and an API token and click **Connect**
4. The plugin is installed as soon as it connects, with its read-only tools selected. To change them later, open it, edit **Selected tools** and click **Update Tools**

Keep these tools selected, because Kody reads tickets with them: `getJiraIssue`, `getAccessibleAtlassianResources` and `getVisibleJiraProjects`. A tool you turn off cannot be used.

## What it enables

### Automatic business logic validation

Reference the Jira ticket in the PR title, branch name or description. With **Business Logic** on in **Code review → What to review** (the default), Kody checks the PR on the first review. Kody reads the ticket and its parent and sub-tasks.

### On-demand validation

Paste any Jira URL, or a ticket key, in a PR comment:

```
@kody -v business-logic https://your-org.atlassian.net/browse/PROJ-123
```

## What you get

Kody posts one **Kody · Business Logic** comment with the requirements it checked and the code behind each result. A re-check updates that comment. See [Business Logic Validation](/en/how_to_use/code_review/business_logic_validation) for result states and re-check options.

## Tips for best results

- Add **acceptance criteria** to your Jira tickets. If they sit under a heading or in a custom field, set **Requirements → Where acceptance criteria live** in the Business Logic settings.
- A Jira sub-task is checked against its parent's requirements that its title covers.
- After fixing a gap, comment `@kody -v business-logic` to re-check.

## Plugin tools in conversations

Kody can use the plugin when you mention it in a PR comment. It can also be turned on for a [custom agent](/en/how_to_use/code_review/custom_agents_knowledge_and_tools#plugins-mcp).
