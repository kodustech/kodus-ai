---
title: "How to set up AI code review on GitLab"
description: "Connect GitLab to Kodus and select repositories for automated review."
---

Kodus connects to GitLab with OAuth or an access token, and receives merge request events through webhooks.

GitLab has no app to install: **Install Gitlab app** is an OAuth sign-in. Reviews are posted as the user who connected with OAuth, or as the token owner.

## Steps

1. **Create an account** at [kodus.io](https://kodus.io) or [self-host Kodus](/en/how_to_deploy/deploy_kodus/generic_vm)
2. **Connect GitLab** — in the **Connect your Git tool** step of onboarding, click **Install Gitlab app** to authorize via OAuth, or **Connect via token** (you can also connect later from **Repositories** in the sidebar: click **Gitlab** under **Connect a provider**, then use the **OAuth** or **Token** tab). For a self-managed GitLab with a token, turn on **Self-hosted** and enter the **Gitlab URL**
3. **Select projects** — choose which GitLab projects Kodus should review, or turn on [Review every repository](/en/how_to_use/code_review/configs/review_all_repositories) on **Repositories**
4. **Webhooks** — Kodus registers the merge request webhook automatically when you save the selection. That needs the **Maintainer** or **Owner** role on each project. If it didn't happen, **Repositories** lists the project with the reason; add the webhook manually with the [GitLab Webhooks](/en/how_to_deploy/platforms/gitlab/gitlab_webhook) guide
5. Open a merge request in a selected project. See [what Kody posts and how to check its status](/en/how_to_use/code_review/flow).

## Custom configuration

Use [kodus-config.yml](/en/how_to_use/code_review/configs/general#kodus-config-yml) to customize review settings per repository.

## Self-hosted

**Install Gitlab app** and **Sign in with Gitlab** need a GitLab OAuth application and its credentials in your `.env`: see [GitLab OAuth](/en/how_to_deploy/platforms/gitlab/gitlab_oauth). A token connection needs none of that; generate it as described in [GitLab PAT](/en/how_to_use/code_review/general_config/gitlab_pat).

For the full setup guide, see [GitLab OAuth](/en/how_to_deploy/platforms/gitlab/gitlab_oauth) and [GitLab Webhooks](/en/how_to_deploy/platforms/gitlab/gitlab_webhook).
