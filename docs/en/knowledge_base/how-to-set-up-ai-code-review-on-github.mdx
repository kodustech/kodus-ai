## Steps

1. **Create an account** at [kodus.io](https://kodus.io) or [self-host Kodus](/en/how_to_deploy/deploy_kodus/generic_vm)
2. **Connect GitHub** — in the **Connect your Git tool** step of onboarding, click **Install Github app** (you can also connect later from **Repositories** in the sidebar: click **Github** under **Connect a provider**, then **Go to OAuth** on the **OAuth** tab)
3. **Select repositories** — choose which repositories Kodus should review, or turn on [Review every repository](/en/how_to_use/code_review/configs/review_all_repositories) on **Repositories**
4. Open a pull request in a selected repository. See [what Kody posts and how to check its status](/en/how_to_use/code_review/flow).

## Custom configuration

Use [kodus-config.yml](/en/how_to_use/code_review/configs/general#kodus-config-yml) to customize review settings per repository.

## Using a Personal Access Token

If you can't install the GitHub App, connect with a GitHub Personal Access Token (PAT) instead. Choose **Connect via token** in onboarding (or the **Token** tab when connecting GitHub on **Repositories**). Reviews are then posted from the token owner's account, and GitHub Checks/PR status aren't available. Kodus creates a webhook on each selected repository; see [Creating a Webhook](/en/how_to_deploy/platforms/github/github_webhook) if that fails.

## Self-hosted

Self-hosted Kodus connects with a GitHub App you create yourself, or with a token. **Install Github app** needs the App's credentials in your `.env`: see [GitHub App setup](/en/how_to_deploy/platforms/github/github_app). To let users sign in with GitHub as well, see [GitHub OAuth App](/en/how_to_deploy/platforms/github/github_oauth).

For the full setup guide, see [Quickstart](/en/how_to_use/quickstart).
