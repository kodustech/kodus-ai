---

<Note>
リアクションに基づくファインチューニングは現在無効です。👍/👎 のリアクションや提案の実装状況は記録できますが、モデルの学習、好みのクラスタリング、次回レビューのフィルタリングには使われません。
</Note>

評価だけでは提案を却下した理由がわかりません。この学習ループを再開するには、否定的なフィードバックの詳しい背景が必要です。

リアクションは任意の製品フィードバックとして残せます。ただし、評価しただけで次回以降の類似提案が自動的に非表示になるわけではありません。

## 今後のレビューに影響する仕組み

- [メモリ](/knowledge_base/ja/how-to-teach-ai-your-team-conventions): `@kody remember` や会話を通じて、明示的なチームの規約を保存します。
- [Kody Rules](/how_to_use/ja/code_review/configs/kody_rules): コードレビュー時に適用する基準を定義します。
- [ルールの自動生成](/how_to_use/ja/code_review/learning/kody_rules_generation): レビュー履歴から手動インポート用のルールを提案します。これはリアクションによる調整とは別の、現在も有効な機能です。
