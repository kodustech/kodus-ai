---
title: "Cockpit の設定"
description: "組織として見せたくない Cockpit のタブや個別メトリクスを、組織レベルの設定ひとつで非表示にします。"
---

すべてのチームがすべてのメトリクスを表示したいわけではありません。Cockpit では Owner が
タブ全体や個別のチャートを**組織全体**に対してオフにできます — そのメトリクスが自分たちの
運用ではノイズになる場合や、開発者ごとの数値を表示したくない場合に有効です。

**Organization → Cockpit Configuration**（`/organization/cockpit`）を開きます。

<Info>
  これは**組織単位**の設定であり、ユーザーごとの環境設定ではありません。メトリクスをオフに
  すると全員に対して非表示になります。
</Info>

## タブ

Cockpit は 2 つのタブに分かれており、それぞれ非表示にできます：

| タブ | 内容 |
| --- | --- |
| **Kodus Review** | Kodus のレビューがどれだけ効果的か — 実装率、重大度キャリブレーション、ネガティブフィードバック、Kody Rules のヘルス。 |
| **Productivity** | デリバリー系メトリクス — デプロイ頻度、サイクルタイム、PR サイズ、チームの活動量。 |

<Warning>
  **少なくとも 1 つのタブは有効なままである必要があります。** 両方オフにするとフォームが拒否します。
</Warning>

Productivity タブを非表示にすると、その中身もすべて非表示になります。したがって以下の個別
トグルは、そのタブが有効な間だけ意味を持ちます。

## サマリーメトリクス

Productivity タブ上部のカード：

| メトリクス | 内容 |
| --- | --- |
| **Deploy Frequency** | 本番デプロイの頻度 |
| **PR Cycle Time** | PR 作成からマージまでの平均時間 |
| **Bug Ratio** | バグ修正 PR の割合 |
| **PR Size** | PR の平均サイズ |

## 詳細チャート

サマリーカードの下にあるチャート：

| チャート | 内容 |
| --- | --- |
| **Lead Time Breakdown** | リードタイムを段階ごとに分解 |
| **PR Cycle Time Chart** | 期間を通じたサイクルタイムの推移 |
| **PRs Opened vs Closed** | 週ごとのオープン／クローズ数 — [オープン vs クローズの PR 数](/how_to_use/ja/cockpit/metrics/prs_opened_vs_closed) を参照 |
| **PRs Merged by Developer** | メンバーごとのマージ済み PR 数 |
| **Team Activity** | チーム全体の活動と貢献 |

## 補足

- 新しいメトリクスは**デフォルトで表示**の状態で追加されます。Kodus がチャートを追加すると、
  誰かがオフにするまで全員に表示されます — 保存済みの設定は現在のデフォルトを置き換えるのでは
  なく、その上にマージされるため、古い設定が新しいものを隠すことはありません。
- メトリクスを非表示にしても影響するのは表示だけです。裏側のデータ取り込みは続くため、再び
  オンにすると、その時点以降だけでなく全履歴が表示されます。
