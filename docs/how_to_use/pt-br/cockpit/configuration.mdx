---
title: "Configuração do Cockpit"
description: "Esconda as abas e as métricas individuais do Cockpit que sua organização não quer expor, a partir de uma única configuração no nível da organização."
---

Nem todo time quer todas as métricas visíveis. O Cockpit permite que um Owner desligue abas
inteiras ou gráficos individuais para a **organização inteira** — útil quando uma métrica é
ruidosa para o seu fluxo, ou quando você não quer números por desenvolvedor em exibição.

Vá em **Organization → Cockpit Configuration** (`/organization/cockpit`).

<Info>
  Esta é uma configuração **da organização**, não uma preferência por usuário. Desligar uma
  métrica esconde ela para todo mundo.
</Info>

## Abas

O Cockpit é dividido em duas abas, e cada uma pode ser escondida:

| Aba | O que contém |
| --- | --- |
| **Kodus Review** | Quão eficazes são as revisões do Kodus — taxa de implementação, calibração de severidade, feedback negativo, saúde das Kody Rules. |
| **Productivity** | Métricas de entrega — frequência de deploy, cycle time, tamanho de PR, atividade do time. |

<Warning>
  **Pelo menos uma aba precisa continuar ligada.** O formulário rejeita desligar as duas.
</Warning>

Esconder a aba Productivity também esconde tudo que está dentro dela, então os toggles
individuais abaixo só importam enquanto essa aba estiver ligada.

## Métricas de resumo

Os cards no topo da aba Productivity:

| Métrica | O que mostra |
| --- | --- |
| **Deploy Frequency** | Com que frequência o time faz deploy para produção |
| **PR Cycle Time** | Tempo médio da criação do PR até o merge |
| **Bug Ratio** | Percentual de PRs que são correções de bug |
| **PR Size** | Tamanho médio dos pull requests |

## Gráficos detalhados

Os gráficos abaixo dos cards de resumo:

| Gráfico | O que mostra |
| --- | --- |
| **Lead Time Breakdown** | Lead time dividido por etapa |
| **PR Cycle Time Chart** | Cycle time ao longo do período |
| **PRs Opened vs Closed** | Contagem semanal de abertos vs fechados — veja [PRs Abertos vs Fechados](/how_to_use/pt-br/cockpit/metrics/prs_opened_vs_closed) |
| **PRs Merged by Developer** | PRs mergeados por pessoa do time |
| **Team Activity** | Atividade e contribuições gerais do time |

## Observações

- Métricas novas chegam **visíveis por padrão**. Se o Kodus adicionar um gráfico, ele aparece
  para todos até alguém desligar — sua configuração salva é mesclada por cima dos padrões atuais
  em vez de substituí-los, então uma config antiga nunca esconde algo novo.
- Esconder uma métrica afeta apenas a exibição. O Kodus continua ingerindo os dados por trás,
  então religar mostra o histórico completo, não só os dados dali para frente.
