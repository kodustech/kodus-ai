---

<Note>
El ajuste basado en reacciones no está activo actualmente. Las reacciones 👍/👎 y el estado de implementación pueden registrarse, pero no entrenan un modelo, no crean grupos de preferencias ni filtran la siguiente revisión.
</Note>

Un pulgar arriba o abajo no explica por qué se rechazó una sugerencia. Se necesita más contexto sobre la retroalimentación negativa antes de reactivar este ciclo.

Puedes seguir dejando reacciones como comentarios opcionales sobre el producto. Reaccionar a una sugerencia no suprime automáticamente sugerencias similares en revisiones posteriores.

## Qué influye en futuras revisiones

- [Memorias](/knowledge_base/es/how-to-teach-ai-your-team-conventions): Guarda convenciones explícitas del equipo mediante `@kody remember` y conversaciones.
- [Kody Rules](/how_to_use/es/code_review/configs/kody_rules): Define estándares que se aplican durante la revisión de código.
- [Generación automática de reglas](/how_to_use/es/code_review/learning/kody_rules_generation): Propone reglas a partir del historial de revisiones para importarlas manualmente. Es una función activa distinta del ajuste basado en reacciones.
