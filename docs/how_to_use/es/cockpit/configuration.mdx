---
title: "Configuración de Cockpit"
description: "Oculta las pestañas y las métricas individuales de Cockpit que tu organización no quiere exponer, desde un único ajuste a nivel de organización."
---

No todos los equipos quieren todas las métricas visibles. Cockpit permite que un Owner desactive
pestañas enteras o gráficos individuales para **toda la organización** — útil cuando una métrica
es ruidosa para tu flujo, o cuando no quieres números por desarrollador a la vista.

Ve a **Organization → Cockpit Configuration** (`/organization/cockpit`).

<Info>
  Este es un ajuste **de la organización**, no una preferencia por usuario. Desactivar una
  métrica la oculta para todos.
</Info>

## Pestañas

Cockpit se divide en dos pestañas, y cada una puede ocultarse:

| Pestaña | Qué contiene |
| --- | --- |
| **Kodus Review** | Qué tan efectivas son las revisiones de Kodus — tasa de implementación, calibración de severidad, feedback negativo, salud de las Kody Rules. |
| **Productivity** | Métricas de entrega — frecuencia de despliegue, cycle time, tamaño de PR, actividad del equipo. |

<Warning>
  **Al menos una pestaña debe permanecer activa.** El formulario rechaza desactivar ambas.
</Warning>

Ocultar la pestaña Productivity también oculta todo lo que hay dentro, así que los toggles
individuales de abajo solo importan mientras esa pestaña esté activa.

## Métricas de resumen

Las tarjetas en la parte superior de la pestaña Productivity:

| Métrica | Qué muestra |
| --- | --- |
| **Deploy Frequency** | Con qué frecuencia el equipo despliega a producción |
| **PR Cycle Time** | Tiempo medio desde la creación del PR hasta el merge |
| **Bug Ratio** | Porcentaje de PRs que son correcciones de bugs |
| **PR Size** | Tamaño medio de los pull requests |

## Gráficos detallados

Los gráficos debajo de las tarjetas de resumen:

| Gráfico | Qué muestra |
| --- | --- |
| **Lead Time Breakdown** | Lead time desglosado por etapa |
| **PR Cycle Time Chart** | Cycle time a lo largo del período |
| **PRs Opened vs Closed** | Conteo semanal de abiertos vs cerrados — consulta [PRs Abiertos vs Cerrados](/how_to_use/es/cockpit/metrics/prs_opened_vs_closed) |
| **PRs Merged by Developer** | PRs mergeados por miembro del equipo |
| **Team Activity** | Actividad y contribuciones generales del equipo |

## Notas

- Las métricas nuevas llegan **visibles por defecto**. Si Kodus añade un gráfico, aparece para
  todos hasta que alguien lo desactive — tu configuración guardada se fusiona sobre los valores
  por defecto actuales en lugar de reemplazarlos, así que una config antigua nunca oculta algo nuevo.
- Ocultar una métrica solo afecta a la visualización. Kodus sigue ingiriendo los datos
  subyacentes, así que reactivarla muestra el historial completo, no solo los datos desde ese momento.
