---
title: "驾驶舱配置"
description: "通过一个组织级设置,隐藏你的组织不希望展示的驾驶舱标签页和单个指标。"
---

并非每个团队都希望所有指标可见。驾驶舱允许 Owner 为**整个组织**关闭整个标签页或单个图表 ——
当某个指标对你们的流程来说噪音过大,或你不希望展示按开发者维度的数字时,这很有用。

前往 **Organization → Cockpit Configuration**(`/organization/cockpit`)。

<Info>
  这是**组织级**设置,不是按用户的偏好。关闭某个指标会对所有人隐藏它。
</Info>

## 标签页

驾驶舱分为两个标签页,每个都可以隐藏:

| 标签页 | 包含内容 |
| --- | --- |
| **Kodus Review** | Kodus 的审查有多有效 —— 采纳率、严重性校准、负面反馈、Kody Rules 健康度。 |
| **Productivity** | 交付类指标 —— 部署频率、cycle time、PR 大小、团队活跃度。 |

<Warning>
  **至少要保留一个标签页处于开启状态。** 表单会拒绝把两个都关闭。
</Warning>

隐藏 Productivity 标签页同时会隐藏其中的全部内容,因此下面的单项开关只在该标签页开启时才有意义。

## 摘要指标

Productivity 标签页顶部的卡片:

| 指标 | 展示内容 |
| --- | --- |
| **Deploy Frequency** | 团队向生产环境部署的频率 |
| **PR Cycle Time** | 从 PR 创建到合并的平均时长 |
| **Bug Ratio** | 属于 bug 修复的 PR 占比 |
| **PR Size** | pull request 的平均大小 |

## 详细图表

摘要卡片下方的图表:

| 图表 | 展示内容 |
| --- | --- |
| **Lead Time Breakdown** | 按阶段拆解的 lead time |
| **PR Cycle Time Chart** | 周期内 cycle time 的走势 |
| **PRs Opened vs Closed** | 每周开启与关闭的数量 —— 参见[开启 vs 关闭的 PR 数](/how_to_use/zh/cockpit/metrics/prs_opened_vs_closed) |
| **PRs Merged by Developer** | 每位成员合并的 PR 数 |
| **Team Activity** | 团队整体活动与贡献 |

## 说明

- 新指标上线时**默认可见**。如果 Kodus 新增了一个图表,在有人关闭之前它对所有人可见 ——
  你保存的配置会合并到当前默认值之上,而不是替换它们,因此旧配置永远不会隐藏新东西。
- 隐藏指标只影响展示。Kodus 仍会持续采集底层数据,因此重新开启时会显示完整历史,而不是只有
  开启之后的数据。
