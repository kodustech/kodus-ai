---
title: "Kodus CLI"
description: "在终端中进行 AI 代码审查、业务验证和代理工作流。"
---

Kodus CLI 直接在终端中审查您的代码变更，赶在它们进入 Pull Request 之前。您可以指向工作目录、暂存区 diff、分支或提交。它会应用团队的 Kody Rules 和代码审查设置。

CLI 可以连接 [Kodus Cloud](/zh/how_to_use/cli/getting_started) 或[自托管实例](/zh/how_to_use/cli/self_hosted)。无需登录即可限量试用基础审查。工作区命令需要登录或团队密钥，具体取决于命令。

## 适用人群

- **独立开发者**：在推送前进行提交前检查。
- **团队**：在所有克隆、IDE 和 CI 作业之间共享一套审查规则，无需每位开发者单独登录。
- **AI 编码代理**（Claude Code、Cursor、Codex、Windsurf 等）：通过结构化输出实现审查-修复循环。
- **CI/CD 流水线**：根据严重级别阈值使构建失败。

## 输出示例

对一次变更运行 `kodus review`，会列出其发现的问题，包含严重级别、位置和建议的修复。在 macOS 和 Linux 的交互式终端中，审查结果会在 Hunk diff 查看器中打开，紧挨着代码。

<img src="/images/kodus_cli_review.jpg" alt="在 CLI 中进行 AI 代码审查"/>

使用 `--prompt-only` 时，同一审查会变成紧凑、结构化的文本，便于 AI 代理解析并执行。使用 `--fail-on` 时，退出码会告诉脚本是否应当停止。

## 限制

| | 试用（无需账户） | 已登录或使用团队密钥 |
|---|---|---|
| 速率限制 | 每个用户、设备和仓库文件夹每小时 2 次审查 | 每个团队每小时 1,000 次请求 |
| 发送给 Kodus 的内容 | 仅 diff | diff，以及工作目录或暂存区审查中的变更文件 |
| Diff | 2000 万字符 | 2000 万字符 |
| 每次审查文件数 | — | 500 |
| 每文件 diff | — | 500,000 字符 |
| 每文件内容 | — | 2,000,000 字符 |
| 请求大小 | 25 MB | 24 MB |

试用的一小时是滚动窗口。试用审查不受文件数或行数限制。对于已登录的团队，这 1,000 次请求计入审查、业务验证检查和 [Kodus Trace](/zh/how_to_use/cli/trace) 会话事件。

使用登录或团队密钥时，超过单文件限制的文件会被跳过并给出警告。`--branch`、`--commit` 和 `--fast` 只发送 diff，这使大型审查保持在请求限制之内。

在试用模式下，`kodus auth status` 会显示您的用量及重置时间。

## CLI 与 Kodus Web

CLI 与 Kodus Web 应用共享 Kody Rules 和代码审查设置。当您希望在 **PR 尚未创建之前** 审查代码（本地分支、暂存 diff 或代理循环中），请使用 CLI；Web 应用则用于 PR 审查、Cockpit 和团队级配置。

CLI 审查会应用团队的 Kody Rules。当您的 git remote 与已添加到 Kodus 的仓库匹配时，它还会应用该仓库的规则、审查模式和仓库指令（`CLAUDE.md`、`AGENTS.md`）。没有匹配时，只运行适用于所有仓库的规则。试用审查没有团队：使用默认设置且不含 Kody Rules。

从 CLI 运行的审查会显示在 Web 应用的 **Reviews → CLI** 下。使用团队密钥运行的审查标记为 **Team · &lt;key name&gt;**，使用登录运行的审查标记为 **Personal**。
