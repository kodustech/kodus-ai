## 审查会应用哪些规则

每次审查都会应用三个范围内的启用规则:**Global → Repository → Directory**。

- **Global** 规则适用于每个代码库。
- **Repository** 规则适用于该代码库中的每个拉取请求。
- **Directory** 规则在拉取请求使用该目录范围的设置进行审查时适用,而这发生在拉取请求恰好涉及一个目录范围时。该代码库其他目录范围的规则不适用。
- 不涉及任何目录范围,或涉及两个及以上目录范围的拉取请求,会使用该代码库的设置进行审查。此时,该代码库**所有**目录范围的规则也会适用于拉取请求中的每个文件。

在父级范围编写的规则始终会被其下级范围继承。在两个范围中以相同指令出现的规则只会运行一次。

<Note>
  **Inheritable** 开关和 **Override and disable for this scope** 会改变规则在 **Kody Rules** 页面上的列出方式。它们不会改变审查应用哪些规则。详见下文。
</Note>

## 在应用中

在 **Kody Rules** 页面上,从更高范围继承的规则会与该范围自身的规则一起列出,并标注其来源范围。它们在此处为只读:打开规则并使用 **View**,或前往创建它的范围进行编辑。**Filters → View** 会显示或隐藏 **Inherited from Global**、**Inherited from Repository** 和 **Disabled Rules**。

### Inheritable

对任意范围的规则,在规则对话框中打开 **Advanced settings** 并关闭 **Inheritable**(默认开启)。

- 该规则不再作为继承规则列在其下级范围中。
- 审查仍然会如上所述在每个范围中应用它。

### Override and disable for this scope

在代码库或目录范围,打开一条继承的规则(**View**)并开启 **Override and disable for this scope**。

- 该规则在此范围中显示为 **Disabled**,并且在 **Filters → View** 中取消勾选 **Disabled Rules** 时会被隐藏。
- 它在下级范围中不会显示为已禁用,下级范围保留各自的设置。
- 审查仍然会应用该规则。

要阻止某条规则生效,请在创建它的范围中暂停或删除它。

## 集中式配置

[集中式配置](/zh/how_to_use/code_review/configs/centralized_config)代码库中的规则文件可以携带相同的设置:

```yaml
inheritance:
  inheritable: true
  exclude: []   # repository or directory IDs
  include: []   # repository or directory IDs
```

`inheritable` 和 `exclude` 的行为如上所述。`include` 在应用中没有对应的控件,对审查也没有影响;`include` 列表非空的规则不会显示在继承列表中。
