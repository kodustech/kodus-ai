title: "PR 摘要"
description: "让 Kody 撰写简洁、可执行的 pull request 描述,并调整语气、触发时机以及对已有描述的处理方式。"
---

Kody 的 PR 摘要功能允许您自动创建简洁、可操作的拉取请求描述。
本配置指南解释了如何根据团队的工作流程和偏好定制该功能。

在侧边栏中打开 **Code review → What Kody writes**;这些设置位于 **PR summary** 部分。页面的实时预览
(**Show preview** / **Hide preview**)会展示摘要在示例拉取请求上的呈现效果。

## 启用自动摘要

启用或禁用拉取请求摘要的自动生成:

切换 **Write a summary on every pull request**。

启用后,Kody 将为每个拉取请求生成摘要,确保一致性并节省时间。

## 当 PR 已有描述时

控制 Kody 如何与现有拉取请求描述交互。您可以从三种模式中选择:

### 替换(默认):

用从头开始新生成的摘要覆盖任何现有描述。

### 连接:

将生成的摘要附加到现有描述的末尾。

### 补充:

将 Kody 生成的见解与当前描述相结合,仅突出显示新的或相关的内容。

## 当有新提交时

控制在 PR 打开后推送新提交时,Kody 的摘要如何处理:

- **Do nothing**(默认)—— 摘要保持不变。
- **Concatenate new summary** —— 在 Kody 现有摘要的基础上追加新摘要。
- **Replace Kody's summary** —— 用新摘要替换 Kody 现有的摘要。

## 摘要说明

通过提供具体指南来微调 Kody 如何生成摘要:

在可选的 **Summary instructions** 字段中添加说明 —— 摘要应关注或省略哪些内容。**Examples** 标签会插入
现成的说明。

**示例:**

* "关注安全更改和性能影响。"
* "简洁地总结,突出显示修改的公共 API。"

点击 **Try on a real PR**,在你的某个拉取请求上预览这些设置生成的摘要。
