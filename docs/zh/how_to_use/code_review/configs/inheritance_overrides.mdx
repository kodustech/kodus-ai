## 概述

Kodus 配置跨三个级别工作：**全局**、**代码库**和**目录**。

<Note>
最具体的级别优先：目录 > 代码库 > 全局
</Note>

```
Global
 ├─ Repository A
 │   ├─ Directory A1
 │   └─ Directory A2
 └─ Repository B
```

## 工作原理

字段默认从父级继承。当您在全局级别更改字段时，所有没有覆盖的代码库和目录都会自动更新。

<Info>
覆盖是按字段进行的。您可以覆盖一个字段并继承其他所有字段。
</Info>

一旦被覆盖，字段将停止跟随父级并使用其本地值。

## 在应用中

- **切换级别：** 侧边栏 **Code review** 分组顶部的作用域选择器会列出 **Global**（"applies to every repository"），然后是 Kody 审查的每个代码库，其目录作用域缩进显示在下方。没有自身设置的代码库会标记为 **Inherits Global**。如果新作用域下存在同一页面，切换作用域时会停留在该页面。
- **添加级别：** 代码库在您首次于其作用域保存更改时获得自己的设置。要添加目录作用域，请选择该代码库，然后选择选择器底部的 **Add directory scope**。参见[目录级设置](/zh/how_to_use/code_review/configs/directory_level)。
- **查看覆盖：** 侧边栏中作用域或页面旁的数字徽标统计在该级别被覆盖的设置数量（"N settings overridden at this level"）。在页面上，每个被覆盖的字段都会显示 **Overridden** 徽标；点击其撤销按钮可让该字段恢复继承。
- **删除级别：** 作用域选择器旁的 **⋯** 菜单中有 **Delete configuration**，目录作用域下还有 **Edit directories**。删除后，代码库使用全局配置，目录的文件夹使用其所属代码库的配置。只有在移除代码库的目录作用域之后，才能删除该代码库的配置。

## kodus-config.yml

当代码库开启 **Prefer kodus-config.yml settings** 时，Kody 会从该代码库默认分支的根目录读取 `kodus-config.yml`。它叠加在全局和代码库自身的设置之上，位于目录作用域所覆盖的任何设置之下。参见[通用设置](/zh/how_to_use/code_review/configs/general#config-priority)。

```
Global
 └─ Repository
     └─ kodus-config.yml at the repository root (optional)
         └─ Directory
```

- 根目录文件是 Kody 读取的唯一文件。它不会读取文件夹内的 `kodus-config.yml`。
- 只有在**代码库**作用域开启该开关时，才会读取根目录文件。该开关也会出现在目录作用域，但它不会改变审查。
- 目录作用域的设置来自应用，或来自[集中式配置](/zh/how_to_use/code_review/configs/centralized_config)仓库，后者会写入同样的全局、代码库和目录设置。
- 只有当 PR 恰好触及一个目录作用域时，目录级别才会生效。参见[目录级设置](/zh/how_to_use/code_review/configs/directory_level#选择规则)。

## 示例

<Tabs>
  <Tab title="全局更改传播">
    您在全局级别更改 **Minimum severity to post**（位于 **What to review**）。

    所有没有覆盖的代码库和目录都会自动更新。已覆盖的保持不变。
  </Tab>

  <Tab title="代码库覆盖">
    在代码库 X 中，您覆盖 **Review starts** 消息（位于 **What Kody writes → Comments during the review**）。

    代码库 X 内的目录现在从代码库 X 继承（除非它们有自己的覆盖）。
  </Tab>

  <Tab title="返回继承">
    在代码库 Y 中，您删除 **What to review** 上类别开关的覆盖。

    该字段再次跟随全局并接收未来的全局更改。
  </Tab>
</Tabs>

## 最佳实践

- 从全局开始设置强大的默认值
- 仅在该代码库/目录有特定需求时才覆盖

## 常见问题

<AccordionGroup>
  <Accordion title="如果我在全局级别更改某些内容，会破坏我的本地调整吗？">
    不会。本地覆盖保持不变。
  </Accordion>

  <Accordion title="我可以只覆盖一个字段并继承其余字段吗？">
    可以。覆盖是按字段进行的。
  </Accordion>

  <Accordion title="目录是从代码库还是全局继承？">
    首先从代码库继承，如果优先使用，则包括该代码库的 `kodus-config.yml`。如果代码库对该字段没有覆盖，则从全局继承。
  </Accordion>
</AccordionGroup>
