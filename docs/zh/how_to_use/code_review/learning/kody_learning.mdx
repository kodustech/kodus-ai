对 Kody 评论的表情反应不会训练模型,也不会过滤下一次审查。Kody 会记录 👍 和 👎 反应以及每条建议是否被采纳,并在 Cockpit 中报告。它们唯一起作用的地方是 **Pause ignored and noisy rules**(见下文):如果某条 Kody Rule 的建议收到 👎 或很少被采纳,该规则可以被暂停。

您仍可以对建议添加表情,作为给团队的反馈。若要阻止某类建议再次出现,请使用下面的机制之一。

## 哪些机制会影响后续审查

- **同一 PR 上的早期建议:** 对于 Kody 已审查过的 PR,它会看到自己此前发布的建议以及这些建议是否被采纳,并避免再次发布。
- [记忆](/zh/knowledge_base/how-to-teach-ai-your-team-conventions): 通过 `@kody remember` 和对话保存明确的团队约定。
- [Kody Rules](/zh/how_to_use/code_review/configs/kody_rules): 定义代码审查时应用的标准。
- [自动规则生成](/zh/how_to_use/code_review/learning/kody_rules_generation): 根据审查历史生成规则。规则默认直接生效;开启 **Kody knowledge approval** 时,则保留在 **Pending review** 中等待批准。
- [Pause ignored and noisy rules](/zh/how_to_use/code_review/configs/kody_rules#pause-ignored-and-noisy-rules): 适用于 Teams 和 Enterprise 套餐,默认关闭。开启后,Kody 每天会暂停一次过去 30 天内被标记为 **Ignored**(很少有建议被采纳)或 **Noisy**(大多是 👎)的活跃规则。
