<Note>
基于反馈表情的微调目前未启用。👍/👎 反馈和建议实施状态仍可被记录，但不会训练模型、生成偏好聚类，也不会过滤下一次审查的建议。
</Note>

仅有点赞或点踩无法解释建议被拒绝的原因。重新启用这一学习闭环前，需要更丰富的负面反馈上下文。

你仍可留下表情作为可选的产品反馈，但不要期待点赞或点踩会自动屏蔽后续审查中的类似建议。

## 哪些机制会影响后续审查

- [记忆](/zh/knowledge_base/how-to-teach-ai-your-team-conventions): 通过 `@kody remember` 和对话保存明确的团队约定。
- [Kody Rules](/zh/how_to_use/code_review/configs/kody_rules): 定义代码审查时应用的标准。
- [自动规则生成](/zh/how_to_use/code_review/learning/kody_rules_generation): 根据审查历史提出规则，由用户手动导入。这是与表情反馈微调不同、仍在运行的功能。
