## FGPAT 简介

要使 Kody 能够执行自动代码审查,您需要在 GitHub 中生成一个细粒度个人访问令牌(FGPAT)。此令牌允许 Kody 以受控方式安全地访问您的代码库并执行代码分析。

## 检查细粒度访问权限

默认情况下,细粒度 PAT 可能无法访问您组织的内容。通过以下步骤确保访问权限:

![title](/images/fgpat.png)

1. 您必须是组织所有者。
1. 转到 GitHub 中的组织设置:
   - 您可以使用此 URL 替换为您的组织名称: <small>https://github.com/organizations/YOUR_ORG_NAME/settings/personal-access-tokens</small>。
1. 在左侧边栏的 **Personal access tokens** 下,点击 **Settings**。在 **Fine-grained tokens** 标签页上,选择 **Allow access via personal access tokens** 并点击 **Save**。

## 生成 FGPAT(细粒度个人访问令牌)

按照以下步骤正确设置令牌:

1. **访问 GitHub 并进入您的个人资料设置**:

   - [点击此处访问个人资料设置页面](https://github.com/settings/profile)。

2. **导航到 `Developer Settings`**:

   - 在左侧边栏中,向下滚动找到 `Developer Settings` 并点击它。

3. **转到 `Personal Access Tokens`**:

   - 仍在左侧边栏中,在 `Developer Settings` 下,选择 `Personal Access Tokens`。
   - 然后,点击 [Fine-grained Tokens](https://github.com/settings/tokens?type=beta)。

4. **生成新令牌**:

   - 点击 `Generate new token` 按钮。

5. **使用以下规格设置新令牌**:

   - **Token Name**:选择一个容易识别的名称,例如 `kody_code_review`。
   - **Expiration Date**:如果可能,选择较长的到期日期,最好至少 180 天。
   - **Resource Owner**:确保组织设置为令牌所有者,因为团队的代码库位于组织下。
   - **Repository Access**:选择 **All repositories** 以允许令牌访问所有代码库。
   - **Permissions**:配置以下权限:
   - **Repository**:
     - **Commit statuses**:读权限。
     - **Contents**:读和写权限。
     - **Issues**:读权限。
     - **Metadata**:读权限。
     - **Pull requests**:读和写权限。
     - **Webhooks**:读和写权限。
   - **Organization**:
     - **Members**:读权限。

   Kody 不使用 **Actions** 或 **Deployments**;请将它们保持为 **No access**。

6. **完成并保存令牌**:
   - 设置权限后,点击 `Generate token`。
   - 确保复制生成的令牌并安全存储,因为您需要它来配置 Kody。

## 将令牌添加到 Kody

生成令牌后,将其粘贴到 Kodus 中:

- **在入门引导期间**:在 **Connect your Git tool** 上选择 **Github** 标签页,然后点击 **Connect via token**。
- **之后**:在侧边栏中打开 **Repositories**,点击 **Connect a provider** 下的 **Github**,切换到 **Token** 标签页,粘贴令牌并点击 **Validate and save**。
- **替换令牌**:在 **Repositories** 中,点击 **Github** 卡片上的 **Reset**,选择 **Just reset the integration**,然后按上述步骤使用新令牌重新连接。

使用令牌时,审查会以您的 GitHub 个人资料而不是 Kody 的身份发布,并且 GitHub Checks / PR 状态不可用。

## GitHub Enterprise Server (Beta)

要使用令牌连接 GitHub Enterprise Server，Cloud 工作区需开通此 Beta 功能。自托管 Kodus 需设置 `BETA_FEATURES=true`。

1. 在您的 GitHub Enterprise Server 实例上创建令牌。
2. 在 **Github** 令牌对话框中,打开 **Self-hosted** 并输入您的 **GitHub Enterprise URL**,例如 `https://github.your-company.com`。它必须以 `http://` 或 `https://` 开头。
3. 粘贴令牌并点击 **Validate and save**。

Kodus 会调用该实例位于 `<GitHub Enterprise URL>/api/v3` 的 API。如果令牌或 URL 有误,对话框会显示 **Invalid Token or GitHub Enterprise URL**。
