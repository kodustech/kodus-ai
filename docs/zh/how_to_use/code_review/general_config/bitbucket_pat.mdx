## 简介

要使 Kody 能够对 Bitbucket Cloud 执行自动代码审查,您需要生成一个 **API 令牌**。此令牌允许 Kody 访问您的代码库、拉取请求、webhooks 和工单,并具有下面列出的特定权限。

---

## 在 Bitbucket 中生成 API 令牌

1. 直接打开 [Atlassian API 令牌页面](https://id.atlassian.com/manage-profile/security/api-tokens)(或从您的 Atlassian 个人资料导航到 **Security → API tokens**)。
2. 点击 **Create API token with scopes**。
3. 为令牌命名(例如 `kody_code_review`)并设置到期日期。
4. 如果出现提示,选择 **Bitbucket** 作为应用程序。
5. 选择所有必需的范围(见下文)。
6. 查看您的选择,然后点击 **Create token**。
7. **立即复制**令牌并安全存储——创建后您将无法再次查看它。

---

## Kody 所需的范围

令牌必须包含 Kody 完整功能所需的**所有**以下范围:

| 范围                         | 用途/启用的功能                                                                   |
| ----------------------------- | ------------------------------------------------------------------------------------------- |
| `read:user:bitbucket`         | 读取基本用户或账户信息。                                                     |
| `read:workspace:bitbucket`    | 读取有关工作区的信息(项目、成员、代码库)。                     |
| `read:project:bitbucket`      | 读取有关项目的元数据。                                                               |
| `read:repository:bitbucket`   | 读取代码库中的代码、分支、源文件。                                          |
| `write:repository:bitbucket`  | 为会修改代码库文件的功能提交文件。                                     |
| `read:pullrequest:bitbucket`  | 查看拉取请求、其状态、评论。                                               |
| `write:pullrequest:bitbucket` | 创建或修改拉取请求评论;批准、拒绝或合并 PR。                      |
| `read:issue:bitbucket`        | 读取工单跟踪器信息。                                                             |
| `read:webhook:bitbucket`      | 查看现有 webhooks 及其设置。                                                  |
| `write:webhook:bitbucket`     | 创建或更新 webhooks。                                                                  |
| `delete:webhook:bitbucket`    | 删除集成时移除 Kodus 的 webhooks。                                      |

Kody 不使用 `admin:repository:bitbucket` 或 `read:pipeline:bitbucket`。CI 状态通过 `read:repository:bitbucket` 读取。

> ⚠️ 确保您仅授予这些必要的权限;避免授予超过所需的权限以降低安全风险。

---

## 将令牌添加到 Kody

- 一旦使用所有必需的范围生成令牌,将其粘贴到 Kodus 中:在入门引导期间(**Connect your Git tool** → **Bitbucket** 标签页 → **Connect via token**),或之后在侧边栏的 **Repositories** → **Connect a provider** → **Bitbucket** 中。填写 **Username**、**Email** 和 **API token**,然后点击 **Validate and save**。
- 要创建用于投递拉取请求事件的 webhook,Kody 需要 `read:webhook:bitbucket` 和 `write:webhook:bitbucket`,并且令牌所属用户必须是该代码库的管理员。
- 要替换令牌,请在 **Repositories** 中点击 **Bitbucket** 卡片上的 **Reset**,选择 **Just reset the integration**,然后使用新令牌重新连接。

---

## Bitbucket Data Center

对于自托管的 Bitbucket Data Center,请在同一表单中打开 **Bitbucket Data Center**(标记为 **Alpha**)。上述 API 令牌及其范围仅适用于 Bitbucket Cloud。Data Center 改用基本认证连接:填写 **Username**、**Bitbucket Data Center Base URL**(例如 `https://bitbucket.your-company.com`)和 **Basic auth password**,然后点击 **Validate and save**。

---

## 重要说明

- 令牌将在创建时**仅显示一次**。请安全保存,因为您将**无法**再次查看它。
- 如果可能,设置**到期日期**以限制令牌的生命周期。
- 如果令牌被泄露,请立即撤销它并创建一个新的。
- 定期审核令牌及其范围,以确认它们仍然必要和有效。
- 检查您的 Bitbucket 计划/账户是否允许上述所有范围;某些范围(项目、工作区)可能取决于订阅/权限。
