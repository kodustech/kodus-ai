## 简介

要使 Kody 能够在 Forgejo 上执行自动代码审查,您需要生成一个**访问令牌**。此令牌允许 Kody 访问您的代码库、拉取请求、webhooks、工单等,并具有下面列出的特定权限。

---

## 在 Forgejo 中生成访问令牌

1. 访问您的 Forgejo 实例,点击右上角的头像图标
2. 选择 **Settings**
3. 导航到 **Applications**
4. 在 **Generate New Token** 下,为令牌命名(例如 `kodus_code_review`)
5. 选择所需的权限(见下文)
6. 点击 **Generate Token**
7. **立即复制**令牌并安全存储 — 关闭页面后将无法再次查看

---

## Kody 所需的权限

令牌必须包含 Kody 完整功能所需的**所有**以下权限:

| 类别 | 级别 | 用途 |
|----------|-------|---------|
| `repository` | **Read & Write** | 访问代码、分支、文件,创建 PR 评论,管理 webhooks |
| `issue` | **Read & Write** | 读取并发布拉取请求评论和反应 |
| `organization` | **Read** | 列出令牌用户所属的组织及其代码库 |
| `user` | **Read** | 读取基本用户信息,认证所需 |

令牌用户还必须是 Kody 审查的**每个代码库的管理员**。Forgejo 只允许代码库管理员创建 webhooks 和驳回审查,否则 Kody 无法自动注册 webhook,也无法在后续审查保留批准时撤回自己的批准。

---

## 将令牌添加到 Kody

将生成的令牌粘贴到 Kodus 中:在入门引导期间(**Connect your Git tool** → **Forgejo** 标签页 → **Connect via token**),或之后在侧边栏的 **Repositories** → **Connect a provider** → **Forgejo** 中。填写 **Forgejo Instance URL** 和 **Personal Access Token**,然后点击 **Validate and save**。

之后要替换令牌,请在 **Repositories** 中点击 **Forgejo** 卡片上的 **Update token**,粘贴新令牌并点击 **Update token**。

---

## 重要说明

- 令牌在创建后**仅显示一次**。请安全保存。
- 如果令牌泄露,请立即撤销并创建新令牌。
- 定期审计令牌及其权限,以确认是否仍然需要。
