## 什么是开发者活动

开发者活动显示每位开发者随时间打开的 pull request，让您可以了解整个团队的工作负载和活动模式。

在 Cockpit 中，它是 **Productivity** 标签页上的 **Team Activity** 图表：一张表格，每位开发者一行，每周一列（周日到周六），最新的在前。每一行显示该开发者在该范围内的 PR 总数，每一周则为每个打开的 PR 显示一个条形。

## 我们如何计算

```
Activity = COUNT(PRs opened) per developer per week
```

- PR 按其**打开**的日期计入，无论其当前状态如何（打开、已合并或已关闭）。对于在其仓库连接之前就已打开、且不在连接时导入的 PR 之列的 PR，该日期是 Kodus 首次记录它的日期。
- 开发者是 PR 作者在您的 Git 提供商上的用户名。没有作者的 PR 会被排除。
- 它涵盖在 Cockpit 顶部选择的日期范围。

请与[开发者的 PR](/zh/how_to_use/cockpit/metrics/prs_by_developer) 对比，后者按 PR **关闭**的日期统计。

## 为什么重要

- **平衡工作负载**：查看工作是否在团队中均匀分布
- **跟踪趋势**：了解活动随时间的变化
- **发现瓶颈**：找到工作堆积在少数人身上的地方

PR 数量并不能说明 PR 的大小或难度，因此请将其与 [PR 大小](/zh/how_to_use/cockpit/metrics/pr_size)对照阅读。
