## 什么是部署频率

部署频率是您的团队每周关闭的 pull request 的平均数量。Cockpit 不会从您的 CI/CD 中读取部署，因此它使用已关闭的 pull request 来代替代码到达生产环境的频率。

在 Cockpit 中，它是 **Productivity** 标签页上的 **Deploy Frequency** 卡片。

## 我们如何计算

```
Deploy Frequency = (PRs closed in the range) ÷ (weeks in the range)
```

- 范围是在 Cockpit 顶部选择的日期范围。其周数向上取整，最少为一周。
- 每个已关闭的 PR 都会计入，无论其基础分支是什么，未合并即关闭的 PR 与已合并的 PR 计数相同。

例如，如果 4 周的范围内关闭了 12 个 PR，则部署频率为每周 3 个。

如果您的团队部署的节奏与关闭 PR 的节奏不同（例如发布列车，或从功能分支部署），请将该数字理解为 PR 吞吐量，而不是部署次数。

## 读懂卡片

卡片显示每周的平均值、一个级别徽章，以及相同长度的上一周期的值和百分比变化。无论选择了哪个范围，页脚都显示 "Last 2 weeks was …"；该数字对应的是上一周期。将鼠标悬停在徽章上可查看各级别：

| 每周关闭的 PR | 级别 |
| --- | --- |
| 多于 5 | Elite |
| 2 到 5 | High |
| 1 到 2 | Fair |
| 少于 1 | Need focus |

## 如何改进

- 将大型更改分解为更小的 PR
- 实施 CI/CD 流水线以实现自动化部署
- 使用功能标志在不暴露功能的情况下部署
- 设置监控和快速回滚
