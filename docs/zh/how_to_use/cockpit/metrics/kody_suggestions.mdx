## 什么是实施率

实施率是 Kody 发送的建议中，您的团队实施的占比。它显示 Kody 的反馈中有多少转化为了代码更改。

在 Cockpit 中，它位于 **Kodus Review** 标签页上，即 **Implementation rate** 和 **Suggestions sent** 卡片以及其下方的图表。参见 [Kodus Review](/zh/how_to_use/cockpit/kodus_review)。

## 我们如何计算

```
Implementation Rate = (Implemented Suggestions) ÷ (Suggestions Sent) × 100
```

- 只有作为 PR 评论发送的建议才会被计入。
- 当一条建议在其 PR 关闭时的状态为 **Implemented** 或 **Partially implemented** 时，即计为已实施。
- 在所选日期范围内关闭的 PR 上的建议会被计入，并按 PR 关闭的那一周分组。
- 实施检查无法判断的建议会被排除在比率之外，而不是被计为被忽略。

例如，如果 Kody 发送了 20 条建议，其中 16 条被实施，则您的实施率为 80%。

## 如何改进

- 配置符合您团队标准的 Kody Rules
- 在 **Kody Rules — health** 表中查找噪音大或被忽略的规则，然后重写或限定其范围
- 查看 **Implementation rate by category**，了解最常被忽略的主题
- 在 **Negative feedback** 中查看 👎 反应，了解团队在哪些地方存在分歧（反应会被记录为反馈，本身不会改变之后的审查；参见[对建议的反馈](/zh/how_to_use/code_review/learning/kody_learning)）
