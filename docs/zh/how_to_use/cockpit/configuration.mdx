---
title: "Cockpit 配置"
description: "通过一个组织级设置，隐藏您的组织不希望展示的 Cockpit 标签页和单个指标。"
---

并非每个团队都希望所有指标可见。Cockpit 允许 Owner 为**整个组织**关闭整个标签页或单个图表 ——
当某个指标对您的工作流来说噪音过大，或您根本不希望展示按开发者维度的数字时，这很有用。

只有 Owner 可以在 **Organization → Cockpit visibility** 中更改全组织的可见性。有关套餐和自托管要求，请参阅 [Cockpit 可用性](/zh/how_to_use/cockpit/overview)。

在侧边栏中打开 **Organization → Cockpit visibility**。该页面的标题为
**Cockpit Configuration**；点击 **Save settings** 应用您的更改。

<Info>
  这是**组织级**设置，不是按用户的偏好。关闭某个指标会对所有人隐藏它。只有 Owner 可以更改它。
</Info>

## 标签页

三个指标标签页中的每一个都可以隐藏（旁边的 **Code hotspots** 和 **Issues** 标签页不受此处控制）：

| 标签页 | 包含内容 |
| --- | --- |
| **Kodus Review** | Kodus 的审查有多有效：实施率、严重程度校准、负面反馈、Kody Rules 健康度。此标签页没有单项开关。 |
| **Delivered as asked** | 对照任务检查的 pull request：满足任务的占比、任务之外的变更，以及按作者和团队的拆分。 |
| **Productivity** | 交付类指标：部署频率、cycle time、PR 大小、团队活跃度。 |

<Warning>
  **至少要保留一个标签页处于开启状态。** 表单会拒绝把它们全部关闭。
</Warning>

隐藏 Productivity 标签页同时会隐藏其中的全部内容，因此下面的单项开关只在该标签页开启时才有意义。当 **Kodus Review** 也被隐藏时，Cockpit 仍会显示 Productivity 标签页。

## 摘要卡片

Productivity 标签页顶部的卡片：

| 指标 | 展示内容 |
| --- | --- |
| **Deploy Frequency** | 每周关闭的 pull request 数。参见[部署频率](/zh/how_to_use/cockpit/metrics/deploy_frequency) |
| **PR Cycle Time** | 从 PR 打开到关闭的时长（第 75 百分位）。参见 [PR 周期时间](/zh/how_to_use/cockpit/metrics/lead_time_for_changes) |
| **Bug Ratio** | 被归类为 bug 修复的已关闭 PR 的百分比。参见 [Bug 比率](/zh/how_to_use/cockpit/metrics/change_failure_rate) |
| **PR Size** | 每个 pull request 的平均变更行数。参见 [PR 大小](/zh/how_to_use/cockpit/metrics/pr_size) |

## 明细图表

摘要卡片下方的图表：

| 图表 | 展示内容 |
| --- | --- |
| **Lead Time Breakdown** | 每周的编码、领取和审查时间。参见 [交付时间细分](/zh/how_to_use/cockpit/metrics/lead_time_breakdown) |
| **PR Cycle Time Chart** | 按周绘制的 cycle time |
| **PRs Opened vs Closed** | 每周打开与关闭的数量。参见[开启 vs 关闭的 PR 数](/zh/how_to_use/cockpit/metrics/prs_opened_vs_closed) |
| **PRs Merged by Developer** | 每位作者每周关闭的 PR 数。参见 [开发者的 PR](/zh/how_to_use/cockpit/metrics/prs_by_developer) |
| **Team Activity** | 每位开发者打开的 PR 数。参见[开发者活动](/zh/how_to_use/cockpit/metrics/developer_activity) |

## 说明

- 您未配置的指标是可见的。您保存的配置会合并到当前默认值之上，因此旧的已保存配置永远不会隐藏后来新增的图表。
- 隐藏指标只影响展示。Kodus 仍会持续采集底层数据，因此重新开启时会显示完整历史，而不是只有开启之后的数据。
