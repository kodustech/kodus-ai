## 什么是驾驶舱分析

驾驶舱分析通过衡量生产力、代码质量和交付效率的关键指标,为您的工程团队绩效提供全面的见解。这些指标帮助您识别改进领域并随时间跟踪进度。

<Warning>
  驾驶舱需要付费档位:**云端的 Teams 或 Enterprise**(包括试用期),或**已授权的自托管 Enterprise**。未授权的自托管(Community)和 free BYOK 套餐不包含它:侧边栏中的 **Cockpit** 项仍会显示,但带有锁形图标,点击后会打开一个模糊的 **Unlock the Cockpit** 预览,其中有一个 **See plans** 按钮(自托管上为 **Activate a license**)。自托管 Enterprise 还需要运行 [Analytics Worker](/zh/how_to_deploy/deploy_kodus/analytics_worker)。
</Warning>

## 主要功能

- 数据默认每 30 分钟刷新一次(`ANALYTICS_INGESTION_CRON`)
- 云端的 Teams / Enterprise(包括试用期),或已授权的自托管 Enterprise
- AI 驱动的指标计算
- 8+ DORA 和自定义指标

## 标签页

驾驶舱分为两个指标标签页,后面还有一个 **Issues** 标签页:

- **Kodus Review**(默认打开)— 衡量 Kodus 审查的有效性:实施率、严重程度校准、负面反馈,以及 Kody 规则的健康状况。这关注的是 Kodus 本身,也是您采取行动的地方。参见 [Kodus 审查](/zh/how_to_use/cockpit/kodus_review)。
- **Productivity** — 通用交付指标:部署频率、交付时间、PR 周期时间、PR 大小以及开发人员活动。
- **Issues** — 打开 [Issues](/zh/how_to_use/issues/overview) 列表,标签名旁边会显示未关闭 issue 的数量。

在页面顶部,您可以选择一个仓库(默认为 **All repositories**)和一个日期范围(默认为 **Last 15 days**;预设有 **Last week**、**Last 15 days**、**Last month**、**Last 3 months**,也可以自定义日期)。没有按开发人员筛选的选项。链接按钮(**Copy link to this view**)会复制一个 URL,用它可以重新打开相同的标签页、仓库和日期范围。

<Note>
  Owner 可以在 **Organization → Cockpit visibility** 中为整个组织隐藏整个标签页或单个指标 —— 参见
  [驾驶舱配置](/zh/how_to_use/cockpit/configuration)。
</Note>

## 关键指标类别

**可用指标:**
- **Kodus 审查:**实施率(总体、按严重程度、按类别)、负面反馈、仓库和 Kody 规则健康状况
- **生产力:**部署频率、交付时间、PR 周期时间
- **质量:**PR 大小、代码审查有效性
- **团队绩效:**协作模式、瓶颈识别


## 开发人员匹配的工作原理

驾驶舱的按开发人员图表(**PRs Merged By Developer**、**Team Activity**)会将每个拉取请求归属到其**作者在 Git 提供商上的用户名**。这可能与以下内容不同:
- GitHub/GitLab 显示名称
- 电子邮件地址
- Kodus 工作区账户

<Tip>
  如果您在开发人员指标中看到差异,请检查同一个人是否使用多个 Git 提供商账户创建拉取请求。
</Tip>
