## 什么是 Kodus

**Kody** 可以审查 GitHub、GitLab、Bitbucket、Azure Repos 和 Forgejo 上的拉取请求，并根据团队规则检查代码变更。Kodus 是开源的，可部署在自己的基础设施上。

## Kodus 能做什么

- [查看审查结果](/zh/how_to_use/code_review/flow#你会得到什么)。了解 Kody 会在 PR 中发布什么，以及如何请求再次审查。
- [调整审查内容](/zh/how_to_use/code_review/configs/what_to_review)。选择审查类别、最低严重级别和要检查的内容。
- [教 Kody 遵守团队规范](/zh/how_to_use/code_review/configs/kody_rules)。使用规则和记忆，在审查中应用团队约定。
- [按任务要求核对 PR](/zh/how_to_use/code_review/business_logic_validation)。将代码实现与任务管理工具中的要求进行对比。

## 支持的语言

Kody 开箱即用地支持任何编程语言或文件类型,使用语义(LLM)分析,并通过代码搜索(grep 样式)提供精确的、代码库范围的上下文。
