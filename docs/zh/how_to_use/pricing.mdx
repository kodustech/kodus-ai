套餐的区别在于功能,而不在于 Kody 可以审查多少个拉取请求。价格和商务条款请见 [kodus.io/pricing](https://kodus.io/pricing)。

<Note>
  **所有套餐的 PR 审查和工作区成员都不限量。** 在付费套餐上,由开发者许可证决定审查谁的拉取请求。在 Free 和 Teams 上,审查使用您自己的 AI 密钥(BYOK)运行。如果一次审查的**可审查文件超过 2,000 个**，Kody 会跳过该次审查。仅由自定义智能体审查的文件也计入上限。
</Note>

## 套餐

<CardGroup cols={3}>
  <Card title="Free" icon="github">
    云端。审查使用您自己的 AI 密钥运行,在您添加之前不会连接任何密钥。
  </Card>
  <Card title="Teams" icon="users">
    云端。按开发者计的许可证,并解锁 Team 功能。审查使用您自己的 AI 密钥运行。
  </Card>
  <Card title="Enterprise" icon="building">
    云端,或使用许可证密钥的自托管。增加 SSO 和活动日志。
  </Card>
</CardGroup>

没有许可证密钥的自托管实例运行 **Community Edition**,其限制与 Free 相同。Teams 是云端套餐。要在自托管实例上解锁 Enterprise,请将您从 Kodus 收到的密钥粘贴到 **Subscription → Activate a license key** 下。密钥过期后,Enterprise 功能会关闭,直到您粘贴续期后的密钥。

在 **Subscription** 下,**Choose a plan**(Free 套餐上为 **Upgrade**)会打开套餐选择器。在付费套餐上,**Manage billing** 会打开 Stripe,您可以在那里更改开发者许可证和付款详情。

## 免费试用

新的 Kodus Cloud 工作区可享受 **14 天试用**。功能试用期限和 Kodus 承担费用的审查次数分别计算。

<CardGroup cols={2}>
  <Card title="14 天试用权限" icon="calendar">
    试用包括 Teams 功能，以及 Enterprise 的 SSO 和活动日志。试用期间，全局规则来源合计最多可导入五条规则。
  </Card>
  <Card title="前 5 次 PR 审查由我们承担" icon="gift">
    Kodus 承担 AI token 费用,因此您无需 API 密钥即可试用 Kody。试用审查使用 Kodus 提供的高效模型运行。连接您自己的密钥即可使用更大的模型。
  </Card>
</CardGroup>

**Subscription** 会显示如何获得更多试用审查:使用公司邮箱注册、邀请队友,或连接拥有 10 名或更多开发者的 Git 组织。**Request review** 会请求 Kodus 查看您的试用并为其延期。

要在试用审查用完后继续审查,请在 [**AI providers**](/zh/how_to_use/byok) 下连接您的 AI 密钥。之后审查会使用您的密钥运行,在任何套餐上都没有审查数量限制,即使 14 天结束后也是如此。如果试用审查在您连接密钥之前用完,Kody 会暂停审查,并在开启 **Show status feedback** 时,在拉取请求上发表评论,附上添加密钥的链接。试用结束后,请在 **Subscription** 下选择一个套餐以保留 Team 功能。

在没有密钥的自托管实例上,**Subscription** 上的 **Request a trial** 会向 Kodus 申请一个许可证密钥用于试用。

## 开发者许可证

在带有席位的付费套餐上,开发者持有许可证时,其拉取请求才会被审查。许可证统计的是您 Git 组织中的开发者。工作区成员(即配置 Kodus 的人)是单独的,且不限量。

- 所有者在 **Subscription** 的 **PR licenses** 标签页中分配或释放许可证。
- 开启 **Auto-assign licenses** 后,开发者的第一个 PR 会在没有席位的情况下被审查,当他们打开另一个 PR 时,如果有空闲席位,就会分配一个席位。请参阅[自动许可证分配](/zh/how_to_use/auto_license_assignment)。
- Free 套餐和试用没有按开发者计的许可证。

## 所有套餐上的 BYOK

您连接自己的提供方,由提供方向您收取 token 费用。在 Enterprise 上,Kodus 也可以按照您的协议运行这些模型。提供方和设置请参阅 [BYOK](/zh/how_to_use/byok),支出提醒请参阅[月度支出上限](/zh/how_to_use/spend-limit)。

## 付款

付费套餐通过 Stripe 计费。**Subscription** 上的 **Manage billing** 会打开用于付款方式和发票的 Stripe 页面,所有者和计费管理员可以使用。如果付款失败,审查会暂停,直到更新账单。已取消或已过期的订阅也会暂停审查,直到您再次订阅。
