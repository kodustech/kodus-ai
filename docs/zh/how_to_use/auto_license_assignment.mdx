---
title: "自动许可证分配"
description: "让 Kodus 自动把许可证分配给真正在贡献的开发者,而不必逐个手动管理席位。"
---

自动许可证分配功能简化了组织内开发人员许可证的管理。Kodus 可以自动为活跃贡献者分配许可证,而不是手动为每个开发人员分配许可证。

## 工作原理

启用后,Kodus 会监控代码库中的拉取请求活动。

-   **自动分配:**如果用户创建了多个拉取请求,Kodus 会检查组织中是否有可用的许可证槽位。
    -   如果有可用槽位,用户将自动分配许可证,并审查他们的 PR。
    -   如果没有可用槽位,Kodus 将对拉取请求做出反应,对于 Github 使用点踩表情符号(👎),对于 Gitlab 使用挂锁表情符号(🔒),以表明由于缺少许可证而无法执行审查(仅当 **Code review → General** 中开启了 **Show Status Feedback** 时)。

## 忽略的用户

您可以配置**忽略的用户**列表。这些用户将被排除在自动分配流程之外。该列表在 **Repositories** 页面的 **PR author filters** 选项卡中通过 **Exclude PR authors** 设置(或者反过来,使用 **Only these PR authors**)。

-   **不审查:**Kodus 不会审查忽略用户创建的拉取请求——除非该用户持有许可证,许可证会覆盖此过滤器。
-   **不反应:**即使超过 PR 限制,Kodus 也不会对他们的 PR 做出反应。就像 Kodus 完全忽略了 PR 一样。

这对于机器人、服务账户或不需要代码审查的特定团队成员很有用。

## 配置

要启用和配置自动许可证分配:

1. 在侧边栏中,打开 **Organization → Subscription**。
2. 停留在 **PR licenses** 选项卡。
3. 开启或关闭 **Auto-assign licenses**。
    - **Release seats automatically**(同一卡片中)会在成员离开您的 git 组织几天后(默认 7 天)释放其许可证。
    - 要排除用户,请使用 **Repositories → PR author filters**(参见[忽略的用户](#忽略的用户))。

这些开关仅在有效的付费计划或已获得许可的自托管实例中显示,并且仅对可以管理席位的成员(Owners)可见。
