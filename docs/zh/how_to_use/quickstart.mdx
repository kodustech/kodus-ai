---
title: "快速开始"
description: "让 Kody 开始审查你的 pull request:创建账户、连接 Git 提供商、选择代码库并运行第一次审查。"
---

准备一个有权访问目标仓库的 Git 账号。如果使用自托管 Kodus，请在实例的 URL 上注册。

<Steps>
  <Step title="创建账户">
    使用 Kodus Cloud 时，请打开[注册页面](https://app.kodus.io/sign-up)。如果你使用自托管版 Kodus，请打开自己实例上的注册页面。

    点击 **Sign up with Github** 或 **Sign up with Gitlab**,或使用您的电子邮件注册。电子邮件注册需要企业邮箱地址:Gmail 或 Outlook 等免费域名会被拒绝。

    <Frame caption="Kodus Cloud 注册页面">
      <img src="/images/cloud-sign-up.png" alt="使用 GitHub、GitLab 或企业邮箱注册的选项" width="440" />
    </Frame>
  </Step>

  <Step title="创建您的工作区">
    如果某个工作区为您的电子邮件域名开启了自动加入,Kodus 会显示 **We found some organizations!**。选择它并点击 **Continue**,以 Contributor 身份加入(在 Kodus Cloud 上,随后需要确认您的电子邮件),或点击 **Create a new organization**。

    在 **Let's create a Workspace** 页面,将自动生成的 **Organization Name** 替换为您自己的并点击 **Next**。**Phone** 是可选的。**Enable Auto Join** 默认对您的电子邮件域名开启(公共域名除外),因此该域名下任何地址的用户都可以加入;如果您不希望如此,请将其关闭。参见[自动加入](/zh/how_to_use/workspace_roles#工作区成员的自动加入)。其后的两题调查可点击 **Skip for now** 跳过。
  </Step>

  <Step title="连接您的 Git 工具">
    在 **Connect your Git tool** 页面,打开您的提供商标签页,通过应用或令牌连接:

    | 提供商 | 连接方式 | 令牌指南 |
    | --- | --- | --- |
    | GitHub | **Install Github app**(推荐)或 **Connect via token** | [GitHub 令牌](/zh/how_to_use/code_review/general_config/github_pat) |
    | GitLab | 点击 **Install Gitlab app** 通过 OAuth 登录 GitLab，或选择 **Connect via token** | [GitLab 令牌](/zh/how_to_use/code_review/general_config/gitlab_pat) |
    | Bitbucket | **Connect via token** | [Bitbucket 令牌](/zh/how_to_use/code_review/general_config/bitbucket_pat) |
    | Azure Repos | **Connect via token** | [Azure DevOps 令牌](/zh/how_to_use/code_review/general_config/azure_devops_pat) |
    | Forgejo | **Connect via token** | [Forgejo 令牌](/zh/how_to_use/code_review/general_config/forgejo_pat) |

    GitHub 应用会让 Kody 以其自己的机器人身份发布评论。在其他所有情况下,审查都会显示在连接的账户下:令牌所有者,或授权 OAuth 的 GitLab 用户。

    您自己网络中的服务器(GitHub Enterprise Server,beta;自托管 GitLab;Bitbucket Data Center;Forgejo)通过令牌及其 URL 连接。令牌指南中说明了在哪里输入。

    <Note>
      要将 Kodus Cloud 连接到您自己网络中的服务器?请先在防火墙中将 Kodus 的 IP `52.55.217.197` 加入白名单。
    </Note>
  </Step>

  <Step title="选择代码库">
    在 **Select repositories** 下选择代码库。在 **Who should Kody review?** 下,选择 **PRs opened by me** 以在不影响团队的情况下试用,或选择 **All PRs in selected repos**(默认)。点击 **Enable on my PRs** 或 **Enable for team**。之后您可以在 **Repositories** 下添加更多代码库。

    如果连接的账户没有显示任何代码库,屏幕会显示 **No repositories found**:请通过 **Update connection** 或 **Try again**,使用其他账户或权限更多的令牌重新连接。
  </Step>

  <Step title="选择 Kody 是否从过去的审查中学习">
    在 **Learn from past reviews?** 页面,打开开关,让 Kody 根据团队的审查评论起草 Kody Rules,并可在 **Whose reviews should Kody learn from?** 下排除某些开发者。默认关闭。点击 **Continue** 或 **Skip for now**。参见[自动生成规则](/zh/how_to_use/code_review/learning/kody_rules_generation)。
  </Step>

  <Step title="设置最低严重性">
    在 **Set up your first review** 页面,在 **Minimum severity level** 下选择 Kody 发布建议的最低严重性:**Low/All**、**Medium**(默认)、**High** 或 **Critical**。点击 **Continue**。参见[建议控制](/zh/how_to_use/code_review/configs/suggestion_control)。
  </Step>

  <Step title="引入您团队的规则">
    在 **Teach Kody how your team builds software** 页面,Kody 会列出它在 `.kody/rules` 中找到的 Kody Rule 文件并保持同步。**Use your coding-agent instructions in reviews?** 开关允许审查读取 `CLAUDE.md` 和 `AGENTS.md` 等文件。默认关闭。点击 **Continue** 或 **Skip for now**。参见[代码库规则](/zh/how_to_use/code_review/configs/repository_rules)。
  </Step>

  <Step title="运行您的第一次审查">
    在 **Kody is ready for your first PR review** 页面,在 **Select a PR to review** 下选择一个拉取请求并点击 **Review now**,或点击 **Skip for now**。如果所选代码库最近没有拉取请求,设置会在不显示此页面的情况下结束。Kody 会在您的 Git 工具中发布审查。之后,Kody 会根据您在 **Who should Kody review?** 中的选择审查新的 PR。
  </Step>
</Steps>

Kody 完成审查后，[查看如何在 PR 中阅读结果](/zh/how_to_use/code_review/flow#你会得到什么)。

## 试用与 AI 密钥

Kodus Cloud 的新工作区可试用 14 天。前五次 PR 审查的模型费用由 Kodus 承担。用完包含的审查次数后，在 **AI providers** 中连接自己的密钥即可继续审查。有关试用功能和额外审查次数，请参阅[套餐与许可证](/zh/how_to_use/pricing)。
