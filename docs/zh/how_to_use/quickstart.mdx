---
title: "快速开始"
description: "让 Kody 开始审查你的 pull request:创建账户、连接 Git 提供商、选择代码库并运行第一次审查。"
---

<Steps>
  <Step title="创建账户">
    使用 **Sign up with Github** 或 **Sign up with Gitlab** 注册，或使用您的电子邮件（姓名和密码）注册。电子邮件注册需要企业邮箱地址——Gmail、Outlook、Hotmail 或 Yahoo 等免费域名会被拒绝。
  </Step>

  <Step title="创建您的工作区">
    在 **Let's create a Workspace** 页面，输入您的 **Organization Name**（可选填写电话号码，并为您已批准的电子邮件域名开启 **Enable Auto Join**），然后回答一份包含两个问题的调查。如果您的电子邮件域名下已存在工作区，Kodus 会先提示您加入其中之一。
  </Step>

  <Step title="连接您的 Git 工具">
    在 **Connect your Git tool** 页面，选择您的提供商标签页（**Github**、**Gitlab**、**Bitbucket**、**Azure Repos** 或 **Forgejo**）。
    <AccordionGroup>
        <Accordion title="设置 GitHub" icon="github">
            通过安装应用或使用令牌连接 GitHub：
              - **应用（推荐）**：点击 **Install Github app**。您将被重定向到 GitHub。
                - ✅ Kody 在 PR 中显示为专用机器人
                - ✅ 更好的审计跟踪（清晰区分人工和 AI 审查）
                - 需要您组织的 `owner` 权限
                - 授予对所有您希望 Kody 分析的代码库的访问权限（稍后可以调整）
              - **令牌**：点击 **Connect via token**。审查将以您的用户名显示。<a href="/zh/how_to_use/code_review/general_config/github_pat">访问 GitHub 令牌设置页面了解详细说明。</a>

            <Note>使用 GitHub Enterprise？请在连接前将 Kodus 的 IP `52.55.217.197` 添加到您的网络防火墙白名单。</Note>
        </Accordion>

        <Accordion title="设置 GitLab" icon="gitlab">
            通过安装应用或使用令牌连接 GitLab：
              - **应用（推荐）**：点击 **Install Gitlab app**，您将被重定向到 GitLab 的身份验证页面。
                - ✅ Kody 在 PR 中显示为专用机器人
                - 授予对所有您希望 Kody 分析的代码库的访问权限（稍后可以调整）
              - **令牌**：点击 **Connect via token**。审查将以您的用户名显示。<a href="/zh/how_to_use/code_review/general_config/gitlab_pat">访问 GitLab 令牌设置页面了解详细说明。</a>

            <Note>使用自托管 GitLab 实例？请在连接前将 Kodus 的 IP `52.55.217.197` 添加到您的网络防火墙白名单。</Note>
        </Accordion>
              <Accordion title="设置 Bitbucket" icon="bitbucket">
            Bitbucket 仅支持通过令牌连接——点击 **Connect via token**：
              - **令牌**：<a href="/zh/how_to_use/code_review/general_config/bitbucket_pat">访问 Bitbucket 令牌设置页面了解详细说明。</a>

            <Note>使用 Bitbucket Data Center（自托管）？请在连接前将 Kodus 的 IP `52.55.217.197` 添加到您的网络防火墙白名单。</Note>
        </Accordion>
        <Accordion title="设置 Azure DevOps" icon="microsoft">
            Azure DevOps 仅支持通过令牌连接——打开 **Azure Repos** 标签页并点击 **Connect via token**：
              - **令牌**：<a href="/zh/how_to_use/code_review/general_config/azure_devops_pat">访问 Azure DevOps 令牌设置页面了解详细说明。</a>

            <Note>使用 Azure DevOps Server（自托管）？请在连接前将 Kodus 的 IP `52.55.217.197` 添加到您的网络防火墙白名单。</Note>
        </Accordion>
        <Accordion title="设置 Forgejo" icon="/images/forgejo.svg">
            Forgejo 仅支持通过令牌连接——点击 **Connect via token**：
              - **令牌**：<a href="/zh/how_to_use/code_review/general_config/forgejo_pat">访问 Forgejo 令牌设置页面了解详细说明。</a>

            <Note>Forgejo 支持由社区维护。</Note>
        </Accordion>
    </AccordionGroup>


  </Step>

<Step title="选择代码库">
  选择您希望 Kody 访问的代码库，以进行自动审查和可操作的洞察。在 **Who should Kody review?** 下，选择 **PRs opened by me**（在不影响团队的情况下试用）或 **All PRs in selected repos**。
</Step>

<Step title="选择 Kody 从谁的审查中学习">
  在 **Whose reviews should Kody learn from?** 页面，默认包含所有人。选择 Kody 不应从其审查中学习的开发人员。
</Step>

<Step title="设置最低严重性">
  在 **Minimum severity level** 页面，选择 Kody 发布建议的最低严重性：**Low/All**、**Medium**、**High** 或 **Critical**。
</Step>

<Step title="检查您的 Kody 规则">
  在 **Review your Kody Rules** 页面，Kody 会列出它在您代码库的配置文件中检测到的规则。选择您需要的规则并点击 **Apply N and continue**，或点击 **I'll do this later**。
</Step>

<Step title="运行您的第一次 PR 审查">
  在 **Kody is ready for your first PR review** 页面，使用 **Select a PR to review** 选择一个拉取请求（PR），然后点击 **Review now**（或 **Skip for now**）。这将展示自动代码审查的强大功能。选择后，Kody 将直接在您的 Git 工具中执行审查。不用担心，这只是第一次——之后，Kody 将根据您在 **Who should Kody review?** 中的选择自动审查新的 PR。
</Step>
<Step title="享受 Kody 的自动审查！🔥">
  坐下来放松，让 Kody 通过智能建议和可操作的洞察来简化您的审查流程。
</Step>

</Steps>
