## Fireworks AI 的工作原理

Fireworks AI 是一个推理平台,通过 **OpenAI 兼容**的 API 提供热门开源模型,例如 DeepSeek、Kimi、GLM 和 Qwen。Kodus 通过 OpenAI 兼容提供商与它通信,无需任何代码修改,仅需 BYOK 凭证。

## 推荐模型

<Info>
  Fireworks 的目录经常变化。请在 [Fireworks 模型库](https://fireworks.ai/models)查看当前的模型、上下文窗口和定价。
</Info>

Fireworks 的模型 ID 形如 `accounts/fireworks/models/<model>`,版本号用 `p` 表示:GLM 5.3 是 `glm-5p3`。请从模型库中该模型的页面复制 ID。

| 模型 ID | 上下文窗口 |
| -------- | -------------- |
| `accounts/fireworks/models/glm-5p3` | 1,048,576 tokens |

Kodus 的审查 Agent 会调用工具并期望结构化输出。请选择支持函数调用的模型,模型页面会注明这一点。

## 创建 API 密钥

<Warning>需要 Fireworks AI 账户才能创建 API 密钥。</Warning>

1. 在 [app.fireworks.ai](https://app.fireworks.ai) 登录,或创建账户。
2. 打开 API 密钥页面:[app.fireworks.ai/settings/users/api-keys](https://app.fireworks.ai/settings/users/api-keys)。
3. 点击 **Create API key**。
4. 复制密钥并保存在安全的地方。Fireworks 不会再次显示它。

## 在 Kodus 中配置 Fireworks AI

### 方式 1 — AI providers 页面(推荐)

按照[连接提供商](/zh/how_to_use/byok#连接提供商)的步骤选择 **Custom → OpenAI-compatible**，然后使用下列值填写表单。

| 字段 | 值 |
| --- | --- |
| **Base URL** | `https://api.fireworks.ai/inference/v1` |
| **Model** | 例如 `accounts/fireworks/models/glm-5p3` |
| **API key** | 您的 Fireworks API 密钥 |
| **Max concurrent requests** | 可选;如果看到限流错误,请调低它(位于 **Advanced (optional)** 下) |

点击 **Test & save**，然后在 [Routing](/zh/how_to_use/code_review/configs/routing) 中选择默认模型和后备模型。

<Note>
  使用不带 `/chat/completions` 的 base URL。在 **Code review → Routing** 中,将另一个提供商的模型设置为 **Fallback model**,这样当 Fireworks 出错时审查仍能继续。
</Note>

### 方式 2 — 自托管(环境变量)

要通过 `.env` 为自托管实例指定一个模型:

```env
API_LLM_PROVIDER=openai_compatible
API_LLM_PROVIDER_MODEL="accounts/fireworks/models/glm-5p3"
API_LLM_BASE_URL="https://api.fireworks.ai/inference/v1"
API_LLM_API_KEY="your-fireworks-api-key"
```

按照安装指南[应用模型配置变更](/zh/how_to_deploy/deploy_kodus/generic_vm#应用模型配置变更)。

## 故障排查

<AccordionGroup>
  <Accordion title="API 密钥问题">
    - 在 [Fireworks AI 控制台](https://app.fireworks.ai)中验证您的 API 密钥是否正确且处于活动状态
    - 检查您的 Fireworks AI 账户中是否有足够的额度
    - 确保 `.env` 值中没有尾随空格或引号
  </Accordion>

  <Accordion title="模型未找到">
    - 使用完整的 `accounts/fireworks/models/<model>` ID,拼写与模型库中一致
    - 验证该模型可用于无服务器推理;部分模型需要专用部署
  </Accordion>

  <Accordion title="连接错误">
    - 验证您的服务器是否有互联网访问权限以访问 `api.fireworks.ai`
    - 检查是否有任何防火墙限制
    - 查看 API 和 worker 日志获取具体的上游错误
  </Accordion>

  <Accordion title="速率限制">
    - 在 Fireworks AI 控制面板中检查您当前的使用情况
    - 没有付款方式或额度的账户,请求上限要低得多。参见 Fireworks 的[速率限制](https://docs.fireworks.ai/guides/quotas_usage/rate-limits)
    - 调低模型上的 **Max concurrent requests**,或考虑使用专用部署以获得更高吞吐量
  </Accordion>
</AccordionGroup>
