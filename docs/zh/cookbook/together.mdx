## Together AI 的工作原理

Together AI 通过 **OpenAI 兼容**的 API 提供开源模型,例如 DeepSeek、Kimi、GLM 和 gpt-oss。Kodus 通过 OpenAI 兼容提供商与它通信,无需任何代码修改,仅需 BYOK 凭证。

## 推荐模型

<Info>
  Together 的无服务器目录经常变化。请在[无服务器模型列表](https://docs.together.ai/docs/serverless-models)查看当前的模型 ID、上下文长度和定价。请使用精确的 API 模型字符串。
</Info>

Together 列出了以下支持函数调用和结构化输出的无服务器聊天模型:

| 模型 ID | 上下文窗口 |
| -------- | -------------- |
| `moonshotai/Kimi-K3` | 约 1M tokens |
| `deepseek-ai/DeepSeek-V4-Pro-0813` | 约 1M tokens |
| `zai-org/GLM-5.3` | 约 1M tokens |
| `openai/gpt-oss-120b` | 约 131k tokens |

## 创建 API 密钥

<Warning>创建 API 密钥需要 Together AI 账户。Together 是预付费的:您必须先购买额度才能创建密钥,余额降到零时 API 访问会被暂停。参见 [Together 的计费文档](https://docs.together.ai/docs/billing)。</Warning>

直接访问 [Together 的 API 密钥页面](https://api.together.ai/settings/projects/~current/api-keys)创建新的 API 密钥。

或者,按照以下步骤操作:

1. 在 [api.together.ai](https://api.together.ai) 创建账户,已有账户则直接登录
2. 打开 [API 密钥页面](https://api.together.ai/settings/projects/~current/api-keys)
3. 点击 **Create key**
4. 为其命名,例如 'Kodus' 或任何描述性名称
5. 复制您的 API 密钥。Together 只会显示新密钥一次

## 在 Kodus 中配置 Together AI

### 方式 1 — AI providers 页面(推荐)

按照[连接提供商](/zh/how_to_use/byok#连接提供商)的步骤选择 **Custom → OpenAI-compatible**，然后使用下列值填写表单。

| 字段 | 值 |
| --- | --- |
| **Key**(在 **API key** 卡片中) | 您的 Together API 密钥 |
| **Base URL** | `https://api.together.ai/v1` |
| **Model** | 例如 `zai-org/GLM-5.3` |
| **Max concurrent requests** | 可选;位于 **Advanced (optional)** 下,展开 **Advanced settings**;如果看到限流错误,请调低它 |

点击 **Test & save**，然后在 [Routing](/zh/how_to_use/code_review/configs/routing) 中选择默认模型和后备模型。

<Note>
  使用不带 `/chat/completions` 的 base URL。将另一个提供商的模型设置为 **Fallback model**,这样当 Together 对您限流时审查仍能继续。
</Note>

### 方式 2 — 自托管(环境变量)

要通过 `.env` 为自托管实例指定一个模型:

```env
API_LLM_PROVIDER=openai_compatible
API_LLM_PROVIDER_MODEL="zai-org/GLM-5.3"
API_LLM_BASE_URL="https://api.together.ai/v1"
API_LLM_API_KEY="your-together-api-key"
```

按照安装指南[应用模型配置变更](/zh/how_to_deploy/deploy_kodus/generic_vm#应用模型配置变更)。

## 故障排查

<AccordionGroup>
  <Accordion title="API 密钥问题">
    - 在 [API 密钥页面](https://api.together.ai/settings/projects/~current/api-keys)验证您的 API 密钥是否正确且处于活动状态
    - 检查您的 Together AI 账户是否有额度余额;余额为零时 API 访问会被暂停
    - 确保 `.env` 值中没有尾随空格或引号
  </Accordion>

  <Accordion title="模型未找到">
    - 使用[无服务器模型列表](https://docs.together.ai/docs/serverless-models)中精确的 API 模型字符串,包括大小写
    - 无服务器端点和专用端点支持的模型不同;不在无服务器列表中的模型需要专用端点
  </Accordion>

  <Accordion title="连接错误">
    - 验证您的服务器是否有互联网访问权限以访问 `api.together.ai`
    - 检查是否有任何防火墙限制
    - 查看 API 和 worker 日志获取具体的上游错误
  </Accordion>

  <Accordion title="速率限制">
    - 超出限制时 Together 会返回 HTTP 429。参见 Together 的[速率限制文档](https://docs.together.ai/docs/rate-limits)
    - 调低模型上的 **Max concurrent requests**,或联系 Together 申请更高的限制
  </Accordion>
</AccordionGroup>
