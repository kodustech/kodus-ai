## Groq 的工作原理

Groq Cloud 通过 **OpenAI 兼容**的 API 提供开放模型。Kodus 通过 OpenAI 兼容提供商与它通信,无需任何代码修改,仅需 BYOK 凭证。

## 推荐模型

<Info>
  Groq 的目录经常变化。请在 [Groq 的模型页面](https://console.groq.com/docs/models)查看当前的生产模型、上下文窗口、价格和限制。
</Info>

| 模型 ID | 上下文窗口 |
| -------- | -------------- |
| `openai/gpt-oss-120b` | 131,072 tokens |

Kodus 的审查 Agent 会调用工具并期望结构化输出。Groq 针对该模型的页面列出了工具使用和 JSON Schema 模式。切换到其他模型之前,请先检查这两项。

## 创建 API 密钥

<Warning>需要 Groq Cloud 账户才能创建 API 密钥。</Warning>

直接访问 [Groq 的 API 密钥页面](https://console.groq.com/keys)创建新的 API 密钥。

或者,按照以下步骤操作:

1. 访问 [Groq 控制台](https://console.groq.com)
2. 登录或创建您的账户
3. 打开 **API Keys**
4. 点击 **Create API Key**
5. 为其命名,例如 'Kodus' 或任何描述性名称
6. 复制 API 密钥并将其保存在安全的地方

<Info>
  在 Groq 中,只有团队所有者或具有开发者角色的用户可以创建或管理 API 密钥。
</Info>

## 在 Kodus 中配置 Groq

### 方式 1 — AI providers 页面(推荐)

按照[连接提供商](/zh/how_to_use/byok#连接提供商)的步骤选择 **Custom → OpenAI-compatible**，然后使用下列值填写表单。

| 字段 | 值 |
| --- | --- |
| **Key**(在 **API key** 卡片中) | 您的 Groq API 密钥 |
| **Base URL** | `https://api.groq.com/openai/v1` |
| **Model** | `openai/gpt-oss-120b` |
| **Max concurrent requests** | 可选;位于 **Advanced (optional)** 下,展开 **Advanced settings**;如果看到限流错误,请调低它 |

点击 **Test & save**，然后在 [Routing](/zh/how_to_use/code_review/configs/routing) 中选择默认模型和后备模型。

<Note>
  使用不带 `/chat/completions` 的 base URL。将另一个提供商的模型设置为 **Fallback model**,这样当 Groq 对您限流时审查仍能继续。
</Note>

### 方式 2 — 自托管(环境变量)

要通过 `.env` 为自托管实例指定一个模型:

```env
API_LLM_PROVIDER=openai_compatible
API_LLM_PROVIDER_MODEL="openai/gpt-oss-120b"
API_LLM_BASE_URL="https://api.groq.com/openai/v1"
API_LLM_API_KEY="your-groq-api-key"
```

按照安装指南[应用模型配置变更](/zh/how_to_deploy/deploy_kodus/generic_vm#应用模型配置变更)。

## 故障排查

<AccordionGroup>
  <Accordion title="API 密钥问题">
    - 在 [Groq 控制台](https://console.groq.com/keys)中验证您的 API 密钥是否正确且处于活动状态
    - 检查您的 Groq 套餐是否可以使用所选的模型
    - 确保 `.env` 值中没有尾随空格或引号
  </Accordion>

  <Accordion title="模型未找到">
    - 检查模型 ID 的拼写是否与 Groq 的模型页面完全一致
    - 验证该模型在 Groq 当前的模型列表中;模型会随时间下线
    - Groq 已于 2026 年 8 月 16 日为 Free 和 Developer 套餐下线 `llama-3.3-70b-versatile` 和 `llama-3.1-8b-instant`。Enterprise 合同不受影响。参见 Groq 的[弃用说明](https://console.groq.com/docs/deprecations)
  </Accordion>

  <Accordion title="连接错误">
    - 验证您的服务器是否有互联网访问权限以访问 `api.groq.com`
    - 检查是否有任何防火墙限制
    - 查看 API 和 worker 日志获取具体的上游错误
  </Accordion>

  <Accordion title="速率限制">
    - 超出限制时 Groq 会返回 HTTP 429,限制取决于您的套餐
    - 在 Groq 账户的 Limits 页面([console.groq.com/settings/limits](https://console.groq.com/settings/limits))以及 [Groq 速率限制文档](https://console.groq.com/docs/rate-limits)中查看您组织的确切限制
    - 调低模型上的 **Max concurrent requests**,或升级您的套餐
  </Accordion>
</AccordionGroup>
