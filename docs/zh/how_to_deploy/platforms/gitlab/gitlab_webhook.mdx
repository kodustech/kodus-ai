---
title: 创建 Webhook
description: "当自动注册未发生时，手动创建 GitLab webhook，并选择 Kodus 消费的事件。"
icon: webhook
---

当您保存仓库选择时，Kodus 通常会自动创建 webhook。这需要项目上的 **Maintainer** 或 **Owner** 角色。如果自动创建没有发生，**Repositories** 页面会列出该项目及原因，您可以手动设置 webhook：

<Note>
  Webhook URL 必须能到达 Webhooks 服务（端口 3332）。仅当反向代理将 `/.../webhook` 路径转发到 webhooks 服务时，才能使用 API 域名。
</Note>

1. 导航到您的 GitLab 项目
2. 转到 "Settings" > "Webhooks"
3. 配置您的 webhook：

   - **URL**：输入 `.env` 文件中的 URL：`API_GITLAB_CODE_MANAGEMENT_WEBHOOK`（以 `/gitlab/webhook` 结尾）
   - **勾选 Show full URL**
   - **Name**：（可选）Kodus Code Review
   - **Description**：（可选）Kodus Code Review Webhook
   - **Secret token**：留空
   - **SSL verification**：启用 SSL 验证
   - **Trigger**：选择以下事件：
     - Comments
     - Merge request events

4. 单击 "Add webhook"

您已成功为 GitLab 项目中的代码审查设置了 webhook。

<Note>
  Kodus 只消费评论和合并请求事件。issue 事件在到达后即被丢弃。
</Note>
