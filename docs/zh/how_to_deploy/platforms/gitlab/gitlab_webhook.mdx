---
title: 创建 Webhook
description: "当自动注册未发生时,手动创建 GitLab webhook,并选择 Kodus 消费的事件。"
icon: webhook
---

Kodus 通常会自动创建 webhook。如果没有发生，请按照以下步骤手动设置：

<Note>
  Webhook URL 必须指向 Webhooks 服务（端口 3332）。仅当反向代理将 `/.../webhook` 路径转发到 Webhooks 服务时，才能使用 API 域名。
</Note>

1. 导航到您的 GitLab 项目
2. 转到"设置">"Webhooks"
3. 配置您的 webhook：

   - **URL**：输入 `.env` 文件中的 URL：`API_GITLAB_CODE_MANAGEMENT_WEBHOOK`
   - **勾选显示完整 URL**
   - **名称**：（可选）Kodus 代码审查
   - **描述**：（可选）Kodus 代码审查 Webhook
   - **Secret token**：留空
   - **SSL verification**：启用 SSL 验证
   - **触发器**：选择以下事件：
     - 评论(Comments)
     - 合并请求事件(Merge request events)

4. 单击"添加 webhook"

您已成功为 GitLab 仓库中的代码审查设置了 webhook。

<Note>
  Kodus 只消费评论和合并请求事件。工单事件在到达后即被丢弃。
</Note>
