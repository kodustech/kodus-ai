---
title: "连接 Jira 并验证拉取请求"
description: "在 Kodus 中设置 Atlassian Rovo，并根据 Jira 工单验证 PR。"
---

你需要有权读取拉取请求所引用的 Jira 项目。

## 如何连接

1. 在侧边栏中打开 **Plugins**(安装插件需要 Owner 角色)
2. 点击 **Atlassian Rovo** 磁贴(Jira)
3. 点击 **Authenticate with** 该插件并授权访问您的 Jira 工作区(OAuth),或输入您的 Atlassian 电子邮件和 API 令牌并点击 **Connect**
4. 插件在连接后立即安装,并选中其只读工具。之后如需更改,请打开它,编辑 **Selected tools** 并点击 **Update Tools**

请保持选中以下工具,因为 Kody 使用它们读取工单:`getJiraIssue`、`getAccessibleAtlassianResources` 和 `getVisibleJiraProjects`。被关闭的工具无法使用。

## 启用的功能

### 自动业务逻辑验证

在 PR 标题、分支名或描述中引用Jira 工单。在 **Code review → What to review** 中开启 **Business Logic**（默认开启）后，Kody 会在第一次审查时验证 PR。 Kody 会读取工单、父任务和子任务。

### 按需验证

在 PR 评论中粘贴任何 Jira URL 或工单键:

```
@kody -v business-logic https://your-org.atlassian.net/browse/PROJ-123
```

## 查看结果

Kody 会发布一条 **Kody · Business Logic** 评论，列出已检查的要求和每项结果所依据的代码。再次验证时会更新同一条评论。有关结果状态和重新验证方式，请参阅[业务逻辑验证](/zh/how_to_use/code_review/business_logic_validation)。

## 提示

- 在 Jira 工单中写明**验收标准**。如果标准位于特定标题下或自定义字段内，请在业务逻辑设置中配置 **Requirements → Where acceptance criteria live**。
- 对于 Jira 子任务，Kody 会根据子任务标题选取父工单中相关的需求进行检查。
- 修复缺口后，评论 `@kody -v business-logic` 重新检查。

## 对话中的插件工具

当您在 PR 评论中提及 Kody 时,它可以使用该插件。也可以为[自定义代理](/zh/how_to_use/code_review/custom_agents_knowledge_and_tools#plugins-mcp)开启它。
