从头编写代码审查规则可能很繁琐。Kodus 可以分析团队的审查历史并根据发现的模式自动建议规则。

## 工作原理

1. 在侧边栏 **Code review** 分组顶部的范围选择器中选择代码库，打开 **Kody Rules**，然后点击 **Configuration**
2. 开启 **Generate from past reviews**
3. Kodus 扫描代码库中最近 3 个月已关闭的 PR
4. 识别反复出现的反馈模式和编码偏好
5. 生成适合您团队的规则，这些规则会列在 Kody Rules 页面上，来源标记为 **Kody-generated**

## 接下来

- 默认情况下，生成的规则会立即激活，并在代码审查期间执行
- 如果想在规则生效前先审查，请在同一个 **Configuration** 面板中开启 **Kody knowledge approval**：新规则随后会在 **Pending review** 部分等待，直到您 **Approve** 或 **Discard** 它们
- 可以像编辑其他 Kody 规则一样编辑、暂停或删除任何生成的规则

## 持续学习

初始设置后，Kodus **每周**生成新的规则，随着团队编码风格的演变。定期查看新规则。

## 要求

- 代码库中至少 **3 个月**的审查历史
- 定期的代码审查活动以获得更好的模式检测
- 具有适当权限的代码库访问

更多详情，请参阅[自动规则生成](/zh/how_to_use/code_review/learning/kody_rules_generation)。
