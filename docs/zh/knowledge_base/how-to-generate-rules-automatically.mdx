从头编写代码审查规则可能很繁琐。Kodus 可以读取团队在已关闭拉取请求上留下的评论,并根据发现的模式起草规则。

## 工作原理

1. 在侧边栏 **Code review** 分组顶部的范围选择器中选择 **Global** 或某个代码库,打开 **Kody Rules**,然后点击 **Configuration**
2. 开启 **Generate from past reviews**
3. Kody 读取代码库中最近 3 个月已关闭 PR 上审查者的评论(不包括机器人,也不包括 Kody 自己的评论)。为某个代码库开启时,会立即开始;在 **Global** 开启时,代码库会在下一次每周运行时被处理
4. 它会针对反复出现的标准起草规则,这些规则会列在 Kody Rules 页面上,来源为 **Kody-generated**

可选:使用开关下方的审查者选择器,排除 Kody 不应从其评论中学习的开发者。

## 接下来

- 默认情况下,生成的规则会立即激活,并在代码审查期间检查
- 如果想先审查它们,请在同一个 **Configuration** 面板中开启 **Kody knowledge approval**:新规则随后会在 **Pending review** 部分等待,直到您 **Approve** 或 **Discard** 它们
- 可以像编辑其他 Kody Rule 一样编辑、暂停或删除任何生成的规则

## 持续学习

首轮处理之后,Kodus **每周**读取最近一周的审查者评论,并据此起草新规则。

## 要求

- 代码库中已关闭拉取请求上的审查者评论。没有最低历史数据量要求
- 在云端,试用期之外,需要您自己的模型密钥([BYOK](/zh/how_to_use/byok));自托管实例使用该部署的模型

更多详情,请参阅[自动规则生成](/zh/how_to_use/code_review/learning/kody_rules_generation)。
