## 如何连接

1. 在侧边栏中打开 **Plugins**(安装插件需要 Owner 角色)
2. 点击 **Linear** 磁贴
3. 点击 **Authenticate with** 该插件并授权访问您的 Linear 工作区(OAuth),或输入 Linear API 密钥并点击 **Connect**
4. 插件在连接后立即安装,并选中其只读工具。之后如需更改,请打开它,编辑 **Selected tools** 并点击 **Update Tools**

请保持选中以下工具,因为 Kody 使用它们读取问题:`get_issue`、`get_team`、`list_teams`、`list_issues` 和 `get_document`。被关闭的工具无法使用。

## 启用的功能

### 自动业务逻辑验证

在 PR 标题、分支名或描述中引用Linear 问题。在 **Code review → What to review** 中开启 **Business Logic**（默认开启）后，Kody 会在第一次审查时验证 PR。 Kody 会读取问题、父问题、子问题和附加文档。

### 按需验证

在 PR 评论中粘贴任何 Linear URL 或问题键:

```
@kody -v business-logic https://linear.app/your-team/issue/TEAM-123
```

## 查看结果

Kody 会发布一条 **Kody · Business Logic** 评论，列出已检查的要求和每项结果所依据的代码。再次验证时会更新同一条评论。有关结果状态和重新验证方式，请参阅[业务逻辑验证](/zh/how_to_use/code_review/business_logic_validation)。

## 提示

- 在 Linear Issue 中写清验收标准，验证结果会更全面。
- 如果需求由子 Issue 实现，验证状态会显示为 **CHECK MANUALLY**。

## 对话中的插件工具

当您在 PR 评论中提及 Kody 时,它可以使用该插件。也可以为[自定义代理](/zh/how_to_use/code_review/custom_agents_knowledge_and_tools#plugins-mcp)开启它。
