将 Linear 连接到 Kodus 启用根据 Linear 问题的自动**业务逻辑验证**和更丰富的代码审查上下文。

## 如何连接

1. 在侧边栏中打开 **Plugins**
2. 点击 **Linear** 磁贴
3. 进行身份验证并授权访问您的 Linear 工作区
4. 选择 Kody 可以使用的工具，然后点击 **Install plugin**

## 启用的功能

### 自动业务逻辑验证

当 PR 关联到 Linear 问题，且 **Code review → What to review** 中的 **Business Logic** 类别已开启时，Kodus 自动：
- 获取问题标题、描述和验收标准
- 将 PR 差异与需求进行比较
- 报告缺失的实现和差距

### 按需验证

在 PR 评论中粘贴任何 Linear URL：

```
@kody -v business-logic https://linear.app/your-team/issue/TEAM-123
```

### 更丰富的代码审查上下文

连接 Linear 后，Kody 可以在规则和对话中引用任务上下文。

更多详情，请参阅[业务逻辑验证](/zh/how_to_use/code_review/business_logic_validation)和[插件](/zh/how_to_use/code_review/plugins)。
