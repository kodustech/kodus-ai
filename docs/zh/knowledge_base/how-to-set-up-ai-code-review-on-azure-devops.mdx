---
title: "如何在 Azure DevOps 上设置 AI 代码审查"
description: "将 Azure DevOps 连接到 Kodus，并选择要自动审查的仓库。"
---

Kodus 使用个人访问令牌连接到 Azure DevOps Services(`dev.azure.com`),并通过 service hooks 接收拉取请求事件。

## 步骤

1. **创建账户** — 在 [kodus.io](https://kodus.io) 或[自托管 Kodus](/zh/how_to_deploy/deploy_kodus/generic_vm)
2. **连接 Azure DevOps** — 在入门引导的 **Connect your Git tool** 步骤中,打开 **Azure Repos** 选项卡,点击 **Connect via token**,然后输入您的 Azure Repos 组织名称和个人访问令牌(之后也可以从侧边栏的 **Repositories** 进行连接:在 **Connect a provider** 下点击 **Azure Repos**)
3. **选择代码库** — 选择 Kodus 应审查的 Azure DevOps 代码库,或在 **Repositories** 上开启[审查所有代码库](/zh/how_to_use/code_review/configs/review_all_repositories)
4. **Webhooks** — 保存选择时,Kodus 会自动创建拉取请求 service hooks。这需要在项目上拥有 **Edit subscriptions** 权限(Project Administrators 拥有该权限)。请在 **Project settings** → **Service hooks** 下检查它们;只有开启 **Review every repository** 时,**Repositories** 才会列出 hooks 创建失败的代码库及原因。如果它们缺失,请按照 [Azure DevOps Webhooks](/zh/how_to_deploy/platforms/azure_devops/azdevops_webhook) 指南手动注册 hooks
5. 在已选仓库中打开一个拉取请求。[查看 Kody 会发布什么以及如何确认审查状态](/zh/how_to_use/code_review/flow)。

如需按 Azure Boards 工作项验证 PR，请选择自定义插件作为 **Task source**。[查看验证设置](/zh/how_to_use/code_review/business_logic_validation)。

## 自定义配置

通过 [kodus-config.yml](/zh/how_to_use/code_review/configs/general#kodus-config-yml) 自定义各仓库的审查配置。

## 使用个人访问令牌

Azure DevOps 需要 PAT 以便 Kodus 访问您的代码库并发布审查评论。请使用 [Azure DevOps PAT](/zh/how_to_use/code_review/general_config/azure_devops_pat) 指南中列出的范围创建它;没有 **Code: Read & Write**,Kodus 可以读取您的代码库但无法评论。

完整设置指南,请参阅 [Azure DevOps Webhooks](/zh/how_to_deploy/platforms/azure_devops/azdevops_webhook) 和 [Azure DevOps PAT](/zh/how_to_use/code_review/general_config/azure_devops_pat)。
