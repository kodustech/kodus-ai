---
title: "如何跨代码库共享编码标准"
description: "使用全局规则、规则继承和全局规则来源,在所有代码库中保持一致的编码标准。"
---

当您有多个代码库时,保持编码标准一致是一个挑战。Kodus 让您只需定义一次规则,即可在任何地方应用。

## 全局规则

在 **Global** 范围创建规则,它们会应用于每个代码库:

1. 在侧边栏 **Code review** 分组顶部的范围选择器中选择 **Global**,然后打开 **Kody Rules**
2. 使用 **New rule** 创建您的规则,或从[规则库](/zh/how_to_use/code_review/configs/rules_library)添加
3. 代码库和目录会继承它们

## 规则继承

规则从 Global → 代码库 → 目录向下流动:

- **全局规则**应用于每个代码库
- **代码库规则**在该代码库中叠加到全局规则之上
- **目录规则**对于使用该目录设置审查的拉取请求,叠加到它们之上

代码库可以在其列表中将继承的规则标记为已禁用,规则也可以被标记为不可继承。两者只改变规则的列出方式;审查仍会应用每一条全局和代码库规则。参见[规则继承](/zh/how_to_use/code_review/configs/rules_inheritance)。

## 将标准保存在一个代码库中

如果您的标准存放在专用代码库中,[全局规则来源](/zh/how_to_use/code_review/configs/global_rule_sources)会将其规则文件导入为全局规则,并在拉取请求在那里合并时更新它们。Free 套餐不可用。每个项目自己的 `.kody/rules` 文件夹中的规则(参见[代码库规则](/zh/how_to_use/code_review/configs/repository_rules))仅应用于该项目。

要从一个代码库管理整个组织的审查设置和规则,请使用[集中配置](/zh/how_to_use/code_review/configs/centralized_config)。

## 跨组织的记忆

范围限定为**组织**的记忆应用于所有代码库。在 **Global** 范围使用 **New memory** 创建一条,或在 PR 评论中让 Kody 创建:

```
@kody remember: across all repos, we use ESLint flat config format.
```

更多详情,请参阅[规则继承](/zh/how_to_use/code_review/configs/rules_inheritance)。
