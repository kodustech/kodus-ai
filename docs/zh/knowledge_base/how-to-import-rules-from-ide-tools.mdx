title: "如何从 Cursor、Copilot 或 Claude 导入规则"

---

如果您已经在 Cursor、GitHub Copilot、Claude 或其他 AI 编码工具中定义了规则，可以将它们导入 Kodus，使相同的约定在代码审查中得到执行。

## 工作原理

Kodus 检测代码库中的规则文件并将其同步为 Kody 规则。支持的文件格式包括：

- `.cursorrules`（Cursor）
- `.github/copilot-instructions.md`（GitHub Copilot）
- `CLAUDE.md`（Claude）
- 其他 AI 工具配置文件

## 设置

1. 在侧边栏 **Code review** 分组顶部的范围选择器中选择代码库，打开 **Kody Rules**，然后点击 **Configuration**
2. 开启 **Auto-sync rules from repo**。首次开启时，Kodus 会询问是立即扫描代码库（**Sync now**）还是 **Skip initial scan**
3. Kodus 将找到的规则文件导入为 Kody 规则（来源为 **Auto-sync**），并从此保持同步
4. 导入的规则会立即在代码审查期间执行。如果想先审查，请在同一个 **Configuration** 面板中开启 **Kody knowledge approval**：导入的规则随后会在 **Pending review** 部分等待，直到您 **Approve** 或 **Discard** 它们

## 为什么这很重要

如果不同步，您的 IDE 和代码审查工具会执行不同的标准。开发者遵循 Cursor 的规则可能仍然在审查期间被标记 — 反之亦然。

导入确保整个工作流中**统一的编码标准来源**。

更多详情，请参阅[同步 IDE 规则](/zh/how_to_use/code_review/configs/rules_file_detection)。
