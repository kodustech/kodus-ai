Se você já tem regras definidas no Cursor, GitHub Copilot, Claude ou outras ferramentas de codificação com IA, pode importá-las para o Kodus para que as mesmas convenções sejam aplicadas durante a revisão de código.

## Como funciona

O Kodus detecta arquivos de regras no seu repositório e os sincroniza como Regras do Kody. Os formatos de arquivo suportados incluem:

- `.cursorrules` (Cursor)
- `.github/copilot-instructions.md` (GitHub Copilot)
- `CLAUDE.md` (Claude)
- Outros arquivos de configuração de ferramentas de IA

## Configurando

1. Selecione o repositório no seletor de escopo no topo do grupo **Code review** na barra lateral, abra **Kody Rules** e clique em **Configuration**
2. Ative **Auto-sync rules from repo**. Na primeira vez, o Kodus pergunta se deve escanear o repositório imediatamente (**Sync now**) ou pular a varredura inicial (**Skip initial scan**)
3. O Kodus importa os arquivos de regras que encontrar como Regras do Kody (origem **Auto-sync**) e os mantém sincronizados a partir de então
4. As regras importadas são aplicadas durante a revisão de código imediatamente. Para revisá-las antes, ative **Kody knowledge approval** na mesma tela de **Configuration**: as regras importadas passam a aguardar na seção **Pending review** até você aprová-las (**Approve**) ou descartá-las (**Discard**)

## Por que isso importa

Sem sincronização, sua IDE e as ferramentas de revisão de código aplicam padrões diferentes. Um desenvolvedor seguindo as regras do Cursor ainda pode ser sinalizado durante a revisão por algo que a IDE não identificou — ou vice-versa.

A importação garante **uma única fonte de verdade** para padrões de codificação em todo o seu fluxo de trabalho.

Para detalhes, consulte [Sincronização de Regras de IDE](/pt-BR/how_to_use/code_review/configs/rules_file_detection).
