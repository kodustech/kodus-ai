---
title: "Como configurar revisão de código com IA no Azure DevOps"
description: "Instale e configure o Kodus para repositórios Azure DevOps e receba revisão de código automatizada com IA em cada pull request."
---

O Kodus integra-se com o Azure DevOps via webhooks. Uma vez configurado, cada pull request é revisado automaticamente.

## Passos

1. **Crie uma conta** em [kodus.io](https://kodus.io) ou [hospede o Kodus por conta própria](/pt-BR/how_to_deploy/deploy_kodus/generic_vm)
2. **Conecte o Azure DevOps** — na etapa **Connect your Git tool** do onboarding, abra a aba **Azure Repos**, clique em **Connect via token** e informe o nome da sua organização no Azure Repos e seu Personal Access Token (você também pode conectar depois em **Repositories** na barra lateral)
3. **Selecione os repositórios** — escolha quais repositórios Azure DevOps o Kodus deve revisar
4. **Webhooks** — o Kodus cria os service hooks de pull request automaticamente quando você salva a seleção. Se isso não acontecer (normalmente em instalações self-hosted), registre-os manualmente com o guia [Azure DevOps Webhooks](/pt-BR/how_to_deploy/platforms/azure_devops/azdevops_webhook)
5. **Abra um pull request** — o Kodus o revisa automaticamente

## O que você recebe

- Revisões automatizadas em cada PR
- Comentários postados diretamente no pull request
- Regras personalizáveis, categorias de revisão e um limite mínimo de severidade
- Validação de lógica de negócio contra itens de trabalho vinculados

## Configuração personalizada

Coloque um `kodus-config.yml` na raiz do seu repositório para personalizar o comportamento por repositório. O arquivo substitui as configurações da interface quando **kodus Config File Overrides Web Preferences** está ativado para esse repositório (**Code review → General**).

## Usando um Personal Access Token

O Azure DevOps requer um PAT para que o Kodus acesse seus repositórios e poste comentários de revisão. Certifique-se de que o token tem os escopos adequados para leitura de código e acesso a comentários de PR.

Para o guia completo de configuração, consulte [Azure DevOps Webhooks](/pt-BR/how_to_deploy/platforms/azure_devops/azdevops_webhook) e [Azure DevOps PAT](/pt-BR/how_to_use/code_review/general_config/azure_devops_pat).
