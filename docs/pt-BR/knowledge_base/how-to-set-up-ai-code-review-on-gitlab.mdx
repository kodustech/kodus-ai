---
title: "Como configurar revisão de código com IA no GitLab"
description: "Instale e configure o Kodus para projetos GitLab e receba revisão de código automatizada com IA em cada merge request."
---

O Kodus integra-se com o GitLab via OAuth e webhooks. Uma vez configurado, os merge requests são revisados automaticamente.

## Passos

1. **Crie uma conta** em [kodus.io](https://kodus.io) ou [hospede o Kodus por conta própria](/pt-BR/how_to_deploy/deploy_kodus/generic_vm)
2. **Conecte o GitLab** — na etapa **Connect your Git tool** do onboarding, clique em **Install Gitlab app** para autorizar via OAuth, ou em **Connect via token** (você também pode conectar depois em **Repositories** na barra lateral)
3. **Selecione os projetos** — escolha quais projetos GitLab o Kodus deve revisar
4. **Webhooks** — o Kodus registra o webhook de merge request automaticamente quando você salva a seleção. Se isso não acontecer (por exemplo, em algumas instalações self-hosted), adicione-o manualmente com o guia [GitLab Webhooks](/pt-BR/how_to_deploy/platforms/gitlab/gitlab_webhook)
5. **Abra um merge request** — o Kodus o revisa automaticamente

## O que você recebe

- Revisões automatizadas em cada MR
- Comentários postados diretamente no merge request
- Regras personalizáveis, categorias de revisão e um limite mínimo de severidade
- Validação de lógica de negócio contra tarefas vinculadas

## Configuração personalizada

Coloque um `kodus-config.yml` na raiz do seu repositório para personalizar o comportamento por projeto. O arquivo substitui as configurações da interface quando **kodus Config File Overrides Web Preferences** está ativado para esse projeto (**Code review → General**).

Para o guia completo de configuração, consulte [GitLab OAuth](/pt-BR/how_to_deploy/platforms/gitlab/gitlab_oauth) e [GitLab Webhooks](/pt-BR/how_to_deploy/platforms/gitlab/gitlab_webhook).
