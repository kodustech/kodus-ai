---
title: Criando um Webhook
description: "Crie manualmente o webhook do Forgejo quando o registro automático não aconteceu, e selecione os eventos que a Kodus consome."
icon: webhook
---

<Note>
  O suporte para Forgejo é mantido pela comunidade.
</Note>

A Kodus geralmente cria o webhook automaticamente quando você salva a seleção de repositórios. Isso exige acesso de admin ao repositório e o escopo `write:repository` no token. Se isso não aconteceu, **Repositories** lista o repositório com o motivo, e você pode configurar o webhook manualmente:

<Note>
  As URLs de webhook devem alcançar o serviço de Webhooks (porta 3332). Usar o domínio da API só funciona se seu proxy reverso rotear os caminhos `/.../webhook` para o serviço de webhooks.
</Note>

1. Navegue até seu repositório no Forgejo
2. Abra a aba **Settings** do repositório
3. Selecione **Webhooks**
4. Clique em **Add webhook** → **Forgejo**
5. Configure seu webhook:

   - **Target URL**: Insira a URL que você definiu em `API_FORGEJO_CODE_MANAGEMENT_WEBHOOK` no seu arquivo `.env` (ela termina com `/forgejo/webhook`)
   - **HTTP method**: POST
   - **POST content type**: `application/json`
   - **Trigger on**: **Custom events**, depois selecione:
        - Repository events: **Push**
        - Pull request events: **Modification**, **Synchronized** e **Comments**
   - **Active**: Marque

6. Clique em **Add webhook**

Pronto! Você configurou com sucesso um webhook para reviews de código no seu repositório Forgejo.

<Note>
  O Forgejo entrega os comentários de pull request como `issue_comment`, e a Kodus age sobre entregas de `pull_request`, `push` e `issue_comment`. Dos eventos de pull request, ela age sobre `opened`, `synchronized`, `reopened` e `closed`; **Synchronized** é o que entrega novos commits em um pull request.

  Eventos de push importam especificamente no Forgejo: são os únicos que carregam o head anterior
  e o atual da branch, que é como a Kodus detecta force-push e mapeia uma branch de volta aos seus
  pull requests abertos. Eventos de issue são descartados na chegada.
</Note>
