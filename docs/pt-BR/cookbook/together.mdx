## Como o Together AI funciona

O Together AI serve modelos open-source, como DeepSeek, Kimi, GLM e gpt-oss, por meio de uma API **compatível com OpenAI**. O Kodus se comunica com ele pelo provedor compatível com OpenAI, então não há alterações de código — apenas credenciais BYOK.

## Modelos Recomendados

<Info>
  O catálogo serverless do Together muda com frequência. Veja a [lista de modelos serverless](https://docs.together.ai/docs/serverless-models) para os IDs de modelo, tamanhos de contexto e preços atuais. Use a string exata do modelo na API.
</Info>

O Together lista estes modelos de chat serverless com function calling e saídas estruturadas:

| ID do Modelo | Janela de Contexto |
| ------------ | ------------------ |
| `moonshotai/Kimi-K3` | ~1M tokens |
| `deepseek-ai/DeepSeek-V4-Pro-0813` | ~1M tokens |
| `zai-org/GLM-5.3` | ~1M tokens |
| `openai/gpt-oss-120b` | ~131k tokens |

## Criando a Chave de API

<Warning>Uma conta no Together AI é necessária para criar uma chave de API. O Together é pré-pago: você precisa comprar créditos antes de criar chaves, e o acesso à API é suspenso quando o saldo chega a zero. Veja a [documentação de cobrança do Together](https://docs.together.ai/docs/billing).</Warning>

Acesse diretamente a [página de chaves de API do Together](https://api.together.ai/settings/projects/~current/api-keys) para criar uma nova Chave de API.

Ou siga estas etapas:

1. Crie uma conta em [api.together.ai](https://api.together.ai) ou faça login se já tiver uma
2. Abra a [página de chaves de API](https://api.together.ai/settings/projects/~current/api-keys)
3. Clique em **Create key**
4. Dê um nome como 'Kodus' ou qualquer nome descritivo
5. Copie sua chave de API. O Together mostra uma chave nova apenas uma vez

## Configurar o Together AI no Kodus

### Opção 1 — Página AI providers (recomendado)

Siga [Conectar um provedor](/pt-BR/how_to_use/byok#conectar-um-provedor) e escolha **Custom → OpenAI-compatible**. Preencha o formulário com estes valores.

| Campo | Valor |
| --- | --- |
| **Key** (no card **API key**) | sua chave de API do Together |
| **Base URL** | `https://api.together.ai/v1` |
| **Model** | ex.: `zai-org/GLM-5.3` |
| **Max concurrent requests** | opcional; em **Advanced (optional)**, expanda **Advanced settings**; diminua se você vir erros de rate limit |

Clique em **Test & save** e escolha os modelos padrão e de fallback em [Modos e modelos de revisão](/pt-BR/how_to_use/code_review/configs/routing).

<Note>
  Use a base URL sem `/chat/completions`. Defina um modelo de outro provedor como **Fallback model** para que as revisões continuem funcionando se o Together aplicar rate limit.
</Note>

### Opção 2 — Self-hosted (variáveis de ambiente)

Para dar a uma instância self-hosted um modelo via `.env`:

```env
API_LLM_PROVIDER=openai_compatible
API_LLM_PROVIDER_MODEL="zai-org/GLM-5.3"
API_LLM_BASE_URL="https://api.together.ai/v1"
API_LLM_API_KEY="your-together-api-key"
```

Siga o guia de instalação para [aplicar a mudança de modelo](/pt-BR/how_to_deploy/deploy_kodus/generic_vm#aplicar-mudanças-no-modelo).

## Solução de problemas

<AccordionGroup>
  <Accordion title="Problemas com a Chave de API">
    - Verifique se sua chave de API está correta e ativa na [página de chaves de API](https://api.together.ai/settings/projects/~current/api-keys)
    - Confira se sua conta do Together AI tem saldo de créditos; o acesso à API é suspenso em zero
    - Certifique-se de que não há espaços em excesso ou aspas no valor do `.env`
  </Accordion>

  <Accordion title="Modelo Não Encontrado">
    - Use a string exata do modelo na API da [lista de modelos serverless](https://docs.together.ai/docs/serverless-models), incluindo a capitalização
    - Endpoints serverless e dedicados suportam modelos diferentes; um modelo que não está na lista serverless precisa de um endpoint dedicado
  </Accordion>

  <Accordion title="Erros de Conexão">
    - Verifique se seu servidor tem acesso à internet para alcançar `api.together.ai`
    - Confira se há restrições de firewall
    - Revise os logs da API e do worker para o erro upstream exato
  </Accordion>

  <Accordion title="Rate Limiting">
    - O Together retorna HTTP 429 quando um limite é excedido. Veja a [documentação de rate limits](https://docs.together.ai/docs/rate-limits) do Together
    - Diminua **Max concurrent requests** no modelo, ou fale com o Together sobre limites maiores
  </Accordion>
</AccordionGroup>
