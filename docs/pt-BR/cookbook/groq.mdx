## Como o Groq funciona

O Groq Cloud serve modelos abertos por meio de uma API **compatível com OpenAI**. A Kodus se comunica com ele pelo provedor compatível com OpenAI, então não há alterações de código — apenas credenciais BYOK.

## Modelos Recomendados

<Info>
  O catálogo do Groq muda com frequência. Veja a [página de modelos do Groq](https://console.groq.com/docs/models) para os modelos de produção atuais, janelas de contexto, preços e limites.
</Info>

| ID do Modelo | Janela de Contexto |
| ------------ | ------------------ |
| `openai/gpt-oss-120b` | 131.072 tokens |

Os agentes de revisão da Kodus chamam ferramentas e esperam saída estruturada. A página do Groq para este modelo lista tool use e modo JSON Schema. Confira os dois em qualquer outro modelo antes de trocar.

## Criando a Chave de API

<Warning>Uma conta no Groq Cloud é necessária para criar a Chave de API.</Warning>

Acesse diretamente a [página de Chaves de API do Groq](https://console.groq.com/keys) para criar uma nova Chave de API.

Ou siga estas etapas:

1. Acesse o [Groq Console](https://console.groq.com)
2. Entre ou crie sua conta
3. Abra **API Keys**
4. Clique em **Create API Key**
5. Dê um nome como 'Kodus' ou qualquer nome descritivo
6. Copie a Chave de API e salve em um local seguro

<Info>
  Apenas proprietários de times ou usuários com o papel de desenvolvedor podem criar ou gerenciar chaves de API no Groq.
</Info>

## Configurar o Groq na Kodus

### Opção 1 — Página AI providers (recomendado)

Siga [Conectar um provedor](/pt-BR/how_to_use/byok#conectar-um-provedor) e escolha **Custom → OpenAI-compatible**. Preencha o formulário com estes valores.

| Campo | Valor |
| --- | --- |
| **Key** (no card **API key**) | sua chave de API do Groq |
| **Base URL** | `https://api.groq.com/openai/v1` |
| **Model** | `openai/gpt-oss-120b` |
| **Max concurrent requests** | opcional; em **Advanced (optional)**, expanda **Advanced settings**; diminua se você vir erros de rate limit |

Clique em **Test & save** e escolha os modelos padrão e de fallback em [Modos e modelos de revisão](/pt-BR/how_to_use/code_review/configs/routing).

<Note>
  Use a base URL sem `/chat/completions`. Defina um modelo de outro provedor como **Fallback model** para que as revisões continuem funcionando se o Groq aplicar rate limit.
</Note>

### Opção 2 — Self-hosted (variáveis de ambiente)

Para dar a uma instância self-hosted um modelo via `.env`:

```env
API_LLM_PROVIDER=openai_compatible
API_LLM_PROVIDER_MODEL="openai/gpt-oss-120b"
API_LLM_BASE_URL="https://api.groq.com/openai/v1"
API_LLM_API_KEY="your-groq-api-key"
```

Siga o guia de instalação para [aplicar a mudança de modelo](/pt-BR/how_to_deploy/deploy_kodus/generic_vm#aplicar-mudanças-no-modelo).

## Solução de problemas

<AccordionGroup>
  <Accordion title="Problemas com a Chave de API">
    - Verifique se sua chave de API está correta e ativa no [Groq Console](https://console.groq.com/keys)
    - Confira se o seu plano do Groq pode usar o modelo escolhido
    - Certifique-se de que não há espaços em excesso ou aspas no valor do `.env`
  </Accordion>

  <Accordion title="Modelo Não Encontrado">
    - Confira se o ID do modelo está escrito exatamente como na página de modelos do Groq
    - Verifique se o modelo está na lista atual de modelos do Groq; modelos são aposentados com o tempo
    - O Groq aposentou `llama-3.3-70b-versatile` e `llama-3.1-8b-instant` para os planos Free e Developer em 16 de agosto de 2026. Contratos Enterprise não são afetados. Veja as [deprecações](https://console.groq.com/docs/deprecations) do Groq
  </Accordion>

  <Accordion title="Erros de Conexão">
    - Verifique se seu servidor tem acesso à internet para alcançar `api.groq.com`
    - Confira se há restrições de firewall
    - Revise os logs da API e do worker para o erro upstream exato
  </Accordion>

  <Accordion title="Rate Limiting">
    - O Groq retorna HTTP 429 quando um limite é excedido, e os limites dependem do seu plano
    - Veja os limites exatos da sua organização na página Limits da sua conta do Groq ([console.groq.com/settings/limits](https://console.groq.com/settings/limits)) e na [documentação de rate limits do Groq](https://console.groq.com/docs/rate-limits)
    - Diminua **Max concurrent requests** no modelo, ou faça upgrade do seu plano
  </Accordion>
</AccordionGroup>
