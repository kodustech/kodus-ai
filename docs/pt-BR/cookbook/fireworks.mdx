## Como o Fireworks AI funciona

O Fireworks AI é uma plataforma de inferência que serve modelos open-source populares, como DeepSeek, Kimi, GLM e Qwen, por meio de uma API **compatível com OpenAI**. A Kodus se comunica com ela pelo provedor compatível com OpenAI, então não há alterações de código — apenas credenciais BYOK.

## Modelos Recomendados

<Info>
  O catálogo do Fireworks muda com frequência. Veja a [biblioteca de modelos do Fireworks](https://fireworks.ai/models) para os modelos atuais, janelas de contexto e preços.
</Info>

Os IDs de modelo do Fireworks têm o formato `accounts/fireworks/models/<model>` e escrevem uma versão com `p`: o GLM 5.3 é `glm-5p3`. Copie o ID da página do modelo na biblioteca.

| ID do Modelo | Janela de Contexto |
| ------------ | ------------------ |
| `accounts/fireworks/models/glm-5p3` | 1.048.576 tokens |

Os agentes de revisão da Kodus chamam ferramentas e esperam saída estruturada. Escolha um modelo que suporte function calling, o que a página do modelo informa.

## Criando a Chave de API

<Warning>Uma conta no Fireworks AI é necessária para criar a Chave de API.</Warning>

1. Entre em [app.fireworks.ai](https://app.fireworks.ai) ou crie uma conta.
2. Abra a página de chaves de API: [app.fireworks.ai/settings/users/api-keys](https://app.fireworks.ai/settings/users/api-keys).
3. Clique em **Create API key**.
4. Copie a chave e guarde em um local seguro. O Fireworks não a mostra novamente.

## Configurar o Fireworks AI na Kodus

### Opção 1 — Página AI providers (recomendado)

Siga [Conectar um provedor](/pt-BR/how_to_use/byok#conectar-um-provedor) e escolha **Custom → OpenAI-compatible**. Preencha o formulário com estes valores.

| Campo | Valor |
| --- | --- |
| **Base URL** | `https://api.fireworks.ai/inference/v1` |
| **Model** | ex.: `accounts/fireworks/models/glm-5p3` |
| **API key** | sua chave de API do Fireworks |
| **Max concurrent requests** | opcional; diminua se você vir erros de rate limit (em **Advanced (optional)**) |

Clique em **Test & save** e escolha os modelos padrão e de fallback em [Modos e modelos de revisão](/pt-BR/how_to_use/code_review/configs/routing).

<Note>
  Use a base URL sem `/chat/completions`. Em **Code review → Routing**, defina um modelo de outro provedor como **Fallback model** para que as revisões continuem funcionando se o Fireworks falhar.
</Note>

### Opção 2 — Self-hosted (variáveis de ambiente)

Para dar a uma instância self-hosted um modelo via `.env`:

```env
API_LLM_PROVIDER=openai_compatible
API_LLM_PROVIDER_MODEL="accounts/fireworks/models/glm-5p3"
API_LLM_BASE_URL="https://api.fireworks.ai/inference/v1"
API_LLM_API_KEY="your-fireworks-api-key"
```

Siga o guia de instalação para [aplicar a mudança de modelo](/pt-BR/how_to_deploy/deploy_kodus/generic_vm#aplicar-mudanças-no-modelo).

## Solução de problemas

<AccordionGroup>
  <Accordion title="Problemas com a Chave de API">
    - Verifique se sua chave de API está correta e ativa no [Fireworks AI Console](https://app.fireworks.ai)
    - Confira se você tem créditos suficientes na sua conta do Fireworks AI
    - Certifique-se de que não há espaços em excesso ou aspas no valor do `.env`
  </Accordion>

  <Accordion title="Modelo Não Encontrado">
    - Use o ID completo `accounts/fireworks/models/<model>`, escrito como na biblioteca de modelos
    - Verifique se o modelo está disponível para inferência serverless; alguns modelos exigem um deployment dedicado
  </Accordion>

  <Accordion title="Erros de Conexão">
    - Verifique se seu servidor tem acesso à internet para alcançar `api.fireworks.ai`
    - Confira se há restrições de firewall
    - Revise os logs da API e do worker para o erro upstream exato
  </Accordion>

  <Accordion title="Rate Limiting">
    - Confira seu uso atual no painel do Fireworks AI
    - Uma conta sem forma de pagamento ou créditos tem um limite de requisições muito menor. Veja os [rate limits](https://docs.fireworks.ai/guides/quotas_usage/rate-limits) do Fireworks
    - Diminua **Max concurrent requests** no modelo, ou considere um deployment dedicado para maior throughput
  </Accordion>
</AccordionGroup>
