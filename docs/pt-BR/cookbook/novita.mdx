## Como a Novita funciona

A Novita é uma plataforma de inferência serverless que hospeda modelos open-source, como DeepSeek, Kimi, GLM, MiniMax e Qwen, por trás de uma API **compatível com OpenAI**. A Kodus tem um provedor **Novita** dedicado, então você só precisa de uma chave de API.

## Modelos Recomendados

<Info>
  Veja a [lista de modelos da Novita](https://novita.ai/models/llm) para os modelos e preços atuais. A lista em `https://api.novita.ai/openai/v1/models` é pública e mostra o tamanho de contexto e os recursos de cada modelo.
</Info>

Os IDs de modelo da Novita são strings `org/model`, na maioria em minúsculas. Estes listam function calling e saídas estruturadas no catálogo da Novita:

| ID do Modelo | Janela de Contexto |
| ------------ | ------------------ |
| `deepseek/deepseek-v4-pro` | ~1M tokens |
| `moonshotai/kimi-k3` | ~1M tokens |
| `zai-org/glm-5.3` | ~1M tokens |
| `minimax/minimax-m3` | ~1M tokens |
| `qwen/qwen3.8-27b` | ~1M tokens |

## Criando a Chave de API

<Warning>Uma conta na Novita é necessária para criar uma chave de API.</Warning>

1. Abra [**Key Management**](https://novita.ai/settings/key-management) no console da Novita.
2. Selecione **Create API Key** e dê um nome, por exemplo `kodus`.
3. Escolha uma expiração: **Permanent**, 90 dias, 30 dias ou 24 horas. Você não pode alterá-la depois, e a Novita rejeita uma chave expirada.
4. Copie a chave. A Novita a mostra por completo apenas uma vez.

## Configurar a Novita na Kodus

### Opção 1 — Página AI providers (recomendado)

Este fluxo é o mesmo na Kodus Cloud e em uma instância self-hosted.

<Steps>
  <Step title="Abrir AI providers e escolher Novita">
    Na barra lateral, abra **AI providers** ([app.kodus.io/byok](https://app.kodus.io/byok) no Cloud, `/byok` na sua própria instância). Na aba **Providers**, clique no card **Novita**. Ele fica em **Connect your first provider**, ou depois de **Add another provider** se você já conectou um.
  </Step>

  <Step title="Colar sua chave de API e escolher o modelo">
    Cole sua chave da Novita no campo **Key** do card **API key**. Deixe **Base URL (optional)** vazio: a Kodus então chama `https://api.novita.ai/v3/openai`. No card **Model**, escolha um modelo da lista ou selecione **Type model manually**.
  </Step>

  <Step title="Test & save">
    Clique em **Test & save**. A Kodus envia ao modelo uma requisição de um token e salva a configuração em caso de sucesso.
  </Step>
</Steps>

Em seguida, abra **Code review → Routing** (o botão **Configure routing** na página **AI providers** abre essa tela). No card **Models**, defina o modelo da Novita como **Default model** e um modelo de outro provedor conectado, como OpenAI ou Anthropic, como **Fallback model**, para que as revisões continuem funcionando se a Novita estiver indisponível. Clique em **Save settings**.

### Opção 2 — Self-hosted (variáveis de ambiente)

Em uma instância self-hosted, selecione o provedor OpenAI-compatible no `.env` e use a mesma URL base do provedor Novita integrado.

```env
API_LLM_PROVIDER=openai_compatible
API_LLM_PROVIDER_MODEL="deepseek/deepseek-v4-pro"
API_LLM_BASE_URL="https://api.novita.ai/v3/openai"
API_LLM_API_KEY="your-novita-api-key"
```

Siga o guia de instalação para [aplicar a mudança de modelo](/pt-BR/how_to_deploy/deploy_kodus/generic_vm#aplicar-mudanças-no-modelo).

## Solução de problemas

<AccordionGroup>
  <Accordion title="Problemas com a Chave de API">
    - Verifique se sua chave de API está correta e ativa no [console da Novita](https://novita.ai/settings/key-management)
    - Confira se você tem créditos suficientes na sua conta da Novita
    - Certifique-se de que não há espaços em excesso ou aspas no valor do `.env`
  </Accordion>

  <Accordion title="Modelo Não Encontrado">
    - Os IDs de modelo são strings `org/model`, e alguns contêm maiúsculas. Copie o ID exato da lista de modelos da Novita
    - Confira se o modelo ainda está na lista em `https://api.novita.ai/openai/v1/models`
  </Accordion>

  <Accordion title="Erros de Conexão">
    - Verifique se seu servidor tem acesso à internet para alcançar `api.novita.ai`
    - Confira se há restrições de firewall
    - Revise os logs da API e do worker para o erro upstream exato
  </Accordion>
</AccordionGroup>
