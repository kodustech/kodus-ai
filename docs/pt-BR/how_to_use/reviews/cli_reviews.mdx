title: "CLI reviews"
description: "Veja os reviews que o seu time rodou com a CLI do Kodus, quem os rodou e o que eles encontraram."
---

**Reviews → CLI** lista os reviews que o seu time rodou pelo terminal com a [CLI do Kodus](/pt-BR/how_to_use/cli/introduction). Fica ao lado da aba [Pull requests](/pt-BR/how_to_use/reviews/pull_requests) e está aberta para Owners, Repo Admins e Contributors. Até alguém rodar um review pela CLI, ela mostra *No CLI reviews yet*.

## A lista

| Coluna | O que mostra |
| --- | --- |
| **When** | Há quanto tempo o review rodou |
| **User** | A conta do Kodus que o rodou, senão o e-mail do git, senão *Anonymous*. Uma linha abaixo diz se ele usou uma key de **Team** (com o nome da key) ou um login **Personal**, e mostra `git:` com o e-mail do git local quando ele difere da conta |
| **Repo** | O repositório revisado |
| **Branch** | A branch revisada |
| **Commit** | O hash curto do commit |
| **Status** | **Success**, **Error**, **In Progress**, **Skipped**, **Partial Error** ou **Pending** |
| **Issues** | Quantos problemas o review encontrou |
| **Duration** | Quanto tempo o review levou |

Branch, commit e duração ficam ocultos em telas estreitas.

Clique em uma linha para expandi-la. Ela mostra a timeline do review com o status, a duração e o horário de início de cada etapa, qualquer mensagem de erro, a versão da CLI do Kodus e as sugestões que o review produziu, cada uma com severidade, categoria, arquivo e linha, explicação e mudança proposta. Enquanto um review ainda está rodando, as sugestões podem aparecer como uma prévia que não é final.

## Filtros

- **Search by user email**
- **Repository**
- **Date**: **Today**, **Last 7 days** ou **Last 30 days**

O contador **Reviewed today** no canto superior direito mostra quantos reviews pela CLI o seu time rodou hoje e, ao ser clicado, filtra a lista por eles. Os filtros ativos aparecem como chips, **Clear all** os redefine, e a URL os mantém para que uma visão filtrada possa ser compartilhada.
