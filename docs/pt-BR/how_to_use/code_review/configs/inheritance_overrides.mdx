## Visão Geral

As configurações do Kodus funcionam em três níveis: **Global**, **Repositório** e **Diretório**.

<Note>
O nível mais específico prevalece: Diretório > Repositório > Global
</Note>

```
Global
 ├─ Repositório A
 │   ├─ Diretório A1
 │   └─ Diretório A2
 └─ Repositório B
```

## Como Funciona

Os campos herdam do nível pai por padrão. Quando você altera um campo no Global, todos os repositórios e diretórios sem uma sobrescrita são atualizados automaticamente.

<Info>
As sobrescritas são por campo. Você pode sobrescrever um campo e herdar todo o resto.
</Info>

Uma vez sobrescrito, um campo para de seguir o pai e usa seu valor local.

## No app

- **Trocando de nível:** o seletor de escopo no topo do grupo **Code review** da barra lateral lista **Global** ("applies to every repository"), depois cada repositório que tem sua própria configuração, com seus diretórios recuados abaixo. Trocar de escopo mantém você na mesma página (General, What to review, Kody Rules, What Kody writes).
- **Adicionando um nível:** no seletor de escopo, escolha **Add repository configuration**. O diálogo **Create repository settings** pede para você usar **Select the target repository** e, opcionalmente, **Select the target directories**; clique em **Create settings**. Veja [Configurações por Diretório](/pt-BR/how_to_use/code_review/configs/directory_level).
- **Vendo as sobrescritas:** um indicador numérico ao lado de um escopo ou página na barra lateral conta as configurações sobrescritas naquele nível ("N settings overridden at this level"). Na página, cada campo sobrescrito mostra um badge **Overridden**; o botão de desfazer dele devolve o campo à herança.
- **Removendo um nível:** o menu **⋯** ao lado do seletor de escopo tem **Delete configuration** (e **Edit directories** para um escopo de diretório).

## Exemplos

<Tabs>
  <Tab title="Alteração global se propaga">
    Você altera **Minimum severity to post** (em **What to review**) no Global.
    
    Todos os repositórios e diretórios sem uma sobrescrita são atualizados automaticamente. Os que têm sobrescrita permanecem inalterados.
  </Tab>

  <Tab title="Sobrescrita de repositório">
    No Repositório X, você sobrescreve a mensagem **Review starts** (em **What Kody writes → Comments during the review**).
    
    Os diretórios dentro do Repositório X agora herdam do Repositório X (a menos que tenham sua própria sobrescrita).
  </Tab>

  <Tab title="Retornar à herança">
    No Repositório Y, você remove a sobrescrita dos switches de categoria em **What to review**.
    
    O campo segue o Global novamente e recebe futuras alterações globais.
  </Tab>
</Tabs>

## Boas Práticas

- Comece no Global com padrões sólidos
- Sobrescreva apenas quando tiver uma necessidade específica para aquele repositório/diretório

## Perguntas Frequentes

<AccordionGroup>
  <Accordion title="Se eu alterar algo no Global, isso vai quebrar meus ajustes locais?">
    Não. As sobrescritas locais permanecem inalteradas.
  </Accordion>

  <Accordion title="Posso sobrescrever apenas um campo e herdar o restante?">
    Sim. As sobrescritas são por campo.
  </Accordion>

  <Accordion title="Um Diretório herda do Repositório ou do Global?">
    Do Repositório primeiro. Se o Repositório não tiver uma sobrescrita para aquele campo, herda do Global.
  </Accordion>
</AccordionGroup>
