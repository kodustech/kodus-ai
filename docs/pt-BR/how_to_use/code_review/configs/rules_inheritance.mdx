## Quais regras um review aplica

Todo review aplica as regras ativas de três escopos: **Global → Repository → Directory**.

- As regras **Global** se aplicam a todos os repositórios.
- As regras de **Repository** se aplicam a todo pull request desse repositório.
- As regras de **Directory** se aplicam quando o pull request é revisado com as configurações daquele escopo de diretório, o que acontece quando ele toca exatamente um escopo de diretório. As regras dos outros escopos de diretório do repositório não se aplicam.
- Um pull request que não toca nenhum escopo de diretório, ou toca dois ou mais, é revisado com as configurações do repositório. Nesse caso, as regras de **todos** os escopos de diretório do repositório também se aplicam, a todos os arquivos do pull request.

Uma regra escrita em um escopo pai é sempre herdada pelos escopos abaixo dele. Uma regra que aparece em dois escopos com instruções idênticas roda uma vez.

<Note>
  O switch **Inheritable** e **Override and disable for this scope** mudam como as regras são listadas na página **Kody Rules**. Eles não mudam quais regras um review aplica. Veja abaixo.
</Note>

## No app

Na página **Kody Rules**, as regras herdadas de escopos mais altos são listadas junto com as regras do próprio escopo, marcadas com o escopo de origem. Ali elas são somente leitura: abra a regra e use **View**, ou vá ao escopo onde ela foi criada para editá-la. **Filters → View** mostra ou oculta **Inherited from Global**, **Inherited from Repository** e **Disabled Rules**.

### Inheritable

Em uma regra de qualquer escopo, abra **Advanced settings** no diálogo da regra e desative **Inheritable** (ativado por padrão).

- A regra deixa de ser listada como herdada nos escopos abaixo dela.
- Um review ainda a aplica em todos os escopos, como descrito acima.

### Override and disable for this scope

Em um escopo de repositório ou de diretório, abra uma regra herdada (**View**) e ative **Override and disable for this scope**.

- A regra aparece como **Disabled** nesse escopo e fica oculta quando **Disabled Rules** está desmarcado em **Filters → View**.
- Ela não aparece como desabilitada nos escopos abaixo, que mantêm a própria configuração.
- Um review ainda aplica a regra.

Para impedir que uma regra se aplique, pause-a ou exclua-a no escopo onde ela foi criada.

## Centralized config

Um arquivo de regra em um repositório de [configuração centralizada](/pt-BR/how_to_use/code_review/configs/centralized_config) pode trazer as mesmas configurações:

```yaml
inheritance:
  inheritable: true
  exclude: []   # repository or directory IDs
  include: []   # repository or directory IDs
```

`inheritable` e `exclude` se comportam como descrito acima. `include` não tem controle no app e não tem efeito em um review; uma regra com uma lista `include` não vazia não aparece na lista de herdadas.
