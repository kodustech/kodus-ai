As Fontes Globais de Regras permitem apontar o Kodus para um ou mais repositórios conectados e importar seus arquivos de regra como Kody Rules **globais**. Diferente das [Regras de Repositório](/pt-BR/how_to_use/code_review/configs/repository_rules), que valem apenas no repositório onde estão, as regras importadas de uma fonte global valem em **todos** os repositórios durante o code review.

Use isso quando o time mantém seus padrões de arquitetura e de código em um repositório dedicado de "standards" e quer esses padrões aplicados em todo lugar, sem copiar arquivos de regra para cada projeto.

## Como funciona

- Você seleciona repositórios conectados para atuar como **fontes**.
- O Kodus varre a branch padrão de cada repositório fonte em busca de arquivos de regra, nos mesmos locais e com o mesmo template das [Regras de Repositório](/pt-BR/how_to_use/code_review/configs/repository_rules) (`.kody/rules/`, `rules/**/*.md` e assim por diante).
- Cada arquivo de regra vira uma regra global, exibida na página global de **Kody Rules** com o arquivo de onde veio.
- No code review de qualquer repositório, essas regras globais valem junto com as regras do próprio repositório, respeitando a [herança](/pt-BR/how_to_use/code_review/configs/rules_inheritance).
- Instruções escritas para agentes de código (`CLAUDE.md`, `AGENTS.md`, `.cursor/rules/**`) não são importadas. Regras globais importadas delas no passado são mantidas, mas congeladas; veja [Instruções para agentes de código](/pt-BR/how_to_use/code_review/configs/rules_file_detection).

<Info>
Somente repositórios já conectados na página **Repositories** podem ser fontes, para que as regras importadas fiquem atualizadas pelo gatilho de pull request descrito abaixo.
</Info>

## Configuração

1. Na barra lateral, escolha **Global** no seletor de escopo no topo do grupo **Code review** e abra **Kody Rules**.
2. Clique em **Configuration** para abrir o painel lateral e encontre **Global rule sources**.
3. Clique no seletor de repositórios e escolha um ou mais repositórios conectados.
4. Clique em **Import selected**.

A importação roda em background. Quando termina, as regras importadas aparecem na sua lista de Kody Rules globais. Um repositório que você escolheu mas ainda não importou mostra **Not imported yet**.

## Mantendo as regras atualizadas

- **No merge:** quando um pull request recebe merge em um repositório fonte, seus arquivos de regra são varridos de novo e as regras globais são atualizadas. Arquivos sem alteração são pulados.
- **Resync now:** varre de novo todas as fontes sob demanda. Use depois de um push direto na branch padrão de um repositório fonte, que não é detectado automaticamente.

## Removendo uma fonte

Remover um repositório da lista **apaga as regras globais importadas dele**, então elas deixam de valer durante o code review. Você precisa confirmar antes. As regras das suas outras fontes, e as regras que você escreveu à mão, não são afetadas.

## Repositórios fonte não são revisados

Um repositório usado como fonte de regras globais é tratado como um repositório de configuração, não como uma base de código. O Kodus **pula o code review** nos pull requests abertos nele, do mesmo jeito que faz com um repositório de [configuração centralizada](/pt-BR/how_to_use/code_review/configs/centralized_config).

## Disponibilidade por plano

| Plano | Acesso |
|------|--------|
| **Free**, self-hosted sem license key válida, ou um plano cancelado ou expirado | Não disponível. |
| **Trial** | Até **5 regras globais no total**, somando todos os repositórios fonte. Só as 5 primeiras regras encontradas são importadas; ao atingir o limite, nada mais é importado até você remover algumas ou fazer upgrade. |
| **Pago** (cloud) e **self-hosted licenciado** | Ilimitado. |

No plano Trial, um contador mostra quantas das 5 regras estão em uso, e um diálogo de confirmação diz quantas mais serão adicionadas antes de você importar.
