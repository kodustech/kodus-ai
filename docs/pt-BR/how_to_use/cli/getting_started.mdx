description: "Instale o Kodus CLI, autentique-se e execute sua primeira revisão."
---

Este guia leva você do zero a um diff revisado em menos de cinco minutos.

<Steps>
  <Step title="Instalar">
    <Tabs>
      <Tab title="Instalador de Skills (Recomendado)">
        Instala ou atualiza o CLI e depois instala as skills do Kodus nos agentes de IA que encontrar na sua máquina (Claude Code, Cursor, Codex e outros — veja [Agentes de IA](/pt-BR/how_to_use/cli/ai_agents)).

        macOS e Linux:

        ```bash
        curl -fsSL https://review-skill.com/install | bash
        ```

        Windows PowerShell:

        ```powershell
        powershell -NoProfile -ExecutionPolicy Bypass -Command "$tmp = Join-Path $env:TEMP 'kodus-install.ps1'; Invoke-WebRequest https://review-skill.com/install.ps1 -OutFile $tmp; & $tmp"
        ```
      </Tab>
      <Tab title="npm">
        ```bash
        npm install -g @kodus/cli
        ```

        `pnpm add -g @kodus/cli`, `yarn global add @kodus/cli` e `bun add -g @kodus/cli` funcionam da mesma forma.
      </Tab>
      <Tab title="npx (Sem Instalação)">
        ```bash
        npx @kodus/cli review
        ```
      </Tab>
    </Tabs>

    <Note>Requer Node.js 22.19.0 ou superior.</Note>

    Verifique a instalação:

    ```bash
    kodus --version
    kodus status
    ```
  </Step>

  <Step title="Autenticar">
    Escolha o caminho que corresponde à sua situação. Você também pode pular a autenticação e executar `kodus review` diretamente — funciona em modo trial com limites por hora.

    <Tabs>
      <Tab title="Desenvolvedor solo">
        Faça login com uma conta pessoal:

        ```bash
        kodus auth login
        ```

        O CLI abre a página **Authorize Kodus CLI** no seu navegador e imprime a URL caso o navegador não abra. Confira os detalhes de **Device**, **Mode** e **Expires**, clique em **Authorize CLI** e volte ao terminal.

        Se você não estiver logado no Kodus nesse navegador, primeiro cai na página de login e, depois de entrar, no dashboard. Abra novamente a URL do terminal para chegar em **Authorize CLI**. O CLI espera por até 10 minutos.

        Em uma máquina sem navegador (uma sessão SSH, CI ou um terminal não interativo), o CLI imprime uma URL e um código. A página não tem campo para digitar o código. Abra a URL em qualquer dispositivo com o código adicionado como parâmetro `code` (`https://app.kodus.io/cli/authorize?code=ABCD-EFGH`) e clique em **Authorize CLI**. O código expira após 10 minutos. Adicione `--device-code` para usar esse fluxo em qualquer máquina.

        Seu login é armazenado em `~/.kodus/credentials.json` e atualizado automaticamente.
      </Tab>
      <Tab title="Equipe (chave compartilhada)">
        Um owner da organização gera uma chave de equipe na barra lateral em **Organization → CLI keys** (<a href="https://app.kodus.io/organization/cli-keys" target="_blank">app.kodus.io/organization/cli-keys</a>). Aplique-a:

        ```bash
        kodus auth team-key --key kodus_xxxxx
        ```

        Ou distribua o comando de bootstrap para sua equipe. Ele instala o CLI, aplica a chave e instala as skills:

        ```bash
        curl -fsSL https://review-skill.com/install | bash -s -- --team-key kodus_xxxxx
        ```

        <Warning>Salve a chave quando ela for exibida — ela não será mostrada novamente.</Warning>
      </Tab>
      <Tab title="Agente de IA">
        Para agentes de código com IA (Claude Code, Cursor, Codex), chaves de equipe são o caminho recomendado — sem login individual, sem prompts interativos. Defina a chave uma vez:

        ```bash
        export KODUS_TEAM_KEY=kodus_xxxxx
        ```

        Adicione-a ao perfil do seu shell para que o agente a use em toda execução.
      </Tab>
      <Tab title="CI/CD">
        Use uma chave de equipe. Armazene-a como secret e exponha-a ao job como `KODUS_TEAM_KEY`:

        ```bash
        export KODUS_TEAM_KEY=kodus_xxxxx
        ```

        Veja [Configuração Self-Hosted](/pt-BR/how_to_use/cli/self_hosted#integração-com-ci/cd) para exemplos de GitHub Actions, GitLab CI e pipelines genéricos.
      </Tab>
    </Tabs>

    <Info>
      **Hospedando o Kodus por conta própria?** Aponte o CLI para a sua API antes de autenticar:

      ```bash
      export KODUS_API_URL=https://kodus-api.yourcompany.com
      ```

      HTTPS é obrigatório, exceto para `localhost`.
    </Info>

    Confirme o estado da autenticação:

    ```bash
    kodus auth status
    ```
  </Step>

  <Step title="Execute sua primeira revisão">
    Dentro de qualquer repositório git com alterações não commitadas:

    ```bash
    kodus review
    ```

    O CLI analisa o diff da sua árvore de trabalho e imprime um resumo. Em um terminal interativo no macOS e no Linux, os achados abrem no visualizador de diff Hunk, ao lado do código. No Windows, ou com `--no-hunk`, você navega por uma lista arquivo a arquivo, visualiza as correções sugeridas e as aplica.

    Variações comuns:

    ```bash
    kodus review --staged             # Only staged files
    kodus review --branch main        # Compare current branch against main
    kodus review --commit abc123      # Analyze a single commit
    kodus review --fix                # Apply every fixable issue (asks to confirm)
    kodus review --prompt-only        # Compact output for AI agents
    kodus review --fail-on error      # Exit 1 on error-or-worse issues (CI-friendly)
    ```

    <Tip>
      Com login ou chave de equipe, revisões de árvore de trabalho (padrão) e `--staged` enviam o conteúdo dos arquivos alterados junto com o diff. `--branch`, `--commit` e `--fast` enviam apenas o diff, já que o backend consegue ler esses commits por conta própria. É por isso que funcionam bem em branches enormes. Revisões trial sempre enviam apenas o diff.
    </Tip>

    <Note>
      Apenas alterações rastreadas são revisadas. Execute `git add` em um arquivo novo para incluí-lo.
    </Note>
  </Step>

  <Step title="Escolha o próximo passo">
    Dependendo do seu objetivo:

    <CardGroup cols={2}>
      <Card title="Automatize a cada push" icon="shield-check" href="/pt-BR/how_to_use/cli/commands#kodus-hook">
        Instale o hook de pre-push com `kodus hook install`. Ele revisa a branch que você envia e bloqueia o push quando há achados críticos.
      </Card>
      <Card title="Rode revisões no CI" icon="infinity" href="/pt-BR/how_to_use/cli/self_hosted#integração-com-ci/cd">
        Exemplos de GitHub Actions, GitLab CI e pipelines genéricos.
      </Card>
      <Card title="Conecte a um agente de IA" icon="robot" href="/pt-BR/how_to_use/cli/ai_agents">
        Alimente o Claude Code, o Cursor ou o Codex com `--prompt-only` para loops de correção autônomos.
      </Card>
      <Card title="Configure o repositório" icon="sliders" href="/pt-BR/how_to_use/cli/commands#kodus-config-remote">
        Leia e altere as configurações de revisão pelo CLI.
      </Card>
    </CardGroup>
  </Step>
</Steps>

## Variáveis de Ambiente

Essas variáveis de ambiente configuram o CLI em todos os comandos.

| Variable                     | Description                                                                        |
| ---------------------------- | ---------------------------------------------------------------------------------- |
| `KODUS_API_URL`              | Endpoint da API (padrão: `https://api.kodus.io`)                                     |
| `KODUS_APP_URL`              | URL do web app para a qual `kodus config remote open` aponta (padrão: `https://app.kodus.io`) |
| `KODUS_TEAM_KEY`             | Chave de equipe para acesso compartilhado e agentes de IA                                           |
| `KODUS_TOKEN`                | Um token de acesso de login, usado como está e sem renovação. Tem prioridade sobre qualquer outra credencial. Para CI, use uma chave de equipe |
| `KODUS_GITHUB_PAT`           | Token do GitHub para revisões trial de repositórios privados. `GITHUB_TOKEN` e `GH_TOKEN` também são lidos |
| `KODUS_SKIP_HOOK`            | Defina com qualquer valor para pular o hook de pre-push em um único `git push`                 |
| `KODUS_REQUEST_TIMEOUT_MIN`  | Timeout de cada requisição à API em minutos (padrão: `60`)                             |
| `KODUS_DISABLE_UPDATE_CHECK` | Defina como `1` para desativar o aviso de atualização                                           |
| `CF_ACCESS_CLIENT_ID`        | Client ID do Cloudflare Access (APIs atrás do Zero Trust)                               |
| `CF_ACCESS_CLIENT_SECRET`    | Client secret do Cloudflare Access                                                    |

Para configurações self-hosted e Cloudflare Access, veja [Configuração Self-Hosted](/pt-BR/how_to_use/cli/self_hosted).
