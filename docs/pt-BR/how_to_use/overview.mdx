## O que é o Kodus

O **Kody** revisa pull requests no GitHub, GitLab, Bitbucket, Azure Repos e Forgejo. Ele confere as alterações com as regras do seu time. O Kodus é open source e pode rodar na sua própria infraestrutura.

## O que o Kodus faz

- [Entenda o resultado da revisão](/pt-BR/how_to_use/code_review/flow#o-que-você-recebe). Veja o que o Kody publica no PR e como pedir outra revisão.
- [Ajuste o que o Kody verifica](/pt-BR/how_to_use/code_review/configs/what_to_review). Escolha categorias, severidade mínima e o que o Kody deve inspecionar.
- [Ensine os padrões do seu time](/pt-BR/how_to_use/code_review/configs/kody_rules). Use regras e memórias para aplicar as convenções do time durante a revisão.
- [Confira o PR com a tarefa](/pt-BR/how_to_use/code_review/business_logic_validation). Compare a implementação com os requisitos no gerenciador de tarefas.

## Linguagens Suportadas

O Kody funciona com qualquer linguagem de programação ou tipo de arquivo imediatamente, usando análise semântica (LLM), apoiada por busca de código (estilo grep) para contexto preciso em todo o repositório.
