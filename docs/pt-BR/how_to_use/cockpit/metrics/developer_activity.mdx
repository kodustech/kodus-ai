## O que é Atividade do Desenvolvedor

A Atividade do Desenvolvedor mostra os pull requests que cada desenvolvedor abre ao longo do tempo, para que você veja a carga de trabalho e os padrões de atividade do time.

No Cockpit, é o gráfico **Team Activity** na aba **Productivity**: uma tabela com uma linha por desenvolvedor e uma coluna por semana (de domingo a sábado), da mais recente para a mais antiga. Cada linha mostra o total de PRs do desenvolvedor no intervalo, e cada semana mostra uma barra por PR aberto.

## Como Calculamos

```
Activity = COUNT(PRs opened) per developer per week
```

- Um PR conta na data em que foi **aberto**, qualquer que seja seu status hoje (aberto, mergeado ou fechado). Para um PR aberto antes de o repositório ser conectado, e que não esteja entre os PRs importados na conexão, essa é a data em que o Kodus o registrou pela primeira vez.
- O desenvolvedor é o nome de usuário do autor do PR no seu provedor Git. PRs sem autor ficam de fora.
- Cobre o intervalo de datas selecionado no topo do Cockpit.

Compare com [PRs by Developer](/pt-BR/how_to_use/cockpit/metrics/prs_by_developer), que conta PRs pela data em que foram **fechados**.

## Por que é Importante

- **Equilibrar a carga de trabalho**: veja se o trabalho está distribuído de forma uniforme entre o time
- **Acompanhar tendências**: veja como a atividade muda ao longo do tempo
- **Identificar gargalos**: encontre onde o trabalho se acumula em poucas pessoas

A contagem de PRs não diz nada sobre o tamanho ou a dificuldade do PR, então leia-a junto com [PR Size](/pt-BR/how_to_use/cockpit/metrics/pr_size).
