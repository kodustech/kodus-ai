プランの違いは機能であり、Kody がレビューできるプルリクエストの数ではありません。料金と商取引条件については、[kodus.io/pricing](https://kodus.io/pricing) を参照してください。

<Note>
  **PR レビューとワークスペースメンバーは、すべてのプランで無制限です。** 有料プランでは、開発者ライセンスによって、誰のプルリクエストがレビューされるかが決まります。Free と Teams では、レビューは自分の AI キー（BYOK）で実行されます。Kody は、カスタムエージェントだけが対象にするファイルを含め、**レビュー可能なファイルが 2,000 件を超える**レビューをスキップします。
</Note>

## プラン

<CardGroup cols={3}>
  <Card title="Free" icon="github">
    クラウド。レビューは自分の AI キーで実行され、追加するまでは何も接続されていません。
  </Card>
  <Card title="Teams" icon="users">
    クラウド。開発者ごとのライセンスで、Team 機能が利用できます。レビューは自分の AI キーで実行されます。
  </Card>
  <Card title="Enterprise" icon="building">
    クラウド、またはライセンスキーを使ったセルフホスト。SSO とアクティビティログが追加されます。
  </Card>
</CardGroup>

ライセンスキーのないセルフホストインスタンスは **Community Edition** で動作し、Free と同じ制限があります。Teams はクラウドプランです。セルフホストインスタンスで Enterprise を有効にするには、Kodus から受け取ったキーを **Subscription → Activate a license key** に貼り付けます。キーの有効期限が切れると、更新したキーを貼り付けるまで、Enterprise 機能はオフになります。

**Subscription** で、**Choose a plan**（Free プランでは **Upgrade**）をクリックすると、プラン選択画面が開きます。有料プランでは、**Manage billing** で Stripe が開き、開発者ライセンスと支払い情報を変更できます。

## 無料トライアル

Kodus Cloud の新しいワークスペースでは **14 日間のトライアル**が始まります。機能へのアクセス期間と、Kodus が費用を負担するレビューの件数は別々に管理されます。

<CardGroup cols={2}>
  <Card title="14 日間の利用" icon="calendar">
    トライアルには Teams の機能に加え、Enterprise の SSO とアクティビティログが含まれます。この期間にグローバルルールのソースからインポートできるルールは、合計 5 件までです。
  </Card>
  <Card title="最初の 5 件の PR レビューは Kodus が負担" icon="gift">
    Kodus が AI トークンを負担するため、API キーなしで Kody を試せます。トライアルのレビューは、Kodus が提供する効率的なモデルで実行されます。より大きなモデルを使うには、自分のキーを接続してください。
  </Card>
</CardGroup>

**Subscription** には、トライアルのレビューを増やす方法が表示されます。会社のメールアドレスでサインアップする、チームメイトを招待する、または 10 人以上の開発者がいる Git 組織を接続する方法です。**Request review** をクリックすると、Kodus にトライアルの確認と延長を依頼できます。

トライアルのレビューを使い切った後もレビューを続けるには、[**AI providers**](/ja/how_to_use/byok) で自分の AI キーを接続します。レビューはそのキーで実行され、どのプランでも、14 日間が終了した後でも、レビュー数の上限はありません。キーを接続する前にトライアルのレビューを使い切ると、Kody はレビューを一時停止し、**Show status feedback** がオンの場合は、追加するためのリンクを付けたコメントをプルリクエストに投稿します。トライアルが終了したら、Team 機能を使い続けるために **Subscription** でプランを選択してください。

キーのないセルフホストインスタンスでは、**Subscription** の **Request a trial** で、試用のためのライセンスキーを Kodus に依頼できます。

## 開発者ライセンス

シート付きの有料プランでは、開発者がライセンスを持っている場合に、その開発者のプルリクエストがレビューされます。ライセンスは、Git 組織の開発者を数えます。Kodus を設定する人であるワークスペースメンバーは別で、無制限です。

- オーナーは、**Subscription** の **PR licenses** タブでライセンスを割り当てたり、解除したりします。
- **Auto-assign licenses** をオンにすると、開発者の最初の PR はシートなしでレビューされ、その開発者が別の PR を開いたときに、空きがあればシートが割り当てられます。[ライセンスの自動割り当て](/ja/how_to_use/auto_license_assignment) を参照してください。
- Free プランとトライアルには、開発者ごとのライセンスはありません。

## すべてのプランで BYOK

自分のプロバイダーを接続し、トークンはプロバイダーから請求されます。Enterprise では、代わりに Kodus が、お客様との契約に基づいてモデルを実行することもできます。プロバイダーとセットアップについては [BYOK](/ja/how_to_use/byok) を、支出アラートについては [月次スペンドリミット](/ja/how_to_use/spend-limit) を参照してください。

## 支払い

有料プランは Stripe を通じて請求されます。**Subscription** の **Manage billing** で、支払い方法と請求書の Stripe ページが開きます。オーナーと Billing Manager が利用できます。支払いに失敗すると、請求情報が更新されるまでレビューが一時停止します。サブスクリプションがキャンセルまたは期限切れになった場合も、再度サブスクリプションするまでレビューが一時停止します。
