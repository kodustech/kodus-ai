**Organization → Token usage** では、レビューで消費したトークン数と推定コストを確認できます。

Owner、Billing Manager、Repo Admin がダッシュボードを開けます。ログイン後に `kodus usage tokens` でも使用量を確認できます。

アラート付きの月次予算については、[スペンドリミット](/ja/how_to_use/spend-limit) を参照してください。そこから、詳細な内訳であるこのページにリンクしています。

ターミナルでトークン使用量と推定コストを確認したり、JSON で出力したりするには、[`kodus usage tokens`](/ja/how_to_use/cli/commands#usage-tokens) を使います。

## フィルター

- **Models**：含めるモデルにチェックを入れます。デフォルトではすべて選択されています。
- **Repository**：接続済みのリポジトリがある場合に表示されます。
- **View**：**Daily**、**By PR**、**By Review**、**By Developer**。**By PR** では **PR Number** ボックスが、**By Developer** では開発者ピッカーが追加されます。
- **Date range**：**Last week**、**Last 15 days**、**Last month**、**Last 3 months**、またはカスタム日付。デフォルトは直近 15 日間です。

## サマリーカード

範囲とフィルターの合計です。表示される場合は、同じ長さの前の期間との変化も示されます。

| カード | 表示される内容 |
| --- | --- |
| **Total cost** | 推定コスト（1 日あたりと PR あたりの平均付き） |
| **Total tokens** | 推論トークンを含む、使用されたすべてのトークン |
| **Uncached input** | 入力の通常価格で課金される入力トークン |
| **Cache read** | プロバイダーのプロンプトキャッシュから提供され、割引価格で課金される入力トークンと、それによる節約額 |
| **Output** | 推論を含む出力トークン |
| **Cache write** | キャッシュエントリを作成した入力トークン。ある場合にのみ表示されます |

コストは、各モデルのトークンあたりの価格から推定されます。**Price unavailable** と表示されるモデルの使用量もトークン数に含まれます。合計コストにはこれらのモデルの費用が含まれないため、把握できた分の概算として扱ってください。

月次予算を設定している場合、**Monthly spend limit (BYOK)** のバーに、今月の支出が予算に対してどれだけかが表示されます。常に今月を対象とし、日付範囲は無視します。

## チャート

チャートは、選択した **View** に従い、**Tokens** / **USD** で単位を切り替えます。**By PR**、**By Review**、**By Developer** では、トークン数で上位 24 件の消費者が表示されます。

- **Daily**：**Usage over time**。キャッシュなしの入力、キャッシュ、出力、推論に分けて表示されます。
- **By PR**：**Top pull requests**。最も多くのトークンを使った PR。
- **By Review**：**Top review runs**。各バーは 1 回のレビュー実行を表すため、2 回レビューされた PR は 2 回表示されます。下の **Review activity** テーブルには、各実行が PR、開始時刻、モデル、トークン、コストとともに、コストの高い順に最大 100 件まで一覧表示されます。残りを確認するには、フィルターを絞り込んでください。
- **By Developer**：**Top developers**。使用量は PR の作成者に帰属します。

## トークンの使われ方

**Where tokens go** は、Code Review、Kody Rules Review、PR Summary、Conversation、Custom Agents などのタスクごとに支出を内訳表示し、入力、キャッシュ、出力、推論の構成を示すバーが付いています。タスクを展開すると、実行されたステップと、どのモデルがいつ実行したかが表示されます。タスクに紐付けられない支出は **Unrouted** として一覧表示されます。

その下には、各モデルのコストが行ごとに表示されます。行を展開すると、トークンの種類ごとのトークン数とコストが表示され、価格アイコンにカーソルを合わせると、そのモデルの料金が表示されます。
