Kody のコメントへのリアクションが、モデルの学習や次回レビューのフィルタリングに使われることはありません。Kody は 👍 と 👎 のリアクション、および各提案が適用されたかどうかを記録し、Cockpit に表示します。これらが作用する唯一の場所が、以下の **Pause ignored and noisy rules** です。提案が 👎 を集める、またはほとんど適用されない Kody Rule は一時停止されることがあります。

提案にリアクションして、チームへのフィードバックとして残すことはできます。ある種類の提案が再び表示されないようにするには、以下の仕組みのいずれかを使用してください。

## 今後のレビューに影響する仕組み

- **同じ PR での過去の提案：** Kody がすでにレビューした PR では、以前に投稿した提案とそれらが適用されたかどうかを参照し、同じ提案を再び投稿しないようにします。
- [メモリ](/ja/knowledge_base/how-to-teach-ai-your-team-conventions)：`@kody remember` や会話を通じて、明示的なチームの規約を保存します。
- [Kody Rules](/ja/how_to_use/code_review/configs/kody_rules)：コードレビュー時に適用する基準を定義します。
- [ルールの自動生成](/ja/how_to_use/code_review/learning/kody_rules_generation)：レビュー履歴からルールを生成します。ルールはデフォルトで有効になります。**Kody knowledge approval** がオンの場合は、承認のため **Pending review** に保留されます。
- [Pause ignored and noisy rules](/ja/how_to_use/code_review/configs/kody_rules#pause-ignored-and-noisy-rules)：Teams および Enterprise プランで利用でき、デフォルトではオフです。オンにすると、Kody は直近 30 日間で **Ignored**（適用された提案が少ない）または **Noisy**（👎 が多い）とラベル付けされた有効なルールを、1 日 1 回一時停止します。
