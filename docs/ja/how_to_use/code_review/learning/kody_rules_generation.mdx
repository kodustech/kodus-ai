<Warning>
  **リポジトリで少なくとも 3 ヶ月の Kody レビュー履歴が必要です。** この機能は PR の Kody の過去のレビューからルールを導出するため、オンボードしたばかりのリポジトリは有用なサジェストを生成しません。最近 Kody の使用を開始した場合は、数ヶ月の実際のレビュー後に戻ってきてください。
</Warning>

## クイック概要

- **自動生成**：Kody がレビュー履歴を分析して新しいルールを作成します
- **データドリブン**：インテリジェントなインサイトのために 3 ヶ月のレビューデータを使用します
- **スマートサジェスト**：実際のチームパターンに基づいてルールを生成します
- **任意の承認**：生成されたルールはデフォルトで有効です。有効になる前に 1 つずつレビューしたい場合は **Kody knowledge approval** をオンにします
- **継続的な学習**：チームの進化に合わせて週次でルールを更新します

## 仕組み

### 1. ルール生成をオンにする

ルール生成はリポジトリごとに設定します：

1. サイドバーで、**Code review** グループ上部のスコープピッカーでリポジトリを選択し、**Kody Rules** を開きます
2. **Configuration** をクリックしてサイドシートを開きます
3. **Generate from past reviews** をオンにします
4. 必要に応じて、トグルの下にあるレビュアーピッカー（デフォルトは **Learning from all reviewers**）を使って、Kody に学習させたくないレビューコメントを書く開発者を除外します

### 2. 分析プロセス

リポジトリで初めて **Generate from past reviews** をオンにすると、Kody は以下を行います：

- **レビュー履歴のスキャン**：リポジトリの過去 3 ヶ月のクローズされた PR を分析します
- **パターンの識別**：一般的なフィードバックのテーマとコーディングの設定を発見します
- **標準の抽出**：レビューパターンをアクション可能なルールに変換します
- **ルールの生成**：チームのスタイルに合わせたカスタムルールを作成します

これには数分かかる場合があります。生成されたルールは、その後リポジトリの **Kody Rules** ページに表示されます。

### 3. 生成されたルールのレビュー

生成されたルールは **Kody-generated** のオリジン付きで一覧表示されます（それだけを表示するには **Filters → Origin → Kody-generated** を使用します）。いずれかを開くと、他のルールと同様に編集、一時停止、削除ができます。

### 4. 有効になる前にルールを承認する

<Warning>
  デフォルトでは、生成されたルールは**作成された時点で有効**になり、
  次のコードレビューから適用されます。
</Warning>

生成されたルールを有効になる前にレビューするには、同じ **Configuration** シートで **Kody knowledge approval** をオンにします。承認をオンにすると：

- **保留中のレビュー**：新しく生成されたルールは適用される代わりに、Kody Rules ページ上部の **Pending review** セクションに入ります
- **選択的に選択**：チームのニーズに合ったルールを **Approve** し、残りは **Discard** します
- **有効化**：承認されたルールのみがコードレビュー中に適用されます

## 継続的な学習

初期セットアップ後、Kody は継続的な学習サイクルを維持します：

- **週次更新**：Kody は毎週新しいルールのサジェストを生成します
- **進化する標準**：チームのコーディングスタイルが進化するにつれてルールのサジェストが適応します
- **精度の向上**：時間の経過とともにサジェストが精度を増します
- **定期的なレビュー**：新しいルールが毎週表示されます（承認がオンの場合は **Pending review** に表示されます）

## 要件

- **最低データ**：リポジトリで少なくとも 3 ヶ月のレビュー履歴
- **アクティブなレビュー**：より良いパターン検出のための定期的なコードレビュー活動
- **リポジトリアクセス**：リポジトリルールを変更するための適切な権限
