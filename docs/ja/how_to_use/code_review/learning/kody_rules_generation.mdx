---
title: "自動ルール生成"
description: "Kody は、レビュアーが Pull Request に残したコメントから Kody Rules の下書きを作成し、その後も毎週学習を続けます。"
---

Kody は、リポジトリの Pull Request（オープン、クローズを問わず）にチームが書いたレビューコメントを読み取り、レビュアーが繰り返し指摘している基準を見つけて、[Kody Rules](/ja/how_to_use/code_review/configs/kody_rules) の下書きとして作成します。重複を避けるため、既存のルールも考慮されます。

- レビュアーのコメントのうち、100 文字を超えるものから学習します。ボットや Kody 自身によるコメントは対象外です。
- リポジトリごとに実行されます。
- 生成されたルールには **Kody-generated** のオリジンが表示され、パスを設定するまですべてのファイルに適用されます。
- 生成されたルールはすぐに有効になります。**Kody knowledge approval** がオンの場合は、**Pending review** で承認を待ちます。

## オンにする

1. サイドバーの **Code review** グループ上部にあるスコープピッカーで **Global** またはリポジトリを選択し、**Kody Rules** を開きます。
2. **Configuration** をクリックしてサイドシートを開きます。
3. **Generate from past reviews** をオンにします。
4. 必要に応じて、トグルの下にあるレビュアーピッカー（デフォルトは **Learning from all reviewers**）を使って、Kody に学習させたくないレビューコメントを書く開発者を除外します。ここには現在のメンバーと最近の Pull Request の作成者が表示され、選択を適用すると **Excluding N reviewers** と表示されます。

この設定は通常の階層に従います。**Global** がすべてのリポジトリのデフォルトで、リポジトリごとに独自の値を設定できます。ディレクトリごとの設定はできません。

新しいワークスペースでは、オンボーディングの **Kody learns from your past reviews** ステップで確認されます。オンにしない限りオフで、選択は Global レベルに保存されます。

## 実行されるタイミング

- **リポジトリで初めて：** Kody は直近 **3 ヶ月**のレビューコメントを読み取ります。リポジトリレベルでトグルをオンにするとすぐに開始され、数分かかる場合があります。Global レベルでオンにしても、その時点では何も開始されません。それに従うリポジトリは、次回の週次実行で対象になります。この最初の処理は、リポジトリにまだ生成されたルールがない間にのみ行われます。
- **その後：** 週に 1 回、Kody は直近 1 週間のコメントを読み取ります。デフォルトのスケジュールは土曜日 00:00（サンパウロ時間、`America/Sao_Paulo`）です。セルフホストのインスタンスでは `API_CRON_KODY_LEARNING` で変更できます。

必要な履歴の最小量はありません。対象期間内にレビュアーのコメントがないリポジトリでは、ルールは生成されません。

新しいルールが作成されると、Kody はそのタイトルをチームに通知します。

## モデルの要件

クラウドでは、トライアル期間外は自分のモデルキーを使って生成するため、**BYOK** を設定する必要があります。設定していない場合、何も生成されません。トライアル期間中は Kodus がモデルを提供します。セルフホストのインスタンスは、デプロイに設定されたモデルを使用します。[BYOK](/ja/how_to_use/byok) を参照してください。

## Kody が生成した内容の確認

生成されたルールは **Kody-generated** のオリジン付きで一覧表示されます。それだけを表示するには **Filters → Origin → Kody-generated** を使用します。いずれかを開くと、他のルールと同様に編集、一時停止、削除ができます。

有効になる前にルールを承認するには、同じ **Configuration** シートで **Kody knowledge approval** をオンにします。新しく生成されたルールはページ上部の **Pending review** に入り、チームに合うものを **Approve** し、残りを **Discard** します。承認されたルールのみが適用されます。[Approval](/ja/how_to_use/code_review/configs/kody_rules#承認) を参照してください。

<Warning>
  承認なしの場合、生成されたルールは作成されるとすぐに有効になり、次回のコードレビューから適用されます。
</Warning>

開発者に無視されたり 👎 が付けられたりし続けるルールは、自動的に一時停止される場合があります。[Pause ignored and noisy rules](/ja/how_to_use/code_review/configs/kody_rules#pause-ignored-and-noisy-rules) を参照してください。
