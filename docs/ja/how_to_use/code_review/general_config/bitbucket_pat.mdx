## はじめに

Kody が Bitbucket Cloud で自動コードレビューを実行できるようにするには、**API Token** を生成する必要があります。このトークンにより、Kody は以下に記載された特定の権限で、リポジトリ、プルリクエスト、Webhook、イシューにアクセスできます。

---

## Bitbucket での API トークンの生成

1. [Atlassian API トークンページ](https://id.atlassian.com/manage-profile/security/api-tokens)を直接開きます（または、Atlassian プロフィールから **Security → API tokens** に移動します）。
2. **Create API token with scopes** をクリックします。
3. トークンに名前（例：`kody_code_review`）を付け、有効期限を設定します。
4. 求められた場合は、アプリケーションとして **Bitbucket** を選択します。
5. 必要なスコープをすべて選択します（下記参照）。
6. 選択内容を確認し、**Create token** をクリックします。
7. トークンをすぐに**コピー**して安全に保管してください。作成後に再度表示することはできません。

---

## Kody に必要なスコープ

Kody のすべての機能を使うには、トークンに次のスコープを**すべて**含める必要があります。

| スコープ                         | 目的 / 有効になる機能                                                                   |
| ----------------------------- | ------------------------------------------------------------------------------------------- |
| `read:user:bitbucket`         | ユーザーまたはアカウントの基本情報を読み取る。                                                     |
| `read:workspace:bitbucket`    | ワークスペースに関する情報（プロジェクト、メンバー、リポジトリ）を読み取る。                     |
| `read:project:bitbucket`      | プロジェクトのメタデータを読み取る。                                                               |
| `read:repository:bitbucket`   | リポジトリ内のコード、ブランチ、ソースファイルを読み取る。                                          |
| `write:repository:bitbucket`  | リポジトリのファイルを変更する機能のために、ファイルをコミットする。                                     |
| `read:pullrequest:bitbucket`  | プルリクエスト、そのステータス、コメントを表示する。                                               |
| `write:pullrequest:bitbucket` | プルリクエストのコメントを作成または変更し、PR を承認、辞退、またはマージする。                      |
| `read:issue:bitbucket`        | イシュートラッカーの情報を読み取る。                                                             |
| `read:webhook:bitbucket`      | 既存の Webhook とその設定を表示する。                                                  |
| `write:webhook:bitbucket`     | Webhook を作成または更新する。                                                                  |
| `delete:webhook:bitbucket`    | インテグレーションを削除するときに Kodus の Webhook を削除する。                                      |

Kody は `admin:repository:bitbucket` と `read:pipeline:bitbucket` を使用しません。CI ステータスは `read:repository:bitbucket` で読み取ります。

> ⚠️ 必要な権限のみを付与してください。セキュリティリスクを減らすため、必要以上の権限は付与しないでください。

## Kody へのトークンの追加

- 必要なすべてのスコープを付けてトークンを生成したら、Kodus に貼り付けます。オンボーディング中（**Connect your Git tool** → **Bitbucket** タブ → **Connect via token**）、または後からサイドバーの **Repositories** → **Connect a provider** → **Bitbucket** で行います。**Username**、**Email**、**API token** を入力し、**Validate and save** をクリックします。
- プルリクエストイベントを配信する Webhook を作成するには、Kody に `read:webhook:bitbucket` と `write:webhook:bitbucket` が必要で、トークンのユーザーがリポジトリの管理者である必要があります。
- トークンを置き換えるには、**Repositories** の **Bitbucket** カードで **Reset** をクリックし、**Just reset the integration** を選択してから、新しいトークンで再度接続します。

---

## Bitbucket Data Center

セルフホストの Bitbucket Data Center の場合は、同じフォームで **Bitbucket Data Center**（**Alpha** と表示）をオンにします。上記の API トークンとスコープは Bitbucket Cloud のみが対象です。Data Center は代わりにベーシック認証で接続します。**Username**、**Bitbucket Data Center Base URL**（例：`https://bitbucket.your-company.com`）、**Basic auth password** を入力し、**Validate and save** をクリックします。

---

## 重要な注意事項

- トークンは作成時に**一度だけ表示**されます。再度表示することは**できない**ため、安全に保管してください。
- トークンの有効期間を制限するため、可能であれば**有効期限**を設定してください。
- トークンが漏洩した場合は、すぐに失効させて新しいトークンを作成してください。
- トークンとそのスコープを定期的に監査し、引き続き必要かつ有効であることを確認してください。
- お使いの Bitbucket のプラン / アカウントが上記のすべてのスコープを許可しているか確認してください。一部のスコープ（project、workspace）は、サブスクリプションや権限に依存する場合があります。
