## はじめに

Kody が Forgejo で自動コードレビューを実行できるようにするには、**Access Token** を生成する必要があります。このトークンにより、Kody は以下に記載された特定の権限で、リポジトリ、プルリクエスト、Webhook、Issue などにアクセスできます。

---

## Forgejo でのアクセストークンの生成

1. Forgejo インスタンスにアクセスし、右上のアバターアイコンをクリックします
2. **Settings** を選択します
3. **Applications** に移動します
4. **Generate New Token** でトークンに名前を付けます（例：`kodus_code_review`）
5. 必要な権限を選択します（下記参照）
6. **Generate Token** をクリックします
7. トークンをすぐに**コピー**して安全に保管してください。ページを閉じると再表示できません

---

## Kody に必要な権限

Kody のすべての機能を使うには、トークンに次の権限を**すべて**含める必要があります。

| カテゴリ | レベル | 目的 |
|----------|-------|---------|
| `repository` | **Read & Write** | コード、ブランチ、ファイルへのアクセス、PR コメントの作成、Webhook の管理 |
| `issue` | **Read & Write** | プルリクエストのコメントとリアクションの読み取りと投稿 |
| `organization` | **Read** | トークンのユーザーが所属する組織とそのリポジトリの一覧取得 |
| `user` | **Read** | ユーザーの基本情報の読み取り（認証に必要） |

トークンのユーザーは、Kody がレビューする**各リポジトリの管理者**でもある必要があります。Forgejo では、Webhook の作成とレビューの却下をリポジトリ管理者のみが行えるため、管理者でない場合、Kody は Webhook を自動登録できず、後のレビューで承認を保留したときに自身の承認を取り消すこともできません。

---

## Kody へのトークンの追加

生成したトークンを Kodus に貼り付けます。オンボーディング中（**Connect your Git tool** → **Forgejo** タブ → **Connect via token**）、または後からサイドバーの **Repositories** → **Connect a provider** → **Forgejo** で行います。**Forgejo Instance URL** と **Personal Access Token** を入力し、**Validate and save** をクリックします。

トークンを後から置き換えるには、**Repositories** の **Forgejo** カードで **Update token** をクリックし、新しいトークンを貼り付けて **Update token** をクリックします。

---

## 重要な注意事項

- トークンは作成後に**一度だけ表示**されます。安全に保管してください。
- トークンが漏洩した場合は、すぐに失効させて新しいトークンを作成してください。
- トークンとその権限を定期的に監査し、引き続き必要であることを確認してください。
