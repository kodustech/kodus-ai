## PAT の概要

Kody が自動コードレビューを実行できるようにするには、GitLab で Personal Access Token（PAT）を生成する必要があります。このトークンにより、Kody はリポジトリに安全にアクセスし、制御された方法でコード分析を実行できます。

Kody は、トークンの所有者である GitLab ユーザーとしてレビューを投稿します。個人用アクセストークンを使うと、OAuth で接続した場合と同様に、レビューはあなた自身のアカウントで表示されます。別のボットユーザーとして表示させたい場合は、以下で説明するグループアクセストークンを使用してください。

## PAT（Personal Access Token）の生成

トークンを正しく設定するには、次の手順に従ってください。

1. **GitLab にアクセスし、プロフィール設定に移動します**：

   - [プロフィール設定ページにアクセスするにはここをクリックしてください](https://gitlab.com/-/user_settings/personal_access_tokens)。

2. **`Access Tokens` に移動します**：

   - 左サイドバーを下にスクロールして `Access Tokens` を見つけ、クリックします。

3. **新しいトークンを追加します**：

   - `Add new token` ボタンをクリックします。最近の GitLab バージョンでは、代わりに `Generate token` ドロップダウンを開いて `Legacy token` を選択します。

4. **新しいトークンを次の内容で設定します**：

   - **Token Name**：`kody_code_review` など、識別しやすい名前を付けます。
   - **Expiration Date**：可能であれば、長めの有効期限（できれば 180 日以上）を選択します。
   - 個人用アクセストークンの **Scopes** では `api` のみを選択します。Kody の API 呼び出しと HTTPS 経由のリポジトリアクセスが含まれます。

5. **トークンを確定して保存します**：
   - 権限を設定したら、`Generate token` をクリックします。
   - 生成されたトークンは必ずコピーして安全に保管してください。Kody の設定に必要になります。

## グループアクセストークンの使用

グループアクセストークンを使うと、GitLab がそのトークン用に作成するボットユーザー（トークンと同じ名前）としてレビューが投稿されます。このボットは、グループとそのサブグループ内のすべてのプロジェクトにアクセスできます。

<Note>
  GitLab.com では、グループアクセストークンには Premium または Ultimate のサブスクリプションが必要で、トライアル期間中は利用できません。GitLab Self-Managed と GitLab Dedicated では、どのライセンスでも利用できます。
</Note>

1. **グループのアクセストークン設定を開きます**：

   - GitLab で、リポジトリを含むグループを開き、`Settings` > `Access tokens` に移動します。

2. **新しいトークンを追加します**：

   - `Add new token` ボタンをクリックします。

3. **新しいトークンを次の内容で設定します**：

   - **Token name**：Kody のレビューに表示される名前です。例：`Kody`。
   - **Expiration date**：可能であれば、長めの有効期限（できれば 180 日以上）を選択します。
   - **Role**：`Maintainer`。Kody は各プロジェクトに Webhook を作成するためにこのロールを必要とします。
   - **Scopes** では、API 呼び出し用に `api` を、Kody がグループのリポジトリを HTTPS でクローンするために `read_repository` を選択します。

4. **トークンを確定して保存します**：
   - `Create group access token` をクリックします。
   - トークンをコピーして安全に保管してください。GitLab はトークンを一度しか表示しません。

## Kody へのトークンの追加

トークンを生成したら、Kodus に貼り付けます。

- **オンボーディング中**：**Connect your Git tool** で **Gitlab** タブを選び、**Connect via token** をクリックします。
- **後から**：サイドバーで **Repositories** を開き、**Connect a provider** の下の **Gitlab** をクリックし、**Token** タブに切り替えてトークンを貼り付け、**Validate and save** をクリックします。セルフマネージドの GitLab の場合は、**Self-hosted** をオンにして **Gitlab URL** を入力します。
- **トークンの置き換え**：**Repositories** で **Gitlab** カードの **Update token** をクリックし、新しいトークンを貼り付けて **Update token** をクリックします。Webhook と選択済みのリポジトリは保持されます。
- **OAuth からの切り替え**：OAuth で作成した接続には **Update token** は表示されません。**Reset** をクリックして **Just reset the integration** を選択し、上記の手順でトークンを使って再接続してから、リポジトリを選択します。
