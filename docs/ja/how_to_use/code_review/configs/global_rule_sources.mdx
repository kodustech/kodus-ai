グローバルルールソースを使うと、接続済みの1つ以上のリポジトリを Kodus に指定し、そのルールファイルを**グローバル**の Kody Rules としてインポートできます。置かれているリポジトリにのみ適用される[リポジトリルール](/ja/how_to_use/code_review/configs/repository_rules)とは異なり、グローバルソースからインポートされたルールは、コードレビューで**すべての**リポジトリに適用されます。

チームがアーキテクチャとコーディング標準を専用の「standards」リポジトリで管理していて、各プロジェクトにルールファイルをコピーせずに、それらをあらゆる場所で適用したい場合に使用します。

## 仕組み

- **ソース**として使用する接続済みのリポジトリを選択します。
- Kodus は、各ソースリポジトリのデフォルトブランチで、[リポジトリルール](/ja/how_to_use/code_review/configs/repository_rules)と同じ場所、同じテンプレート（`.kody/rules/`、`rules/**/*.md` など）のルールファイルをスキャンします。
- 各ルールファイルはグローバルルールになり、グローバルの **Kody Rules** ページに、取得元のファイルとともに表示されます。
- 任意のリポジトリのコードレビューでは、これらのグローバルルールが、そのリポジトリ自身のルールとともに適用されます（[継承](/ja/how_to_use/code_review/configs/rules_inheritance)に従います）。
- コーディングエージェント向けに書かれた指示（`CLAUDE.md`、`AGENTS.md`、`.cursor/rules/**`）はインポートされません。過去にそれらからインポートされたグローバルルールは保持されますが、固定されます。[コーディングエージェント向け指示](/ja/how_to_use/code_review/configs/rules_file_detection)を参照してください。

<Info>
**Repositories** ページですでに接続されているリポジトリのみをソースにできます。これにより、インポートされたルールは、後述のプルリクエストのトリガーによって最新の状態に保たれます。
</Info>

## セットアップ

1. サイドバーの **Code review** グループ上部にあるスコープピッカーで **Global** を選択し、**Kody Rules** を開きます。
2. **Configuration** をクリックしてサイドシートを開き、**Global rule sources** を探します。
3. リポジトリピッカーをクリックし、接続済みのリポジトリを1つ以上選択します。
4. **Import selected** をクリックします。

インポートはバックグラウンドで実行されます。完了すると、インポートされたルールがグローバルの Kody Rules の一覧に表示されます。選択したもののまだインポートされていないリポジトリには、**Not imported yet** と表示されます。

## ルールを最新の状態に保つ

- **マージ時:** ソースリポジトリでプルリクエストがマージされると、そのルールファイルが再スキャンされ、グローバルルールが更新されます。変更のないファイルはスキップされます。
- **Resync now:** すべてのソースをオンデマンドで再スキャンします。ソースリポジトリのデフォルトブランチへの直接プッシュの後に使用してください。直接プッシュは自動では検出されません。

## ソースの削除

リストからリポジトリを削除すると、**そのリポジトリからインポートされたグローバルルールが削除され**、コードレビューで適用されなくなります。事前に確認が求められます。他のソースのルールや、手動で作成したルールには影響しません。

## ソースリポジトリはレビューされない

グローバルルールのソースとして使用されるリポジトリは、コードベースではなく、設定用のリポジトリとして扱われます。Kodus は、そのリポジトリで開かれたプルリクエストの**コードレビューをスキップ**します。これは、[集中設定](/ja/how_to_use/code_review/configs/centralized_config)リポジトリの場合と同じです。

## プランによる利用可否

| プラン | アクセス |
|------|--------|
| **Free**、有効なライセンスキーのないセルフホスト、またはキャンセル済みか期限切れのプラン | 利用できません。 |
| **Trial** | すべてのソースリポジトリを合わせて**最大5件のグローバルルール**。最初に見つかった5件のルールのみがインポートされ、上限に達すると、いくつか削除するかアップグレードするまで、それ以上はインポートされません。 |
| **有料**（クラウド）および**ライセンス済みのセルフホスト** | 無制限。 |

Trial プランでは、5件のうちいくつ使用しているかがカウンターに表示され、インポートの前に、確認ダイアログでさらにいくつ追加されるかが示されます。
