---
title: "PR サマリー"
description: "プルリクエストの説明文を Kody に書かせ、既存の説明文や新しいコミットをどう扱うかを選択します。"
---

Kody は、プルリクエストの変更内容をまとめた説明文を書くことができます。**Code review → What Kody writes** を開き、**PR summary** セクションで設定します。設定は Global、Repository、Directory の各スコープで行えます。

ページのプレビュー（**Show preview** / **Hide preview**）では、サンプルのプルリクエストにサマリーがどのように表示されるかを確認できます。

## サマリーを書く

**Write a summary on every pull request** をオンにします。デフォルトではオンです。オフにすると Kody はサマリーを書かず、以下のオプションは無効になります。

Kody は、[General](/ja/how_to_use/code_review/configs/general) の **Kody Language** で設定した言語でサマリーを書きます。

## PR にすでに説明がある場合

作成者が書いた説明文を Kody がどう扱うかを選択します。

- **Replace**（デフォルト）— 新しい説明文を最初から書き直します。
- **Concatenate** — 既存の説明文の末尾にサマリーを追加します。
- **Complement** — 既存の説明文を読み、新しい内容や関連する内容だけをハイライトした説明文を書きます。

Replace と Complement では、`Closes #12`、`AB#12`、トラッカーのリンクなど、タスクにリンクしている古い説明文の行が、新しい説明文の先頭に残ります。Concatenate では説明文全体がそのまま残ります。

Kody のテキストは 2 つの非表示コメントマーカーの間に置かれるため、再実行しても新しいブロックが積み重なることはなく、そのブロックが更新されます。

## 新しいコミットが届いたとき

プルリクエストのオープン後にコミットがプッシュされたとき、Kody のサマリーをどう扱うかを選択します。

- **Do nothing**（デフォルト）— サマリーはそのまま残ります。
- **Concatenate new summary** — 新しいコミットのサマリーが、Kody の既存のブロックに追加されます。
- **Replace Kody's summary** — Kody のブロックが、プルリクエスト全体のサマリーに置き換えられます。

変更されるのは Kody のブロックだけです。作成者が書いたテキストはそのまま残ります。

## サマリーの指示

任意の **Summary instructions** フィールドで、サマリーで重視すべきことや省くべきことを Kody に伝えます。**Examples** チップを使うと、用意された指示を追加できます。

- 「セキュリティの変更とパフォーマンスへの影響に焦点を当てる」
- 「変更されたパブリック API をハイライトしながら簡潔にまとめる」

指示では、レビューで見つかった内容を参照することもできます。たとえば、最も高い重大度に言及させることができます。指示ではリポジトリ内のファイルも参照できます。[External References](/ja/how_to_use/code_review/configs/custom_prompts#外部参照) を参照してください。

**Try on a real PR** は、現在の設定を自分のプルリクエストの 1 つで実行します。サマリーがオンで、プルリクエストを読み取れる場合に利用できます。プレビューはレビューの前に実行されるため、レビューの指摘は表示されません。

<Note>
  モデルのコンテキストに数回のパスでは収まらないほど大きなプルリクエストでは、Kody はサマリーをスキップします。
</Note>

プロバイダーの上限を超える説明文は、切り詰めの注記付きで切り詰められます。上限は Azure DevOps が 4,000 文字、Bitbucket が 32,768 文字、GitHub が 65,536 文字です。Azure DevOps では、既存の説明文の分を確保するため、Kody はサマリーを短くします。

## YAML

```yaml
summary:
    generatePRSummary: true
    behaviourForExistingDescription: 'replace' # replace | concatenate | complement
    behaviourForNewCommits: 'none' # none | concatenate | replace
    customInstructions: ''
```

このファイルは、**Prefer kodus-config.yml settings** がオンの場合にのみ読み込まれます。[General](/ja/how_to_use/code_review/configs/general#設定の優先度) を参照してください。
