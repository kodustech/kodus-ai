## 概要

ディレクトリスコープは、リポジトリの1つ以上のフォルダーに、独自のコードレビュー設定を適用します。領域ごとに基準や担当者が異なるモノレポで使用します。

Kody は、プルリクエストごとに1つの設定を使用します: **Directory** → **Repository** → **Global**。

<Note>
  設定がレベル間でどのように引き継がれるかについては、<a href="/ja/how_to_use/code_review/configs/inheritance_overrides">設定の継承とオーバーライド</a>を参照してください。
</Note>

## 仕組み

- ディレクトリスコープには、1つまたは複数のフォルダーを含められます。そのスコープのすべてのフォルダーが同じ設定を共有します。
- フォルダーは、`api/src/services` のように、任意の深さに置けます。
- 必要な数だけディレクトリスコープを追加できます。
- 1つのフォルダーが属せるディレクトリスコープは1つだけです。すでにスコープがあるフォルダーの内側のフォルダーは選択できません。

### 選択ルール

Kody は、プルリクエストがどのディレクトリスコープに触れているかを確認します。

- **1つのスコープに触れている場合:** そのスコープの設定を使用します。どのスコープにも属さないファイルがあっても、これは変わりません。
- **どのスコープにも触れていない場合:** リポジトリの設定を使用します。リポジトリに設定がなければ Global を使用します。
- **2つ以上のスコープに触れている場合:** リポジトリの設定を使用します。リポジトリに設定がなければ Global を使用します。

<Note>
  Kody は、レビューを予測しやすくするために、プルリクエストごとに1つの設定を使用します。設定を混在させると競合が発生します。
</Note>

## セットアップ

1. サイドバーの **Code review** グループ上部にあるスコープピッカーで、リポジトリを選択します。
2. もう一度ピッカーを開き、下部の **Add directory scope** を選択します。
3. **Add directory scope** ダイアログで、**Select directories** の下にあるフォルダーにチェックを入れます。選択したフォルダーは **Selected directories** に一覧表示されます。**Add directory scope** をクリックします。
4. 新しいスコープを選択します。ピッカーでは、そのリポジトリの下にインデントされて表示されます。任意のページで設定を変更し、**Save settings** をクリックします。

後でフォルダーを変更するには、スコープピッカーの横にある **⋯** メニューを開き、**Edit directories** を選択してから、**Save directories** をクリックします。**Delete configuration** はスコープを削除します。それらのフォルダーには、再びリポジトリの設定が適用されます。

## kodus-config.yml とディレクトリスコープ

- Kody は、リポジトリのデフォルトブランチのルートにある `kodus-config.yml` のみを読み取ります。フォルダー内に置かれた `kodus-config.yml` は読み取りません。
- ルートのファイルが読み取られるのは、**リポジトリ**スコープで **Prefer kodus-config.yml settings** がオンの場合のみです。このスイッチはディレクトリスコープにも表示されますが、レビューには影響しません。そこでオンにしても、Kody がそのディレクトリのファイルを読み取るようにはならず、オフにしても、リポジトリのファイルの適用は止まりません。
- ディレクトリスコープで上書きした設定は、リポジトリのファイル内の同じ設定よりも優先されます。
- ディレクトリスコープの設定をファイルで管理するには、[集中設定](/ja/how_to_use/code_review/configs/centralized_config)リポジトリを使用します。スコープのフォルダー内にある `kodus-config.yml` が、ディレクトリスコープの設定に同期されます。

ファイル自体については[一般設定](/ja/how_to_use/code_review/configs/general#設定の優先度)、優先順位については[設定の継承とオーバーライド](/ja/how_to_use/code_review/configs/inheritance_overrides#kodus-config-yml)を参照してください。

## ディレクトリスコープの Kody Rules

プルリクエストは、上記の設定と同じ選択に従って、ディレクトリスコープの Kody Rules でレビューされます。単一のスコープが選択されない場合は、そのリポジトリのすべてのディレクトリスコープのルールが適用されます。[ルール継承](/ja/how_to_use/code_review/configs/rules_inheritance)を参照してください。
