---
title: "カスタムメッセージ"
description: "レビューの開始時、終了時、失敗時に Kody が投稿するコメントと、プルリクエスト上でのコメントの表示方法を編集します。"
---

**Code review → What Kody writes** を開きます。メッセージは **Comments during the review** セクションにあり、メッセージごとに **Review starts**、**Review ends**、**Review fails** のタブがあります。各タブには **Message** ボックスと **Reset to…** メニューがあります。このメニューには、リポジトリとディレクトリのスコープでは **Inherited message**、Global では **Default message** が表示されます。

メッセージは Global、Repository、Directory のスコープで設定できます。

## メッセージの表示のされ方

Kody は、レビューの開始時に開始メッセージを投稿します。レビューが終了すると、同じコメントを編集して終了メッセージにします。サジェストは、その間にレビューコメントとして投稿されます。

- **開始と終了の両方を投稿する場合:** コメントは1つで、最初は開始メッセージが表示され、レビューが完了すると終了メッセージが表示されます。
- **今回の実行で開始メッセージを投稿しなかった場合:** 終了メッセージは、レビュー後に新しいコメントとして投稿されます。
- **終了メッセージを Never に設定した場合:** 開始コメントは、レビューが失敗した場合も含め、そのまま残ります。その場合、失敗を示すのは 😕 のリアクションだけです。
- **レビューが失敗した場合:** Kody は、終了メッセージの代わりにデフォルトのエラーコメントを投稿し、その下に **Review fails** のテキストを表示します。

GitHub では、新しいレビューが始まると、Kody は前回のレビューのコメントを折りたたみます。

## Post this message

**Review starts** と **Review ends** では、**Post this message** セレクトで、そのメッセージを投稿するタイミングを設定します。設定はメッセージごとに個別です。

- **On every push**（`every_push`、デフォルト）— レビューが実行されるたびに投稿されます。プルリクエストが開かれたとき、およびレビューをトリガーする各プッシュの後です。
- **Only when the PR opens**（`only_when_opened`）— 最初のレビュー実行時に1回だけ投稿されます。
- **Never**（`off`）— 投稿されません。テキストは保持され、**Message** ボックスと **Add context** は無効になります。Kody は引き続きレビューを実行し、サジェストを投稿します。

メッセージが投稿されるのは、レビューが実行されるときだけです。レビューの頻度が **Manual** で **Automated code review** がオンの場合、最初のレビューはプルリクエストが開かれたときに実行されます。以降のプッシュでは、誰かが `@kody start-review` とコメントするまで何も投稿されません。

## Add context

**Message** の横にある **Add context** メニューは、Kody がプルリクエストの実際のデータに置き換えるトークンを挿入します。

| メニュー項目 | トークン | 追加される内容 |
| --- | --- | --- |
| **Changed files** | `@changedFiles` | 変更されたファイルの折りたたみ可能な表。ステータス、追加行、削除行を含みます。 |
| **Changes summary** | `@changeSummary` | ファイル数、追加行数、削除行数、変更数の合計。 |
| **Review options** | `@reviewOptions` | どのレビューカテゴリがオンまたはオフか。 |
| **Review cadence** | `@reviewCadence` | フォローアップレビューの動作（自動、制限付きの自動一時停止、または手動）。 |
| **Review scope** | `@reviewScope` | このレビューに使用されたレベル（グローバル、リポジトリ、またはディレクトリ）。 |
| **Agent Prompt** | `@agentPrompt` | レビューのすべてのサジェストを、コーディングエージェントに貼り付けられる1つのプロンプトにまとめたもの。折りたたみ可能な **Open Agent Prompt** ブロックに表示されます。 |

`@agentPrompt` は、その内容がレビュー後にしか存在しないため、**Review ends** でのみ利用できます。

## Review fails メッセージ

**Review fails** タブにテキストを書くと、レビューが失敗したときに Kody が投稿するコメントの下にそのテキストが追加されます。たとえば、AI プロバイダーが設定されていない場合や、プロバイダーがリクエストを拒否した場合です。社内の担当者や runbook への案内に使用してください。

このメッセージにスイッチはありません。テキスト自体がスイッチです。空（デフォルト）の場合は、Kody の標準のエラーコメントがそのまま使われます。

## コメントの表示

**Comment visibility** セクションには2つの設定があります。

| 設定 | デフォルト | 内容 |
| --- | --- | --- |
| **Post as hidden comment**（`hideComments`） | オフ | **Review starts** と **Review ends** のメッセージを含むコメントが、古いものとして折りたたまれた状態で投稿され、プルリクエストの会話が短く保たれます。インラインのサジェストと PR レベルのコメントは折りたたまれません。GitHub のみ。GitHub が接続されていない場合、このスイッチは表示されません。 |
| **Add a copyable prompt to each suggestion**（`suggestionCopyPrompt`） | オン | 各サジェストに、開発者が AI アシスタントに貼り付けて修正を適用できるプロンプトが付きます。Bitbucket では、プロンプトは同じスレッドへの返信として投稿されます。この設定がオフの場合、Bitbucket のコメントには修正が表示されません。 |

## YAML

メッセージは、[集中設定](/ja/how_to_use/code_review/configs/centralized_config)リポジトリの `kodus-config.yml` ファイルに `customMessages` として保存されます。レビュー対象のリポジトリのルートにある `kodus-config.yml` では変更できません。アプリを使用してください。

```yaml
customMessages:
    startReviewMessage:
        status: 'every_push' # every_push | only_when_opened | off
        content: |
            Review started. @changedFiles
    endReviewMessage:
        status: 'every_push' # every_push | only_when_opened | off
        content: |
            Review finished. @changeSummary
    errorReviewMessage:
        status: 'active' # off | active; a review reads only content
        content: |
            Reviews failing? Ping #platform-eng.
    globalSettings:
        hideComments: false
        suggestionCopyPrompt: true
```
