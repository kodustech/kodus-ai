## レビューで適用されるルール

すべてのレビューでは、**Global → Repository → Directory** の 3 つのスコープの有効なルールが適用されます。

- **Global** ルールは、すべてのリポジトリに適用されます。
- **Repository** ルールは、そのリポジトリのすべてのプルリクエストに適用されます。
- **Directory** ルールは、そのディレクトリスコープの設定でプルリクエストがレビューされるときに適用されます。これは、プルリクエストがちょうど 1 つのディレクトリスコープに触れる場合に起こります。リポジトリの他のディレクトリスコープのルールは適用されません。
- ディレクトリスコープに触れない、または 2 つ以上に触れるプルリクエストは、リポジトリの設定でレビューされます。その場合は、リポジトリの **すべての** ディレクトリスコープのルールも、プルリクエスト内のすべてのファイルに適用されます。

親スコープで作成されたルールは、その下のスコープに常に継承されます。2 つのスコープに同一の指示で存在するルールは、1 回だけ実行されます。

<Warning>
  **Kody Rules** ページで無効として表示されていても、レビューには上位スコープの有効なルールが適用されます。適用を止めるには作成元のスコープで一時停止するか、**Path** が使える場合は対象を絞り込んでください。
</Warning>

## アプリ内

**Kody Rules** ページでは、上位のスコープから継承されたルールが、そのスコープ自身のルールの隣に、継承元のスコープを示すマーク付きで一覧表示されます。そこでは読み取り専用です。ルールを開いて **View** を使うか、ルールが作成されたスコープに移動して編集してください。**Filters → View** では、**Inherited from Global**、**Inherited from Repository**、**Disabled Rules** の表示と非表示を切り替えられます。

### Inheritable

任意のスコープのルールで、ルールダイアログの **Advanced settings** を開き、**Inheritable**（デフォルトでオン）をオフにします。

- そのルールは、下のスコープでは継承されたものとして一覧表示されなくなります。
- レビューでは、上記のとおり、すべてのスコープで引き続き適用されます。

### Override and disable for this scope

リポジトリまたはディレクトリスコープで、継承されたルールを開き（**View**）、**Override and disable for this scope** をオンにします。

- そのスコープでルールは **Disabled** と表示され、**Filters → View** で **Disabled Rules** のチェックを外すと非表示になります。
- 下のスコープでは無効として表示されず、それぞれの設定が維持されます。
- レビューでは、引き続きそのルールが適用されます。

ルールの適用を止めるには、ルールが作成されたスコープで一時停止または削除してください。

## 集中設定

[集中設定](/ja/how_to_use/code_review/configs/centralized_config) リポジトリ内のルールファイルにも、同じ設定を記述できます。

```yaml
inheritance:
  inheritable: true
  exclude: []   # repository or directory IDs
  include: []   # repository or directory IDs
```

`inheritable` と `exclude` は、上記のとおりに動作します。`include` にはアプリ内のコントロールがなく、レビューへの影響もありません。`include` リストが空でないルールは、継承一覧に表示されません。
