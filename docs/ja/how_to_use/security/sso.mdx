## 概要

シングルサインオン（SSO）を使用すると、単一のアイデンティティプロバイダーを通じて Kodus へのアクセスを管理し、認証を効率化してセキュリティを強化できます。

## はじめに

<Steps>
    <Step title="SSO 設定にアクセス">
        サイドバーで **Organization → SSO**
        （[app.kodus.io/organization/sso](https://app.kodus.io/organization/sso)）を開きます。
        SSO は Enterprise プラン（およびトライアル中）で利用できます。その他のプランでは、ページにロックされたプレビューが表示されます。
    </Step>

    <Step title="IdP の設定を入力">
        **SAML SSO Configuration** で、IdP の設定（**IDP Issuer**、**SSO URL**、**X.509 Certificate**）を入力します。これらは手動で入力するか、IdP の **Metadata URL (optional)**（その後 **Fetch**）またはメタデータ XML ファイル（**Upload Metadata XML File**）を提供することで入力できます。

        <Info>
            これらの値は通常、IdP のドキュメントまたは管理コンソールで確認できます。
        </Info>
    </Step>

    <Step title="IdP で Kodus を SP として設定">
        エンティティ ID（**Service Provider Entity ID**、デフォルトは `kodus-orchestrator`）と組織の **Callback URL**（どちらも SSO 設定ページに表示されます）を提供することで、IdP で Kodus を SP として設定します。

        名前 ID フォーマットがメールに設定されていることを確認してください。

        <Warning>
            IdP の SP 設定で署名証明書を無効にしてください。
        </Warning>
    </Step>

    <Step title="ドメインを検証">
        **Allowed Domains** にメールドメインを追加し、それぞれで **Verify** をクリックします。**Verify Enterprise Domain** で、そのドメインのメールアドレスを入力すると検証リンクが届きます（セルフホストインスタンスでは即座に検証されます）。SSO を有効にするには、各ドメインが **Verified** と表示されている必要があります。
    </Step>

    <Step title="SSO をテストして有効化">
        **Test connection** をクリックし、IdP でのログインを完了します。テストが成功したら、**Enable SAML SSO** をオンにして **Save settings** をクリックします。IdP に関連付けられたメールドメインでログインしようとすると、**Continue with SSO** が表示されます。
    </Step>

</Steps>

## オプション設定

### 属性マッピング

IdP から Kodus ユーザーへの以下の属性をマッピングして、ユーザーエクスペリエンスを向上させることができます。

-   名（First Name）、`firstName` にマッピング
-   姓（Last Name）、`lastName` にマッピング
