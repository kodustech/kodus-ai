## どのモデルがコードをレビューするのか

固定のモデルはありません。**Kodus はすべてのプランでデフォルトが BYOK（Bring Your Own Key）** です。つまり、モデルと、その背後にあるプロバイダーとの関係は、通常は当社ではなくお客様のものです。

<Info>
  このページでは、選択はお客様次第であるため、モデル名を固定していません。接続できるプロバイダーと、ルーティングがタスクごとにモデルを選ぶ方法については、[BYOK](/ja/how_to_use/byok) を参照してください。
</Info>

経路は 4 つあり、どれに当てはまるかでデータに関する契約の相手が変わります。

| 経路 | プロバイダーアカウントの所有者 | モデル |
| --- | --- | --- |
| **BYOK**（デフォルト、全プラン） | **お客様。** お客様のキー、お客様の請求、お客様とプロバイダーの契約。 | 設定したもの。フロンティアモデル、コード特化モデル、セルフホストまたは互換エンドポイントなど。 |
| **LLM 環境変数を使うセルフホスト** | **お客様。** インスタンスの所有者が、サーバーの環境でプロバイダーとキーを設定します。 | 環境で指定されたモデル。**AI providers** ページに、キーなしで表示されます。 |
| **トライアル、キー未接続** | Kodus（トライアルに含まれるレビューの分）。 | トライアル用に Kodus が提供するモデル。 |
| **Enterprise（Kodus 管理のキー）** | Kodus（お客様の Enterprise 契約に基づく）。 | Kodus が選定したモデル。 |

### サポートするプロバイダーのクラス

BYOK では、Kodus を次のいずれにも向けられます。

- **ファーストパーティのプロバイダー**：OpenAI、Anthropic、Google（Gemini）。各社の API を使用します。
- **クラウドホスト型のゲートウェイ**：Google Vertex AI、Amazon Bedrock、Azure OpenAI。既存のクラウドアカウントで課金され、そのクラウドの IAM、リージョン、データレジデンシーの条件が適用されます。
- **アグリゲーターとモデルホスト**：OpenRouter、Novita、Moonshot、Z.ai。
- **OpenAI 互換または Anthropic 互換の任意のエンドポイント**：自社でホストするモデルを含みます。**AI providers** ページには、公開アドレスに解決される `https://` の URL が必要です。

現時点の完全な一覧と設定手順は [BYOK](/ja/how_to_use/byok) にあります。

<Note>
  **BYOK のレビューが、黙って Kodus 管理のモデルにフォールバックすることはありません。** 設定したモデルが失敗し、かつ自前のフォールバックを設定していない場合、レビューは失敗します。お客様のコード（と請求）を当社のインフラに迂回させることはしません。
</Note>

## Kodus がコードに対して行うこと

- コードはそのレビューを生成するためだけに、必要な部分のみ（差分と、レビューに必要なコンテキスト）がモデルプロバイダーへ送られます。
- Kodus が学習のために保持するものはありません。
- レビュー結果（サジェスト、メタデータ）は、製品が履歴を表示し、サジェストの重複を避け、メトリクスを算出できるように保存されます。

## プロバイダーがコードに対して行うこと

ここは注意して読む価値があります。**BYOK では、これは Kodus との契約ではなく、お客様とプロバイダーとの契約に支配されるからです。**

- 商用 API のほとんどのティアは、デフォルトでは API トラフィックを学習に使わないと明示しています。実際に契約しているプランで確認してください。無料やコンシューマー向けのティアは、有料の API ティアと条件が異なることがよくあります。
- 保持期間（たとえば不正利用監視のためのもの）はプロバイダーが定めるもので、Kodus ではありません。
- 契約上の保証（ゼロ保持、特定のリージョン、署名済みの DPA）が必要な場合は、プロバイダーから直接取得してください。あるいはクラウドホスト型のゲートウェイやセルフホストのエンドポイントを使えば、それらの条件は既存の契約にすでに含まれています。

<Warning>
  プロバイダーを選ぶのはお客様であるため、**Kodus がプロバイダーに代わってデータの取り扱いを約束することはできません。** コンプライアンス要件が特定の保証に依存する場合は、Kodus を向ける前にプロバイダーに確認してください。
</Warning>

## Kodus 側のセキュリティ対策

- **キーの取り扱い**：プロバイダーのキーと Git トークンは暗号化して保存され、プロバイダーのキーが平文で表示し直されることはありません。
- **アクセス制御**：ワークスペースへのロールベースアクセス。[ワークスペースロール](/ja/how_to_use/workspace_roles) を参照してください。
- **セルフホスト**：コードを一切ネットワーク外に出したくない場合は、スタック全体を自社のインフラで運用できます。[Kodus のデプロイ](/ja/how_to_deploy/deploy_kodus/generic_vm) を参照してください。

## セルフホストのテレメトリ

Kodus をセルフホストで運用している場合、各インスタンスは 1 日 1 回、集計されたカウンターとランタイムのメタデータを含む匿名のハートビートを `telemetry.kodus.io` に送信します。コード、識別情報、ユーザーを特定しうるものは一切含まれません。送信内容は `pnpm run telemetry:preview` で確認でき、`KODUS_TELEMETRY_DISABLED=true` で無効化できます。スキーマ全体、保持ポリシー、ソースコードへのリンクは [匿名テレメトリ](/ja/how_to_deploy/deploy_kodus/telemetry) に記載しています。
