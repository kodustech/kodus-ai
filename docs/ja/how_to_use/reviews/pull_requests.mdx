---
title: "プルリクエスト"
description: "すべての Kody のレビューを追跡し、結果で絞り込み、任意のプルリクエストの指摘を開きます。"
---

**Reviews → Pull requests** には、Kody が実行されたプルリクエストと、各レビューの結果が一覧表示されます。すべてのプランで、オーナー、Repo Admin、Contributor が利用でき、レビューの実行中は更新されます。隣の **CLI** タブには、[CLI レビュー](/ja/how_to_use/reviews/cli_reviews) が一覧表示されます。

## 一覧

各行が 1 つのプルリクエストです。複数回レビューされた PR も 1 行になります。

| 列 | 表示される内容 |
| --- | --- |
| **Pull request** | 番号、タイトル、リポジトリ、ソースブランチ、オープンされた時期、作成者。タイトルをクリックするとレビュー画面が開き、矢印アイコンをクリックすると Git プロバイダー上の PR が開きます |
| **Reviews** | Kody が PR をレビューした回数と、最近のレビューの時期 |
| **Suggestions** | 2 つの件数：PR に投稿された数（チェックアイコン）と、レビュー設定によって保留された数（フィルターアイコン） |
| **Status** | 最新のレビュー：**Success**、**Review failed**、**In Progress**、**Skipped**、**Partial Error**、**Pending**。PR がマージされると、**Merged** に置き換わります |

行をクリックすると展開されます。PR の各レビューが、ステータス、所要時間、レビューしたコミット、実行されたステージのタイムラインとともに一覧表示されます。**Open full review** でレビュー画面が開きます。

モードが記録されている場合、各レビューに **Balanced** または **Heavy** のバッジが表示されます。PR の行には、その PR をレビューした最新の実行のモードが表示されます。スペシャリストのデータがある Heavy レビューでは、タイムラインの **Specialist Agents** を展開すると、各エージェントの所要時間、ツール呼び出し、検出結果、記録された失敗理由を確認できます。**Findings** は、検証を通過した検出結果を重複の除去前に数えたものです。 このタイムラインの詳細は、セルフホスト版 2.2.11 より後に追加されました。

レビューは成功したものの、本来より少ない情報で動作した場合（たとえば、リポジトリのチェックアウトがなかった、一部の Kody Rules が評価されなかったなど）、展開されたレビューに、失われたものが一覧表示されます。これらの通知はここにのみ表示され、プルリクエストには表示されません。

## ショートカット

右上の 3 つのカウンターは、クリックすると一覧を絞り込みます。

- **Reviewed today**：今日（UTC）Kody がレビューした PR の数（重複なし）。**Status** フィルターを追加すると、たとえば失敗したレビューに絞り込めます。
- **Kody skipped**：Kody が起動されたものの、設定（ライセンスなし、BYOK、manual または一時停止中の cadence、無視されたユーザー）が原因でスキップされ、レビューされなかった PR。1 日ごとの数ではなく現在のバックログで、専用の一覧が開きます。
- **Needs attention**：Kody がサジェストを投稿したが、作成者がまだ適用していないオープンな PR。次の実装チェックまで反映が遅れることがあります。

## フィルター

**タイトル**、**番号**、**作成者** で検索し、次の項目で絞り込みます。

- **Repository**
- **Authors**：デフォルトでは、レビュー設定で除外されている作成者の PR は非表示になります。**All authors** はすべての人を表示し、**Excluded authors** は除外された人だけを表示します
- **Suggestions**：**Has suggestions** または **No suggestions**
- **Date**：レビュー日の範囲。プリセット（**Last week**、**Last 15 days**、**Last month**、**Last 3 months**）またはカスタム日付から選択します
- **PR state**：**Open** または **Closed**。プルリクエスト自体の状態です
- **Status**：レビューの結果（**Success**、**Error**、**Partial error**、**Skipped**、**In progress**、**Pending**）

アクティブなフィルターは、削除できるチップとして表示され、**Clear all** でリセットできます。フィルターは URL に保持されるため、絞り込んだ表示を共有できます。

## レビュー画面

PR のタイトルをクリックすると、その **Code Review** 画面が開きます。PR のすべてのレビューの指摘が、差分の上に表示されます。

- **左：** 変更されたファイル。フォルダーツリー、または **Group by role** でロールごとにグループ化して表示します。指摘のあるファイルにはマークが付き、ファイルを閲覧済みにマークできます。
- **中央：** **Review** タブと **Commits** タブのある PR ヘッダー、潜在的なバグとフラグの数および閲覧済みのファイル数を示すバー、そして unified または split ビューの差分。Kody の指摘は、対象の行の下にインラインで表示されます。
- **右：** 重大度（**Critical**、**High**、**Medium**、**Low**）ごとにグループ化された指摘。クリックすると、その指摘にジャンプします。

Critical と High の指摘には **Potential Bug**、Medium には **Suggestion**、Low には **Nit** のラベルが付きます。指摘には、Kody の説明、**Suggested fix** または **Recommendation**、そして **Copy fix**、**Copy AI prompt**（修正を適用するためにコーディングエージェントに貼り付けられるプロンプト）、**Open on provider** のボタンが表示されます。

レビューで指摘が生成されなかった場合、画面にその理由が表示されます。たとえば **Nothing to flag.**、**Review failed — nothing to show.**、**Review skipped.** です。

ファイル単位ではなく、プルリクエスト全体に対するサジェストは、この画面には表示されません。

ショートカット：**J** と **K** で次のファイルと前のファイルに移動し、**B** でファイルツリーの表示と非表示を切り替え、**Esc** で選択したファイルを解除します。

[サジェスト](/ja/how_to_use/cockpit/suggestions) から **Open in PR review** でサジェストを開くと、画面がその指摘までスクロールします。
