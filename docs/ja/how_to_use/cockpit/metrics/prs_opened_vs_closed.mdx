## オープン vs クローズの PR 数とは

このチャートは、同じ週に**オープンされた** PR 数と**クローズされた** PR 数を並べて表示します。
チームが自分たちでオープンした作業に追いつけているのか、それともプルリクエストがクローズより
速く積み上がっているのかが分かります。

## 計算方法

選択した日付範囲の各週について：

- **Opened**：その週にオープンされたプルリクエスト（現在のステータスは問いません）。リポジトリが
  接続される前にオープンされ、接続時にインポートされた PR に含まれなかった PR については、
  Kodus が最初に記録した日付になります。
- **Closed**：その週にクローズされたプルリクエスト（マージされたもの、マージされずにクローズされたものを含む）。

両者は独立に数えられます。ある週にオープンされ、3 週間後にクローズされた PR は、1 週目の
**Opened** バーと 4 週目の **Closed** バーに数えられます。これによってバックログが可視化されます。

## 読み方

- **毎週 Closed が Opened に近い**：定常状態。チームはオープンした分をクローズできています。
- **Opened が数週間にわたって Closed を上回る**：バックログが増えています。
- **Closed が Opened を大きく上回る**：多くの場合、放置されていた PR をまとめてクローズした結果です。
  生産性の向上と読む前に確認してください。
- **両方が同時に落ち込む**：通常は、休暇、フリーズ、またはインシデントの影響です。

<Tip>
  [PR サイクルタイム](/ja/how_to_use/cockpit/metrics/lead_time_for_changes)と併せて見てください。
  ここでの差の拡大とサイクルタイムの上昇が重なるときは、レビューがボトルネックであることを示しています。
</Tip>

## 表示場所

Cockpit → **Productivity** タブの詳細チャートセクション。週は月曜日に始まり、チャートの下の **Opened** または **Closed** の名前をクリックすると、その系列を非表示にできます。

<Note>
  このチャートは組織全体で非表示にできます。表示されない場合は
  **Organization → Cockpit visibility** を確認してください。[Cockpit の設定](/ja/how_to_use/cockpit/configuration)を参照してください。
</Note>
