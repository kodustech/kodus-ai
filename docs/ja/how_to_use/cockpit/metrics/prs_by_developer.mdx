## 開発者別 PR とは

開発者別 PR は、各チームメンバーが**クローズした**プルリクエストの数を、週ごとにグループ化して数えます。完了した作業に焦点を当てており、アウトプットと、それがチーム全体にどのように分散されているかを確認できます。

Cockpit では、**Productivity** タブの **PRs Merged By Developer** チャートです。週ごとに 1 本の積み上げバーで、開発者ごとに 1 色が割り当てられます。バーにカーソルを合わせると、各開発者の件数が表示されます。

## 計算方法

```
Weekly PRs per Developer = COUNT(closed PRs) per developer per week
```

- PR は、**クローズされた**週に数えられます。マージされたものと、マージされずにクローズされたものの両方が対象です。チャートの名前にかかわらず、Cockpit は両者を区別しません。
- 開発者とは、Git プロバイダー上の PR の作成者のユーザー名です。
- 週は月曜日に始まります。
- オープン中の PR、ドラフトの PR、クローズ日のない PR、作成者のいない PR は数えられません。

## 開発者アクティビティと開発者別 PR の違い

| | 開発者アクティビティ | 開発者別 PR |
| --- | --- | --- |
| **数えるもの** | オープンされた PR | クローズされた PR |
| **日付の基準** | オープン日 | クローズ日 |
| **ステータスフィルター** | なし | クローズ済みの PR のみ |
| **表示形式** | 週ごとに 1 列のテーブル | 週ごとの積み上げバー |

## 留意すべき背景

- PR の数が少なくても大きな PR を出している開発者も、同じように生産的である可能性があります。[PR サイズ](/ja/how_to_use/cockpit/metrics/pr_size)と併せてチャートを読んでください。
- アウトプットは、作業の種類、役割、プロジェクトのフェーズによって異なります。
- レビューしたり、ペアで取り組んだりした作業は、ここには表示されません。
