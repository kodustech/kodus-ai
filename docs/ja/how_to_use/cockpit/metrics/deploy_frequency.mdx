## デプロイ頻度とは

デプロイ頻度は、チームが週あたりにクローズするプルリクエスト数の平均です。Cockpit は CI/CD からデプロイを読み取らないため、コードが本番環境に届く頻度の代わりに、クローズされたプルリクエストを使用します。

Cockpit では、**Productivity** タブの **Deploy Frequency** カードです。

## 計算方法

```
Deploy Frequency = (PRs closed in the range) ÷ (weeks in the range)
```

- 範囲は Cockpit 上部で選択した日付範囲です。週単位の長さは切り上げられ、最小は 1 週間です。
- クローズされたすべての PR が、ベースブランチにかかわらず数えられます。マージされずにクローズされた PR も、マージされた PR と同じように数えられます。

たとえば、4 週間の範囲で 12 件の PR がクローズされた場合、デプロイ頻度は週 3 件です。

チームのデプロイのリズムが PR のクローズのリズムと異なる場合（たとえば、リリーストレインや、フィーチャーブランチからのデプロイ）、この数値はデプロイではなく、PR のスループットとして読んでください。

## カードの読み方

カードには、週あたりの平均、レベルのバッジ、同じ長さの前の期間の値と変化率が表示されます。フッターには、選択した範囲にかかわらず「Last 2 weeks was …」と表示されますが、その数値は前の期間のものです。バッジにカーソルを合わせると、レベルを確認できます。

| 週あたりのクローズ済み PR | レベル |
| --- | --- |
| 5 超 | Elite |
| 2 から 5 | High |
| 1 から 2 | Fair |
| 1 未満 | Need focus |

## 改善方法

- 大きな変更を、より小さな PR に分割する
- 自動デプロイのための CI/CD パイプラインを実装する
- 機能を公開せずにデプロイするためにフィーチャーフラグを使用する
- 監視とクイックロールバックを設定する
