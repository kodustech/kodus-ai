## 実装率とは

実装率は、Kody が送信した提案のうち、チームが実装したものの割合です。Kody のフィードバックのどれだけがコードの変更につながっているかを示します。

Cockpit では、**Kodus Review** タブの **Implementation rate** と **Suggestions sent** のカード、およびその下のチャートにあります。[Kodus Review](/ja/how_to_use/cockpit/kodus_review)を参照してください。

## 計算方法

```
Implementation Rate = (Implemented Suggestions) ÷ (Suggestions Sent) × 100
```

- PR コメントとして届けられた提案のみが数えられます。
- 提案は、その PR がクローズされた時点でのステータスが **Implemented** または **Partially implemented** の場合に、実装済みとして数えられます。
- 選択した日付範囲内にクローズされた PR の提案が数えられ、PR がクローズされた週ごとにグループ化されます。
- 実装チェックで判断できなかった提案は、無視されたものとして数えられず、実装率から除外されます。

たとえば、Kody が 20 件の提案を送り、16 件が実装された場合、実装率は 80% です。

## 改善方法

- チームの基準に合わせた Kody Rules を設定する
- **Kody Rules — health** テーブルで、ノイズが多い、または無視されているルールを確認し、書き換えるかスコープを絞る
- **Implementation rate by category** で、最も無視されているテーマを確認する
- **Negative feedback** の 👎 リアクションを読んで、チームがどこで反対しているかを確認する（リアクションはフィードバックとして記録されますが、それだけでは以降のレビューは変わりません。[提案へのフィードバック](/ja/how_to_use/code_review/learning/kody_learning)を参照）
