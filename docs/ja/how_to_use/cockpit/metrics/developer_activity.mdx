## 開発者アクティビティとは

開発者アクティビティは、各開発者が時間の経過とともにオープンしたプルリクエストを示し、チーム全体の作業負荷とアクティビティのパターンを把握できるようにします。

Cockpit では、**Productivity** タブの **Team Activity** チャートです。開発者ごとに 1 行、週ごとに 1 列（日曜日から土曜日）のテーブルで、新しい週が先に表示されます。各行には、その範囲での開発者の PR 合計が表示され、各週にはオープンされた PR ごとに 1 本のバーが表示されます。

## 計算方法

```
Activity = COUNT(PRs opened) per developer per week
```

- PR は、現在のステータス（オープン、マージ済み、クローズ済み）にかかわらず、**オープンされた**日付で数えられます。リポジトリが接続される前にオープンされ、接続時にインポートされた PR に含まれなかった PR については、Kodus が最初に記録した日付になります。
- 開発者とは、Git プロバイダー上の PR の作成者のユーザー名です。作成者のいない PR は除外されます。
- Cockpit 上部で選択した日付範囲が対象です。

PR を**クローズされた**日付で数える[開発者別 PR](/ja/how_to_use/cockpit/metrics/prs_by_developer)と比較してください。

## 重要な理由

- **作業負荷のバランス**：作業がチーム全体に均等に分散されているかを確認する
- **トレンドの追跡**：アクティビティが時間とともにどう変化するかを確認する
- **ボトルネックの特定**：作業が少数の人に集中している箇所を見つける

PR の数からは、PR のサイズや難易度は分かりません。[PR サイズ](/ja/how_to_use/cockpit/metrics/pr_size)と併せて読んでください。
