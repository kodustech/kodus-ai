**Cockpit › Suggestions** は、[Kodus Review](/ja/how_to_use/cockpit/kodus_review) の数値の元になっている提案を一覧表示します。サイドバーにはエントリがありません。Kodus Review タブでカテゴリのバー（実装またはネガティブフィードバック）や Kody Rule の行をクリックして開きます。Cockpit と同じプランが必要です。

## 一覧の内容

Kody が PR コメントとして届けた提案のうち、ページ上部に表示されている Cockpit の日付範囲内に作成されたものがすべて、1 ページ 20 件ずつ表示されます。PR をクローズした日付で数える Kodus Review のチャートとは異なり、この一覧は提案が作成された日付で絞り込むため、まだオープン中のプルリクエストへの提案も表示されます。Cockpit のリポジトリピッカーには連動しません。

一覧の上部には、条件に一致する提案の件数と、現在のページにあるもののうち実装された件数が表示されます。

## フィルター

- **Category**
- **Severity**：critical、high、medium、low
- **Status**：**Implemented**、**Partially implemented**、**Not implemented**、**Not measured**
- **Search**：Enter キーを押すと、提案のサマリーまたはファイルパスに一致するものを検索します
- **Rule**：Kody Rule からページを開いた場合、ルール名のチップが表示され、一覧がそのルールに絞り込まれます。チップをクリックすると絞り込みを解除します

**Clear all** で、すべてのフィルターをリセットします。

### ステータス

| ステータス | 意味 |
| --- | --- |
| **Implemented** | その後の変更で、提案が求めた内容が実現された |
| **Partially implemented** | その後の変更で、一部が実現された。Cockpit の実装率では実装済みとして数えられる |
| **Not implemented** | 実装が記録されていません。オープンなプルリクエストの提案など、実装チェックを待っている提案も含みます。 |
| **Not measured** | 実装チェックを実行しましたが、結果を判断できませんでした。Cockpit の実装率からは除外されます。 |

## 提案の詳細

各行には、重大度、サマリー、カテゴリ、ステータス、ファイル、PR 番号が表示されます。行をクリックすると、既存のコードと提案されたコードを表示するサイドパネルが開きます。**Open in PR review** は、プルリクエストの[レビュー画面](/ja/how_to_use/reviews/pull_requests)を、その提案の位置で開きます。
