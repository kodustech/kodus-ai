---
title: "ライセンスの自動割り当て"
description: "シートを 1 つずつ手作業で管理する代わりに、実際にコントリビュートしている開発者へ Kodus がライセンスを自動割り当てします。"
---

ライセンスの自動割り当て機能は、組織内の開発者ライセンスの管理を簡素化します。各開発者にライセンスを手動で割り当てる代わりに、Kodus はアクティブなコントリビューターにライセンスを自動的に割り当てることができます。

## 仕組み

有効にすると、Kodus はリポジトリのプルリクエストのアクティビティを監視します。

-   **自動割り当て:** ユーザーが複数のプルリクエストを作成すると、Kodus は組織内に利用可能なライセンス枠があるかどうかを確認します。
    -   空きがある場合、ユーザーにライセンスが自動的に割り当てられ、PRがレビューされます。
    -   空きがない場合、Kodus はライセンス不足によりレビューを実施できないことを示すために、GitHub のプルリクエストに「👎」の絵文字、GitLab には「🔒」の絵文字でリアクションします（**Code review → General** で **Show Status Feedback** がオンの場合のみ）。

## 無視するユーザー

**無視するユーザー**のリストを設定できます。これらのユーザーは自動割り当てプロセスから除外されます。このリストは **Repositories** ページの **PR author filters** タブで、**Exclude PR authors**（逆に指定する場合は **Only these PR authors**）を使って設定します。

-   **レビューなし:** 無視されたユーザーが作成したプルリクエストは Kodus によってレビューされません。ただし、そのユーザーがライセンスを保持している場合は、ライセンスがフィルターより優先されます。
-   **リアクションなし:** Kodus はそのユーザーの PR にリアクションしません。PR の上限を超えた場合でも同様です。Kodus が PR を完全に無視したかのように扱われます。

これはボット、サービスアカウント、またはコードレビューを必要としない特定のチームメンバーに役立ちます。

## 設定

ライセンスの自動割り当てを有効化・設定するには:

1. サイドバーで **Organization → Subscription** を開きます。
2. **PR licenses** タブのままにします。
3. **Auto-assign licenses** をオンまたはオフにします。
    - **Release seats automatically**（同じカード）は、メンバーが Git 組織を離れてから数日後（デフォルトでは 7 日）にライセンスを解放します。
    - ユーザーを除外するには、**Repositories → PR author filters** を使用します（[無視するユーザー](#無視するユーザー)を参照）。

これらのトグルは、有効な有料プランまたはライセンス済みのセルフホストインスタンスがある場合にのみ、シートを管理できるメンバー（Owner）に対してのみ表示されます。
