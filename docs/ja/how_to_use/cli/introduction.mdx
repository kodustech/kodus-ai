---
title: "Kodus CLI"
description: "AI 駆動のコードレビュー、ビジネス検証、エージェントワークフローをターミナルから。"
---

Kodus CLI は、プルリクエストに到達する前の変更を、ターミナルから直接レビューします。作業ツリー、ステージ済みの差分、ブランチ、コミットを対象にでき、チームの Kody Rules とコードレビュー設定が適用されます。

CLI は [Kodus Cloud](/ja/how_to_use/cli/getting_started) と[セルフホスト環境](/ja/how_to_use/cli/self_hosted)に接続できます。基本のレビューはログインせず、回数制限付きで試せます。ワークスペースの操作にはコマンドに応じてログインまたはチームキーが必要です。

## 対象ユーザー

- **個人開発者** — プッシュ前にコミット前チェックを実行。
- **チーム** — 各開発者がサインインすることなく、すべてのクローン、IDE、CI ジョブで共通のレビュールールセットを使いたい場合。
- **AI コーディングエージェント**（Claude Code、Cursor、Codex、Windsurf など）— 構造化出力によるレビュー・修正ループを実行。
- **CI/CD パイプライン** — 重大度のしきい値を超える問題があればビルドを失敗させる。

## 画面の例

変更に対して `kodus review` を実行すると、指摘事項が重大度、場所、修正の提案とともに一覧表示されます。macOS と Linux のインタラクティブなターミナルでは、指摘事項がコードの横の Hunk 差分ビューアーで開きます。

<img src="/images/kodus_cli_review.jpg" alt="CLI での AI コードレビュー"/>

`--prompt-only` を指定すると、同じレビューが、AI エージェントが解析して処理するためのコンパクトな構造化テキストになります。`--fail-on` を指定すると、終了コードによってスクリプトが停止すべきかどうかを判断できます。

## 制限

|                        | トライアル（アカウントなし）                                   | サインイン済みまたはチームキー                                    |
| ---------------------- | -------------------------------------------------------------- | ----------------------------------------------------------------- |
| レート制限             | 1時間あたり2回のレビュー（ユーザー、デバイス、リポジトリフォルダごと） | 1時間あたり1,000リクエスト（チームごと）                          |
| Kodus に送信される内容 | 差分のみ                                                       | 差分に加えて、作業ツリーまたはステージ済みのレビューでは変更されたファイル |
| 差分                   | 2,000万文字                                                    | 2,000万文字                                                       |
| レビューごとのファイル数 | —                                                            | 500                                                               |
| ファイルごとの差分     | —                                                              | 500,000文字                                                       |
| ファイルごとの内容     | —                                                              | 2,000,000文字                                                     |
| リクエストサイズ       | 25 MB                                                          | 24 MB                                                             |

トライアルの1時間は、スライディングウィンドウです。トライアルのレビューには、ファイル数や行数の制限はありません。サインイン済みのチームでは、1,000リクエストには、レビュー、ビジネス検証のチェック、[Kodus Trace](/ja/how_to_use/cli/trace) のセッションイベントが含まれます。

ログインまたはチームキーを使用している場合、ファイルごとの上限を超えるファイルは、警告を表示してスキップされます。`--branch`、`--commit`、`--fast` は差分のみを送信するため、大規模なレビューでもリクエストの上限内に収まります。

トライアルモードでは、`kodus auth status` で使用状況とリセットされるタイミングを確認できます。

## CLI と Kodus Web の比較

CLI と Kodus の Web アプリは、Kody Rules とコードレビュー設定を共有します。**PR が存在する前に**、つまりローカルブランチ、ステージ済みの差分、またはエージェントループ内でレビューしたい場合は CLI を使用してください。PR レビュー、Cockpit、チームレベルの設定には Web アプリを使用してください。

CLI のレビューには、チームの Kody Rules が適用されます。git のリモートが Kodus に追加されたリポジトリと一致する場合は、そのリポジトリのルール、レビューモード、リポジトリの指示（`CLAUDE.md`、`AGENTS.md`）も適用されます。一致しない場合は、すべてのリポジトリに適用されるルールのみが実行されます。トライアルのレビューにはチームがないため、デフォルト設定で実行され、Kody Rules は適用されません。

CLI から実行したレビューは、Web アプリの **Reviews → CLI** に表示されます。チームキーで実行したレビューには **Team · &lt;key name&gt;**、ログインで実行したレビューには **Personal** というラベルが付きます。
