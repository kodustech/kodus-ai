---
title: "Forgejo で AI コードレビューをセットアップする方法"
description: "Forgejo を Kodus に接続し、自動レビューの対象となるリポジトリを選びます。"
---

Kodus は、アクセストークンで Forgejo インスタンスに接続し、リポジトリの Webhook を通じて Pull Request のイベントを受信します。Forgejo のサポートはコミュニティによって維持されています。

## 手順

1. [kodus.io](https://kodus.io) で**アカウントを作成**するか、[Kodus をセルフホスト](/ja/how_to_deploy/deploy_kodus/generic_vm)します
2. **Forgejo に接続** — オンボーディングの **Connect your Git tool** ステップで **Forgejo** タブを開き、**Connect via token** をクリックして、**Forgejo Instance URL** と **Personal Access Token** を入力します（後からサイドバーの **Repositories** で、**Connect a provider** の下の **Forgejo** をクリックして接続することもできます）
3. **リポジトリを選択** — Kodus がレビューする Forgejo リポジトリを選択するか、**Repositories** で [Review every repository](/ja/how_to_use/code_review/configs/review_all_repositories) をオンにします
4. **Webhook** — 選択を保存すると、Kodus が Pull Request の Webhook を自動的に作成します。そのためには、リポジトリへの管理者アクセスと、トークンの `write:repository` スコープが必要です。作成されなかった場合は、**Repositories** にそのリポジトリが理由とともに一覧表示されます。[Forgejo の Webhook](/ja/how_to_deploy/platforms/forgejo/forgejo_webhook) ガイドに従って手動で Webhook を追加してください
5. 選択したリポジトリでプルリクエストを開きます。[Kody が投稿する内容とステータスの確認方法](/ja/how_to_use/code_review/flow)を参照してください。

## カスタム設定

リポジトリごとのレビュー設定は [kodus-config.yml](/ja/how_to_use/code_review/configs/general#kodus-config-yml) でカスタマイズできます。
