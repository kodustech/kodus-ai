---
title: "GitLab で AI コードレビューをセットアップする方法"
description: "GitLab を Kodus に接続し、自動レビューの対象となるリポジトリを選びます。"
---

Kodus は、OAuth またはアクセストークンで GitLab に接続し、Webhook を通じてマージリクエストのイベントを受信します。

GitLab にはインストールするアプリがありません。**Install Gitlab app** は OAuth サインインです。レビューは、OAuth で接続したユーザー、またはトークンの所有者として投稿されます。

## 手順

1. [kodus.io](https://kodus.io) で**アカウントを作成**するか、[Kodus をセルフホスト](/ja/how_to_deploy/deploy_kodus/generic_vm)します
2. **GitLab に接続** — オンボーディングの **Connect your Git tool** ステップで、**Install Gitlab app** をクリックして OAuth で認可するか、**Connect via token** を選択します（後からサイドバーの **Repositories** で、**Connect a provider** の下の **Gitlab** をクリックし、**OAuth** または **Token** タブを使って接続することもできます）。セルフマネージドの GitLab にトークンで接続する場合は、**Self-hosted** をオンにして **Gitlab URL** を入力します
3. **プロジェクトを選択** — Kodus がレビューする GitLab プロジェクトを選択するか、**Repositories** で [Review every repository](/ja/how_to_use/code_review/configs/review_all_repositories) をオンにします
4. **Webhook** — 選択を保存すると、Kodus がマージリクエストの Webhook を自動的に登録します。そのためには、各プロジェクトに対する **Maintainer** または **Owner** ロールが必要です。登録されなかった場合は、**Repositories** にそのプロジェクトが理由とともに一覧表示されます。[GitLab の Webhook](/ja/how_to_deploy/platforms/gitlab/gitlab_webhook) ガイドに従って手動で Webhook を追加してください
5. 選択したプロジェクトでマージリクエストを開きます。[Kody が投稿する内容とステータスの確認方法](/ja/how_to_use/code_review/flow)を参照してください。

## カスタム設定

リポジトリごとのレビュー設定は [kodus-config.yml](/ja/how_to_use/code_review/configs/general#kodus-config-yml) でカスタマイズできます。

## セルフホスト

**Install Gitlab app** と **Sign in with Gitlab** には、GitLab の OAuth アプリケーションと、その認証情報を `.env` に設定する必要があります。[GitLab OAuth](/ja/how_to_deploy/platforms/gitlab/gitlab_oauth) を参照してください。トークンによる接続にはそれらは不要です。[GitLab PAT](/ja/how_to_use/code_review/general_config/gitlab_pat) の説明に従ってトークンを生成してください。

完全なセットアップガイドについては、[GitLab OAuth](/ja/how_to_deploy/platforms/gitlab/gitlab_oauth) と [GitLab の Webhook](/ja/how_to_deploy/platforms/gitlab/gitlab_webhook) を参照してください。
