---
title: "リポジトリ間でコーディング標準を共有する方法"
description: "グローバルルール、ルールの継承、グローバルルールソースを使用して、すべてのリポジトリで同じコーディング標準を維持します。"
---

複数のリポジトリがあると、コーディング標準を一貫して保つのは大変です。Kodus では、ルールを一度定義すれば、どこにでも適用できます。

## グローバルルール

**Global** スコープでルールを作成すると、すべてのリポジトリに適用されます。

1. サイドバーの **Code review** グループ上部にあるスコープピッカーで **Global** を選択し、**Kody Rules** を開きます
2. **New rule** でルールを作成するか、[Rules Library](/ja/how_to_use/code_review/configs/rules_library) から追加します
3. リポジトリとディレクトリがそれらを継承します

## ルールの継承

ルールは Global → リポジトリ → ディレクトリの順に引き継がれます。

- **Global ルール**はすべてのリポジトリに適用されます
- **リポジトリルール**は、そのリポジトリで Global ルールに追加されます
- **ディレクトリルール**は、そのディレクトリの設定でレビューされる Pull Request で、それらに追加されます

リポジトリは、継承したルールを一覧上で無効としてマークでき、ルールを継承不可としてマークすることもできます。どちらもルールの一覧での表示が変わるだけで、レビューではすべての Global ルールとリポジトリルールが引き続き適用されます。[ルールの継承](/ja/how_to_use/code_review/configs/rules_inheritance)を参照してください。

## 標準を 1 つのリポジトリで管理する

標準を専用のリポジトリで管理している場合、[Global Rule Sources](/ja/how_to_use/code_review/configs/global_rule_sources) はそのルールファイルをグローバルルールとしてインポートし、そこで Pull Request がマージされると更新します。Free プランでは利用できません。各プロジェクト自身の `.kody/rules` フォルダ内のルール（[リポジトリルール](/ja/how_to_use/code_review/configs/repository_rules)を参照）は、そのプロジェクトにのみ適用されます。

組織全体のレビュー設定とルールを 1 つのリポジトリから管理するには、[集中管理設定](/ja/how_to_use/code_review/configs/centralized_config)を使用します。

## 組織全体のメモリ

**組織**にスコープされたメモリは、すべてのリポジトリに適用されます。**Global** スコープで **New memory** から作成するか、PR コメントで Kody に依頼します。

```
@kody remember: across all repos, we use ESLint flat config format.
```

詳細については、[ルールの継承](/ja/how_to_use/code_review/configs/rules_inheritance)を参照してください。
