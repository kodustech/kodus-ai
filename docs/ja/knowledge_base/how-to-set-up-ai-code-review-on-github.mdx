## 手順

1. [kodus.io](https://kodus.io) で**アカウントを作成**するか、[Kodus をセルフホスト](/ja/how_to_deploy/deploy_kodus/generic_vm)します
2. **GitHub に接続** — オンボーディングの **Connect your Git tool** ステップで **Install Github app** をクリックします（後からサイドバーの **Repositories** で、**Connect a provider** の下の **Github** をクリックし、**OAuth** タブの **Go to OAuth** をクリックして接続することもできます）
3. **リポジトリを選択** — Kodus がレビューするリポジトリを選択するか、**Repositories** で [Review every repository](/ja/how_to_use/code_review/configs/review_all_repositories) をオンにします
4. 選択したリポジトリでプルリクエストを開きます。[Kody が投稿する内容とステータスの確認方法](/ja/how_to_use/code_review/flow)を参照してください。

## カスタム設定

リポジトリごとのレビュー設定は [kodus-config.yml](/ja/how_to_use/code_review/configs/general#kodus-config-yml) でカスタマイズできます。

## Personal Access Token の使用

GitHub App をインストールできない場合は、代わりに GitHub の Personal Access Token（PAT）で接続します。オンボーディングで **Connect via token** を選択します（**Repositories** で GitHub を接続する場合は **Token** タブ）。この場合、レビューはトークン所有者のアカウントから投稿され、GitHub Checks/PR ステータスは利用できません。Kodus は選択した各リポジトリに Webhook を作成します。失敗した場合は、[Webhook の作成](/ja/how_to_deploy/platforms/github/github_webhook)を参照してください。

## セルフホスト

セルフホストの Kodus は、自分で作成した GitHub App、またはトークンで接続します。**Install Github app** には、`.env` に App の認証情報が必要です。[GitHub App のセットアップ](/ja/how_to_deploy/platforms/github/github_app)を参照してください。ユーザーが GitHub でサインインできるようにするには、[GitHub OAuth App](/ja/how_to_deploy/platforms/github/github_oauth) を参照してください。

完全なセットアップガイドについては、[クイックスタート](/ja/how_to_use/quickstart)を参照してください。
