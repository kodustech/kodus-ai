---
title: "コードレビューが一時停止している理由"
description: "Kodusの自動一時停止の動作と自動コードレビューを再開する方法を理解します。"
---

以前は正常に動作していたのにKodusがPRのレビューを停止した場合は、**自動一時停止**機能が原因である可能性が高いです。

## 自動一時停止とは

自動一時停止は、アクティブな開発中のレビュースパムを防ぎます。Kodusが連続した急速なプッシュを検出したとき（デフォルト：15分以内に3回のプッシュ）、そのPRのレビューを一時停止し、「Auto-paused – comment @kody start-review when you're ready.」というコメントを投稿します。再開するまで、以降のプッシュはスキップされます。

これはバグではなく機能です — まだアクティブに変更をプッシュしている間、PRに複数のレビューが氾濫するのを避けます。

## 再開方法

- PRに `@kody start-review` と**コメント**して再開し、すぐにレビューをトリガーします
- すべてのプッシュでレビューが必要な場合は**頻度を「自動」に変更**します

## 動作の変更

**Code review → General** → **Enable Automated Code Review** → **Review Cadence** に移動します：

| モード | 動作 |
|------|----------|
| **Automatic** | すべてのプッシュをレビュー — 一時停止なし（デフォルト） |
| **Auto-pause** | 連続したプッシュの後に一時停止。**Pushes to trigger pause** と **Time window (minutes)** で調整します |
| **Manual** | `@kody start-review` とコメントしたときのみレビュー |

詳細については、[一般設定](/ja/how_to_use/code_review/configs/general)を参照してください。
