---
title: "AIコードレビューがトリガーされない理由"
description: "KodusがプルリクエストをAutomaticにレビューしない場合の一般的な原因と修正方法。"
---

KodusがPRをレビューしていない場合は、以下の一般的な原因を確認してください：

## 1. 自動レビューが無効になっている

自動レビューが有効になっていることを確認します：
- **Code review → General** に移動します
- **Enable Automated Code Review** がオンになっていることを確認します
- または `kodus-config.yml` で確認します：

```yaml
automatedReviewActive: true
```

## 2. Webhookが設定されていない

KodusはPRが開かれたり更新されたりしたときを知るためにWebhookが必要です：
- Gitプロバイダーのwebhook設定に移動します
- KodusのWebhook URLが登録されてアクティブであることを確認します
- 配信失敗の試行を確認します

## 3. PRのタイトルが無視キーワードに一致している

PRのタイトルに無視キーワードが含まれている場合、Kodusはレビューをスキップします：

```yaml
ignoredTitleKeywords:
  - "release"
  - "WIP"
```

**Code review → General** の **Ignore title keywords**（または `kodus-config.yml` の `ignoredTitleKeywords`）を確認してください。

## 4. ベースブランチが監視されていない

デフォルトでは、KodusはデフォルトブランチをターゲットとするPRをレビューします。PRが別のブランチをターゲットにしている場合は、**Code review → General** の **Base Branches**、または `kodus-config.yml` の `baseBranches` に追加します：

```yaml
baseBranches:
  - develop
  - staging
```

## 5. レビューの頻度が手動に設定されている

**Review Cadence**（**Code review → General** の **Enable Automated Code Review** の下）が **Manual** に設定されている場合、Kodusは `@kody start-review` とコメントしたときのみレビューします。

## 6. 自動一時停止がアクティブになっている

複数回素早くプッシュした場合、自動一時停止が発動し、KodyがPRに「Auto-paused」コメントを投稿している可能性があります。`@kody start-review` とコメントするまで、PRは一時停止されたままです。

## まだ動作しない場合

PRに `@kody start-review` とコメントして手動レビューをトリガーしてみてください。それでも動作しない場合は、[トラブルシューティングガイド](/ja/how_to_use/code_review/troubleshooting)を確認してください。
