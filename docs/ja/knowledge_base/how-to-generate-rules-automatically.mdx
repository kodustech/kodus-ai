---
title: "コードレビュールールを自動生成する方法"
description: "Kody にレビュアーの過去のコメントを読み取らせ、繰り返し指摘される基準からルールの下書きを作成します。"
---

コードレビュールールをゼロから書くのは手間がかかります。Kodus は、クローズされた Pull Request にチームが残したコメントを読み取り、見つかったパターンからルールの下書きを作成できます。

## 仕組み

1. サイドバーの **Code review** グループ上部にあるスコープピッカーで **Global** またはリポジトリを選択し、**Kody Rules** を開いて **Configuration** をクリックします
2. **Generate from past reviews** をオンにします
3. Kody は、リポジトリで直近 3 ヶ月分のクローズされた PR を読み取り、レビュアーのコメント（ボットや Kody 自身のコメントは除く）を確認します。リポジトリに対してオンにするとすぐに開始され、**Global** でオンにした場合は、次回の週次実行でリポジトリが対象になります
4. 繰り返し出てくる基準についてルールの下書きを作成し、Kody Rules ページにオリジン **Kody-generated** として一覧表示します

必要に応じて、トグルの下のレビュアーピッカーで、Kody に学習させたくないコメントを書く開発者を除外できます。

## その後の流れ

- デフォルトでは、生成されたルールはすぐに有効になり、コードレビュー中にチェックされます
- 先にレビューしたい場合は、同じ **Configuration** シートで **Kody knowledge approval** をオンにします。新しいルールは、**Approve** または **Discard** するまで **Pending review** セクションで待機します
- 生成されたルールは、他の Kody Rule と同様に編集、一時停止、削除できます

## 継続的な学習

最初の処理の後、Kodus は**毎週**、直近 1 週間のレビュアーのコメントを読み取り、そこから新しいルールの下書きを作成します。

## 要件

- リポジトリのクローズされた Pull Request に対するレビュアーのコメント。必要な履歴の最小量はありません
- クラウドでトライアル期間外の場合は、自分のモデルキー（[BYOK](/ja/how_to_use/byok)）。セルフホストのインスタンスは、デプロイのモデルを使用します

詳細については、[自動ルール生成](/ja/how_to_use/code_review/learning/kody_rules_generation)を参照してください。
