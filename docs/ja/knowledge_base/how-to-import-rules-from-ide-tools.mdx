---

Cursor、GitHub Copilot、Claude、その他のコーディングエージェント向けの指示をすでに管理している場合、Kody はコードレビュー中にそれらを読み取り、それに反する変更を指摘できます。

## 仕組み

Kody は、Pull Request が変更するファイルをカバーする指示ファイルを読み取ります。サポートされているファイルは次のとおりです。

- `.cursorrules` と `.cursor/rules/**/*.mdc`（Cursor）
- `.github/copilot-instructions.md` と `.github/instructions/**/*.instructions.md`（GitHub Copilot）
- `CLAUDE.md`（Claude）
- `AGENTS.md`、`.agents.md`、`.agent.md`、`.agents/rules/**`（agents.md 規約）
- `.windsurfrules`（Windsurf）
- `.sourcegraph/**/*.rule.md`（Sourcegraph Cody）

これらに反する変更は **Repo Instruction** ラベル付きで報告され、指示とその取得元のファイルが引用されます。これらのファイルが Kody Rules に変換されることはないため、レビューポリシーが知らないうちに変わることはありません。

## セットアップ方法

1. サイドバーの **Code review** グループ上部にあるスコープピッカーで **Global** またはリポジトリを選択し、**What to review** を開きます
2. **Coding-agent instructions** をオンにします
3. そのスコープで次にレビューされる Pull Request は、その変更をカバーする指示ファイルに照らしてチェックされます

新しいワークスペースでは、オンボーディング中に、各リポジトリで見つかったコーディングエージェント向けファイルの一覧とともにこの設定について尋ねられます。

## すべてのレビューで規約を強制する

コーディングエージェント向けの指示はコンテキストです。Kody が違反を報告するのは、その指示が変更された行に明確に当てはまる場合だけです。他のレビュールールと同じように強制したい規約は、`.kody/rules` に[リポジトリルール](/ja/how_to_use/code_review/configs/repository_rules)として記述してください。ルールファイルは、それを変更する Pull Request がマージされたときに、1 ファイルにつき 1 ルールとして、書かれたとおりに同期されます。

詳細については、[コーディングエージェントの指示](/ja/how_to_use/code_review/configs/rules_file_detection)を参照してください。
