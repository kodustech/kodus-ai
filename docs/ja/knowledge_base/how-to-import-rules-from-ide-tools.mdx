Cursor、GitHub Copilot、Claude、またはその他のAIコーディングツールにすでにルールが定義されている場合、それらをKodusにインポートして、コードレビュー中も同じ規約が適用されるようにできます。

## 動作方法

Kodusはリポジトリ内のルールファイルを検出し、Kodyルールとして同期します。サポートされているファイル形式には以下が含まれます：

- `.cursorrules`（Cursor）
- `.github/copilot-instructions.md`（GitHub Copilot）
- `CLAUDE.md`（Claude）
- その他のAIツール設定ファイル

## セットアップ方法

1. サイドバーの **Code review** グループ上部にあるスコープピッカーでリポジトリを選択し、**Kody Rules** を開いて **Configuration** をクリックします
2. **Auto-sync rules from repo** をオンにします。初回は、すぐにリポジトリをスキャンするか（**Sync now**）、**Skip initial scan** するかを尋ねられます
3. Kodusは見つかったルールファイルをKodyルール（オリジン **Auto-sync**）としてインポートし、以降は同期を維持します
4. インポートされたルールはすぐにコードレビュー中に適用されます。先にレビューしたい場合は、同じ **Configuration** シートで **Kody knowledge approval** をオンにします。インポートされたルールは **Approve** または **Discard** するまで **Pending review** セクションで待機します

## なぜ重要か

同期しないと、IDEとコードレビューツールが異なる標準を適用します。Cursorのルールに従っている開発者が、IDEでは検出されなかったことでレビュー中にフラグされる可能性があります（またはその逆）。

インポートにより、ワークフロー全体でコーディング標準の**単一の信頼できる情報源**が確保されます。

詳細については、[IDEルールの同期](/ja/how_to_use/code_review/configs/rules_file_detection)を参照してください。
