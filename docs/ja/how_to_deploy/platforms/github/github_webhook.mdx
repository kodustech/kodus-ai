Kodusは通常、Webhookを自動的に作成します。それが行われなかった場合は、以下の手順に従って手動で設定してください：

<Note>
  WebhookのURLはWebhooksサービス（ポート3332）に到達できる必要があります。APIドメインを使用するのは、リバースプロキシが`/.../webhook`パスをWebhooksサービスにルーティングする場合のみ機能します。
</Note>

1. GitHubリポジトリに移動
2. 「Settings」をクリック
3. 左サイドバーの「Webhooks」を見つける
4. 「Add webhook」をクリック
5. Webhookを設定します：

   - **Payload URL**: `.env`ファイルのURLを入力：`API_GITHUB_CODE_MANAGEMENT_WEBHOOK`
   - **Content type**: `application/json`
   - **Secret**: 空欄のまま
   - **SSL verification**: SSL検証を有効にする
   - **Which events would you like to trigger this webhook?**: 個別のイベントを選択する
   - 以下のボックスにチェックを入れます：
     - Issue comment
     - Pull request review comments
     - Pull requests

6. 「Add webhook」をクリック

GitHubリポジトリのコードレビュー用Webhookのセットアップが完了しました。

<Note>
  Kodus が利用するのはこの 3 つのイベントだけです。それ以外（pushes、pull request reviews、
  review threads）を選んでも、届いた時点で破棄されるトラフィックが増えるだけです。
</Note>
