1つのGitLabアプリケーションで、Kodusの次の2つの機能をまかないます：

- サインインページの**Sign in with GitLab**。
- **Connect your Git tool**ステップの**Install Gitlab app**、または**Repositories**でGitLabを接続するときの**OAuth**タブにある**Go to OAuth**。どちらも、OAuthでGitLabをコードレビュー用に接続します。

ユーザーがメールでサインインし、[パーソナルまたはグループアクセストークン](/ja/how_to_use/code_review/general_config/gitlab_pat)でGitLabを接続する場合は、このページは不要です。トークンによる接続にはOAuthアプリは必要ありません。

## 前提条件

- **WEB_DOMAIN**: フロントエンドのURL（例：`https://app.yourdomain.com`または`http://localhost:3000`）

## ステップ1：OAuthアプリの作成

1. GitLabで**User Settings** > **Applications**に移動
2. **New application**をクリック
3. アプリケーション名を入力

## ステップ2：リダイレクトURIの設定

**Redirect URI**に、次の2つのURIを1行ずつ追加します：

```
WEB_DOMAIN/api/auth/callback/gitlab
WEB_DOMAIN/setup/gitlab
```

1つ目は**Sign in with GitLab**を完了するためのものです。2つ目は、OAuthでGitLabを接続した後にGitLabから戻るためのものです。どちらも、実際のWebドメインとスキーム（http/https）と一致していることを確認してください。

## ステップ3：スコープの設定

次のスコープを選択します：

- `api`
- `read_user`
- `read_repository`

各フローは、それぞれ独自のスコープを要求します：

- **Sign in with GitLab**は`read_user`のみを要求します。
- **Install Gitlab app**と**Go to OAuth**は、`WEB_GITLAB_SCOPES`（ステップ4）のスコープを要求します。

Kodyがレビューコメントを投稿し、Webhookを作成、編集、削除するには、`api`が必要です。`read_api`では読み取りはできますが、投稿はできません。

<Warning>
  `.env.schema`では、`WEB_GITLAB_SCOPES`のデフォルトが`read_api read_user read_repository`になっています。この値で接続すると、リポジトリを読み取ることはできますが、コメントの投稿やWebhookの管理はできません。ステップ4に示す値を設定してください。
</Warning>

## ステップ4：.envへの認証情報の追加

GitLabから**Application ID**と**Secret**をコピーします。WebアプリとAPIがそれぞれ独自の変数を読み取るため、どちらの値も2組の変数に設定します：

```
# Sign in with GitLab
WEB_OAUTH_GITLAB_CLIENT_ID="your_application_id_here"
WEB_OAUTH_GITLAB_CLIENT_SECRET="your_secret_here"

# Connect GitLab with OAuth
GLOBAL_GITLAB_CLIENT_ID="your_application_id_here"
GLOBAL_GITLAB_CLIENT_SECRET="your_secret_here"
GLOBAL_GITLAB_REDIRECT_URL="WEB_DOMAIN/setup/gitlab"
WEB_GITLAB_SCOPES="api read_user read_repository"
WEB_GITLAB_OAUTH_URL="https://gitlab.com/oauth/authorize"
API_GITLAB_TOKEN_URL="https://gitlab.com/oauth/token"
```

セルフマネージドのGitLabの場合は、`WEB_GITLAB_OAUTH_URL`と`API_GITLAB_TOKEN_URL`のホストを、インスタンスのドメインに置き換えてください（例：`https://gitlab.yourdomain.com/oauth/authorize`と`https://gitlab.yourdomain.com/oauth/token`）。

どちらか一方のみを使用する場合は、その変数だけを設定してください。

変更を適用するために、WebアプリケーションとAPIを再起動してください。
