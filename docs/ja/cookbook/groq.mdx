## Groq の仕組み

Groq Cloud は、オープンモデルを **OpenAI 互換**の API で提供します。Kodus は OpenAI 互換プロバイダーを通じて接続するため、コードの変更は不要で、必要なのは BYOK の認証情報だけです。

## 推奨モデル

<Info>
  Groq のカタログは頻繁に更新されます。現在の本番モデル、コンテキストウィンドウ、料金、制限は [Groq のモデルページ](https://console.groq.com/docs/models)で確認してください。
</Info>

| モデル ID | コンテキストウィンドウ |
| -------- | -------------- |
| `openai/gpt-oss-120b` | 131,072 トークン |

Kodus のレビューエージェントはツールを呼び出し、構造化された出力を期待します。このモデルの Groq のページには、ツール使用と JSON Schema モードが記載されています。他のモデルに切り替える前に、その両方を確認してください。

## APIキーの作成

<Warning>APIキーを作成するには Groq Cloud アカウントが必要です。</Warning>

新しいAPIキーを作成するには、[Groq の API Keys ページ](https://console.groq.com/keys)に直接アクセスしてください。

または、次の手順に従います。

1. [Groq Console](https://console.groq.com) にアクセスします
2. サインインするか、アカウントを作成します
3. **API Keys** を開きます
4. **Create API Key** をクリックします
5. 'Kodus' など、わかりやすい名前を付けます
6. APIキーをコピーして安全な場所に保管します

<Info>
  Groq で APIキーを作成・管理できるのは、チームオーナーまたは developer ロールを持つユーザーのみです。
</Info>

## Kodus で Groq を設定する

### オプション1 — AI providers ページ（推奨）

[プロバイダーを接続する](/ja/how_to_use/byok#プロバイダーを接続する)の手順に従い、**Custom → OpenAI-compatible** を選びます。フォームには次の値を指定します。

| フィールド | 値 |
| --- | --- |
| **Key**（**API key** カード内） | Groq の APIキー |
| **Base URL** | `https://api.groq.com/openai/v1` |
| **Model** | `openai/gpt-oss-120b` |
| **Max concurrent requests** | 任意。**Advanced (optional)** 内の **Advanced settings** を展開します。レート制限エラーが出る場合は下げてください |

**Test & save** をクリックし、[Routing](/ja/how_to_use/code_review/configs/routing) でデフォルトモデルとフォールバックモデルを選びます。

<Note>
  ベース URL は `/chat/completions` を付けずに指定してください。Groq でレート制限を受けてもレビューを継続できるよう、他のプロバイダーのモデルを **Fallback model** に設定してください。
</Note>

### オプション2 — セルフホスト（環境変数）

セルフホスト環境で `.env` から 1 つのモデルを指定するには、次のように設定します。

```env
API_LLM_PROVIDER=openai_compatible
API_LLM_PROVIDER_MODEL="openai/gpt-oss-120b"
API_LLM_BASE_URL="https://api.groq.com/openai/v1"
API_LLM_API_KEY="your-groq-api-key"
```

インストールガイドに従って[モデルの変更を反映してください](/ja/how_to_deploy/deploy_kodus/generic_vm#モデルの変更を反映する)。

## トラブルシューティング

<AccordionGroup>
  <Accordion title="APIキーの問題">
    - [Groq Console](https://console.groq.com/keys) で、APIキーが正しく有効であることを確認します
    - 選択したモデルを Groq のプランで利用できることを確認します
    - `.env` の値に末尾のスペースや引用符が含まれていないことを確認します
  </Accordion>

  <Accordion title="モデルが見つからない">
    - モデル ID が Groq のモデルページの表記と完全に一致していることを確認します
    - モデルが Groq の現在のモデル一覧に含まれていることを確認します。モデルは随時終了されます
    - Groq は、2026年8月16日に Free プランと Developer プラン向けの `llama-3.3-70b-versatile` と `llama-3.1-8b-instant` を終了しました。Enterprise 契約には影響しません。Groq の[非推奨情報](https://console.groq.com/docs/deprecations)を参照してください
  </Accordion>

  <Accordion title="接続エラー">
    - サーバーがインターネット経由で `api.groq.com` に到達できることを確認します
    - ファイアウォールの制限がないか確認します
    - API とワーカーのログで、上流の正確なエラーを確認します
  </Accordion>

  <Accordion title="レート制限">
    - Groq は制限を超過すると HTTP 429 を返します。制限はプランによって異なります
    - 組織ごとの正確な制限は、Groq アカウントの Limits ページ（[console.groq.com/settings/limits](https://console.groq.com/settings/limits)）と [Groq のレート制限に関するドキュメント](https://console.groq.com/docs/rate-limits)で確認できます
    - モデルの **Max concurrent requests** を下げるか、プランをアップグレードしてください
  </Accordion>
</AccordionGroup>
