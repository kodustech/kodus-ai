## Fireworks AI の仕組み

Fireworks AI は、DeepSeek、Kimi、GLM、Qwen などの人気のオープンソースモデルを **OpenAI 互換**の API で提供する推論プラットフォームです。Kodus は OpenAI 互換プロバイダーを通じて接続するため、コードの変更は不要で、必要なのは BYOK の認証情報だけです。

## 推奨モデル

<Info>
  Fireworks のカタログは頻繁に更新されます。最新のモデル、コンテキストウィンドウ、料金は [Fireworks モデルライブラリ](https://fireworks.ai/models)で確認してください。
</Info>

Fireworks のモデル ID は `accounts/fireworks/models/<model>` の形式で、バージョン表記には `p` を使います。たとえば GLM 5.3 は `glm-5p3` です。ID はライブラリ内の各モデルのページからコピーしてください。

| モデル ID | コンテキストウィンドウ |
| -------- | -------------- |
| `accounts/fireworks/models/glm-5p3` | 1,048,576 トークン |

Kodus のレビューエージェントはツールを呼び出し、構造化された出力を期待します。関数呼び出しに対応したモデルを選んでください。対応状況はモデルのページに記載されています。

## APIキーの作成

<Warning>APIキーを作成するには Fireworks AI アカウントが必要です。</Warning>

1. [app.fireworks.ai](https://app.fireworks.ai) にサインインするか、アカウントを作成します。
2. APIキーのページ [app.fireworks.ai/settings/users/api-keys](https://app.fireworks.ai/settings/users/api-keys) を開きます。
3. **Create API key** をクリックします。
4. キーをコピーして安全な場所に保管します。Fireworks では再表示されません。

## Kodus で Fireworks AI を設定する

### オプション1 — AI providers ページ（推奨）

[プロバイダーを接続する](/ja/how_to_use/byok#プロバイダーを接続する)の手順に従い、**Custom → OpenAI-compatible** を選びます。フォームには次の値を指定します。

| フィールド | 値 |
| --- | --- |
| **Base URL** | `https://api.fireworks.ai/inference/v1` |
| **Model** | 例：`accounts/fireworks/models/glm-5p3` |
| **API key** | Fireworks の APIキー |
| **Max concurrent requests** | 任意。レート制限エラーが出る場合は下げてください（**Advanced (optional)** 内） |

**Test & save** をクリックし、[Routing](/ja/how_to_use/code_review/configs/routing) でデフォルトモデルとフォールバックモデルを選びます。

<Note>
  ベース URL は `/chat/completions` を付けずに指定してください。**Code review → Routing** で、他のプロバイダーのモデルを **Fallback model** に設定しておくと、Fireworks に障害が発生してもレビューを継続できます。
</Note>

### オプション2 — セルフホスト（環境変数）

セルフホスト環境で `.env` から 1 つのモデルを指定するには、次のように設定します。

```env
API_LLM_PROVIDER=openai_compatible
API_LLM_PROVIDER_MODEL="accounts/fireworks/models/glm-5p3"
API_LLM_BASE_URL="https://api.fireworks.ai/inference/v1"
API_LLM_API_KEY="your-fireworks-api-key"
```

インストールガイドに従って[モデルの変更を反映してください](/ja/how_to_deploy/deploy_kodus/generic_vm#モデルの変更を反映する)。

## トラブルシューティング

<AccordionGroup>
  <Accordion title="APIキーの問題">
    - [Fireworks AI コンソール](https://app.fireworks.ai)で、APIキーが正しく有効であることを確認します
    - Fireworks AI アカウントに十分なクレジットがあることを確認します
    - `.env` の値に末尾のスペースや引用符が含まれていないことを確認します
  </Accordion>

  <Accordion title="モデルが見つからない">
    - モデルライブラリの表記どおりに、`accounts/fireworks/models/<model>` の完全な ID を使用します
    - モデルがサーバーレス推論で利用できることを確認します。一部のモデルは専用デプロイメントが必要です
  </Accordion>

  <Accordion title="接続エラー">
    - サーバーがインターネット経由で `api.fireworks.ai` に到達できることを確認します
    - ファイアウォールの制限がないか確認します
    - API とワーカーのログで、上流の正確なエラーを確認します
  </Accordion>

  <Accordion title="レート制限">
    - Fireworks AI ダッシュボードで現在の使用状況を確認します
    - 支払い方法やクレジットがないアカウントは、リクエスト上限が大幅に低くなります。Fireworks の[レート制限](https://docs.fireworks.ai/guides/quotas_usage/rate-limits)を参照してください
    - モデルの **Max concurrent requests** を下げるか、より高いスループットが必要な場合は専用デプロイメントを検討してください
  </Accordion>
</AccordionGroup>
