## Together AI の仕組み

Together AI は、DeepSeek、Kimi、GLM、gpt-oss などのオープンソースモデルを **OpenAI 互換**の API で提供します。Kodus は OpenAI 互換プロバイダーを通じて接続するため、コードの変更は不要で、必要なのは BYOK の認証情報だけです。

## 推奨モデル

<Info>
  Together のサーバーレスカタログは頻繁に更新されます。最新のモデル ID、コンテキスト長、料金は[サーバーレスモデル一覧](https://docs.together.ai/docs/serverless-models)を参照してください。API のモデル文字列は正確に指定してください。
</Info>

Together では、次のサーバーレスのチャットモデルが関数呼び出しと構造化出力に対応していると記載されています。

| モデル ID | コンテキストウィンドウ |
| -------- | -------------- |
| `moonshotai/Kimi-K3` | 約1M トークン |
| `deepseek-ai/DeepSeek-V4-Pro-0813` | 約1M トークン |
| `zai-org/GLM-5.3` | 約1M トークン |
| `openai/gpt-oss-120b` | 約131k トークン |

## APIキーの作成

<Warning>APIキーを作成するには Together AI アカウントが必要です。Together はプリペイド制です。キーを作成する前にクレジットを購入する必要があり、残高がゼロになると API へのアクセスは停止されます。[Together の課金に関するドキュメント](https://docs.together.ai/docs/billing)を参照してください。</Warning>

新しいAPIキーを作成するには、[Together の APIキーのページ](https://api.together.ai/settings/projects/~current/api-keys)に直接アクセスしてください。

または、次の手順に従います。

1. [api.together.ai](https://api.together.ai) でアカウントを作成するか、すでにお持ちの場合はログインします
2. [APIキーのページ](https://api.together.ai/settings/projects/~current/api-keys)を開きます
3. **Create key** をクリックします
4. 'Kodus' など、わかりやすい名前を付けます
5. APIキーをコピーします。Together は新しいキーを 1 回しか表示しません

## Kodus で Together AI を設定する

### オプション1 — AI providers ページ（推奨）

[プロバイダーを接続する](/ja/how_to_use/byok#プロバイダーを接続する)の手順に従い、**Custom → OpenAI-compatible** を選びます。フォームには次の値を指定します。

| フィールド | 値 |
| --- | --- |
| **Key**（**API key** カード内） | Together の APIキー |
| **Base URL** | `https://api.together.ai/v1` |
| **Model** | 例：`zai-org/GLM-5.3` |
| **Max concurrent requests** | 任意。**Advanced (optional)** 内の **Advanced settings** を展開します。レート制限エラーが出る場合は下げてください |

Base URL は Together の [OpenAI 互換性ガイド](https://docs.together.ai/docs/inference/openai-compatibility)を参照してください。

**Test & save** をクリックし、[Routing](/ja/how_to_use/code_review/configs/routing) でデフォルトモデルとフォールバックモデルを選びます。

<Note>
  ベース URL は `/chat/completions` を付けずに指定してください。Together でレート制限を受けてもレビューを継続できるよう、他のプロバイダーのモデルを **Fallback model** に設定してください。
</Note>

### オプション2 — セルフホスト（環境変数）

セルフホスト環境で `.env` から 1 つのモデルを指定するには、次のように設定します。

```env
API_LLM_PROVIDER=openai_compatible
API_LLM_PROVIDER_MODEL="zai-org/GLM-5.3"
API_LLM_BASE_URL="https://api.together.ai/v1"
API_LLM_API_KEY="your-together-api-key"
```

インストールガイドに従って[モデルの変更を反映してください](/ja/how_to_deploy/deploy_kodus/generic_vm#モデルの変更を反映する)。

## トラブルシューティング

<AccordionGroup>
  <Accordion title="APIキーの問題">
    - [APIキーのページ](https://api.together.ai/settings/projects/~current/api-keys)で、APIキーが正しく有効であることを確認します
    - Together AI アカウントにクレジット残高があることを確認します。残高がゼロになると API へのアクセスは停止されます
    - `.env` の値に末尾のスペースや引用符が含まれていないことを確認します
  </Accordion>

  <Accordion title="モデルが見つからない">
    - [サーバーレスモデル一覧](https://docs.together.ai/docs/serverless-models)にある API のモデル文字列を、大文字小文字を含めて正確に使用します
    - サーバーレスと専用エンドポイントでは対応するモデルが異なります。サーバーレスの一覧にないモデルには専用エンドポイントが必要です
  </Accordion>

  <Accordion title="接続エラー">
    - サーバーがインターネット経由で `api.together.ai` に到達できることを確認します
    - ファイアウォールの制限がないか確認します
    - API とワーカーのログで、上流の正確なエラーを確認します
  </Accordion>

  <Accordion title="レート制限">
    - Together は制限を超過すると HTTP 429 を返します。Together の[レート制限に関するドキュメント](https://docs.together.ai/docs/rate-limits)を参照してください
    - モデルの **Max concurrent requests** を下げるか、より高い上限について Together に問い合わせてください
  </Accordion>
</AccordionGroup>
