## Moonshot の仕組み

Moonshot AI は **Kimi** モデル（K3.1 Pro、K3、および以前の K2 シリーズ）を公開しています。API は OpenAI 互換と Anthropic 互換の両方に対応しています。Kodus には専用の **Moonshot** プロバイダーがあり、Anthropic 互換エンドポイント（`https://api.moonshot.ai/anthropic`）経由で接続します。**OpenAI-compatible** プロバイダーを通じて Kimi に接続することもできます。

Moonshot では Kimi モデルを利用する**2 つの経路**が用意されており、それぞれ独自のエンドポイントとキーを使用します。

- **Developer API**（`platform.kimi.ai`）：トークン単位の従量課金です。レート制限は累計のチャージ額によって決まります。
- **Kimi Code Plan**（`kimi.com/code`）：Kimi メンバーシップに含まれる、**コーディング専用のエンドポイント**です。利用は 5 時間のローリングレートウィンドウと月間クォータで制限されます。

<Note>
  Kimi Code は Kimi メンバーシップに付属します。現行プランでは Plus 以上、旧プランでは Andante 以上が対象です。キーは Developer API のキーとは別です。
</Note>

Moonshot は中国向けプラットフォームも `platform.kimi.com` で運営しており（`platform.moonshot.cn` はそこにリダイレクトされます）、ベース URL は `https://api.moonshot.cn/v1` です。`platform.kimi.ai` のキーと中国向けプラットフォームのキーは別物です。

## プランの概要

### Kimi Code Plan（サブスクリプション）

| 項目 | 値 |
| --- | --- |
| **エンドポイント** | `https://api.kimi.ai/coding/v1`（海外）<br />`https://api.kimi.com/coding/v1`（中国） |
| **モデル** | `k3.1-pro`、`k3`、`k3-256k`。ID は Developer API とは異なり、利用できるモデルはプランによって決まります。[Kimi Code のドキュメント](https://www.kimi.com/code/docs/en/)を参照してください。 |
| **制限** | 5 時間のローリングレートウィンドウと月間クォータ。[メンバーシップの特典](https://www.kimi.com/code/docs/en/kimi-code/membership.html)を参照してください。 |
| **課金** | メンバーシップのサブスクリプション |
| **キーの取得元** | [Kimi Code Console](https://www.kimi.com/code/console) |

### Developer API（トークン従量課金）

<Info>
  Moonshot は料金を [platform.kimi.ai/docs/pricing/chat](https://platform.kimi.ai/docs/pricing/chat)、レート制限を [platform.kimi.ai/docs/pricing/limits](https://platform.kimi.ai/docs/pricing/limits) で公開しています。モデルを選ぶ前に確認してください。
</Info>

| モデル | コンテキストウィンドウ | 備考 |
| ----- | -------------- | ----- |
| **Kimi K3.1 Pro** (`kimi-k3.1-pro`) | 1,048,576 トークン | 最新のフラッグシップ。 |
| **Kimi K3** (`kimi-k3`) | 1,048,576 トークン | 前世代のフラッグシップ。 |
| **Kimi K2 シリーズ** | 262,144 トークン | 2026年10月31日以降に新規登録したユーザーは利用できません。すべての K2 モデルは 2026年12月末までに終了する予定です。 |

Developer API のエンドポイントは `https://api.moonshot.ai/v1`（OpenAI 互換）と `https://api.moonshot.ai/anthropic`（Anthropic 互換）です。同時実行数、1 分あたりのリクエスト数、1 分あたりのトークン数は累計のチャージ額によって決まります。

## APIキーの作成

<Warning>APIキーを作成するには Moonshot アカウントが必要です。</Warning>

<Tabs>
  <Tab title="Kimi Code Plan の契約者">
    1. [kimi.com/code](https://www.kimi.com/code) にアクセスし、Kimi Code を含むメンバーシップに登録します。
    2. [Kimi Code Console](https://www.kimi.com/code/console) を開きます。
    3. **Create API Key** をクリックし、名前を入力して確定します。キーをコピーしてください。コンソールでは再表示されません。

    <Note>
      Kimi Code のキーは Kimi Code のエンドポイント専用です。Kimi Code で Developer API のキーやベース URL を使用すると 401 が返されます。
    </Note>
  </Tab>

  <Tab title="Developer API（トークン従量課金）">
    1. [platform.kimi.ai](https://platform.kimi.ai) にサインインします。中国向けプラットフォームの場合は [platform.kimi.com](https://platform.kimi.com) です。
    2. アカウントにチャージします。`platform.kimi.ai` では、API の利用を開始するための最低チャージ額は $1 です。
    3. [platform.kimi.ai/console/api-keys](https://platform.kimi.ai/console/api-keys) を開き、キーを作成します。わかりやすい名前（例：`kodus-prod`）を付けてコピーします。

    <Note>
      `platform.kimi.ai` のキーは `api.moonshot.ai` 用です。`api.moonshot.cn` 用の中国向けプラットフォームのキーとは別物です。
    </Note>
  </Tab>
</Tabs>

## Kodus で Moonshot を設定する

基本の手順は **AI providers** ページで、Kodus Cloud でもセルフホスト環境でも共通です。プロバイダーをプロセスレベルで固定したいセルフホストのユーザーは、代わりに環境変数を使用できます。

### オプション1 — Moonshot プロバイダー（Developer API に推奨）

<Steps>
  <Step title="AI providers を開いて Moonshot を選択する">
    サイドバーで **AI providers** を開きます（Cloud では [app.kodus.io/byok](https://app.kodus.io/byok)、自社環境では `/byok`）。**Providers** タブで **Moonshot** タイルをクリックします（**Connect your first provider** の下、すでにプロバイダーを接続済みの場合は **Add another provider** の後にあります）。
  </Step>

  <Step title="APIキーを貼り付けてモデルを選択する">
    [platform.kimi.ai](https://platform.kimi.ai/console/api-keys) の Developer APIキーを **API key** カードに貼り付けます。すると **Model** ピッカーに Moonshot のモデルが読み込まれます。モデル（例：`kimi-k3.1-pro`）を選択するか、**Type model manually** を選択します。`https://api.moonshot.ai/anthropic` エンドポイントは Kodus が自動で入力します。このタイルにはプランの選択もベース URL のフィールドもないため、Kimi Code Plan のキーや中国向けプラットフォームを使う場合は、後述のオプション2を使用してください。
  </Step>

  <Step title="Test & save">
    **Test & save** をクリックします。Kodus は接続をテストし、成功すると設定を保存します。401 が返された場合は、キーが間違っているか、別のプラットフォームのキーです。
  </Step>
</Steps>

### 推論

Kimi K3.1 Pro と K3 は常に推論を行います。Moonshot の API にはこれをオフにする設定がなく、これらのモデルに `thinking` パラメーターを送らないよう案内されています。**Advanced (optional)** 内の **Thinking / Reasoning** はデフォルトのままにし、**Custom** で `thinking` ブロックを追加しないでください。これらのモデルでは、**Test & save** は **Off** を受け付けません。[Thinking models](https://platform.kimi.ai/docs/guide/use-thinking-models) を参照してください。

### 同時実行数の調整

- **Kimi Code Plan**：Moonshot はこのプランの同時実行数を公開していません。**Max concurrent requests**（**Advanced (optional)** 内）を低い値に設定し、レビューが 429 エラーなしで実行される間は少しずつ引き上げてください。
- **Developer API**：空欄のままにします（上限なし）。上限は累計のチャージ額によって決まります。レビュー中に 429 エラーが出る場合に設定してください。

<Note>
  **Code review → Routing** で、**Default model** に Kimi を設定し、他のプロバイダーのモデルを **Fallback model** に選択します。呼び出しが失敗した場合、Kodus はフォールバックで 1 回だけ再実行します。[ルーティング](/ja/how_to_use/byok#ルーティング：各タスクを実行するモデル)を参照してください。
</Note>

### オプション2 — OpenAI 互換エンドポイント

Kimi Code Plan、中国向けプラットフォーム、または Moonshot の OpenAI 互換エンドポイントを使う場合は、**AI providers** を開き、**Providers** タブで **Custom** の下にある **OpenAI-compatible** を選択して、次のように入力します。

| フィールド | 値 |
| --- | --- |
| **Base URL** | `https://api.moonshot.ai/v1`（Developer API）<br />`https://api.kimi.ai/coding/v1`（Kimi Code Plan、海外）<br />`https://api.kimi.com/coding/v1`（Kimi Code Plan、中国）<br />`https://api.moonshot.cn/v1`（中国向けプラットフォーム） |
| **Model** | Developer API と中国向けプラットフォームでは `kimi-k3.1-pro` または `kimi-k3`<br />Kimi Code では `k3.1-pro` または `k3` |
| **API key** | Moonshot または Kimi Code のキー（上記のベース URL に対応するもの） |
| **Max concurrent requests**（**Advanced (optional)** 内） | Kimi Code Plan では低い値にし、レビューが 429 エラーなしで実行される間は引き上げます。Developer API では空欄 |

### オプション3 — セルフホスト（環境変数）

セルフホスト環境で `.env` から 1 つのモデルを指定するには、次のように設定します。

```env
API_LLM_PROVIDER=openai_compatible
API_LLM_PROVIDER_MODEL="kimi-k3.1-pro"
API_LLM_BASE_URL="https://api.moonshot.ai/v1"    # or https://api.kimi.ai/coding/v1 for Kimi Code Plan (model k3.1-pro)
API_LLM_API_KEY="your-moonshot-or-kimi-code-api-key"
```

代わりに Anthropic 互換エンドポイントを使用するには、`API_LLM_PROVIDER=anthropic_compatible` と `API_LLM_BASE_URL="https://api.moonshot.ai/anthropic"` を設定します。

インストールガイドに従って[モデルの変更を反映してください](/ja/how_to_deploy/deploy_kodus/generic_vm#モデルの変更を反映する)。

## Kimi Code Plan、Developer API、アグリゲーターの選び方

- **Kimi Code Plan**：専用のコーディングエンドポイントを利用する定額のメンバーシップで、5 時間のローリングレートウィンドウと月間クォータがあります。PR の量が安定している場合に最適です。サードパーティのツールから Kimi Code のキーを使用する場合の条件は Moonshot の利用規約を確認してください。また、[サブスクリプションとコーディングプラン](/ja/how_to_use/byok#サブスクリプションとコーディングプラン)も参照してください。
- **Moonshot Developer API**：トークン単位の従量課金で、レート制限は累計のチャージ額によって決まります。負荷の変動が大きいワークロードに最適です。
- **OpenRouter**：多数のプロバイダーを 1 つの請求関係にまとめられます。OpenRouter は推論料金に上乗せしませんが、クレジット購入時に手数料がかかります。詳しくは [FAQ](https://openrouter.ai/docs/faq) を参照してください。Kimi が複数プロバイダー構成の中の 1 モデルである場合に選択してください。

## トラブルシューティング

<AccordionGroup>
  <Accordion title="Test 後に 401 が返される — キーとエンドポイントが一致していない">
    - Kimi Code のキーは Kimi Code のエンドポイント専用です。Kimi Code で Developer API のキーやベース URL を使用すると 401 が返されます。
    - `platform.kimi.ai` のキーは `api.moonshot.ai`（`/v1` と `/anthropic`）用です。
    - `platform.kimi.com` のキーは `api.moonshot.cn/v1` 用です。
    - **Moonshot** タイルは常に `https://api.moonshot.ai/anthropic` を使用するため、`platform.kimi.ai` のキーが必要です。Kimi Code や中国向けプラットフォームのキーは、対応する **Base URL** を指定して **OpenAI-compatible** から接続してください。
  </Accordion>

  <Accordion title="429 エラーと残高不足">
    - Developer API では、残高がなくなると `exceeded_current_quota_error` とともに 429 が返されます。コンソールでアカウントにチャージしてください。
    - 429 は、レート制限（同時実行数、1 分あたりのリクエスト数、1 分あたりのトークン数）やエンジンの過負荷が原因の場合もあります。レート制限の場合は **Max concurrent requests** を下げてください。エンジンの過負荷はチャージでは解消しません。
    - Kimi Code は、5 時間ウィンドウ、月間クォータ、または同時実行数の上限に達すると 429 を返します。Moonshot の [Kimi Code エラーリファレンス](https://www.kimi.com/code/docs/en/kimi-code/error-reference)と [Developer API のエラーコード](https://platform.kimi.ai/docs/api/errors)を参照してください。
  </Accordion>

  <Accordion title="モデルが見つからない">
    - Developer API の ID は `kimi-k3.1-pro` と `kimi-k3` です。Kimi Code の ID は `k3.1-pro`、`k3`、`k3-256k` です。
    - Developer API の最新の一覧は [platform.kimi.ai/docs/models](https://platform.kimi.ai/docs/models) で確認してください。古いモデルは終了します。
  </Accordion>

  <Accordion title="応答が遅い">
    - Kimi K3.1 Pro と K3 は常に推論を行い、推論をオフにできないため、応答に時間がかかることがあります。
    - Developer API では、Moonshot が K3.1 Pro の高速版として `kimi-k3.1-pro-highspeed` を提供しています。
  </Accordion>

  <Accordion title="リージョン / 接続">
    - Developer API のキーはプラットフォームに紐づいています。`api.moonshot.ai` には `platform.kimi.ai`、`api.moonshot.cn` には `platform.kimi.com` のキーを使用します。
    - Kimi Code にはそれぞれ別のエンドポイントがあります。`api.kimi.ai/coding/v1`（海外）と `api.kimi.com/coding/v1`（中国）です。
    - Kodus のデプロイ環境から、選択したエンドポイントへのアウトバウンド HTTPS が許可されていることを確認します。
  </Accordion>
</AccordionGroup>
