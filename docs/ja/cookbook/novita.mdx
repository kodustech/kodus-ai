## Novita の仕組み

Novita は、DeepSeek、Kimi、GLM、MiniMax、Qwen などのオープンソースモデルを **OpenAI 互換**の API で提供するサーバーレス推論プラットフォームです。Kodus には専用の **Novita** プロバイダーがあるため、必要なのは APIキーだけです。

## 推奨モデル

<Info>
  最新のモデルと料金は [Novita のモデル一覧](https://novita.ai/models/llm)を参照してください。`https://api.novita.ai/openai/v1/models` の一覧は公開されており、各モデルのコンテキストサイズと機能が表示されます。
</Info>

Novita のモデル ID は `org/model` 形式の文字列で、ほとんどが小文字です。次のモデルは、Novita のカタログで関数呼び出しと構造化出力に対応しています。

| モデル ID | コンテキストウィンドウ |
| -------- | -------------- |
| `deepseek/deepseek-v4-pro` | 約1M トークン |
| `moonshotai/kimi-k3` | 約1M トークン |
| `zai-org/glm-5.3` | 約1M トークン |
| `minimax/minimax-m3` | 約1M トークン |
| `qwen/qwen3.8-27b` | 約1M トークン |

## APIキーの作成

<Warning>APIキーを作成するには Novita アカウントが必要です。</Warning>

1. Novita コンソールで [**Key Management**](https://novita.ai/settings/key-management) を開きます。
2. **Create API Key** を選択し、`kodus` などの名前を付けます。
3. 有効期限を選択します。**Permanent**、90 日、30 日、24 時間から選べます。後から変更することはできず、期限切れのキーは Novita に拒否されます。
4. キーをコピーします。Novita がキーの全体を表示するのは 1 回だけです。

## Kodus で Novita を設定する

### オプション1 — AI providers ページ（推奨）

この手順は Kodus Cloud でもセルフホスト環境でも共通です。

<Steps>
  <Step title="AI providers を開いて Novita を選択する">
    サイドバーで **AI providers** を開きます（Cloud では [app.kodus.io/byok](https://app.kodus.io/byok)、自社環境では `/byok`）。**Providers** タブで **Novita** タイルをクリックします。まだプロバイダーを接続していない場合は **Connect your first provider** の下に、すでに接続済みの場合は **Add another provider** の後に表示されます。
  </Step>

  <Step title="APIキーを貼り付けてモデルを選択する">
    **API key** カードの **Key** フィールドに Novita のキーを貼り付けます。**Base URL (optional)** は空欄のままにします。その場合、Kodus は `https://api.novita.ai/v3/openai` を呼び出します。**Model** カードで一覧からモデルを選択するか、**Type model manually** を選択します。
  </Step>

  <Step title="Test & save">
    **Test & save** をクリックします。Kodus はモデルに 1 トークンのリクエストを送信し、成功すると設定を保存します。
  </Step>
</Steps>

次に **Code review → Routing** を開きます（**AI providers** ページの **Configure routing** ボタンから開けます）。**Models** カードで、Novita のモデルを **Default model** に、OpenAI や Anthropic など接続済みの他のプロバイダーのモデルを **Fallback model** に設定します。これにより、Novita が利用できない場合でもレビューを継続できます。**Save settings** をクリックします。

### オプション2 — セルフホスト（環境変数）

セルフホスト環境で `.env` から 1 つのモデルを指定するには、OpenAI 互換プロバイダーを使用します。

```env
API_LLM_PROVIDER=openai_compatible
API_LLM_PROVIDER_MODEL="deepseek/deepseek-v4-pro"
API_LLM_BASE_URL="https://api.novita.ai/openai"
API_LLM_API_KEY="your-novita-api-key"
```

インストールガイドに従って[モデルの変更を反映してください](/ja/how_to_deploy/deploy_kodus/generic_vm#モデルの変更を反映する)。

## トラブルシューティング

<AccordionGroup>
  <Accordion title="APIキーの問題">
    - [Novita のコンソール](https://novita.ai/settings/key-management)で、APIキーが正しく有効であることを確認します
    - Novita アカウントに十分なクレジットがあることを確認します
    - `.env` の値に末尾のスペースや引用符が含まれていないことを確認します
  </Accordion>

  <Accordion title="モデルが見つからない">
    - モデル ID は `org/model` 形式の文字列で、一部に大文字が含まれます。Novita のモデル一覧から ID を正確にコピーしてください
    - `https://api.novita.ai/openai/v1/models` の一覧にモデルが引き続き含まれていることを確認します
  </Accordion>

  <Accordion title="接続エラー">
    - サーバーがインターネット経由で `api.novita.ai` に到達できることを確認します
    - ファイアウォールの制限がないか確認します
    - API とワーカーのログで、上流の正確なエラーを確認します
  </Accordion>
</AccordionGroup>
