# libs/runtime/run/testing

Test doubles of the Run's stores, imported as `@libs/runtime/run/testing` by specs and test fixtures only.

## Owns
- `in-memory-run-projection.store.ts` `InMemoryRunProjectionStore`: the projection with the same filters as `PgRunProjectionStore`.
- `in-memory-run-stream.store.ts` `InMemoryRunStreamStore`: the stream with opaque offsets.

## Rules and limits
- No production file imports this path, and no barrel re-exports it (`apps/runtime/src/shared/testing-boundary.spec.ts`).
- A filter or rule added to the Postgres store is added here too, so specs see the same answers.
