# libs/runtime/redaction

The token-pattern pass of redaction (S-51), shared with the cell: a curated subset of gitleaks' rules, run over text after the exact known values were already replaced. A pure domain library used wherever text leaves for a model, a log, a span or the PR: the LLM gateways, the planner and recipe author, probe labels, telemetry, the hub and the worker's evidence.

## Owns
- The rule data: `gitleaks-rules.json` (rules, keywords, examples, source commit and license), loaded as `redaction.ts` `REDACTION_RULES` and `REDACTION_RULES_SOURCE`.
- The pass: `redaction.ts` `redactPatterns` (file order, keyword prefilter, secret group only), returning the text, the count and counts by rule. The marker is `redactionMarker` (`[redacted:<rule>]`).

## Does not own
- Replacing known values (a token the caller holds) and their encoded variants: the caller, and the cell's `internal/redact`.
- Telemetry scrubbing: `libs/runtime/telemetry/telemetry-guard.ts` `scrubText`, which calls this pass.

## Rules and limits
- `gitleaks-rules.json` is byte-identical to `apps/runtime-cell/internal/redact/rules/gitleaks-rules.json`; change both in one PR ([`AGENTS.md`](../AGENTS.md) "Protocol changes").
- Every pattern must mean the same in RE2 and ECMAScript: the cell compiles the same file.
- Replacement is one way; nothing restores a redacted value.

## Where new code goes
- A new rule: an entry in both JSON copies, with `examples` that the spec runs.
- The Go golden of secret variants: `scripts/` ([its own AGENTS.md](scripts/AGENTS.md)).

## Tests
- `node node_modules/jest/bin/jest.js --runInBand libs/runtime/redaction` (pure; checks the Go copy is identical), and `go test ./internal/redact/` in `apps/runtime-cell`.
