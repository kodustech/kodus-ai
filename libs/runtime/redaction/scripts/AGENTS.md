# libs/runtime/redaction/scripts

A developer script, never imported: it writes the Go cell's golden file for `redact.Variants` from the TypeScript original, so the cell's port of secret variants stays faithful.

## Owns
- `dump-variants-golden.ts`: runs `secretVariants` and `maskSecrets` (`libs/code-review/infrastructure/agents/custom-agent-cli/cli-output-mask.ts`) over fixed sample secrets and writes `apps/runtime-cell/internal/redact/testdata/ts-variants.json` (or the path given as its argument).

## Does not own
- The variant rules: `cli-output-mask.ts` in `libs/code-review`, and its Go port in `apps/runtime-cell/internal/redact`.

## Rules and limits
- The samples are synthetic; never add a real credential.
- Rerun it and commit the golden whenever `cli-output-mask.ts` changes; the Go test reads the checked-in file.

## Tests
- Run: `node -r ts-node/register/transpile-only -r tsconfig-paths/register libs/runtime/redaction/scripts/dump-variants-golden.ts`, then `go test ./internal/redact/` in `apps/runtime-cell`.
