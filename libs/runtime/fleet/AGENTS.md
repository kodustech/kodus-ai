# libs/runtime/fleet

The host provider port and host pools (docs/runtime/host-providers.md §4.2, §5.1). A pure domain library: the contract an adapter implements, the error it throws, the pool and class schemas, and the test doubles every adapter is checked against. `runtime-fleet` (`apps/runtime/src/fleet/`) is the only process that holds a provider.

## Owns
- The port: `host-provider.ts` `HostProvider`, `CreateHostRequest`, `ProviderHost`, `BootstrapPayload`, `HostImagePort` (named images, the environment template), `BOOTSTRAP_PATH`.
- The error: `provider-error.ts` `ProviderError` with a closed `kind` (`throttled`, `quota_exceeded`, `capacity_unavailable`, `invalid_class`, `unauthorized`, `transient`) and `retryable`.
- The schemas: `pool.ts` `HostPoolSchema`, `HostClassSchema`, `PoolLifecycleSchema` (`perRun` | `pooled`), `poolIdOf`, `orgDefaultPoolId`, `KODUS_STATIC_POOL_ID`, `isControlled`, `poolSpecHash`.
- The doubles: `testing.ts` `FakeHostProvider` and `describeHostProviderConformance`.

## Does not own
- Adapters (`apps/runtime/src/fleet/providers/<kind>/`), the reconcile loop and host workflows (`apps/runtime/src/fleet/`).
- Which pool takes a claim: `libs/runtime/placement`.
- The Runtime tables that store pools and hosts: `apps/runtime/src/shared/persistence/runtime-schema.ts`.

## Rules and limits
- Pure: zod and `crypto` only. No I/O, no Nest.
- A stored pool carries its class resolved; `provider` of the pool and its class must agree.
- An optional provider part (`extend`, `images`) is declared by being present, never stubbed (the cell's driver rule).
- A provider error never carries a provider message or body: only its code, the HTTP status and the wait.

## Where new code goes
- A new provider kind: its class in `HostClassSchema`, its adapter under `apps/runtime/src/fleet/providers/<kind>/`, and a spec that runs `describeHostProviderConformance` on it.
- A new rule every adapter keeps: a case in `describeHostProviderConformance`.

## Tests
- `node node_modules/jest/bin/jest.js libs/runtime/fleet`, and each adapter's conformance spec.
