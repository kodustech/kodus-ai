# libs/runtime/api/infrastructure/a2a

The A2A (agent-to-agent, protocol 1.0) transport of external findings: another agent submits findings it observed and asks the Runtime to verify them, and reads the result as a task. An inbound adapter in the product API, served by `apps/api/src/controllers/runtime/runtime-a2a.controller.ts` (`GET .well-known/agent-card.json`, `POST runtime/a2a`) over `../../application/external-findings.service.ts`.

## Owns
- The JSON-RPC handler and the agent card: `runtime-a2a.adapter.ts` `RuntimeA2AAdapter` (`SendMessage`, `GetTask`, `CancelTask`), `a2aTask` (a view as an SDK `Task`), the fixed error mapping, and the endpoint from `RUNTIME_A2A_BASE_URL` only.
- Authentication: `runtime-a2a.guard.ts` `RuntimeA2ABearerGuard` (a team key on every call; a user JWT or the MCP service JWT is refused).
- Bounds before any codec: `runtime-a2a.validation.ts` `A2A_MAX_BODY_BYTES`, `isBoundedA2ABody`, `checkedA2AWire`; `a2a-body-parser.ts` `runtimeA2AJsonParser`, installed in `apps/api/src/main.ts` before the product parser.

## Does not own
- What a finding is and its limits: `libs/runtime/contracts/external-findings.ts`. Quotas, storage and verification: `ExternalFindingsService`, `../typeorm-external-findings.store.ts`, `../../application/external-verification-reconciler.ts`.

## Rules and limits
- An external observation is bounded input data, never replay proof (ADR-023/049).
- The advertised interface comes from configuration; a request's Host header is never authority. Only `https`, or `http` on loopback.
- Push notifications, streaming and subscriptions are refused. Errors carry fixed text; the only detail returned is the environment ids the key already reaches.
- `runtime-a2a.adapter.ts` imports `EnvironmentRequiredException` from `application/`, which [`AGENTS.md`](../../../AGENTS.md) says an adapter never does.

## Tests
- `API_NODE_ENV=test npx jest libs/runtime/api/infrastructure/a2a libs/runtime/api/__tests__/a2a-config.spec.ts`; the round trips (`__tests__/transport.integration.spec.ts`, `../../__tests__/a2a-roundtrip.integration.spec.ts`) run in process with real HTTP and the official SDK client, no database.
