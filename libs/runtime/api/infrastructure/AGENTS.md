# libs/runtime/api/infrastructure

The adapters of the product's Runtime API: readers of the Runtime Postgres, TypeORM stores of the product's own Runtime tables, the Git, BYOK, OpenBao and worker clients, the config loaders, and the inbound drivers (queue consumer, crons, guard, body parsers). Infrastructure layer, bound to the ports of `../domain/` in `../runtime-api.module.ts`; it runs in the product API and the product worker. The A2A transport is in `a2a/` ([its AGENTS.md](a2a/AGENTS.md)).

## Owns
- Runtime Postgres reads: `runtime-read-db.ts` `RuntimeReadDb` (one pool, `RUNTIME_DATABASE_READ_URL` only, every query in `BEGIN READ ONLY`, 503 without the URL) and the readers that take it as `SqlQuery`: `pg-runtime-readers.ts` (`ReadOnlyRunProjectionStore`, setups, lessons, build-state evictions, environments), `pg-runtime-*.reader.ts` (cells and cell tokens, claim and machine usage, egress, health, preview audit, run stream, usage report), `pg-pull-request-runs.reader.ts`, `pg-pull-request-sessions.reader.ts`, `pg-external-stop.reader.ts`.
- Product tables (TypeORM): entities in `runtime-product.models.ts`, `runtime-product-state.models.ts`, `runtime-external-finding.models.ts`; stores in `typeorm-runtime-product.stores.ts` (environments, repositories, settings, finding feedback and intent), `typeorm-llm-budget.store.ts` (counters and reservations under a per-org lock), `typeorm-setup-calls.store.ts`, `typeorm-model-turn-receipts.store.ts`, `typeorm-env-audit.store.ts`, `typeorm-runtime-secrets.store.ts`, `typeorm-reconciled-heads.store.ts`, `typeorm-external-findings.store.ts`, over `typeorm-sql.ts` `TypeOrmSql`.
- External systems: `code-management-git.adapter.ts` `CodeManagementRuntimeGitAdapter` (facts, a diff bounded with `truncated`, membership), `repo-token-issuer.adapter.ts`, `membership-pull-request.gate.ts`, `dev-stub-git.adapter.ts` (dev only); `byok-runtime-llm.provider.ts`, `byok-model-turn.provider.ts`; `openbao-secret-vault.adapter.ts` (write-only role); `http-env-session.client.ts` (the worker's signed listener); `telemetry-llm-spend.reader.ts` (usage spans); `local-git-repo.reader.ts`.
- Config: `runtime-api.config.ts` `loadRuntimeApiConfig`, `runtime-cron-schedules.ts`.
- Inbound: `runtime-trigger.consumer.ts`, the crons (`runtime-pool-scheduler`, `runtime-pr-session-sweep`, `runtime-product-retention`, `runtime-webhook-reconciler`), `runtime-reader.guard.ts` `RuntimeReaderAuthGuard` (JWT or team key), `worker-rpc-body-parser.ts`.

## Does not own
- Runtime-owned stores and the shared Postgres helpers: `libs/runtime/run/adapters` (`PgSql`, `DocumentTable`, `PgRunStreamStore`). The product tables' schema: the migrations in `apps/api`.

## Rules and limits
- Never a write to the Runtime database; product tables are the only ones written here.
- The process environment is read only by `runtime-api.config.ts`, `runtime-cron-schedules.ts` and the module-build loaders of `openbao-secret-vault.adapter.ts`, `http-env-session.client.ts` and `dev-stub-git.adapter.ts` (`apps/runtime/src/shared/config-boundary.spec.ts`); [`AGENTS.md`](../../AGENTS.md) names only the first two.
- A platform error message is never logged or returned; an unknown answer from the platform denies.
- [`AGENTS.md`](../../AGENTS.md) says an adapter never imports `application/`. Here the crons and the consumer drive use cases (expected for inbound adapters), but `pg-pull-request-sessions.reader.ts` implements a port declared in a use case, `local-git-repo.reader.ts` imports `RepoReader` from `application/recipe-author`, `runtime-reader.guard.ts` imports `RuntimePrincipal` from `application/`, and `pg-runtime-health.reader.ts` declares its own port and token.

## Where new code goes
- A Runtime read: a `pg-runtime-*.reader.ts` taking `RuntimeReadDb`, org-filtered in SQL, with an index and a limit, and its grant in `scripts/runtime/runtime-reader-grants.sql`.
- A product table: its entity, a migration, a store over `TypeOrmSql`, and retention in `runtime-product-retention.cron.ts` if rows expire.

## Tests
- `API_NODE_ENV=test npx jest libs/runtime/api` (unit). Readers and stores: `*.integration.spec.ts` in `../__tests__/` with `RUNTIME_IT_DATABASE_URL`.
