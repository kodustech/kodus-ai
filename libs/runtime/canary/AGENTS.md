# libs/runtime/canary

Per-Run canaries (ADR-043): decoy credentials planted in a Run's machine (an `.npmrc` token, a config key, a seed row) that nothing legitimate reads back out. A pure domain library: it derives the canaries of a Run and says whether a text carries one. The runtime-worker plants them and guards its boundaries with them (`apps/runtime/src/worker/canary/canary.ts`); the API's model-turn gateway checks every prompt for them.

## Owns
- The derivation: `index.ts` `HmacCanaryVault.forRun`, HMAC of `runId`, `runToken` and the slot, so a resumed workflow sees the same canaries and nothing is stored.
- The detector: `index.ts` `containsCanary` (verbatim, base64, base64url, or the random core in any case).
- The key: `index.ts` `canaryKeyFrom`, derived from the seal key (one secret, separate purposes).

## Does not own
- Planting them in the machine, the leak error and its site, redacting a canary out of a value: `apps/runtime/src/worker/canary/canary.ts` (`CanaryLeakError`, `redactCanaries`).
- The prompt check of the product gateway: `libs/runtime/api/application/use-cases/model-turn-gateway.use-case.ts`.
- The telemetry pattern that scrubs canary-shaped values: `libs/runtime/telemetry/telemetry-guard.ts` `TELEMETRY_SECRET_SHAPES`.

## Rules and limits
- Pure: `crypto` only.
- Both sides must derive from the same inputs: the sealed `runToken` the Run request carries and `canaryKeyFrom(seal key)`. A vault built with the default key (the public domain string) yields canaries anyone with the Run's id and token can compute; production callers always pass the derived key.
- A canary value is never logged, checkpointed, projected or published; a leak names its site, never the value.

## Where new code goes
- A new slot: `CanarySlot` and `SLOTS` here, its planting in the worker's acquire, and the telemetry shape if its prefix changes.
- A new place to check: the caller, with `containsCanary`; the site goes in `LeakSite`.

## Tests
- No spec here; the behavior is covered by `apps/runtime/src/worker/canary/canary.spec.ts` and `libs/runtime/api/__tests__/model-turn-gateway.spec.ts`.
