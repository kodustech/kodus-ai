# libs/runtime/telemetry

The one telemetry vocabulary of the Kody Runtime (docs/runtime/observability.md) and the gates every signal passes before it leaves a process. Used by the runtime-worker, the hub, the preview edge, the product side (the Run request builder and setup requester, the GitHub webhook handler) and the protocol's Go constants script. See [`libs/runtime/README.md`](../README.md) "telemetry".

## Owns
- The taxonomy: `taxonomy.json` (attributes, closed values, the metric catalog), typed as `catalog.ts` `TAXONOMY`, `ATTR`, `DIMENSION_VALUES` and the value lists (`STUCK_STATES`, `STEP_OUTCOMES`, …), and `blockerSignatureClass`.
- Instruments made only from the catalog: `instruments.ts` `CatalogMeter`; the control plane's metrics: `runtime-telemetry.ts` `RuntimeMetrics`, `METRIC`.
- The Run's trace: `runtime-telemetry.ts` `traceIdFromCorrelationId`, `runContext`, `withRunSpan`, `traceHeaders`, `contextFromTraceparent`.
- The redaction gates: `telemetry-guard.ts` `metricAttributes`, `spanAttributes`, `scrubText`, `TELEMETRY_SECRET_SHAPES`; `redacting-span-exporter.ts` `RedactingSpanExporter`.
- Failure classification: `failure.ts` `safeFailure`, `recordSafeFailure` (imported by path; not in the barrel).

## Does not own
- SDK setup and exporters: `apps/runtime/src/shared/observability/otel.ts`, which wraps every exporter in `RedactingSpanExporter`. Log field filtering: `apps/runtime/src/shared/observability/diagnostic-fields.ts`.
- The cell's metrics: `apps/runtime-cell/internal/telemetry`, from the same taxonomy.

## Rules and limits
- `taxonomy.json` is byte-identical to `apps/runtime-cell/internal/telemetry/taxonomy.json`; the Go test reads this file and fails on a difference. Change both in one PR.
- A metric not in the catalog cannot be created; a label the catalog does not list, an id, or a dimension value outside its list is dropped or becomes `other`.
- A value the app under test chooses (a host, a path) never becomes a metric attribute ([`AGENTS.md`](../AGENTS.md) "Tokens and secrets").
- Span status messages are dropped on export; failures record a kind chosen from code, never exception text.
- `catalog.ts` `RUN_VERDICTS` is a hand copy of `run/run-state.ts` `VerdictState`, not derived from it.

## Where new code goes
- A new metric or attribute: `taxonomy.json` (both copies) first, then `METRIC` and a `RuntimeMetrics` method, with its buckets for a histogram.
- A new secret shape: `TELEMETRY_SECRET_SHAPES`; the cell gets it through `protocol/scripts/go-constants.ts`.

## Tests
- `node node_modules/jest/bin/jest.js --runInBand libs/runtime/telemetry` (pure), and `go test ./internal/telemetry/` in `apps/runtime-cell`.
